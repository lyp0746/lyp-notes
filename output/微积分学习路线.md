# 微积分学习路线

> 基于 [[托马斯微积分-伴读]] 与 [[托马斯微积分-导读]] 整理。适合系统自学或复习。

## 阶段一：地基（第 1–2 章）

**目标**：熟悉函数语言，建立极限与连续性的严格观念。

- [[函数]] → [[极限]] → [[连续性]]
- 关键练习：$\varepsilon$-$\delta$ 证明、夹逼定理、单侧极限、间断点分类。
- 检验点：能用极限定义解释连续性，能求典型极限。

## 阶段二：一元微分（第 3–4 章）

**目标**：掌握求导技术并用于分析函数、求解最优化。

- [[导数]] → [[求导法则]] → [[隐式微分与相关变化率]] → [[线性化与微分]]
- [[中值定理]] → [[极值与最优化]] → [[洛必达法则]] → [[牛顿法]]
- 关键练习：链式法则、相关变化率建模、曲线作图、最优化应用。

## 阶段三：一元积分与级数（第 5–9 章）

**目标**：理解“累积”与“变化率”的互逆，掌握积分技巧与级数展开。

- [[反导数与不定积分]] → [[定积分]] → [[微积分基本定理]]
- [[代换法则]] · [[分部积分与三角代换]] · [[部分分式与积分表]] · [[数值积分]] · [[反常积分]]
- 定积分的应用：[[旋转体体积]] · [[弧长与旋转曲面面积]] · [[功与流体压力]] · [[矩与质心]] · [[指数变化与可分离方程]]
- [[数列与无穷级数]] → [[级数审敛法]] → [[幂级数]] → [[泰勒级数与麦克劳林级数]]
- [[极坐标与圆锥曲线]]

## 阶段四：多元与向量分析（第 10–14 章）

**目标**：把微积分推广到空间，掌握三大积分定理。

- [[向量与空间几何]] → [[向量值函数与曲率]]
- [[偏导数]] → [[方向导数与梯度]] → [[多元极值与拉格朗日乘数]]
- [[二重积分]] → [[三重积分]]
- [[线积分]] → [[路径独立与势函数]] → [[格林定理]] → [[曲面积分与通量]] → [[斯托克斯定理与散度定理]]

## 学习建议

1. **概念优先于计算**：先把[[微积分基本定理]]与[[方向导数与梯度|梯度]]的直观想清楚。
2. **一题多解**：积分题同时尝试理论与数值（[[数值积分]]）。
3. **物理/几何锚点**：用速度–加速度、体积、通量等具体量检验理解。
4. **回看主线**：每学完一章，回到 [[托马斯微积分-导读]] 更新自己的心智地图。
