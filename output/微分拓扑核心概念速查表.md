# 微分拓扑核心概念速查表

> 基于 [[知识索引|wiki]] 压缩。

| 概念 | 一句话 |
| --- | --- |
| [[光滑流形与光滑映射]] | 局部像 $\mathbf{R}^m$ 开集；$C^\infty$ 映射 |
| [[切空间与导射]] | 速度向量空间；$df_x$ 为最佳线性逼近 |
| [[正则值与正则点]] | $df_x$ 满秩；正则值原像是流形，维数 $m-n$ |
| [[Sard定理]] | 临界值测度为零；几乎所有值是正则值 |
| [[模2度]] | $\#f^{-1}(y)\bmod2$，与正则值无关，无需定向 |
| [[定向流形与度]] | $\deg f=\sum\operatorname{sign}\det df_x$，同伦不变 |
| [[向量场与欧拉数]] | Poincaré–Hopf：$\sum\operatorname{index}=\chi(M)$ |
| [[标架式协边]] | 法丛平凡化；相差一个带边标架流形 |
| [[Pontryagin构造]] | $[S^n,S^m]\cong\Omega^{\mathrm{fr}}_{n-m}$ |
| [[一维流形分类]] | 紧致一维流形 ≅ $S^1$ 或 $[0,1]$ |
| [[代数基本定理-拓扑证明]] | 用绕数/度证明非常数复多项式有根 |
