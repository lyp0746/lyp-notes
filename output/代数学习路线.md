# 代数学习路线

> 基于 [[代数Artin-伴读]] 与 [[代数Artin-导读]] 整理。

## 阶段一：群（第 2、6、7 章）

**目标**：把“对称”抽象成运算，掌握群的基本工具。

- [[群]] → [[群同态与同构]] → [[陪集与拉格朗日定理]] → [[正规子群与商群]]
- [[群作用]] · [[置换群]] · [[凯莱定理]] · [[类方程与共轭类]] · [[西罗定理]] · [[自由群与生成元关系]]
- 几何入口：[[平面等距与晶体群]]、[[正交群与旋转]]
- 检验点：能用西罗定理证明某阶群非单；能数共轭类。

## 阶段二：环与模（第 1、8、11、12、14 章）

**目标**：把“数”推广到环，理解唯一分解的成败。

- [[环与理想]] → [[商环与环同态]] → [[多项式环]]
- [[欧几里得整环与主理想整环]] → [[唯一分解整环]]（ED ⊂ PID ⊂ UFD）
- [[双线性型]] · [[模]]
- 检验点：会算 $\mathbb{Z}[\sqrt{-5}]$ 中的非唯一分解；会用模的结构定理。

## 阶段三：线性群与表示（第 5、9、10 章）

**目标**：让群作用在向量空间上，读出群的“频谱”。

- [[线性群]] → [[李代数]]
- [[群表示与特征标]]（舒尔引理、正交关系）
- 检验点：写出 $S_3$ 的特征标表。

## 阶段四：域与伽罗瓦（第 13、15、16 章）

**目标**：用群分类域扩张，回答“方程能否根式解”。

- [[域与域扩张]] → [[有限域]]
- [[对称函数]] → [[伽罗瓦理论]]
- 数论出口：[[代数整数与理想类群]]
- 工具：[[佐恩引理]]
- 检验点：用伽罗瓦群判断三次/五次方程可解性。

## 学习建议

1. **抓住类比**：理想 ↔ 正规子群；商环 ↔ 商群；模 ↔ 向量空间。三处是同一套模式。
2. **对抗式训练**：用非 UFD（$\mathbb{Z}[\sqrt{-5}]$）制造反例，用西罗定理“逼”出正规子群。
3. **几何锚点**：遇到抽象定义，回到对称/旋转/晶体群的例子。
