# 微积分核心概念速查表

> 基于 [[托马斯微积分-伴读]] 与 [[知识索引|wiki 概念页]] 汇总。

## 1. 极限与连续

| 名称 | 公式 / 结论 | 概念 |
| --- | --- | --- |
| 极限定义 | $\lim_{x\to c}f(x)=L$（$\varepsilon$-$\delta$） | [[极限]] |
| 两个重要极限 | $\lim_{x\to0}\frac{\sin x}{x}=1,\ \lim_{x\to\infty}(1+\frac1x)^x=e$ | [[极限]] |
| 连续 | $\lim_{x\to c}f(x)=f(c)$ | [[连续性]] |
| 介值定理 | 连续函数取遍中间值 | [[连续性]] |

## 2. 导数与微分

| 名称 | 公式 | 概念 |
| --- | --- | --- |
| 导数 | $f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}h$ | [[导数]] |
| 链式法则 | $(f\circ g)'=f'(g)g'$ | [[求导法则]] |
| 线性化 | $f(x)\approx f(a)+f'(a)(x-a)$ | [[线性化与微分]] |
| 中值定理 | $f'(c)=\frac{f(b)-f(a)}{b-a}$ | [[中值定理]] |
| 洛必达 | $\lim\frac fg=\lim\frac{f'}{g'}$（$\frac00,\frac\infty\infty$） | [[洛必达法则]] |
| 牛顿法 | $x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}$ | [[牛顿法]] |

## 3. 积分

| 名称 | 公式 | 概念 |
| --- | --- | --- |
| 定积分 | $\int_a^b f=\lim\sum f(c_k)\Delta x_k$ | [[定积分]] |
| 基本定理 | $\int_a^b f=F(b)-F(a)$ | [[微积分基本定理]] |
| 代换 | $\int f(g)g'\,dx=\int f(u)\,du$ | [[代换法则]] |
| 分部积分 | $\int u\,dv=uv-\int v\,du$ | [[分部积分与三角代换]] |
| 反常积分 | $\int_a^\infty f=\lim_{b\to\infty}\int_a^b f$ | [[反常积分]] |
| 数值积分 | 梯形法 / 辛普森法 | [[数值积分]] |
