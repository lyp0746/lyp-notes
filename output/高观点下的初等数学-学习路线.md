# 《高观点下的初等数学》学习路线

> 面向已学过初等微积分与基础线性代数的读者。概念入口见 [[高观点下的初等数学-导读]] 与 [[初等数学核心概念速查表]]。

## 阶段 0 · 先建立三条主线（1–2 天）

在做逐章精读之前，先读这四篇主题页，抓住全书的「神经」：

- [[数系扩张与承袭性：从算术到四元数]]——为什么数要一级级扩张。
- [[不变量与对偶：从格拉斯曼到线性代数]]——为什么几何量是行列式。
- [[几何的变换群视角：从欧几里得到爱尔朗根]]——为什么「几何 = 群的不变量」。
- [[精确与近似：数学的两副面孔]]——为什么经验曲线需要带宽。

## 对抗式训练建议

1. **牺牲律清单**：每扩张一步，写一张「保住了什么 / 牺牲了什么」的表。
2. **子行列式对刀**：同一道面积/力矩题，用初等公式与格拉斯曼子式各做一遍。
3. **变换群层级**：给一个几何命题，问它在哪些群下成立。
4. **带宽实验**：取一组带噪数据，分别用插值、最小二乘、切比雪夫节点拟合，比较外推行为。
