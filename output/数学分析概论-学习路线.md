# 《数学分析概论》学习路线

> 基于 [[数学分析概论-导读]] 与 [[数学分析概论-章节地图]]；概念见 [[知识索引|wiki]]。

## 定位

高木《解析概论》是一部**第二遍**的分析教材：它假设读者已会算，专注讲「为什么」与「如何严格」。因此它适合作为从计算型微积分（[[托马斯微积分]]）迈向现代实分析（[[勒贝格测度]]/[[勒贝格积分]]）的**严格化台阶**。

## 四阶段路线

### 阶段一 · 地基（第 1 章 + 附录 I）

- 打通 [[实数完备性]] 的各等价形式（Dedekind 分割、上确界、区间套、Cauchy 准则、聚点）。
- 掌握 $\varepsilon$-$N$、$\varepsilon$-$\delta$ 与 [[连续性]]、[[一致连续性与可积性|一致连续]]。
- **自测**：[[数学分析概论复习卡]] 第 1 章、附录 I 部分。

### 阶段二 · 一元分析主干（第 2–4 章）

- 微分：[[导数]]、[[中值定理]]、[[凸函数]]、[[泰勒级数与麦克劳林级数]]。
- 积分：[[定积分]]、[[微积分基本定理]]、[[反常积分]]、[[有界变差函数]]。
- 级数：[[级数审敛法]]、[[一致收敛]] 是**全书技术核心**，并读 [[无穷乘积]]、[[二重级数与累次求和]]。
- **重点**：一致收敛与「极限交换」的关系。

### 阶段三 · 复与调和（第 5–6 章）

- 复分析：[[解析函数与柯西积分定理]] → [[留数与孤立奇点]] → [[解析延拓与整函数]] → [[Γ函数与斯特林公式]]。
- 调和分析：[[傅里叶级数与三角展开]] → [[傅里叶积分与傅里叶变换]]。
- **重点**：留数计算实积分、Fourier 展开的收敛性。

### 阶段四 · 多元与测度（第 7–9 章）

- 多元微分：[[隐函数定理与逆映射定理]]、[[包络线]]、[[多元极值与拉格朗日乘数]]。
- 多元积分：[[重积分的变量代换与雅可比]]、[[曲线坐标与正交坐标]]、[[斯托克斯定理与散度定理]]。
- 测度与积分：[[勒贝格测度]] → [[勒贝格积分]] → [[绝对连续与奇异函数]] → [[斯蒂尔切斯积分]]。
- **收束**：[[经典分析与现代测度：从黎曼到勒贝格]]。

## 配合读法

- 与 [[微积分入门]] 对照：小平偏形式与微分形式，高木偏经典严格。
- 与 [[微积分的三种讲法：从 Thomas 到小平与高木]] 一起读，建立「计算 / 严格 / 形式」三层。
- 阶段四配合 [[从微分观点看拓扑]]，把多元分析升级为流形上的分析。
