# 《统计至简》导读

## 概述

整理自 [[统计至简-伴读]]。它把概率统计讲成一条从「度量不确定性」到「从数据推断」的连续线。

## 主线

[[概率空间]] → 随机变量 → 期望/方差 → 分布 → [[大数定律与中心极限定理]] → 参数估计 → [[假设检验]] → 置信区间 → [[充分统计量]] → [[贝叶斯推断]] → [[蒙特卡洛方法]]/MCMC → [[随机过程]]/[[鞅]] → [[信息熵与KL散度|信息论]]。

## 三个转折点

1. **频率 vs 贝叶斯**：同一数据，两种世界观。
2. **充分统计量**：数据压缩的最优性（与 [[统计学七支柱|信息]] 呼应）。
3. **MCMC → 信息论**：从采样到「不确定性本身的度量」。
