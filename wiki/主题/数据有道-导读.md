# 《数据有道》导读

## 概述

整理自 [[数据有道-伴读]]。核心：把数据放在**几何 + 图**里看——距离、内积、投影、图的谱。

## 主线

[[距离与度量|距离]] → [[内积与范数|范数/内积]] → 投影 → [[图与拉普拉斯矩阵|图与谱]] → 随机游走 → [[谱聚类]] → [[降维与主成分分析|降维]] → [[核方法]] → PageRank → 推荐 → [[机器学习|图神经网络]]。

## 三个转折点

1. **距离即建模**：选择距离就是选择「什么算相似」。
2. **图的谱**：Laplacian 的特征值把「割」变成代数问题（[[图与拉普拉斯矩阵]]）。
3. **核技巧**：隐式升维，把非线性变线性（[[核方法]]）。
