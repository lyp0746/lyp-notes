# 《机器学习》导读

## 概述

整理自 [[机器学习-伴读]]。它把 ML 的每个模型都还原成数学：优化、概率、线性代数。

## 主线

线性回归 → [[逻辑回归与交叉熵|逻辑回归]]（MLE）→ [[支持向量机]]（对偶）→ 树/森林/Boosting → [[降维与主成分分析|PCA]]/聚类 → 神经网络 → [[反向传播与自动微分|反向传播]] → CNN/RNN → [[注意力机制|Attention]]/Transformer → VAE/GAN/扩散 → 强化学习。

## 三个转折点

1. **损失函数 = 似然**：逻辑回归的交叉熵来自[[似然|最大似然]]。
2. **SVM 对偶**：把间隔最大化变成二次规划的[[对偶空间|对偶]]（与 [[拉格朗日插值与切比雪夫逼近|Lagrange]] 相关）。
3. **反向传播 = 链式法则**：[[反向传播与自动微分|自动微分]]是深度学习的引擎。
