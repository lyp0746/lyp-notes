# 鸢尾花书 · 系列导读

## 概述

[[姜伟生]] 的《鸢尾花书》是一套「从加减乘除到机器学习」的自学系列，风格是**图解 + 代码 + 贯通**。六卷彼此咬合：

| 卷 | 主题 | 本库概念 |
| --- | --- | --- |
| [[数学要素]] | 数、函数、微积分、向量分析 | 基础分析概念 |
| [[矩阵力量]] | 向量、矩阵、四大分解、矩阵微积分 | [[矩阵分解]] · [[二次型与正定性]] · [[矩阵微积分]] |
| [[线性代数不难]] | 向量空间的公理化深入 | [[向量空间]] · [[基与维数]] |
| [[统计至简]] | 概率、推断、贝叶斯、信息论 | [[假设检验]] · [[充分统计量]] · [[信息熵与KL散度]] |
| [[数据有道]] | 距离、图与谱、降维、核方法 | [[距离与度量]] · [[图与拉普拉斯矩阵]] · [[谱聚类]] · [[核方法]] · [[降维与主成分分析]] |
| [[机器学习]] | 从回归到 Transformer、扩散模型 | [[逻辑回归与交叉熵]] · [[支持向量机]] · [[反向传播与自动微分]] · [[注意力机制]] |

## 阅读路线

1. 先 [[数学要素]] 补齐微积分与向量分析；
2. 再 [[矩阵力量]]（工具） + [[线性代数不难]]（结构）；
3. 然后 [[统计至简]]（不确定性）；
4. 最后 [[数据有道]]（数据几何） → [[机器学习]]（模型）。
