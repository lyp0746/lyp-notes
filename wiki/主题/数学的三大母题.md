# 数学的三大母题

> 本页是 [[数学大地图]] 的**联系轴**。分支分类告诉你「有哪些领域」，母题告诉你「什么东西处处复用」。用法：遇到一个陌生概念，先看它落在哪条母题，再横向对照其他书。

## 概述

现代数学的统摄力，来自**同一个母题在 23 本书中反复出现**。追踪母题的演进（出现地 → 范畴论统摄 → 无穷范畴深化 → 凝聚／朗兰兹大一统 → 生成新问题），就是追踪框架升级的轨迹（见 [[数学统一的地平线]]）。

## 母题一 · 对偶性

**出现地**（本库可指认的实例）：

| 出处 | 形态 | 链接 |
| --- | --- | --- |
| Axler 线性代数 | $V^* = \operatorname{Hom}(V,k)$ | [[对偶空间]] |
| 微积分 / 分析 | Fourier 变换与反演、$L^p$–$L^q$ | [[傅里叶积分与傅里叶变换]] |
| Artin 代数 | 伽罗瓦理论基本定理（子群 ↔ 中间域） | [[伽罗瓦理论]] |
| Klein 初等数学 | 极点—极线对偶、二次互反律 | [[对偶变换与对偶原理]] · [[格拉斯曼行列式原理]] |
| Milnor 微分拓扑 | 同调 ↔ 上同调、Poincaré 对偶 | [[模2度]] |
| 概率 / 优化 | 特征函数、拉格朗日对偶、伴随 | [[伴随与自伴算子]] |

**统摄原理（范畴论）**：所有对偶 = $\operatorname{Hom}(\_,k)$ 这类函子的**伴随**。「转置 = 伴随」把线性代数、泛函分析、表示论的对偶收成同一件事。

**深化（无穷范畴）**：导出对偶 = 外函子（derived functor）的伴随；Poincaré 对偶在导范畴中才显自然。

**大一统角色（朗兰兹）**：对偶群、对偶形式；局部—整体原则本身是一种对偶（见 [[数学统一的地平线]]）。

## 母题二 · 泛性质与自由对象

**出现地**：

- 自由群、自由模、自由代数 —— [[自由群与生成元关系]] · [[模]]
- 张量积、外积、对称积的定义（[[双线性型]] 中的泛构造）
- 同调群 / 商群的构造 —— [[正规子群与商群]] · [[商环与环同态]]
- 表示论中的诱导表示 —— [[群表示与特征标]]
- 乘积 / 余积、极限 / 余极限 —— [[积与商空间]]

**统摄原理**：所有自由对象 = **某个遗忘函子的左伴随**。「用泛性质定义，而不是用具体构造定义」，使同一构造在群、环、模、拓扑空间、层中自动通吃。

**深化**：为什么伴随函子对能生成几乎所有有用的构造？因为左伴随保余极限、右伴随保极限——「自由」与「遗忘」这一对张力，正是构造与结构的通用机器。

**生成新结果**：在 [[演化区分系统与分离曲率|演化区分系统]] 中，「从区分生成结构」可视为这一母题的元层版本；在熵螺旋框架中，它也是新数学对象的生成器。

## 母题三 · 不变量与导函子

**出现地**：

| 层次 | 形态 | 本库链接 |
| --- | --- | --- |
| 古典 | 基本群、同调、上同调、特征类 | [[向量场与欧拉数]] · [[模2度]] |
| 线性 | 秩、迹、行列式、谱 | [[迹与行列式]] · [[本征值与本征向量]] |
| 几何 | 曲率、Euler 数、变换群下的不变量 | [[变换群与爱尔朗根纲领]] · [[不变量与相对不变量]] |
| 统计 | 充分统计量 | [[充分统计量]] |
| 数值 / 数据 | 条件数、谱隙 | [[矩阵范数与条件数]] · [[奇异值分解]] |

**现代形态**：导范畴中的**导函子**——把「不变量」从静态数值升级为可计算的函子机器。

**新高度**：无穷范畴中的高阶不变量；分离曲率 $\kappa$（见 [[演化区分系统与分离曲率]]）是本库自己尝试的一个新不变量。

**应用与生成**：这些不变量族构成「探测空间结构的通用仪器」——给定对象，选一族不变量去「问」它；不变量之间的长正合列，就是结构之间的强制关系。这与 [[统一抽象统摄方法论]] 的「压缩」互为表里：不变量是压缩后仍留存的信息。
