# 词法与语法分析

## 定义

- **词法分析**（lexing）：把字符流切分为有意义的词法单元（token），如标识符、关键字、数值、运算符。用[[形式语言与自动机|正则表达式与有限自动机]]实现。
- **语法分析**（parsing）：按上下文无关文法把 token 流组织成**语法树**（或抽象语法树 AST）。分为自顶向下（LL）与自底向上（LR）。

## 直观

词法分析是「认字」，语法分析是「读句」。先分词，再按文法检查结构。这样分层的好处是：每层的规则都相对简单、可自动化；错误也能在对应层报告。

## 核心要点

- **词法 vs 语法**：正则无法处理嵌套（如括号匹配），故嵌套交给 CFG。
- **最长匹配**：`>=` 应识别为一个 token 而非 `>` + `=`。
- **LL(1)**：从左到右、最左推导、1 个前瞻；用 FIRST/FOLLOW 集构造预测分析表。
- **LR 家族**：SLR、LALR、规范 LR；移进-归约分析；比 LL 能处理的文法更多。
- **冲突消解**：优先级与结合性声明。
- **错误恢复**：恐慌模式、短语层恢复。

## 关键推导

- **Thompson 构造**：正则表达式 → NFA；**子集构造**：NFA → DFA。
- **LR 项集**：把文法产生式加点，构造 DFA 的项集族；`ACTION`/`GOTO` 表驱动分析。
- **LL(1) 条件**：同一非终结符的各产生式的 FIRST 集不相交，且若含 $\varepsilon$ 则与 FOLLOW 不相交。

## 典型例子

- 词法：`int x = 42;` → `int`、`x`、`=`、`42`、`;`。
- 语法：表达式 `a+b*c` 由优先级确定树形。
- 工具：`lex/flex` 做词法，`yacc/bison` 做语法。

## 易错点

- 用正则去匹配嵌套括号。
- 忽略运算符优先级与结合性导致的二义性。
- 认为 LL 与 LR 等价（LR 能力更强）。
- 把词法错误与语法错误混报。
