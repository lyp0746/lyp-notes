# 向量空间

## 定义（定义 1.19）

$V$ 配有**加法**与**标量乘法**，若满足八条公理，则为 $\mathbf{F}$ 上的**向量空间**：

| 加法 | 标量乘法 | 分配律 |
| --- | --- | --- |
| 交换 $u+v=v+u$ | 结合 $(ab)v=a(bv)$ | $a(u+v)=au+av$ |
| 结合 $(u+v)+w=u+(v+w)$ | 单位元 $1v=v$ | $(a+b)v=av+bv$ |
| 单位元 $\exists 0,\ v+0=v$ | | |
| 逆元 $\forall v\ \exists w,\ v+w=0$ | | |

## 直观

把“箭头”里那些与方向、长度无关的性质抽出来，只留下“能加、能缩放”的规则，就得到向量空间。函数、多项式、矩阵都满足这套规则，所以它们**都是向量**。这是线性代数“结构决定身份”的起点。

## 核心要点

- 公理中**没有坐标、没有数组**——满足八条即是向量。
- 推论：加法单位元与逆元唯一；$0v=0$、$a0=0$、$(-1)v=-v$。
- 例子：[[组与Fⁿ|$\mathbf{F}^n$]]、函数空间 $\mathbf{F}^X$、多项式空间、矩阵空间。

## 关键推导

- $0v=(0+0)v=0v+0v$，两边加 $0v$ 的逆元得 $0v=0$。
- $(-1)v+v=(-1+1)v=0v=0$，故 $(-1)v=-v$。

## 典型例子

- $V=\mathbf{R}^2$，配普通加法与数乘。
- $V=$ 所有实系数多项式，配多项式加法与数乘。
- $V=$ 所有 $f:\mathbf{R}\to\mathbf{R}$，配逐点加法与数乘。

## 易错点

- 把“有坐标”当成向量空间的必要条件（函数空间没有坐标数组）。
- 忘记验证八条（尤其加法交换与分配律在某些奇怪定义下会失败）。
- 混淆向量空间的 $0$ 与标量域的 $0$。
