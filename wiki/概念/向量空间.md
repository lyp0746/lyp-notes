# 向量空间

## 定义（定义 1.19）

$V$ 配有**加法**与**标量乘法**，若满足八条公理，则为 $\mathbf{F}$ 上的**向量空间**：

| 加法 | 标量乘法 | 分配律 |
| --- | --- | --- |
| 交换 $u+v=v+u$ | 结合 $(ab)v=a(bv)$ | $a(u+v)=au+av$ |
| 结合 $(u+v)+w=u+(v+w)$ | 单位元 $1v=v$ | $(a+b)v=av+bv$ |
| 单位元 $\exists 0,\ v+0=v$ | | |
| 逆元 $\forall v\ \exists w,\ v+w=0$ | | |

## 核心要点

- 公理中**没有坐标、没有数组**——满足八条即是向量。
- 推论：加法单位元与逆元唯一；$0v=0$、$a0=0$、$(-1)v=-v$。
- 例子：[[组与Fⁿ|$\mathbf{F}^n$]]、函数空间、多项式空间。
