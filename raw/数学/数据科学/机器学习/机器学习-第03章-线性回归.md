# 第3章 线性回归 —— 投影与最小二乘

## 📘 本节概览

线性回归是机器学习最基础的模型——它的数学本质是**正交投影**。最小二乘解=将观测值投影到设计矩阵的列空间。

## 📐 1. 模型与目标

模型：$y = \vec{w}^T\vec{x} + \epsilon$，$\epsilon \sim N(0, \sigma^2)$

目标：$\min_{\vec{w}} \sum_{i=1}^n (y_i - \vec{w}^T\vec{x}_i)^2 = \min_{\vec{w}} \|\vec{y} - X\vec{w}\|^2$

## 📐 2. 正规方程的推导

> 🔍 **推导**：令 $\nabla_{\vec{w}} L = \nabla_{\vec{w}} (\vec{y}-X\vec{w})^T(\vec{y}-X\vec{w}) = -2X^T(\vec{y}-X\vec{w}) = \vec{0}$

得正规方程：$X^TX\vec{w} = X^T\vec{y}$

解：$\hat{\vec{w}} = (X^TX)^{-1}X^T\vec{y}$（当 $X^TX$ 可逆时）

## 📐 3. 几何解释

$\hat{\vec{y}} = X\hat{\vec{w}} = X(X^TX)^{-1}X^T\vec{y} = P\vec{y}$

$P = X(X^TX)^{-1}X^T$ 是投影矩阵——$\hat{\vec{y}}$ 是 $\vec{y}$ 在 $C(X)$ 上的正交投影。

残差 $\vec{e} = \vec{y} - \hat{\vec{y}} \perp C(X)$，即 $X^T\vec{e} = \vec{0}$。

> 💡 线性回归=投影。这是线性代数母题"正交分解"在机器学习中的直接体现。

## 📐 4. 统计性质

**Gauss-Markov定理**：在 $E[\epsilon]=0$，$\text{Var}(\epsilon)=\sigma^2 I$ 下，OLS估计是**最佳线性无偏估计**（BLUE）——所有线性无偏估计中方差最小。

> 🔍 **证明思路**：设 $\tilde{\vec{w}} = C\vec{y}$ 是任意线性无偏估计。无偏性→$CX=I$→$C=(X^TX)^{-1}X^T + D$，$DX=0$。比较方差：$\text{Var}(\tilde{\vec{w}}) = \sigma^2 CC^T = \sigma^2[(X^TX)^{-1}+DD^T] \succeq \sigma^2(X^TX)^{-1} = \text{Var}(\hat{\vec{w}})$。

## 📝 本节要点

1. 线性回归=投影到列空间——正规方程=正交条件。
2. OLS解 $\hat{\vec{w}} = (X^TX)^{-1}X^T\vec{y}$——Gauss-Markov保证BLUE。
3. 几何视角：残差垂直于列空间——正交分解。

### 🤔 问题 1：伪逆解

$X^TX$ 不可逆（$X$ 列不满秩）→正规方程有无穷多解。Moore-Penrose伪逆给出**最小范数解**：$\hat{\vec{w}} = X^+\vec{y} = V\Sigma^+U^T\vec{y}$（SVD）。性质：在所有最小化 $\|\vec{y}-X\vec{w}\|^2$ 的解中，$\|X^+\vec{y}\| \leq \|\vec{w}\|$ 对所有其他解成立。

### 🤔 问题 2：正则化回归

**Ridge**：$\min \|\vec{y}-X\vec{w}\|^2 + \lambda\|\vec{w}\|^2$。解：$\hat{\vec{w}} = (X^TX+\lambda I)^{-1}X^T\vec{y}$。$X^TX+\lambda I$ 总可逆（$\lambda>0$）。几何：在"球$\|\vec{w}\|^2 \leq t$"约束下最小化残差——椭圆与球的切点。

**LASSO**：$\min \|\vec{y}-X\vec{w}\|^2 + \lambda\|\vec{w}\|_1$。无闭式解（L1不可微）。几何：椭圆与菱形的切点→切点常在顶点→**稀疏解**。
