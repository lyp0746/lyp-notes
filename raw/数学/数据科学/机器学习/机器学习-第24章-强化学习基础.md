# 第24章 强化学习基础 —— Bellman方程

## 📘 本节概览

强化学习的数学基础是**Markov决策过程**（MDP）和**Bellman方程**。值函数描述"从某状态出发的期望总回报"。

## 📐 1. MDP定义

$(S, A, P, R, \gamma)$：状态集、动作集、转移概率、奖励函数、折扣因子。

策略 $\pi(a|s)$：状态→动作的分布。

## 📐 2. 值函数与Bellman方程

状态值：$V^\pi(s) = E[\sum_{t=0}^\infty \gamma^t R(s_t, a_t) | s_0 = s]$

动作值：$Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) V^\pi(s')$

> 🔍 **Bellman方程推导**：$V^\pi(s) = \sum_a \pi(a|s)[R(s,a) + \gamma \sum_{s'} P(s'|s,a)V^\pi(s')]$——将"未来"递归地表示为"当前+一步后的值"。

## 📐 3. 最优值函数

$V^*(s) = \max_\pi V^\pi(s) = \max_a [R(s,a) + \gamma \sum_{s'} P(s'|s,a)V^*(s')]$

> 🔍 **Bellman最优方程**：$V^*$ 是**压缩映射** $T$ 的不动点：$TV = V$。$\|TV - TV'\|_\infty \leq \gamma \|V - V'\|_\infty$（$\gamma < 1$）→Banach不动点定理→$V^*$ 存在唯一→值迭代收敛。

## 📐 4. 值迭代与策略迭代

**值迭代**：$V_{k+1} = TV_k$——迭代应用Bellman算子→收敛到 $V^*$。

**策略迭代**：$\pi_k \to V^{\pi_k} \to \pi_{k+1} = \text{greedy}(V^{\pi_k})$——交替评估和改进→收敛到 $\pi^*$。

> 💡 策略迭代通常比值迭代更快收敛（每步策略改进≥值改进），但每步需要精确评估策略（解线性方程组）。

## 📝 本节要点

1. MDP+Bellman方程=强化学习的数学基础。
2. Bellman最优方程是压缩映射→不动点存在唯一→值迭代收敛。
3. 值迭代vs策略迭代——前者简单，后者更快。

### 🤔 问题 1：Q-learning收敛

Q-learning：$Q(s,a) \leftarrow Q(s,a) + \alpha[R + \gamma\max_{a'}Q(s',a') - Q(s,a)]$。收敛条件：(1) 所有$(s,a)$对被无限次访问；(2) 学习率 $\alpha_t$ 满足 $\sum\alpha_t=\infty$，$\sum\alpha_t^2<\infty$（如 $\alpha_t=1/t$）。本质：Q-learning是随机近似算法→Robbins-Monro条件→收敛到Bellman最优方程的解。

### 🤔 问题 2：POMDP

POMDP：智能体只观察 $o_t$（不完整状态信息）→需要维护**信念状态** $b(s) = P(s|o_1,...,o_t,a_1,...,a_{t-1})$。信念空间是连续的（$\Delta^{|S|-1}$）→值函数定义在连续信念空间上→维度灾难。精确解：值迭代在信念空间→每步增加分段数→指数增长。近似：粒子滤波、RNN编码历史。
