# 第9章 极坐标与圆锥曲线 · 9.1 极坐标

> 前面几章我们一直用笛卡儿坐标 $(x,y)$ 描述平面上的点。但有些曲线（如圆、螺线、心形线）用极坐标描述更自然、更简洁。
极坐标用**距离**和**角度**确定点的位置，是描述旋转对称图形和周期现象的有力工具。
本节核心：极坐标的定义、极坐标与笛卡儿坐标的互化、极方程与图形。
>

## 9.1.1 极坐标的定义

### 基本概念

在平面内取一个定点 $O$，称为**极点**（相当于原点）；从 $O$ 出发引一条射线 $Ox$，称为**极轴**（相当于 $x$ 轴正方向）。

对于平面内任意一点 $P$：

- **极径** $r$：点 $P$ 到极点 $O$ 的距离，$r\ge0$；
- **极角** $\theta$：从极轴到射线 $OP$ 的角，逆时针为正。

则点 $P$ 的**极坐标**为：

$$\boxed{P(r,\theta)}$$

### 与笛卡儿坐标的区别

| 特征 | 笛卡儿坐标 | 极坐标 |
| --- | --- | --- |
| 基本量 | $x,y$ | $r,\theta$ |
| 唯一性 | 唯一 | 不唯一 |
| 原点 | $(0,0)$ | $r=0$，$\theta$ 任意 |
| 对称性 | 直角网格 | 极网格 |

### 极坐标的不唯一性

同一个点有无穷多种极坐标表示：

$$(r,\theta)=(r,\theta+2k\pi),\quad k\in\mathbb Z$$

也可以取负的 $r$：

$$(-r,\theta)=(r,\theta+\pi)$$

**例1**：

$$(2,\pi/3)=(2,\pi/3+2\pi)=(2,7\pi/3)$$

$$(-2,\pi/3)=(2,4\pi/3)$$

### 极坐标的约定

- $r\ge0$：通常约定，但也可以允许 $r<0$；
- $\theta$：通常取 $[0,2\pi)$ 或 $(-\pi,\pi]$；
- 极点 $O$：$r=0$，$\theta$ 任意。

## 9.1.2 极坐标与笛卡儿坐标的关系

### 从极坐标到笛卡儿坐标

$$\boxed{
x=r\cos\theta,\quad y=r\sin\theta
}$$

### 从笛卡儿坐标到极坐标

$$\boxed{
r^2=x^2+y^2,\quad \tan\theta=\frac yx
}$$

**注意**：

- $r=\sqrt{x^2+y^2}\ge0$；
- $\theta$ 的象限由 $(x,y)$ 的符号确定；
- 常用 $\theta=\tan^{-1}(y/x)$，但要修正象限。

### 例2：极坐标化笛卡儿坐标

$$(r,\theta)=\left(2,\frac{\pi}{6}\right)$$

$$x=2\cos\frac{\pi}{6}=2\cdot\frac{\sqrt3}{2}=\sqrt3$$

$$y=2\sin\frac{\pi}{6}=2\cdot\frac12=1$$

所以：

$$(x,y)=(\sqrt3,1)$$

### 例3：笛卡儿坐标化极坐标

$$(x,y)=(-1,1)$$

$$r=\sqrt{(-1)^2+1^2}=\sqrt2$$

$\theta$ 在第二象限：

$$\tan\theta=\frac{1}{-1}=-1\implies\theta=\frac{3\pi}{4}$$

所以：

$$(r,\theta)=\left(\sqrt2,\frac{3\pi}{4}\right)$$

### 例4：圆方程

笛卡儿坐标：

$$x^2+y^2=4$$

极坐标：

$$r^2=4\implies r=2$$

**结论**：极坐标下圆方程非常简单。

### 例5：直线方程

笛卡儿坐标：

$$x=3$$

极坐标：

$$r\cos\theta=3\implies r=\frac{3}{\cos\theta}=3\sec\theta$$

## 9.1.3 极方程与图形

### 极方程

极方程是用 $r$ 和 $\theta$ 表示的方程：

$$r=f(\theta)$$

或隐式：

$$F(r,\theta)=0$$

### 绘制极坐标图形的方法

1. 列出 $\theta$ 和对应 $r$ 的数值表；
2. 在极坐标系中描点；
3. 用光滑曲线连接。

### 例6：$r=2$（圆）

$$r=2$$

所有 $\theta$ 对应 $r=2$，所以图形是以极点为中心、半径 2 的圆。

### 例7：$\theta=\frac{\pi}{4}$（射线）

所有点满足 $\theta=\pi/4$，$r\ge0$，图形是从极点出发的射线。

### 例8：$r=2\cos\theta$（圆）

用笛卡儿坐标转换：

$$r=2\cos\theta\implies r^2=2r\cos\theta$$

$$x^2+y^2=2x$$

$$(x-1)^2+y^2=1$$

**结论**：图形是以 $(1,0)$ 为圆心、半径 1 的圆。

### 例9：$r=1+\cos\theta$（心形线）

这是**心形线**（cardioid）。

关键点：

- $\theta=0$：$r=2$；
- $\theta=\pi/2$：$r=1$；
- $\theta=\pi$：$r=0$；
- $\theta=3\pi/2$：$r=1$。

图形关于极轴对称，像一个心形。

### 例10：$r=\theta$（阿基米德螺线）

$$r=\theta,\quad \theta\ge0$$

随着 $\theta$ 增加，$r$ 线性增加，形成螺线。

### 常见极坐标曲线

| 方程 | 图形 |
| --- | --- |
| $r=a$ | 圆 |
| $\theta=\alpha$ | 射线 |
| $r=a\cos\theta$ | 圆（过极点） |
| $r=a\sin\theta$ | 圆（过极点） |
| $r=a(1+\cos\theta)$ | 心形线 |
| $r=a\cos2\theta$ | 四叶玫瑰线 |
| $r=a\sin3\theta$ | 三叶玫瑰线 |
| $r=\theta$ | 阿基米德螺线 |
| $r=e^{a\theta}$ | 对数螺线 |

## 9.1.4 极坐标的对称性

### 三种对称性

**1. 关于极轴对称**：
若 $(r,\theta)$ 在图形上，则 $(r,-\theta)$ 也在图形上。

**检验**：将 $\theta$ 换成 $-\theta$，方程不变。

**2. 关于 $\theta=\pi/2$ 对称**：
若 $(r,\theta)$ 在图形上，则 $(r,\pi-\theta)$ 也在图形上。

**检验**：将 $\theta$ 换成 $\pi-\theta$，方程不变。

**3. 关于极点对称**：
若 $(r,\theta)$ 在图形上，则 $(r,\theta+\pi)$ 或 $(-r,\theta)$ 也在图形上。

**检验**：将 $r$ 换成 $-r$（或 $\theta$ 换成 $\theta+\pi$），方程不变。

### 例11：$r=1+\cos\theta$

将 $\theta$ 换成 $-\theta$：

$$r=1+\cos(-\theta)=1+\cos\theta$$

方程不变，所以关于极轴对称。

### 例12：$r=\cos2\theta$

将 $\theta$ 换成 $-\theta$：

$$r=\cos(-2\theta)=\cos2\theta$$

关于极轴对称。

将 $\theta$ 换成 $\pi-\theta$：

$$r=\cos(2\pi-2\theta)=\cos2\theta$$

也关于 $\theta=\pi/2$ 对称。

### 例13：$r^2=\cos2\theta$

将 $r$ 换成 $-r$：

$$(-r)^2=r^2=\cos2\theta$$

方程不变，所以关于极点对称。

## 9.1.5 极坐标与笛卡儿坐标的转换技巧

### 常用转换公式

| 笛卡儿 | 极坐标 |
| --- | --- |
| $x$ | $r\cos\theta$ |
| $y$ | $r\sin\theta$ |
| $x^2+y^2$ | $r^2$ |
| $\tan\theta$ | $y/x$ |
| $x^2$ | $r^2\cos^2\theta$ |
| $y^2$ | $r^2\sin^2\theta$ |
| $xy$ | $r^2\sin\theta\cos\theta$ |

### 转换步骤

**笛卡儿 → 极坐标**：

1. 代入 $x=r\cos\theta$，$y=r\sin\theta$；
2. 化简，解出 $r=f(\theta)$。

**极坐标 → 笛卡儿**：

1. 用 $r^2=x^2+y^2$，$\cos\theta=x/r$，$\sin\theta=y/r$；
2. 消去 $r$ 和 $\theta$。

### 例14：化 $r=\sec\theta$ 为笛卡儿方程

$$r=\frac{1}{\cos\theta}\implies r\cos\theta=1\implies x=1$$

这是一条竖直线。

### 例15：化 $r=4\sin\theta$ 为笛卡儿方程

$$r=4\sin\theta\implies r^2=4r\sin\theta$$

$$x^2+y^2=4y$$

$$x^2+(y-2)^2=4$$

图形是以 $(0,2)$ 为圆心、半径 2 的圆。

### 例16：化 $r^2=4\cos2\theta$ 为笛卡儿方程

$$r^2=4(\cos^2\theta-\sin^2\theta)=4\cos^2\theta-4\sin^2\theta$$

乘以 $r^2$：

$$r^4=4r^2\cos^2\theta-4r^2\sin^2\theta$$

$$(x^2+y^2)^2=4x^2-4y^2$$

这是双纽线。

## 9.1.6 极坐标图形的绘制

### 绘制步骤

1. 分析对称性；
2. 列出关键点（$\theta=0,\pi/6,\pi/4,\pi/3,\pi/2,\dots$）；
3. 计算对应 $r$ 值；
4. 描点；
5. 利用对称性补全图形。

### 例17：绘制 $r=1+\cos\theta$

关键点：

| $\theta$ | $r$ |
| --- | --- |
| $0$ | $2$ |
| $\pi/4$ | $1+\sqrt2/2\approx1.71$ |
| $\pi/2$ | $1$ |
| $3\pi/4$ | $1-\sqrt2/2\approx0.29$ |
| $\pi$ | $0$ |
| $5\pi/4$ | $0.29$ |
| $3\pi/2$ | $1$ |
| $7\pi/4$ | $1.71$ |

图形关于极轴对称，形成心形线。

### 例18：绘制 $r=\cos2\theta$

关键点：

| $\theta$ | $r$ |
| --- | --- |
| $0$ | $1$ |
| $\pi/4$ | $0$ |
| $\pi/2$ | $-1$ |
| $3\pi/4$ | $0$ |
| $\pi$ | $1$ |

因为 $r$ 可以为负，需要用负 $r$ 的约定。最终图形是四叶玫瑰线。

### 绘制技巧

- 利用对称性减少计算；
- 注意 $r$ 为负时点的位置；
- 用表格辅助描点。

## 本节易错点总结

1. 极坐标不唯一，$(r,\theta)=(r,\theta+2k\pi)=(-r,\theta+\pi)$。
2. 从笛卡儿坐标化极坐标时，要注意象限。
3. $r$ 可以为负，此时点在相反方向。
4. 极方程 $r=f(\theta)$ 中，$r$ 是 $\theta$ 的函数。
5. 利用对称性可以简化绘图。
6. 转换方程时，注意乘以 $r$ 或 $r^2$ 消除分母。
7. 极点处 $r=0$，$\theta$ 任意。
8. 不同极方程可能表示同一图形。

# 一、主动回忆问题详解

## 1. 什么是极坐标？极径和极角分别是什么？

### 极坐标的定义

在平面内取一个定点 $O$，称为**极点**（相当于原点）；从 $O$ 出发引一条射线 $Ox$，称为**极轴**（相当于 $x$ 轴正方向）。

对于平面内任意一点 $P$：

- **极径** $r$：点 $P$ 到极点 $O$ 的距离，通常 $r\ge0$；
- **极角** $\theta$：从极轴到射线 $OP$ 的角，逆时针为正。

则点 $P$ 的**极坐标**为：

$$\boxed{P(r,\theta)}$$

### 关键点

- $r$ 表示“距离”；
- $\theta$ 表示“方向”；
- 极点处 $r=0$，$\theta$ 任意；
- 通常约定 $\theta\in[0,2\pi)$ 或 $(-\pi,\pi]$。

### 与笛卡儿坐标的对比

笛卡儿坐标用横纵坐标 $x,y$ 确定点；极坐标用距离和角度确定点。极坐标适合描述旋转对称图形。

## 2. 写出极坐标与笛卡儿坐标的转换公式

### 极坐标 → 笛卡儿坐标

$$\boxed{
x=r\cos\theta,\quad y=r\sin\theta
}$$

### 笛卡儿坐标 → 极坐标

$$\boxed{
r^2=x^2+y^2,\quad \tan\theta=\frac yx
}$$

### 注意

- $r=\sqrt{x^2+y^2}\ge0$；
- $\theta$ 的象限由 $(x,y)$ 的符号确定；
- 常用 $\theta=\tan^{-1}(y/x)$，但要修正象限。

### 例子

$$(r,\theta)=\left(2,\frac{\pi}{6}\right)\implies(x,y)=(\sqrt3,1)$$

$$(x,y)=(-1,1)\implies(r,\theta)=\left(\sqrt2,\frac{3\pi}{4}\right)$$

## 3. 极坐标为什么不唯一？

### 原因

极角 $\theta$ 可以加上 $2k\pi$，表示同一个方向：

$$(r,\theta)=(r,\theta+2k\pi),\quad k\in\mathbb Z$$

另外，负的 $r$ 表示相反方向：

$$(-r,\theta)=(r,\theta+\pi)$$

所以同一个点有无穷多种极坐标表示。

### 例子

$$(2,\pi/3)=(2,\pi/3+2\pi)=(2,7\pi/3)$$

$$(-2,\pi/3)=(2,4\pi/3)$$

### 极点

极点 $r=0$，$\theta$ 任意，所以极点有无穷多种表示。

### 影响

- 绘图时要注意对称性和重复；
- 解方程时可能有多余解，需要检验。

## 4. 写出 $r=2\cos\theta$ 的笛卡儿方程，并说明图形

### 转换

$$r=2\cos\theta$$

两边乘以 $r$：

$$r^2=2r\cos\theta$$

用 $r^2=x^2+y^2$，$r\cos\theta=x$：

$$x^2+y^2=2x$$

配方：

$$(x-1)^2+y^2=1$$

### 图形

这是以 $(1,0)$ 为圆心、半径 $1$ 的圆。

### 关键点

- 圆经过极点 $(0,0)$；
- 圆心在极轴上；
- 最大 $r=2$，在 $\theta=0$ 处。

### 类似

$$r=2\sin\theta\implies x^2+(y-1)^2=1$$

圆心在 $(0,1)$，半径 1。

## 5. 写出 $r=1+\cos\theta$ 的图形名称和关键点

### 图形名称

**心形线**（cardioid）。

### 关键点

| $\theta$ | $r$ |
| --- | --- |
| $0$ | $2$ |
| $\pi/2$ | $1$ |
| $\pi$ | $0$ |
| $3\pi/2$ | $1$ |

### 图形特征

- 关于极轴对称；
- 在 $\theta=0$ 处最远（$r=2$）；
- 在 $\theta=\pi$ 处回到极点（$r=0$）；
- 形状像一个心形。

### 类似

$$r=1-\cos\theta$$

也是心形线，方向相反。

$$r=a(1+\cos\theta)$$

是一般心形线，$a$ 控制大小。

## 6. 极坐标图形有哪三种对称性？如何检验？

### 三种对称性

**1. 关于极轴对称**
若 $(r,\theta)$ 在图形上，则 $(r,-\theta)$ 也在图形上。

**检验**：将 $\theta$ 换成 $-\theta$，方程不变。

**2. 关于 $\theta=\pi/2$ 对称**
若 $(r,\theta)$ 在图形上，则 $(r,\pi-\theta)$ 也在图形上。

**检验**：将 $\theta$ 换成 $\pi-\theta$，方程不变。

**3. 关于极点对称**
若 $(r,\theta)$ 在图形上，则 $(r,\theta+\pi)$ 或 $(-r,\theta)$ 也在图形上。

**检验**：将 $r$ 换成 $-r$（或 $\theta$ 换成 $\theta+\pi$），方程不变。

### 例子

$$r=1+\cos\theta$$

将 $\theta$ 换成 $-\theta$：

$$r=1+\cos(-\theta)=1+\cos\theta$$

方程不变，所以关于极轴对称。

$$r=\cos2\theta$$

将 $\theta$ 换成 $\pi-\theta$：

$$r=\cos(2\pi-2\theta)=\cos2\theta$$

关于 $\theta=\pi/2$ 对称。

## 7. 如何绘制极坐标图形？

### 绘制步骤

1. **分析对称性**：减少计算量；
2. **列出关键点**：取 $\theta=0,\pi/6,\pi/4,\pi/3,\pi/2,\dots$；
3. **计算对应 $r$ 值**；
4. **描点**：在极坐标系中标出点；
5. **利用对称性补全图形**；
6. **用光滑曲线连接**。

### 例：绘制 $r=1+\cos\theta$

| $\theta$ | $r$ |
| --- | --- |
| $0$ | $2$ |
| $\pi/4$ | $1.71$ |
| $\pi/2$ | $1$ |
| $3\pi/4$ | $0.29$ |
| $\pi$ | $0$ |
| $5\pi/4$ | $0.29$ |
| $3\pi/2$ | $1$ |
| $7\pi/4$ | $1.71$ |

图形关于极轴对称，形成心形线。

### 注意

- 当 $r<0$ 时，点在相反方向；
- 利用对称性可以只计算一半；
- 关键点足够多时，图形更精确。

# 二、发散性提问详解

## 1. 极坐标与笛卡儿坐标各有什么优缺点？为什么某些曲线用极坐标更简单？

### 笛卡儿坐标

**优点**：

- 唯一表示；
- 适合平移、直线、多项式；
- 微积分运算方便。

**缺点**：

- 圆、螺线等旋转对称图形方程复杂。

### 极坐标

**优点**：

- 适合旋转对称图形；
- 圆、心形线、玫瑰线方程简单；
- 物理中描述圆周运动、行星轨道方便。

**缺点**：

- 不唯一；
- 微积分运算复杂（需要雅可比行列式）。

### 为什么某些曲线用极坐标更简单

- 圆 $x^2+y^2=a^2$ 在极坐标下是 $r=a$；
- 心形线 $r=1+\cos\theta$ 在笛卡儿坐标下非常复杂；
- 螺线 $r=\theta$ 在笛卡儿坐标下无法简单表示。

### 结论

选择坐标系取决于图形的对称性和问题的性质。

## 2. 极坐标的不唯一性会带来什么问题？如何选择唯一的表示？

### 问题

- 同一个点有多种表示，可能导致方程有多余解；
- 绘图时可能重复或遗漏；
- 积分区域描述可能不唯一。

### 如何选择唯一表示

通常约定：

- $r\ge0$；
- $\theta\in[0,2\pi)$ 或 $(-\pi,\pi]$。

这样每个非极点有唯一表示，极点 $r=0$ 单独处理。

### 例子

点 $(1,1)$ 的极坐标：

- 标准表示：$\left(\sqrt2,\frac{\pi}{4}\right)$；
- 其他表示：$\left(\sqrt2,\frac{9\pi}{4}\right)$，$\left(-\sqrt2,\frac{5\pi}{4}\right)$。

选择标准表示可以避免混淆。

## 3. 在物理学中，极坐标如何用于描述圆周运动、行星轨道、电磁场？

### 圆周运动

位置：

$$\mathbf r(t)=R(\cos\omega t,\sin\omega t)$$

极坐标下 $r=R$，$\theta=\omega t$。

### 行星轨道

开普勒定律中，行星轨道方程：

$$r=\frac{p}{1+e\cos\theta}$$

其中 $p$ 是半通径，$e$ 是离心率。

### 电磁场

点电荷电场：

$$\mathbf E=\frac{kQ}{r^2}\hat{\mathbf r}$$

极坐标下表达式非常简洁。

### 结论

极坐标是描述中心力场、旋转运动、周期现象的自然语言。

## 4. 在工程中，极坐标如何用于雷达、天线、声纳？

### 雷达

雷达扫描得到目标距离 $r$ 和方位角 $\theta$，直接对应极坐标。

### 天线

天线辐射方向图通常用 $r=f(\theta)$ 表示，例如：

$$r=\cos\theta$$

### 声纳

声纳探测同样用距离和角度确定目标位置。

### 结论

极坐标是雷达、天线、声纳等旋转扫描系统的核心坐标。

## 5. 在计算机图形学中，极坐标如何用于生成圆形和螺旋形图形？

### 圆形

在极坐标下 $r=R$，直接生成圆。

### 螺旋线

$$r=a\theta$$

生成阿基米德螺线。

$$r=e^{a\theta}$$

生成对数螺线。

### 玫瑰线

$$r=a\cos n\theta$$

生成 $n$ 瓣玫瑰线。

### 结论

极坐标是生成旋转对称图形和螺旋图形的自然工具。

## 6. 极坐标与复数有什么关系？极形式如何用于复数乘法和除法？

### 复数极形式

$$z=x+iy=r(\cos\theta+i\sin\theta)=re^{i\theta}$$

其中 $r=|z|$，$\theta=\arg z$。

### 乘法

$$z_1z_2=r_1r_2e^{i(\theta_1+\theta_2)}$$

模相乘，角相加。

### 除法

$$\frac{z_1}{z_2}=\frac{r_1}{r_2}e^{i(\theta_1-\theta_2)}$$

模相除，角相减。

### 德·莫夫定理

$$(\cos\theta+i\sin\theta)^n=\cos n\theta+i\sin n\theta$$

### 结论

极形式把复数乘除法简化为模和角的运算。

## 7. 极坐标在多元微积分中如何推广？极坐标下的二重积分如何计算？

### 二重积分

笛卡儿坐标：

$$\iint_D f(x,y)\,dx\,dy$$

极坐标变换：

$$x=r\cos\theta,\quad y=r\sin\theta$$

面积微元：

$$\boxed{dA=r\,dr\,d\theta}$$

所以：

$$\boxed{
\iint_D f(x,y)\,dx\,dy
=\int_{\alpha}^{\beta}\int_{r_1(\theta)}^{r_2(\theta)}f(r\cos\theta,r\sin\theta)\,r\,dr\,d\theta
}$$

### 例子

圆域 $x^2+y^2\le R^2$：

$$\iint_D 1\,dA
=\int_0^{2\pi}\int_0^R r\,dr\,d\theta
=\pi R^2$$

### 结论

极坐标下的二重积分多出一个因子 $r$，来自雅可比行列式。

# 三、总结

1. 极坐标用 $(r,\theta)$ 表示点，适合旋转对称图形。
2. 转换公式：$x=r\cos\theta$，$y=r\sin\theta$；$r^2=x^2+y^2$，$\tan\theta=y/x$。
3. 极坐标不唯一，但可通过约定 $r\ge0$，$\theta\in[0,2\pi)$ 选择标准表示。
4. 常见图形：圆、心形线、玫瑰线、螺线。
5. 三种对称性：极轴、$\theta=\pi/2$、极点。
6. 绘图步骤：对称性、关键点、描点、连线。
7. 极坐标在物理、工程、计算机图形学、复数、多元微积分中广泛应用。

这些内容把极坐标从“另一种坐标”提升为“描述旋转和周期现象的核心工具”，为极坐标作图和后续圆锥曲线奠定了基础。

# 第9章 极坐标与圆锥曲线 · 9.2 在极坐标中作图

> 上一节我们学习了极坐标的定义和基本转换。本节要系统研究如何绘制极坐标图形：如何利用对称性减少计算？如何求极曲线的斜率？如何高效地画出心形线、玫瑰线、螺线等经典图形？
核心思想：极坐标作图不是简单描点，而是先分析对称性、周期性和关键点，再结合直角坐标转换，画出完整图形。
>

## 9.2.1 对称性

### 三种基本对称性

**1. 关于极轴对称**
若 $(r,\theta)$ 在图形上，则 $(r,-\theta)$ 也在图形上。

**检验方法**：将方程中的 $\theta$ 换成 $-\theta$，若方程不变，则关于极轴对称。

**例1**：

$$r=1+\cos\theta$$

将 $\theta$ 换成 $-\theta$：

$$r=1+\cos(-\theta)=1+\cos\theta$$

方程不变，所以关于极轴对称。

**2. 关于 $\theta=\pi/2$ 对称（关于 $y$ 轴对称）**
若 $(r,\theta)$ 在图形上，则 $(r,\pi-\theta)$ 也在图形上。

**检验方法**：将方程中的 $\theta$ 换成 $\pi-\theta$，若方程不变，则关于 $\theta=\pi/2$ 对称。

**例2**：

$$r=\sin\theta$$

将 $\theta$ 换成 $\pi-\theta$：

$$r=\sin(\pi-\theta)=\sin\theta$$

方程不变，所以关于 $\theta=\pi/2$ 对称。

**3. 关于极点对称（关于原点对称）**
若 $(r,\theta)$ 在图形上，则 $(r,\theta+\pi)$ 或 $(-r,\theta)$ 也在图形上。

**检验方法**：将 $r$ 换成 $-r$，或 $\theta$ 换成 $\theta+\pi$，若方程不变，则关于极点对称。

**例3**：

$$r^2=\cos2\theta$$

将 $r$ 换成 $-r$：

$$(-r)^2=r^2=\cos2\theta$$

方程不变，所以关于极点对称。

### 对称性的作用

- 只需计算一半或四分之一的图形；
- 利用对称性补全其余部分；
- 大幅减少计算量。

### 例4：$r=\cos2\theta$ 的对称性

将 $\theta$ 换成 $-\theta$：

$$r=\cos(-2\theta)=\cos2\theta$$

关于极轴对称。

将 $\theta$ 换成 $\pi-\theta$：

$$r=\cos(2\pi-2\theta)=\cos2\theta$$

关于 $\theta=\pi/2$ 对称。

将 $r$ 换成 $-r$：

$$-r=\cos2\theta\implies r=-\cos2\theta$$

方程改变，不关于极点对称。

所以只需画第一象限部分，然后利用两种对称性补全。

## 9.2.2 斜率

### 极曲线的斜率公式

若极曲线由 $r=f(\theta)$ 给出，则直角坐标参数方程为：

$$x=r\cos\theta=f(\theta)\cos\theta$$

$$y=r\sin\theta=f(\theta)\sin\theta$$

用参数方程求导：

$$\frac{dy}{dx}=\frac{dy/d\theta}{dx/d\theta}$$

计算：

$$\frac{dx}{d\theta}=f'(\theta)\cos\theta-f(\theta)\sin\theta$$

$$\frac{dy}{d\theta}=f'(\theta)\sin\theta+f(\theta)\cos\theta$$

所以：

$$\boxed{
\frac{dy}{dx}
=\frac{f'(\theta)\sin\theta+f(\theta)\cos\theta}
{f'(\theta)\cos\theta-f(\theta)\sin\theta}
}$$

### 例5：求 $r=1+\cos\theta$ 在 $\theta=\pi/2$ 处的斜率

$$f(\theta)=1+\cos\theta,\quad f'(\theta)=-\sin\theta$$

在 $\theta=\pi/2$：

$$f=1,\quad f'=-1$$

$$\frac{dy}{dx}
=\frac{(-1)(1)+1(0)}{(-1)(0)-1(1)}
=\frac{-1}{-1}=1$$

斜率为 1。

### 水平切线和垂直切线

**水平切线**：$\frac{dy}{d\theta}=0$ 且 $\frac{dx}{d\theta}\ne0$。

**垂直切线**：$\frac{dx}{d\theta}=0$ 且 $\frac{dy}{d\theta}\ne0$。

**例6**：$r=1+\cos\theta$

$$\frac{dy}{d\theta}=-\sin\theta\sin\theta+(1+\cos\theta)\cos\theta$$

$$=-\sin^2\theta+\cos\theta+\cos^2\theta$$

$$=\cos\theta+\cos2\theta$$

令 $\frac{dy}{d\theta}=0$：

$$\cos\theta+\cos2\theta=0$$

用 $\cos2\theta=2\cos^2\theta-1$：

$$2\cos^2\theta+\cos\theta-1=0$$

$$(2\cos\theta-1)(\cos\theta+1)=0$$

所以：

$$\cos\theta=\frac12\implies\theta=\frac{\pi}{3},\frac{5\pi}{3}$$

或

$$\cos\theta=-1\implies\theta=\pi$$

这些点处可能有水平切线。

## 9.2.3 作图的方法

### 系统作图步骤

1. **分析对称性**：确定关于极轴、$\theta=\pi/2$、极点的对称性；
2. **确定周期**：若 $f(\theta+2\pi)=f(\theta)$，周期为 $2\pi$；若 $f(\theta+\pi)=f(\theta)$，周期为 $\pi$；
3. **找关键点**：取 $\theta=0,\pi/6,\pi/4,\pi/3,\pi/2,\dots$，计算 $r$；
4. **找零点**：解 $r=0$，确定曲线经过极点的角度；
5. **找最大/最小 $r$**：求 $f'(\theta)=0$ 的点；
6. **描点**：在极坐标系中标出关键点；
7. **利用对称性补全**：画出完整图形；
8. **检查**：确保图形光滑，没有遗漏。

**特点**：$r$ 随 $\theta$ 指数增长。

**图形**：快速向外扩展的螺线，常用于自然界（鹦鹉螺、星系）。

## 9.2.4 极坐标作图的技巧

### 技巧1：利用对称性减少计算

只计算第一象限或上半平面，然后对称补全。

### 技巧2：找零点确定曲线经过极点的位置

令 $r=0$，解出 $\theta$。

**例**：$r=1+\cos\theta=0\implies\cos\theta=-1\implies\theta=\pi$。

### 技巧3：找最大/最小 $r$

令 $f'(\theta)=0$，解出 $\theta$。

**例**：$r=1+\cos\theta$，$f'=-\sin\theta=0\implies\theta=0,\pi$。

$r_{\max}=2$（$\theta=0$），$r_{\min}=0$（$\theta=\pi$）。

### 技巧4：注意负 $r$

当 $r<0$ 时，点在 $\theta+\pi$ 方向，距离为 $|r|$。

### 技巧5：结合直角坐标

有时把极方程转为直角坐标方程更容易看出图形。

**例**：$r=2\cos\theta\implies x^2+y^2=2x\implies(x-1)^2+y^2=1$。

## 本节易错点总结

1. 对称性检验时要注意负 $r$ 的约定。
2. 极坐标不唯一，可能重复或遗漏。
3. 负 $r$ 时点在相反方向。
4. 周期可能不是 $2\pi$，如 $r=\cos2\theta$ 周期为 $\pi$。
5. 求斜率要用参数方程公式。
6. 水平/垂直切线要同时检查分子分母。
7. 作图时关键点要足够多，避免遗漏。
8. 利用对称性可以只画一部分。

## 2. 写出极曲线的斜率公式

### 参数方程表示

若极曲线为 $r=f(\theta)$，则直角坐标参数方程为：

$$x=r\cos\theta=f(\theta)\cos\theta$$

$$y=r\sin\theta=f(\theta)\sin\theta$$

### 斜率公式

$$\boxed{
\frac{dy}{dx}
=
\frac{f'(\theta)\sin\theta+f(\theta)\cos\theta}
{f'(\theta)\cos\theta-f(\theta)\sin\theta}
}$$

### 推导

由参数方程求导：

$$\frac{dy}{dx}=\frac{dy/d\theta}{dx/d\theta}$$

其中：

$$\frac{dx}{d\theta}=f'(\theta)\cos\theta-f(\theta)\sin\theta$$

$$\frac{dy}{d\theta}=f'(\theta)\sin\theta+f(\theta)\cos\theta$$

### 例子

$r=1+\cos\theta$，$f'(\theta)=-\sin\theta$。

在 $\theta=\pi/2$：

$$f=1,\quad f'=-1$$

$$\frac{dy}{dx}
=\frac{(-1)(1)+1(0)}{(-1)(0)-1(1)}
=\frac{-1}{-1}=1$$

## 3. 如何找极曲线的水平切线和垂直切线？

### 水平切线

条件：

$$\frac{dy}{d\theta}=0,\quad \frac{dx}{d\theta}\ne0$$

即：

$$f'(\theta)\sin\theta+f(\theta)\cos\theta=0$$

### 垂直切线

条件：

$$\frac{dx}{d\theta}=0,\quad \frac{dy}{d\theta}\ne0$$

即：

$$f'(\theta)\cos\theta-f(\theta)\sin\theta=0$$

### 例子

$r=1+\cos\theta$：

$$\frac{dy}{d\theta}
=-\sin^2\theta+(1+\cos\theta)\cos\theta
=\cos\theta+\cos2\theta$$

令 $\frac{dy}{d\theta}=0$：

$$\cos\theta+\cos2\theta=0$$

用 $\cos2\theta=2\cos^2\theta-1$：

$$2\cos^2\theta+\cos\theta-1=0$$

$$(2\cos\theta-1)(\cos\theta+1)=0$$

所以：

$$\cos\theta=\frac12\quad\text{或}\quad\cos\theta=-1$$

即：

$$\theta=\frac{\pi}{3},\frac{5\pi}{3},\pi$$

这些角度处可能有水平切线。

### 注意

- 必须同时检查分母不为零；
- 有时分子分母同时为零，需要进一步分析。

## 4. 绘制极坐标图形的步骤是什么？

### 系统步骤

1. **分析对称性**：关于极轴、$\theta=\pi/2$、极点的对称性；
2. **确定周期**：若 $f(\theta+2\pi)=f(\theta)$，周期为 $2\pi$；若 $f(\theta+\pi)=f(\theta)$，周期为 $\pi$；
3. **找关键点**：取 $\theta=0,\pi/6,\pi/4,\pi/3,\pi/2,\dots$，计算 $r$；
4. **找零点**：解 $r=0$，确定曲线经过极点的角度；
5. **找最大/最小 $r$**：求 $f'(\theta)=0$ 的点；
6. **描点**：在极坐标系中标出关键点；
7. **利用对称性补全**：画出完整图形；
8. **检查**：确保图形光滑，没有遗漏。

### 例：绘制 $r=1+\cos\theta$

- 对称性：关于极轴对称；
- 周期：$2\pi$；
- 关键点：$\theta=0$ 时 $r=2$，$\theta=\pi$ 时 $r=0$；
- 图形：心形线。

| $3\pi/4$ | $1-\sqrt2/2\approx0.29$ |
| $\pi$ | $0$ |
| $5\pi/4$ | $0.29$ |
| $3\pi/2$ | $1$ |
| $7\pi/4$ | $1.71$ |

### 图形特征

- 关于极轴对称；
- 在 $\theta=0$ 处最远，$r=2$；
- 在 $\theta=\pi$ 处回到极点；
- 形状像心形，称为**心形线**。

## 6. 绘制 $r=\cos2\theta$ 的关键点

### 关键点表

| $\theta$ | $r=\cos2\theta$ |
| --- | --- |
| $0$ | $1$ |
| $\pi/4$ | $0$ |
| $\pi/2$ | $-1$ |
| $3\pi/4$ | $0$ |
| $\pi$ | $1$ |

### 注意负 $r$

当 $r=-1$ 时，点在 $\theta+\pi$ 方向，距离为 1。

### 图形特征

- 关于极轴对称；
- 关于 $\theta=\pi/2$ 对称；
- 周期为 $\pi$；
- 图形是**四叶玫瑰线**。

## 7. 什么是阿基米德螺线和对数螺线？

### 阿基米德螺线

方程：

$$r=a\theta$$

其中 $a>0$。

**特点**：

- $r$ 与 $\theta$ 成正比；
- 随着 $\theta$ 增加，$r$ 线性增加；
- 相邻圈之间的距离恒定；
- 常见于机械凸轮、钟表发条。

### 对数螺线

方程：

$$r=e^{a\theta}$$

或

$$r=ae^{b\theta}$$

**特点**：

- $r$ 随 $\theta$ 指数增长；
- 相邻圈之间的距离按几何级数增长；
- 具有自相似性；
- 常见于自然界：鹦鹉螺壳、星系旋臂、飓风。

### 对比

| 特征 | 阿基米德螺线 | 对数螺线 |
| --- | --- | --- |
| 方程 | $r=a\theta$ | $r=ae^{b\theta}$ |
| 增长方式 | 线性 | 指数 |
| 圈间距 | 恒定 | 几何增长 |
| 自相似性 | 无 | 有 |

# 二、发散性提问详解

## 1. 为什么极坐标作图要先分析对称性？对称性如何减少计算量？

### 原因

极坐标图形通常具有旋转对称性或反射对称性。如果不利用对称性，需要计算整个 $0$ 到 $2\pi$ 范围的关键点，计算量大。

### 如何减少计算量

- 若关于极轴对称，只需计算 $\theta\in[0,\pi]$，另一半对称补全；
- 若关于 $\theta=\pi/2$ 对称，只需计算 $\theta\in[-\pi/2,\pi/2]$；
- 若关于极点对称，只需计算 $\theta\in[0,\pi]$，另一半反向补全；
- 若同时具有多种对称性，只需计算四分之一甚至更少。

### 例子

$r=\cos2\theta$ 关于极轴和 $\theta=\pi/2$ 都对称，所以只需计算 $0\le\theta\le\pi/4$，然后利用对称性画出整个四叶玫瑰线。

### 结论

对称性分析是极坐标作图的第一步，能大幅提高效率。

## 2. 极曲线的斜率公式与参数方程求导有什么关系？

### 关系

极曲线 $r=f(\theta)$ 可以转化为参数方程：

$$x=f(\theta)\cos\theta,\quad y=f(\theta)\sin\theta$$

其中参数是 $\theta$。

### 参数方程求导

$$\frac{dy}{dx}=\frac{dy/d\theta}{dx/d\theta}$$

### 极曲线斜率公式

$$\frac{dy}{dx}
=
\frac{f'(\theta)\sin\theta+f(\theta)\cos\theta}
{f'(\theta)\cos\theta-f(\theta)\sin\theta}$$

### 本质

极曲线的斜率公式就是参数方程求导公式在极坐标下的具体形式。极坐标只是参数方程的一种特殊参数化。

### 结论

极曲线斜率公式与参数方程求导本质相同，只是用 $r,\theta$ 表示。

## 3. 在物理学中，极坐标作图如何用于描述行星轨道、电磁场、声波？

### 行星轨道

开普勒定律中，行星轨道方程：

$$r=\frac{p}{1+e\cos\theta}$$

其中 $p$ 是半通径，$e$ 是离心率。

- $e=0$：圆；
- $0<e<1$：椭圆；
- $e=1$：抛物线；
- $e>1$：双曲线。

极坐标作图可以直接显示轨道形状。

### 电磁场

点电荷电场：

$$\mathbf E=\frac{kQ}{r^2}\hat{\mathbf r}$$

在极坐标下，电场方向沿径向，大小只依赖于 $r$。

### 声波

声波在均匀介质中沿径向传播：

$$p(r,\theta)=A(r)\cos(\omega t-kr)$$

极坐标作图用于显示声波的方向性和衰减。

### 结论

极坐标是描述中心力场、径向传播、旋转对称现象的自然语言。

## 4. 在工程中，极坐标作图如何用于天线方向图、雷达扫描、机械凸轮设计？

### 天线方向图

天线辐射强度通常用极坐标表示：

$$r=f(\theta)$$

例如：

$$r=\cos\theta$$

表示一个简单的方向图。

### 雷达扫描

雷达扫描得到目标距离 $r$ 和方位角 $\theta$，直接对应极坐标。极坐标作图用于显示雷达覆盖范围和目标分布。

### 机械凸轮设计

凸轮轮廓常用极坐标表示：

$$r=f(\theta)$$

通过设计 $f(\theta)$ 控制从动件的运动规律。

### 结论

极坐标作图在工程中用于描述旋转对称的物理量和机械轮廓。

## 5. 在计算机图形学中，极坐标如何用于生成玫瑰线、螺线、心形线？

### 玫瑰线

$$r=a\cos n\theta$$

或

$$r=a\sin n\theta$$

- $n$ 为奇数：$n$ 瓣；
- $n$ 为偶数：$2n$ 瓣。

### 螺线

$$r=a\theta$$

阿基米德螺线。

$$r=ae^{b\theta}$$

对数螺线。

### 心形线

$$r=a(1+\cos\theta)$$

或

$$r=a(1-\cos\theta)$$

### 生成方法

1. 对 $\theta$ 离散采样；
2. 计算 $r=f(\theta)$；
3. 转换为直角坐标 $(r\cos\theta,r\sin\theta)$；
4. 连接点形成曲线。

### 结论

极坐标是计算机图形学中生成旋转对称图形的自然工具。

## 6. 极坐标作图与直角坐标作图相比，各有什么优缺点？

### 极坐标作图

**优点**：

- 适合旋转对称图形；
- 圆、心形线、玫瑰线、螺线方程简单；
- 物理中描述中心力场、圆周运动方便。

**缺点**：

- 不唯一；
- 微积分运算复杂（需要雅可比行列式）；
- 直线、多项式方程复杂。

### 直角坐标作图

**优点**：

- 唯一表示；
- 适合直线、多项式；
- 微积分运算方便。

**缺点**：

- 旋转对称图形方程复杂；
- 圆、螺线等不自然。

### 选择原则

根据图形的对称性和问题的性质选择坐标系。

### 结论

两种坐标系互补，没有绝对优劣。

## 7. 如何用极坐标作图研究混沌系统中的吸引子？例如洛伦兹吸引子。

### 洛伦兹吸引子

洛伦兹方程：

$$\dot x=\sigma(y-x)$$

$$\dot y=x(\rho-z)-y$$

$$\dot z=xy-\beta z$$

这是三维系统，通常用三维直角坐标作图。

### 极坐标的应用

在某些混沌系统中，极坐标可以揭示旋转对称性和角向结构。

**例子**：

- 圆型限制性三体问题；
- 旋转流体；
- 螺旋波。

### 方法

1. 把系统转换到极坐标 $(r,\theta)$；
2. 分析径向和角向方程；
3. 作 $r$-$\theta$ 图或 $r$-$\dot r$ 图；
4. 观察吸引子的旋转对称性。

### 注意

洛伦兹吸引子本身不是极坐标的典型例子，因为它没有明显的旋转对称性。但许多混沌系统（如罗斯勒系统、陈系统）在特定参数下具有旋转对称性，极坐标作图可以简化分析。

### 结论

极坐标作图在具有旋转对称性的混沌系统中可以帮助揭示吸引子的结构，但不是所有混沌系统都适合。

# 三、总结

1. 极坐标作图的三种对称性：极轴、$\theta=\pi/2$、极点。
2. 极曲线斜率公式由参数方程求导得到。
3. 水平/垂直切线通过 $\frac{dy}{d\theta}=0$ 或 $\frac{dx}{d\theta}=0$ 判断。
4. 作图步骤：对称性、周期、关键点、零点、极值、描点、补全。
5. $r=1+\cos\theta$ 是心形线；$r=\cos2\theta$ 是四叶玫瑰线。
6. 阿基米德螺线 $r=a\theta$，对数螺线 $r=ae^{b\theta}$。
7. 极坐标在物理、工程、计算机图形学中广泛应用。
8. 极坐标与直角坐标互补，选择取决于问题性质。

# 第9章 极坐标与圆锥曲线 · 9.3 极坐标中的面积和长度

> 前面两节我们学习了极坐标的定义、转换和作图。本节要把积分应用到极坐标中：**如何求极曲线围成的面积？如何求极曲线的弧长？**
极坐标下的面积和弧长公式与直角坐标不同，核心是正确写出面积微元和弧长微元。
本节核心：极坐标中的面积公式、弧长公式、对称性简化计算，以及典型例题。
>

## 9.3.1 平面区域的面积

### 从扇形说起

在极坐标中，考虑由射线 $\theta=\alpha$、$\theta=\beta$ 和曲线 $r=f(\theta)$ 围成的区域。

把角度区间 $[\alpha,\beta]$ 分成 $n$ 个小区间，每个小区间宽 $\Delta\theta$。

第 $k$ 个小区间对应一个**小扇形**，半径为 $r_k=f(\theta_k)$，圆心角为 $\Delta\theta$。

扇形面积公式：

$$\Delta A_k=\frac12 r_k^2\Delta\theta$$

求和取极限：

$$A=\lim_{n\to\infty}\sum_{k=1}^n\frac12 f(\theta_k)^2\Delta\theta$$

得到极坐标下的面积公式：

$$\boxed{
A=\int_{\alpha}^{\beta}\frac12 r^2\,d\theta
=\int_{\alpha}^{\beta}\frac12 [f(\theta)]^2\,d\theta
}$$

### 几何直观

- 直角坐标：面积微元 $dA=y\,dx$（矩形条）；
- 极坐标：面积微元 $dA=\frac12 r^2\,d\theta$（小扇形）。

### 使用步骤

1. 确定区域边界：找出曲线 $r=f(\theta)$ 和射线 $\theta=\alpha,\beta$；
2. 确定积分上下限：$\alpha$ 到 $\beta$；
3. 代入公式：

$$A=\int_{\alpha}^{\beta}\frac12 r^2\,d\theta$$

4. 利用对称性简化计算。

### 例1：圆 $r=a$

$$A=\int_0^{2\pi}\frac12 a^2\,d\theta
=\frac12 a^2\cdot2\pi=\pi a^2$$

与已知圆面积公式一致。

### 例2：心形线 $r=1+\cos\theta$

求整个心形线围成的面积。

利用对称性，只需计算上半部分（$\theta=0$ 到 $\pi$），然后乘以 2。

$$A=2\int_0^{\pi}\frac12(1+\cos\theta)^2\,d\theta$$

展开：

$$(1+\cos\theta)^2=1+2\cos\theta+\cos^2\theta$$

用 $\cos^2\theta=\frac{1+\cos2\theta}{2}$：

$$=1+2\cos\theta+\frac12+\frac12\cos2\theta
=\frac32+2\cos\theta+\frac12\cos2\theta$$

积分：

$$A=\int_0^{\pi}\left(\frac32+2\cos\theta+\frac12\cos2\theta\right)d\theta$$

$$=\left[\frac32\theta+2\sin\theta+\frac14\sin2\theta\right]_0^{\pi}$$

$$=\frac32\pi$$

所以整个心形线面积：

$$\boxed{A=\frac{3\pi}{2}}$$

### 例3：四叶玫瑰线 $r=\cos2\theta$

一瓣对应 $\theta\in[-\pi/4,\pi/4]$，面积：

$$A_{\text{一瓣}}=\int_{-\pi/4}^{\pi/4}\frac12\cos^2(2\theta)\,d\theta$$

利用偶函数：

$$=2\int_0^{\pi/4}\frac12\cos^2(2\theta)\,d\theta
=\int_0^{\pi/4}\cos^2(2\theta)\,d\theta$$

用 $\cos^2(2\theta)=\frac{1+\cos4\theta}{2}$：

$$=\int_0^{\pi/4}\frac{1+\cos4\theta}{2}\,d\theta$$

$$=\left[\frac{\theta}{2}+\frac{\sin4\theta}{8}\right]_0^{\pi/4}
=\frac{\pi}{8}$$

四瓣总面积：

$$\boxed{A=4\cdot\frac{\pi}{8}=\frac{\pi}{2}}$$

### 例4：两曲线之间的面积

求 $r=1$ 和 $r=2\cos\theta$ 之间的面积（在圆 $r=1$ 内部、圆 $r=2\cos\theta$ 外部的区域）。

先找交点：

$$1=2\cos\theta\implies\cos\theta=\frac12\implies\theta=\pm\frac{\pi}{3}$$

区域关于极轴对称，计算上半部分再乘 2。

$$A=2\int_0^{\pi/3}\frac12\left[(2\cos\theta)^2-1^2\right]d\theta$$

$$=\int_0^{\pi/3}(4\cos^2\theta-1)\,d\theta$$

用 $4\cos^2\theta=2(1+\cos2\theta)$：

$$=\int_0^{\pi/3}(2+2\cos2\theta-1)\,d\theta
=\int_0^{\pi/3}(1+2\cos2\theta)\,d\theta$$

$$=\left[\theta+\sin2\theta\right]_0^{\pi/3}
=\frac{\pi}{3}+\frac{\sqrt3}{2}$$

所以：

$$\boxed{A=\frac{\pi}{3}+\frac{\sqrt3}{2}}$$

## 9.3.2 极曲线的长度

### 弧长微元

极曲线 $r=f(\theta)$ 的参数方程为：

$$x=f(\theta)\cos\theta,\quad y=f(\theta)\sin\theta$$

弧长微元：

$$ds=\sqrt{\left(\frac{dx}{d\theta}\right)^2+\left(\frac{dy}{d\theta}\right)^2}\,d\theta$$

计算：

$$\frac{dx}{d\theta}=f'(\theta)\cos\theta-f(\theta)\sin\theta$$

$$\frac{dy}{d\theta}=f'(\theta)\sin\theta+f(\theta)\cos\theta$$

平方相加：

$$\left(\frac{dx}{d\theta}\right)^2+\left(\frac{dy}{d\theta}\right)^2
=[f'(\theta)]^2+f(\theta)^2$$

所以：

$$\boxed{
ds=\sqrt{r^2+\left(\frac{dr}{d\theta}\right)^2}\,d\theta
}$$

极曲线的弧长：

$$\boxed{
L=\int_{\alpha}^{\beta}\sqrt{r^2+\left(\frac{dr}{d\theta}\right)^2}\,d\theta
}$$

### 例5：圆 $r=a$

$$\frac{dr}{d\theta}=0$$

$$L=\int_0^{2\pi}\sqrt{a^2+0}\,d\theta
=\int_0^{2\pi}a\,d\theta=2\pi a$$

与圆周长一致。

### 例6：心形线 $r=1+\cos\theta$

$$\frac{dr}{d\theta}=-\sin\theta$$

$$r^2+\left(\frac{dr}{d\theta}\right)^2
=(1+\cos\theta)^2+\sin^2\theta$$

$$=1+2\cos\theta+\cos^2\theta+\sin^2\theta
=2+2\cos\theta$$

$$=4\cos^2\frac{\theta}{2}$$

所以：

$$\sqrt{r^2+(r')^2}=2\left|\cos\frac{\theta}{2}\right|$$

在 $0\le\theta\le2\pi$ 上，$\cos\frac{\theta}{2}\ge0$，所以：

$$L=\int_0^{2\pi}2\cos\frac{\theta}{2}\,d\theta$$

$$=\left[4\sin\frac{\theta}{2}\right]_0^{2\pi}
=4\sin\pi-4\sin0=0$$

这显然不对！因为 $\cos(\theta/2)$ 在 $[0,2\pi]$ 上从 1 到 0 到 -1，不是始终非负。

正确做法：分两段，或利用对称性。

心形线关于极轴对称，计算上半部分（$0\le\theta\le\pi$），然后乘以 2。

在 $0\le\theta\le\pi$ 上，$\cos(\theta/2)\ge0$，所以：

$$L=2\int_0^{\pi}2\cos\frac{\theta}{2}\,d\theta
=4\left[2\sin\frac{\theta}{2}\right]_0^{\pi}
=8$$

所以：

$$\boxed{L=8}$$

### 例7：阿基米德螺线 $r=\theta$，$0\le\theta\le2\pi$

$$\frac{dr}{d\theta}=1$$

$$L=\int_0^{2\pi}\sqrt{\theta^2+1}\,d\theta$$

用公式：

$$\int\sqrt{\theta^2+1}\,d\theta
=\frac12\left[\theta\sqrt{\theta^2+1}+\ln(\theta+\sqrt{\theta^2+1})\right]$$

所以：

$$L=\frac12\left[2\pi\sqrt{4\pi^2+1}+\ln(2\pi+\sqrt{4\pi^2+1})\right]$$

### 例8：对数螺线 $r=e^{a\theta}$，$0\le\theta\le b$

$$\frac{dr}{d\theta}=ae^{a\theta}$$

$$\sqrt{r^2+(r')^2}
=\sqrt{e^{2a\theta}+a^2e^{2a\theta}}
=e^{a\theta}\sqrt{1+a^2}$$

$$L=\int_0^b e^{a\theta}\sqrt{1+a^2}\,d\theta
=\frac{\sqrt{1+a^2}}{a}(e^{ab}-1)$$

## 9.3.3 利用对称性简化计算

### 对称性在面积和弧长中的应用

- 若图形关于极轴对称，可以只计算一半，然后乘以 2；
- 若关于 $\theta=\pi/2$ 对称，可以只计算一半；
- 若关于极点对称，可以只计算一半；
- 若同时具有多种对称性，可以只计算四分之一。

### 例9：玫瑰线 $r=\cos2\theta$ 的弧长

一瓣对应 $\theta\in[-\pi/4,\pi/4]$。

$$\frac{dr}{d\theta}=-2\sin2\theta$$

$$r^2+(r')^2=\cos^2(2\theta)+4\sin^2(2\theta)
=1+3\sin^2(2\theta)$$

弧长：

$$L_{\text{一瓣}}=\int_{-\pi/4}^{\pi/4}\sqrt{1+3\sin^2(2\theta)}\,d\theta$$

这个积分没有初等原函数（椭圆积分）。可以用数值方法计算。

四瓣总弧长是四倍。

### 例10：两曲线之间的面积和弧长

结合面积和弧长公式，可以求复杂区域的面积和边界长度。

## 9.3.4 面积和弧长公式的推导

### 面积公式推导

把区域分成小扇形，每个小扇形面积：

$$\Delta A=\frac12 r^2\Delta\theta$$

求和取极限：

$$A=\int_{\alpha}^{\beta}\frac12 r^2\,d\theta$$

### 弧长公式推导

参数方程：

$$x=r\cos\theta,\quad y=r\sin\theta$$

弧长微元：

$$ds=\sqrt{dx^2+dy^2}$$

计算：

$$dx=\frac{dx}{d\theta}d\theta=(r'\cos\theta-r\sin\theta)d\theta$$

$$dy=(r'\sin\theta+r\cos\theta)d\theta$$

平方相加：

$$dx^2+dy^2=(r'^2+r^2)d\theta^2$$

所以：

$$ds=\sqrt{r^2+(r')^2}\,d\theta$$

## 本节易错点总结

1. 面积微元是 $\frac12 r^2 d\theta$，不是 $r\,d\theta$。
2. 弧长微元是 $\sqrt{r^2+(dr/d\theta)^2}\,d\theta$。
3. 注意积分上下限：$\alpha$ 到 $\beta$，不是 $r$ 的范围。
4. 利用对称性时，注意 $r$ 可能为负。
5. 心形线弧长要分正负段，或利用对称性。
6. 玫瑰线面积和弧长可能需要分段或数值方法。
7. 两曲线之间的面积要用外曲线减内曲线。
8. 极坐标面积和弧长公式中的 $r$ 是 $\theta$ 的函数。

# 一、主动回忆问题详解

## 1. 写出极坐标中的面积公式

### 公式

若区域由射线 $\theta=\alpha$、$\theta=\beta$ 和极曲线 $r=f(\theta)$ 围成，则面积为：

$$\boxed{
A=\int_{\alpha}^{\beta}\frac12 r^2\,d\theta
=\int_{\alpha}^{\beta}\frac12[f(\theta)]^2\,d\theta
}$$

### 几何直观

把区域分成无数小扇形，每个小扇形的面积为：

$$\Delta A=\frac12 r^2\Delta\theta$$

求和取极限即得积分。

### 使用步骤

1. 确定积分上下限 $\alpha,\beta$；
2. 确定 $r=f(\theta)$；
3. 代入公式积分；
4. 利用对称性简化。

### 例子

圆 $r=a$：

$$A=\int_0^{2\pi}\frac12 a^2\,d\theta=\pi a^2$$

## 2. 写出极坐标中的弧长公式

### 公式

极曲线 $r=f(\theta)$ 在 $\alpha\le\theta\le\beta$ 上的弧长：

$$\boxed{
L=\int_{\alpha}^{\beta}\sqrt{r^2+\left(\frac{dr}{d\theta}\right)^2}\,d\theta
}$$

### 推导

参数方程：

$$x=r\cos\theta,\quad y=r\sin\theta$$

弧长微元：

$$ds=\sqrt{dx^2+dy^2}$$

计算得：

$$ds=\sqrt{r^2+(r')^2}\,d\theta$$

### 例子

圆 $r=a$：

$$L=\int_0^{2\pi}\sqrt{a^2+0}\,d\theta=2\pi a$$

## 3. 用极坐标面积公式求圆 $r=a$ 的面积

### 计算

$$A=\int_0^{2\pi}\frac12 a^2\,d\theta$$

$$=\frac12 a^2\cdot2\pi$$

$$=\pi a^2$$

### 结论

$$\boxed{A=\pi a^2}$$

与已知圆面积公式一致。

### 说明

- 圆 $r=a$ 是极坐标下最简单的曲线；
- 积分上下限是 $0$ 到 $2\pi$；
- $r$ 是常数，积分非常简单。

## 4. 用极坐标弧长公式求圆 $r=a$ 的周长

### 计算

$$\frac{dr}{d\theta}=0$$

$$L=\int_0^{2\pi}\sqrt{a^2+0^2}\,d\theta$$

$$=\int_0^{2\pi}a\,d\theta$$

$$=2\pi a$$

### 结论

$$\boxed{L=2\pi a}$$

与已知圆周长公式一致。

### 说明

- 极坐标弧长公式对圆给出正确结果；
- 对于更复杂的曲线，积分可能较复杂；
- 有时需要数值方法。

## 5. 求心形线 $r=1+\cos\theta$ 的面积和弧长

### 面积

利用关于极轴的对称性，计算上半部分（$0\le\theta\le\pi$）再乘 2。

$$A=2\int_0^{\pi}\frac12(1+\cos\theta)^2\,d\theta$$

展开：

$$(1+\cos\theta)^2=\frac32+2\cos\theta+\frac12\cos2\theta$$

积分：

$$A=\int_0^{\pi}\left(\frac32+2\cos\theta+\frac12\cos2\theta\right)d\theta$$

$$=\left[\frac32\theta+2\sin\theta+\frac14\sin2\theta\right]_0^{\pi}$$

$$=\frac{3\pi}{2}$$

所以：

$$\boxed{A=\frac{3\pi}{2}}$$

### 弧长

利用对称性，计算 $0\le\theta\le\pi$ 上的弧长再乘 2。

$$r'=-\sin\theta$$

$$r^2+(r')^2=(1+\cos\theta)^2+\sin^2\theta=2+2\cos\theta=4\cos^2\frac{\theta}{2}$$

在 $0\le\theta\le\pi$ 上，$\cos\frac{\theta}{2}\ge0$，所以：

$$\sqrt{r^2+(r')^2}=2\cos\frac{\theta}{2}$$

$$L=2\int_0^{\pi}2\cos\frac{\theta}{2}\,d\theta
=4\left[2\sin\frac{\theta}{2}\right]_0^{\pi}
=8$$

所以：

$$\boxed{L=8}$$

### 结论

心形线面积 $\frac{3\pi}{2}$，弧长 $8$。

## 6. 求四叶玫瑰线 $r=\cos2\theta$ 的面积

### 一瓣面积

一瓣对应 $\theta\in[-\pi/4,\pi/4]$。

$$A_{\text{一瓣}}=\int_{-\pi/4}^{\pi/4}\frac12\cos^2(2\theta)\,d\theta$$

利用偶函数：

$$=\int_0^{\pi/4}\cos^2(2\theta)\,d\theta$$

用 $\cos^2(2\theta)=\frac{1+\cos4\theta}{2}$：

$$=\int_0^{\pi/4}\frac{1+\cos4\theta}{2}\,d\theta$$

$$=\left[\frac{\theta}{2}+\frac{\sin4\theta}{8}\right]_0^{\pi/4}
=\frac{\pi}{8}$$

### 总面积

四瓣：

$$A=4\cdot\frac{\pi}{8}=\frac{\pi}{2}$$

### 结论

$$\boxed{A=\frac{\pi}{2}}$$

### 注意

- 玫瑰线 $r=\cos2\theta$ 有四瓣；
- 每瓣形状相同；
- 利用对称性只需计算一瓣。

## 7. 如何利用对称性简化极坐标面积和弧长的计算？

### 对称性类型

**关于极轴对称**：

$$(r,\theta)\leftrightarrow(r,-\theta)$$

只需计算 $0\le\theta\le\pi$，然后乘 2。

**关于 $\theta=\pi/2$ 对称**：

$$(r,\theta)\leftrightarrow(r,\pi-\theta)$$

只需计算一半，然后乘 2。

**关于极点对称**：

$$(r,\theta)\leftrightarrow(r,\theta+\pi)$$

只需计算一半，然后乘 2。

### 应用步骤

1. 判断对称性；
2. 确定基本区间；
3. 计算基本区间上的面积或弧长；
4. 乘以对称份数。

### 例子

- 心形线 $r=1+\cos\theta$ 关于极轴对称，计算 $0$ 到 $\pi$ 再乘 2；
- 四叶玫瑰线 $r=\cos2\theta$ 关于极轴和 $\theta=\pi/2$ 都对称，只需计算一瓣；
- 圆 $r=a$ 具有所有对称性，但直接积分更简单。

### 关键点

- 对称性大幅减少计算量；
- 注意 $r$ 的符号变化；
- 弧长计算中，对称性可以避免处理绝对值。

# 二、发散性提问详解

## 1. 极坐标面积公式 $\frac12\int r^2 d\theta$ 与直角坐标面积公式 $\int y\,dx$ 有什么关系？

### 直角坐标面积

$$A=\int_a^b y\,dx$$

其中 $y=f(x)$ 是上曲线。

### 极坐标面积

$$A=\int_{\alpha}^{\beta}\frac12 r^2\,d\theta$$

### 关系

两者都是“面积微元”的积分：

- 直角坐标：面积微元是竖直窄条 $dA=y\,dx$；
- 极坐标：面积微元是小扇形 $dA=\frac12 r^2\,d\theta$。

### 转换

从极坐标到直角坐标：

$$x=r\cos\theta,\quad y=r\sin\theta$$

面积微元：

$$dA=dx\,dy=r\,dr\,d\theta$$

对 $\theta$ 积分（固定 $r$ 从 0 到 $f(\theta)$）：

$$A=\int_{\alpha}^{\beta}\int_0^{f(\theta)}r\,dr\,d\theta
=\int_{\alpha}^{\beta}\frac12[f(\theta)]^2\,d\theta$$

### 结论

极坐标面积公式是直角坐标面积公式在极坐标下的自然推广，两者本质相同。

## 2. 极坐标弧长公式 $\int\sqrt{r^2+(r')^2}d\theta$ 与参数方程弧长公式有什么关系？

### 参数方程弧长

$$L=\int_a^b\sqrt{\left(\frac{dx}{dt}\right)^2+\left(\frac{dy}{dt}\right)^2}\,dt$$

### 极坐标作为参数方程

令 $t=\theta$：

$$x=r(\theta)\cos\theta,\quad y=r(\theta)\sin\theta$$

计算：

$$\frac{dx}{d\theta}=r'\cos\theta-r\sin\theta$$

$$\frac{dy}{d\theta}=r'\sin\theta+r\cos\theta$$

平方相加：

$$\left(\frac{dx}{d\theta}\right)^2+\left(\frac{dy}{d\theta}\right)^2
=(r')^2+r^2$$

所以：

$$L=\int_{\alpha}^{\beta}\sqrt{r^2+(r')^2}\,d\theta$$

### 结论

极坐标弧长公式就是参数方程弧长公式在极坐标参数化下的具体形式。

## 3. 在物理学中，极坐标面积和弧长如何用于计算行星轨道面积、电磁场通量？

### 行星轨道面积

开普勒第二定律：行星与太阳连线在相等时间内扫过相等面积。

面积速度：

$$\frac{dA}{dt}=\frac12 r^2\frac{d\theta}{dt}$$

用极坐标面积公式：

$$A=\int_{\theta_1}^{\theta_2}\frac12 r^2\,d\theta$$

### 电磁场通量

极坐标下，电场通量：

$$\Phi_E=\int_S\mathbf E\cdot d\mathbf A$$

在圆柱对称或球对称问题中，极坐标简化计算。

### 例子

点电荷电场：

$$\mathbf E=\frac{kQ}{r^2}\hat{\mathbf r}$$

通过球面的通量：

$$\Phi_E=\frac{kQ}{r^2}\cdot4\pi r^2=4\pi kQ$$

### 结论

极坐标面积和弧长在行星运动、电磁场、波动问题中广泛应用。

## 4. 在工程中，极坐标面积和弧长如何用于设计凸轮、天线、涡轮叶片？

### 凸轮设计

凸轮轮廓用极坐标表示：

$$r=f(\theta)$$

面积和弧长用于计算材料用量和运动规律。

### 天线设计

天线方向图用极坐标表示：

$$r=f(\theta)$$

面积代表辐射功率，弧长代表方向图边界。

### 涡轮叶片

叶片截面用极坐标描述，面积和弧长用于计算气动性能。

### 例子

凸轮从动件位移：

$$s(\theta)=f(\theta)-r_0$$

### 结论

极坐标面积和弧长是旋转机械设计的核心工具。

## 5. 在计算机图形学中，如何用极坐标面积和弧长生成和测量复杂曲线？

### 生成曲线

1. 对 $\theta$ 采样；
2. 计算 $r=f(\theta)$；
3. 转换为直角坐标；
4. 连接点。

### 测量面积

用极坐标面积公式数值积分：

$$A\approx\sum\frac12 r_i^2\Delta\theta$$

### 测量弧长

用极坐标弧长公式数值积分：

$$L\approx\sum\sqrt{r_i^2+(r_i')^2}\Delta\theta$$

### 应用

- 生成玫瑰线、螺线、心形线；
- 测量曲线长度和面积；
- 碰撞检测。

### 结论

极坐标是计算机图形学中生成和测量旋转对称图形的自然工具。

## 6. 极坐标面积和弧长与格林定理、线积分有什么关系？

### 格林定理

$$\oint_C P\,dx+Q\,dy=\iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dA$$

### 面积作为线积分

取 $P=0$，$Q=x$：

$$A=\oint_C x\,dy$$

极坐标下：

$$x=r\cos\theta,\quad dy=dr\sin\theta+r\cos\theta\,d\theta$$

计算可得：

$$A=\frac12\oint_C r^2\,d\theta$$

这与极坐标面积公式一致。

### 弧长作为线积分

$$L=\oint_C ds$$

极坐标下：

$$ds=\sqrt{r^2+(r')^2}\,d\theta$$

### 结论

极坐标面积和弧长是格林定理和线积分在极坐标下的具体形式，是向量分析的基础。

## 7. 在混沌系统中，极坐标面积和弧长如何用于分析吸引子的分形维数？

### 分形维数

分形维数描述吸引子的复杂程度，常用盒计数维数：

$$D=\lim_{\varepsilon\to0}\frac{\ln N(\varepsilon)}{\ln(1/\varepsilon)}$$

其中 $N(\varepsilon)$ 是覆盖吸引子所需的边长为 $\varepsilon$ 的盒子数。

### 极坐标的应用

在具有旋转对称性的混沌系统中，极坐标可以简化覆盖计算：

- 用极坐标网格覆盖；
- 计算每个扇形内的点数；
- 估计分形维数。

### 例子

- 罗斯勒吸引子；
- 洛伦兹吸引子（虽然不完全旋转对称）；
- 圆型限制性三体问题。

### 方法

1. 把吸引子投影到极坐标平面；
2. 用极坐标网格覆盖；
3. 计算非空格子数；
4. 拟合 $\ln N$ 与 $\ln(1/\varepsilon)$ 的斜率。

### 结论

极坐标面积和弧长在混沌和分形分析中用于描述吸引子的几何结构，是计算分形维数的工具之一。

# 三、总结

1. 极坐标面积公式：$A=\int\frac12 r^2\,d\theta$。
2. 极坐标弧长公式：$L=\int\sqrt{r^2+(r')^2}\,d\theta$。
3. 圆 $r=a$：面积 $\pi a^2$，周长 $2\pi a$。
4. 心形线 $r=1+\cos\theta$：面积 $\frac{3\pi}{2}$，弧长 $8$。
5. 四叶玫瑰线 $r=\cos2\theta$：面积 $\frac{\pi}{2}$。
6. 对称性可以大幅简化计算。
7. 极坐标面积和弧长与直角坐标、参数方程、格林定理密切相关。
8. 在物理、工程、计算机图形学、混沌分析中广泛应用。

这些内容把极坐标面积和弧长从“积分公式”提升为“分析旋转对称图形的核心工具”，为圆锥曲线和后续多元微积分奠定了基础。

## 9.4.1 抛物线

### 定义

**抛物线**是平面内到**定点**（焦点）和**定直线**（准线）距离相等的点的轨迹。

- 焦点：$F$；
- 准线：$l$；
- 抛物线上的点 $P$ 满足：

$$\boxed{PF=Pl}$$

### 标准方程

以焦点在 $x$ 轴上、顶点在原点为例：

- 焦点：$F(p,0)$；
- 准线：$x=-p$。

设抛物线上点为 $P(x,y)$，则：

$$\sqrt{(x-p)^2+y^2}=|x+p|$$

两边平方：

$$(x-p)^2+y^2=(x+p)^2$$

$$x^2-2px+p^2+y^2=x^2+2px+p^2$$

$$y^2=4px$$

所以：

$$\boxed{y^2=4px}$$

### 四种标准形式

| 方程 | 焦点 | 准线 | 开口方向 |
| --- | --- | --- | --- |
| $y^2=4px$（$p>0$） | $(p,0)$ | $x=-p$ | 向右 |
| $y^2=-4px$（$p>0$） | $(-p,0)$ | $x=p$ | 向左 |
| $x^2=4py$（$p>0$） | $(0,p)$ | $y=-p$ | 向上 |
| $x^2=-4py$（$p>0$） | $(0,-p)$ | $y=p$ | 向下 |

### 例1：$y^2=8x$

与 $y^2=4px$ 比较：

$$4p=8\implies p=2$$

焦点：$(2,0)$；
准线：$x=-2$。

开口向右。

### 例2：$x^2=-12y$

与 $x^2=-4py$ 比较：

$$4p=12\implies p=3$$

焦点：$(0,-3)$；
准线：$y=3$。

开口向下。

### 抛物线的性质

- 抛物线关于对称轴对称；
- 顶点是抛物线上离焦点最近的点；
- 抛物线的离心率 $e=1$。

### 平移后的抛物线

若顶点在 $(h,k)$，对称轴平行于 $x$ 轴：

$$(y-k)^2=4p(x-h)$$

对称轴平行于 $y$ 轴：

$$(x-h)^2=4p(y-k)$$

### 例3：$(y-2)^2=8(x-1)$

顶点：$(1,2)$；
$4p=8\implies p=2$；
焦点：$(1+2,2)=(3,2)$；
准线：$x=1-2=-1$。

## 9.4.2 椭圆

### 定义

**椭圆**是平面内到两个定点（焦点）的距离之和为常数的点的轨迹。

- 焦点：$F_1,F_2$；
- 常数：$2a$（$a>0$）。

椭圆上的点 $P$ 满足：

$$\boxed{PF_1+PF_2=2a}$$

### 标准方程

以焦点在 $x$ 轴上、中心在原点为例：

- 焦点：$F_1(-c,0)$，$F_2(c,0)$；
- 长半轴：$a$；
- 短半轴：$b$；
- 焦距：$c$。

其中：

$$\boxed{a^2=b^2+c^2}$$

标准方程：

$$\boxed{\frac{x^2}{a^2}+\frac{y^2}{b^2}=1,\quad a>b>0}$$

### 关键参数

- 长轴：$2a$（水平）；
- 短轴：$2b$（竖直）；
- 焦距：$2c$；
- 离心率：

$$e=\frac ca,\quad 0<e<1$$

### 两种标准形式

| 方程 | 长轴 | 焦点 |
| --- | --- | --- |
| $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$（$a>b$） | 水平 | $(\pm c,0)$ |
| $\frac{x^2}{b^2}+\frac{y^2}{a^2}=1$（$a>b$） | 竖直 | $(0,\pm c)$ |

### 例4：$\frac{x^2}{25}+\frac{y^2}{9}=1$

$$a^2=25\implies a=5$$

$$b^2=9\implies b=3$$

$$c^2=a^2-b^2=25-9=16\implies c=4$$

焦点：$(\pm4,0)$；
长轴：水平，长 $10$；
短轴：竖直，长 $6$；
离心率：$e=4/5=0.8$。

### 例5：$\frac{x^2}{16}+\frac{y^2}{25}=1$

$$a^2=25\implies a=5$$

$$b^2=16\implies b=4$$

$$c^2=25-16=9\implies c=3$$

焦点：$(0,\pm3)$；
长轴：竖直，长 $10$；
短轴：水平，长 $8$。

### 平移后的椭圆

中心在 $(h,k)$：

$$\frac{(x-h)^2}{a^2}+\frac{(y-k)^2}{b^2}=1$$

### 例6：$\frac{(x-2)^2}{9}+\frac{(y+1)^2}{4}=1$

中心：$(2,-1)$；
$a=3$，$b=2$；
$c=\sqrt{9-4}=\sqrt5$；
焦点：$(2\pm\sqrt5,-1)$；
长轴：水平。

### 椭圆的离心率

$$e=\frac ca$$

- $e$ 越接近 0，椭圆越接近圆；
- $e$ 越接近 1，椭圆越扁；
- 圆可以看作 $e=0$ 的椭圆。

## 9.4.3 双曲线

### 定义

**双曲线**是平面内到两个定点（焦点）的距离之差的绝对值为常数的点的轨迹。

- 焦点：$F_1,F_2$；
- 常数：$2a$（$a>0$）。

双曲线上的点 $P$ 满足：

$$\boxed{|PF_1-PF_2|=2a}$$

### 标准方程

以焦点在 $x$ 轴上、中心在原点为例：

- 焦点：$F_1(-c,0)$，$F_2(c,0)$；
- 实半轴：$a$；
- 虚半轴：$b$。

其中：

$$\boxed{c^2=a^2+b^2}$$

标准方程：

$$\boxed{\frac{x^2}{a^2}-\frac{y^2}{b^2}=1}$$

### 关键参数

- 实轴：$2a$（水平，穿过顶点）；
- 虚轴：$2b$（竖直）；
- 焦距：$2c$；
- 离心率：

$$e=\frac ca,\quad e>1$$

### 渐近线

$$\boxed{y=\pm\frac ba x}$$

### 两种标准形式

| 方程 | 开口方向 | 焦点 | 渐近线 |
| --- | --- | --- | --- |
| $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$ | 左右 | $(\pm c,0)$ | $y=\pm\frac ba x$ |
| $\frac{y^2}{a^2}-\frac{x^2}{b^2}=1$ | 上下 | $(0,\pm c)$ | $y=\pm\frac ab x$ |

### 例7：$\frac{x^2}{9}-\frac{y^2}{16}=1$

$$a^2=9\implies a=3$$

$$b^2=16\implies b=4$$

$$c^2=a^2+b^2=9+16=25\implies c=5$$

焦点：$(\pm5,0)$；
渐近线：$y=\pm\frac43x$；
离心率：$e=5/3$。

### 例8：$\frac{y^2}{4}-\frac{x^2}{9}=1$

$$a^2=4\implies a=2$$

$$b^2=9\implies b=3$$

$$c^2=4+9=13\implies c=\sqrt{13}$$

焦点：$(0,\pm\sqrt{13})$；
渐近线：$y=\pm\frac23x$。

### 平移后的双曲线

中心在 $(h,k)$：

$$\frac{(x-h)^2}{a^2}-\frac{(y-k)^2}{b^2}=1$$

### 例9：$\frac{(x-1)^2}{4}-\frac{(y+2)^2}{9}=1$

中心：$(1,-2)$；
$a=2$，$b=3$，$c=\sqrt{13}$；
焦点：$(1\pm\sqrt{13},-2)$；
渐近线：

$$y+2=\pm\frac32(x-1)$$

### 双曲线的离心率

$$e=\frac ca>1$$

- $e$ 越接近 1，双曲线越“窄”；
- $e$ 越大，双曲线越“宽”。

## 9.4.4 圆锥曲线的统一性

### 从圆锥面截取

圆锥曲线可以通过平面截圆锥面得到：

| 截平面与轴夹角 | 曲线 |
| --- | --- |
| 垂直于轴 | 圆 |
| 与轴夹角大于半顶角 | 椭圆 |
| 平行于母线 | 抛物线 |
| 与轴夹角小于半顶角 | 双曲线 |

### 离心率统一

所有圆锥曲线可以用**离心率** $e$ 统一描述：

| 曲线 | 离心率 |
| --- | --- |
| 圆 | $e=0$ |
| 椭圆 | $0<e<1$ |
| 抛物线 | $e=1$ |
| 双曲线 | $e>1$ |

### 焦点-准线统一

圆锥曲线可以统一定义为：到焦点距离与到准线距离之比为常数 $e$ 的点的轨迹：

$$\frac{PF}{Pl}=e$$

- $e=1$：抛物线；
- $0<e<1$：椭圆；
- $e>1$：双曲线。

### 判别式

一般二次方程：

$$Ax^2+Bxy+Cy^2+Dx+Ey+F=0$$

判别式：

$$\Delta=B^2-4AC$$

- $\Delta<0$：椭圆（或圆）；
- $\Delta=0$：抛物线；
- $\Delta>0$：双曲线。

## 本节易错点总结

1. 抛物线的 $p$ 是焦点到顶点的距离，不是焦点到准线的距离（那是 $2p$）。
2. 椭圆的 $a$ 是长半轴，$b$ 是短半轴，$c$ 是焦距的一半。
3. 椭圆中 $a^2=b^2+c^2$，双曲线中 $c^2=a^2+b^2$。
4. 双曲线的渐近线方程要区分两种标准形式。
5. 椭圆的离心率 $0<e<1$，双曲线 $e>1$，抛物线 $e=1$。
6. 平移后的方程要把中心坐标代入。
7. 注意长轴方向：$a^2$ 在哪个变量下，长轴就在哪个方向。
8. 圆锥曲线的类型可以通过判别式判断。

# 一、主动回忆问题详解

## 1. 写出抛物线的定义和标准方程

### 定义

**抛物线**是平面内到**定点**（焦点）和**定直线**（准线）距离相等的点的轨迹。

设焦点为 $F$，准线为 $l$，抛物线上的点 $P$ 满足：

$$\boxed{PF=Pl}$$

### 标准方程（四种形式）

| 方程 | 焦点 | 准线 | 开口方向 |
| --- | --- | --- | --- |
| $y^2=4px$（$p>0$） | $(p,0)$ | $x=-p$ | 向右 |
| $y^2=-4px$（$p>0$） | $(-p,0)$ | $x=p$ | 向左 |
| $x^2=4py$（$p>0$） | $(0,p)$ | $y=-p$ | 向上 |
| $x^2=-4py$（$p>0$） | $(0,-p)$ | $y=p$ | 向下 |

### 推导（以 $y^2=4px$ 为例）

焦点 $F(p,0)$，准线 $x=-p$。

设抛物线上点 $P(x,y)$，则：

$$\sqrt{(x-p)^2+y^2}=|x+p|$$

两边平方：

$$(x-p)^2+y^2=(x+p)^2$$

$$x^2-2px+p^2+y^2=x^2+2px+p^2$$

$$y^2=4px$$

### 平移后的抛物线

顶点在 $(h,k)$：

$$(y-k)^2=4p(x-h)$$

或

$$(x-h)^2=4p(y-k)$$

### 例子

$$y^2=8x$$

与 $y^2=4px$ 比较，$4p=8\implies p=2$。

焦点：$(2,0)$；准线：$x=-2$。

## 2. 写出椭圆的定义和标准方程

### 定义

**椭圆**是平面内到两个定点（焦点）的距离之和为常数的点的轨迹。

设焦点为 $F_1,F_2$，常数为 $2a$（$a>0$），椭圆上的点 $P$ 满足：

$$\boxed{PF_1+PF_2=2a}$$

### 标准方程（中心在原点）

**长轴水平**：

$$\boxed{\frac{x^2}{a^2}+\frac{y^2}{b^2}=1,\quad a>b>0}$$

焦点：$(\pm c,0)$，其中 $c^2=a^2-b^2$。

**长轴竖直**：

$$\boxed{\frac{x^2}{b^2}+\frac{y^2}{a^2}=1,\quad a>b>0}$$

焦点：$(0,\pm c)$，其中 $c^2=a^2-b^2$。

### 关键参数

- 长半轴：$a$；
- 短半轴：$b$；
- 焦距的一半：$c$；
- 关系：

$$\boxed{a^2=b^2+c^2}$$

- 离心率：

$$e=\frac ca,\quad 0<e<1$$

### 平移后的椭圆

中心在 $(h,k)$：

$$\frac{(x-h)^2}{a^2}+\frac{(y-k)^2}{b^2}=1$$

### 例子

$$\frac{x^2}{25}+\frac{y^2}{9}=1$$

$$a^2=25\implies a=5$$

$$b^2=9\implies b=3$$

$$c^2=25-9=16\implies c=4$$

焦点：$(\pm4,0)$；离心率：$e=4/5$。

## 3. 写出双曲线的定义和标准方程

### 定义

**双曲线**是平面内到两个定点（焦点）的距离之差的绝对值为常数的点的轨迹。

设焦点为 $F_1,F_2$，常数为 $2a$（$a>0$），双曲线上的点 $P$ 满足：

$$\boxed{|PF_1-PF_2|=2a}$$

### 标准方程（中心在原点）

**开口左右**：

$$\boxed{\frac{x^2}{a^2}-\frac{y^2}{b^2}=1}$$

焦点：$(\pm c,0)$，其中 $c^2=a^2+b^2$。

**开口上下**：

$$\boxed{\frac{y^2}{a^2}-\frac{x^2}{b^2}=1}$$

焦点：$(0,\pm c)$，其中 $c^2=a^2+b^2$。

### 关键参数

- 实半轴：$a$；
- 虚半轴：$b$；
- 焦距的一半：$c$；
- 关系：

$$\boxed{c^2=a^2+b^2}$$

- 离心率：

$$e=\frac ca,\quad e>1$$

### 渐近线

- 对于 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$：

$$\boxed{y=\pm\frac ba x}$$

- 对于 $\frac{y^2}{a^2}-\frac{x^2}{b^2}=1$：

$$\boxed{y=\pm\frac ab x}$$

### 平移后的双曲线

中心在 $(h,k)$：

$$\frac{(x-h)^2}{a^2}-\frac{(y-k)^2}{b^2}=1$$

### 例子

$$\frac{x^2}{9}-\frac{y^2}{16}=1$$

$$a^2=9\implies a=3$$

$$b^2=16\implies b=4$$

$$c^2=9+16=25\implies c=5$$

焦点：$(\pm5,0)$；渐近线：$y=\pm\frac43x$。

## 4. 椭圆中 $a,b,c$ 的关系是什么？双曲线中呢？

### 椭圆

$$\boxed{a^2=b^2+c^2}$$

其中：

- $a$：长半轴；
- $b$：短半轴；
- $c$：焦距的一半。

因为 $a>b$，所以 $c^2=a^2-b^2>0$，$c<a$。

### 双曲线

$$\boxed{c^2=a^2+b^2}$$

其中：

- $a$：实半轴；
- $b$：虚半轴；
- $c$：焦距的一半。

因为 $c^2=a^2+b^2>a^2$，所以 $c>a$。

### 记忆口诀

- 椭圆：$a$ 最大，$a^2=b^2+c^2$；
- 双曲线：$c$ 最大，$c^2=a^2+b^2$。

### 几何意义

- 椭圆中，焦点在长轴上，且 $c<a$；
- 双曲线中，焦点在实轴上，且 $c>a$。

## 5. 写出双曲线的渐近线方程

### 标准形式1

$$\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$$

渐近线：

$$\boxed{y=\pm\frac ba x}$$

### 标准形式2

$$\frac{y^2}{a^2}-\frac{x^2}{b^2}=1$$

渐近线：

$$\boxed{y=\pm\frac ab x}$$

### 平移后的双曲线

中心在 $(h,k)$：

$$\frac{(x-h)^2}{a^2}-\frac{(y-k)^2}{b^2}=1$$

渐近线：

$$y-k=\pm\frac ba(x-h)$$

### 记忆方法

把双曲线方程右边的 1 换成 0：

$$\frac{x^2}{a^2}-\frac{y^2}{b^2}=0$$

$$y^2=\frac{b^2}{a^2}x^2$$

$$y=\pm\frac ba x$$

### 例子

$$\frac{x^2}{9}-\frac{y^2}{16}=1$$

渐近线：

$$y=\pm\frac43x$$

## 6. 离心率如何区分圆锥曲线？

### 离心率定义

$$e=\frac ca$$

其中 $c$ 是焦点到中心的距离，$a$ 是长半轴或实半轴。

### 区分

| 曲线 | 离心率 |
| --- | --- |
| 圆 | $e=0$ |
| 椭圆 | $0<e<1$ |
| 抛物线 | $e=1$ |
| 双曲线 | $e>1$ |

### 直观理解

- $e$ 越接近 0，椭圆越接近圆；
- $e=1$ 时，椭圆退化为抛物线；
- $e>1$ 时，曲线变成双曲线。

### 统一定义

圆锥曲线可以统一定义为：到焦点距离与到准线距离之比为常数 $e$ 的点的轨迹：

$$\frac{PF}{Pl}=e$$

- $e=1$：抛物线；
- $0<e<1$：椭圆；
- $e>1$：双曲线。

## 7. 如何通过判别式判断圆锥曲线的类型？

### 一般二次方程

$$Ax^2+Bxy+Cy^2+Dx+Ey+F=0$$

### 判别式

$$\boxed{\Delta=B^2-4AC}$$

### 判断规则

| 判别式 | 曲线类型 |
| --- | --- |
| $\Delta<0$ | 椭圆（或圆） |
| $\Delta=0$ | 抛物线 |
| $\Delta>0$ | 双曲线 |

### 注意

- 若 $A=C$ 且 $B=0$，且 $\Delta<0$，则是圆；
- 判别式只判断类型，不判断退化情况；
- 退化情况可能是点、直线或空集。

### 例子

$$x^2+4y^2-2x+8y+1=0$$

$$A=1,\quad B=0,\quad C=4$$

$$\Delta=0^2-4\cdot1\cdot4=-16<0$$

所以是椭圆。

$$x^2-y^2+2x-4y=0$$

$$A=1,\quad B=0,\quad C=-1$$

$$\Delta=0-4\cdot1\cdot(-1)=4>0$$

所以是双曲线。

# 二、发散性提问详解

## 1. 为什么圆锥曲线可以由平面截圆锥得到？这四种曲线有什么统一的几何性质？

### 为什么叫圆锥曲线

用一个平面去截一个双圆锥面，根据平面与圆锥轴线的夹角不同，交线可以是圆、椭圆、抛物线或双曲线。

### 截取方式

| 截平面与轴夹角 | 曲线 |
| --- | --- |
| 垂直于轴 | 圆 |
| 与轴夹角大于半顶角 | 椭圆 |
| 平行于母线 | 抛物线 |
| 与轴夹角小于半顶角 | 双曲线 |

### 统一几何性质

- 都是二次曲线，方程都是二次的；
- 都可以用“到焦点距离与到准线距离之比为 $e$”统一描述；
- 离心率 $e$ 决定了曲线类型。

### 统一极坐标方程

在极坐标中，圆锥曲线有统一方程：

$$r=\frac{ed}{1+e\cos\theta}$$

其中 $e$ 是离心率，$d$ 是焦点到准线的距离。

### 结论

圆锥曲线是平面截圆锥面的交线，具有统一的焦点-准线定义和极坐标方程。

## 2. 椭圆和双曲线的定义中，常数 $2a$ 的几何意义是什么？为什么必须 $2a<2c$（椭圆）或 $2a<2c$（双曲线）？

### 椭圆

定义：

$$PF_1+PF_2=2a$$

**几何意义**：$2a$ 是长轴的长度。

**为什么 $2a>2c$**：

- 若 $2a<2c$，即 $a<c$，则不存在满足条件的点，因为三角形两边之和大于第三边要求 $PF_1+PF_2\ge F_1F_2=2c$；
- 当 $2a=2c$ 时，轨迹退化为线段 $F_1F_2$；
- 所以椭圆要求 $2a>2c$，即 $a>c$。

### 双曲线

定义：

$$|PF_1-PF_2|=2a$$

**几何意义**：$2a$ 是实轴的长度。

**为什么 $2a<2c$**：

- 三角形两边之差小于第三边，所以 $|PF_1-PF_2|<F_1F_2=2c$；
- 即 $2a<2c$，即 $a<c$；
- 若 $a=c$，轨迹退化为两条射线；
- 若 $a>c$，无解。

### 结论

- 椭圆：$a>c$，所以 $a^2=b^2+c^2$；
- 双曲线：$a<c$，所以 $c^2=a^2+b^2$。

## 3. 抛物线、椭圆、双曲线在物理学中分别对应什么运动？例如抛体运动、行星轨道、散射轨道。

### 抛物线

- 抛体运动：忽略空气阻力，物体在重力下的轨迹是抛物线；
- 例子：炮弹、篮球投篮。

### 椭圆

- 行星轨道：开普勒第一定律，行星绕太阳的轨道是椭圆，太阳在其中一个焦点上；
- 例子：地球绕太阳、月球绕地球。

### 双曲线

- 散射轨道：带电粒子在库仑场中的散射轨道是双曲线；
- 例子：α粒子散射（卢瑟福实验）；
- 彗星轨道：某些彗星以双曲线轨道飞过太阳系。

### 统一

- 万有引力或库仑力下，轨道由能量和角动量决定：
  - 能量 $<0$：椭圆；
  - 能量 $=0$：抛物线；
  - 能量 $>0$：双曲线。

### 结论

圆锥曲线是中心力场中运动轨迹的自然分类。

## 4. 在工程中，椭圆、抛物线、双曲线如何用于设计桥梁、天线、光学仪器？

### 椭圆

- 椭圆拱桥；
- 椭圆齿轮；
- 椭圆轨道。

### 抛物线

- 抛物面天线：卫星天线、雷达；
- 抛物线拱桥；
- 车灯反射镜：把点光源发出的光反射成平行光。

### 双曲线

- 双曲面冷却塔；
- 双曲线齿轮；
- 双曲面建筑。

### 光学仪器

- 抛物面镜：平行光聚焦于焦点；
- 椭球镜：从一个焦点发出的光聚焦到另一个焦点；
- 双曲面镜：用于反射望远镜。

### 结论

圆锥曲线在工程和光学中有广泛的应用，源于它们独特的反射性质。

## 5. 在计算机图形学中，圆锥曲线如何用于绘制曲线和曲面？

### 绘制曲线

- 椭圆、抛物线、双曲线可以用参数方程绘制；
- 用极坐标方程绘制；
- 用二次曲线算法（如 Bresenham 算法）绘制。

### 绘制曲面

- 旋转椭圆得到椭球面；
- 旋转抛物线得到抛物面；
- 旋转双曲线得到双曲面。

### 应用

- 3D 建模；
- 计算机辅助设计（CAD）；
- 游戏引擎中的曲面渲染。

### 例子

抛物面天线模型：

$$z=\frac{x^2+y^2}{4p}$$

### 结论

圆锥曲线是计算机图形学中曲线和曲面建模的基本元素。

## 6. 圆锥曲线与二次型、矩阵有什么关系？如何用线性代数分类圆锥曲线？

### 二次型

一般二次方程：

$$Ax^2+Bxy+Cy^2+Dx+Ey+F=0$$

二次部分可以写成矩阵形式：

$$\begin{pmatrix}x&y\end{pmatrix}
\begin{pmatrix}A&B/2\\B/2&C\end{pmatrix}
\begin{pmatrix}x\\y\end{pmatrix}$$

### 矩阵

$$M=\begin{pmatrix}A&B/2\\B/2&C\end{pmatrix}$$

### 分类

- 行列式 $\det M=AC-B^2/4$；
- 若 $\det M>0$：椭圆；
- 若 $\det M=0$：抛物线；
- 若 $\det M<0$：双曲线。

### 特征值

- 两个特征值同号：椭圆；
- 两个特征值异号：双曲线；
- 一个特征值为零：抛物线。

### 结论

线性代数提供了分类圆锥曲线的系统方法，二次型矩阵的特征值决定曲线类型。

## 7. 在极坐标中，圆锥曲线的方程有什么统一形式？为什么极坐标特别适合描述行星轨道？

### 统一极坐标方程

以焦点为极点，准线垂直于极轴：

$$\boxed{r=\frac{ed}{1+e\cos\theta}}$$

其中：

- $e$：离心率；
- $d$：焦点到准线的距离。

### 不同类型

- $e=0$：圆；
- $0<e<1$：椭圆；
- $e=1$：抛物线；
- $e>1$：双曲线。

### 为什么适合行星轨道

- 太阳位于椭圆的一个焦点；
- 极坐标以太阳为极点，直接给出 $r$ 和 $\theta$；
- 开普勒第二定律的面积速度用极坐标表示非常简洁：

$$\frac{dA}{dt}=\frac12 r^2\frac{d\theta}{dt}$$

- 轨道方程简单，便于计算。

### 结论

极坐标统一描述了所有圆锥曲线，特别适合中心力场中的运动问题。

# 三、总结

1. 抛物线定义：到焦点和准线距离相等；标准方程 $y^2=4px$ 等。
2. 椭圆定义：到两焦点距离之和为 $2a$；标准方程 $\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$。
3. 双曲线定义：到两焦点距离之差的绝对值为 $2a$；标准方程 $\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$。
4. 椭圆 $a^2=b^2+c^2$；双曲线 $c^2=a^2+b^2$。
5. 双曲线渐近线 $y=\pm\frac ba x$（或 $y=\pm\frac ab x$）。
6. 离心率区分圆锥曲线：圆 $e=0$，椭圆 $0<e<1$，抛物线 $e=1$，双曲线 $e>1$。
7. 判别式 $\Delta=B^2-4AC$ 判断类型。
8. 圆锥曲线在物理、工程、计算机图形学、线性代数中广泛应用。
9. 极坐标统一方程 $r=\frac{ed}{1+e\cos\theta}$ 特别适合行星轨道。

这些内容把圆锥曲线从“几何曲线”提升为“物理、工程、数学的统一工具”，为极坐标中的圆锥曲线和后续向量分析奠定了基础。

# 第9章 极坐标与圆锥曲线 · 9.5 极坐标中的圆锥曲线

> 上一节我们用直角坐标研究了抛物线、椭圆和双曲线。本节要把它们统一到极坐标中：**所有圆锥曲线都可以用一个统一的极坐标方程表示**。
这个统一形式特别适合描述行星轨道，因为太阳位于椭圆的一个焦点上，而极坐标正好以焦点为极点。
本节核心：离心率、统一极坐标方程、直线和圆的极坐标方程。
>

## 9.5.1 离心率

### 圆锥曲线的统一定义

圆锥曲线可以统一定义为：平面内到**焦点** $F$ 的距离与到**准线** $l$ 的距离之比为常数 $e$ 的点的轨迹。

$$\boxed{
\frac{PF}{Pl}=e
}$$

其中：

- $F$：焦点；
- $l$：准线（不经过焦点）；
- $e$：**离心率**，正常数。

### 离心率与曲线类型

| 离心率 $e$ | 曲线类型 |
| --- | --- |
| $e=0$ | 圆 |
| $0<e<1$ | 椭圆 |
| $e=1$ | 抛物线 |
| $e>1$ | 双曲线 |

### 关键理解

- 离心率刻画曲线“偏离圆”的程度；
- 准线是确定圆锥曲线形状的重要参考线；
- 焦点和准线一一对应。

## 9.5.2 极方程

### 统一极坐标方程

以**焦点**为极点，**准线**垂直于极轴，且位于极点的右侧。

设焦点到准线的距离为 $d$（$d>0$），离心率为 $e$。

圆锥曲线上点 $P(r,\theta)$ 满足：

$$PF=r$$

$$Pl=d+r\cos\theta$$

由定义：

$$\frac{r}{d+r\cos\theta}=e$$

解出 $r$：

$$r=e(d+r\cos\theta)$$

$$r=ed+er\cos\theta$$

$$r(1-e\cos\theta)=ed$$

所以：

$$\boxed{
r=\frac{ed}{1-e\cos\theta}
}$$

### 四种常见形式

根据准线位置和方向，有四种形式：

| 方程 | 准线位置 | 焦点方向 |
| --- | --- | --- |
| $r=\dfrac{ed}{1-e\cos\theta}$ | $x=d$ | 右焦点 |
| $r=\dfrac{ed}{1+e\cos\theta}$ | $x=-d$ | 左焦点 |
| $r=\dfrac{ed}{1-e\sin\theta}$ | $y=d$ | 上焦点 |
| $r=\dfrac{ed}{1+e\sin\theta}$ | $y=-d$ | 下焦点 |

### 关键参数

- $e$：离心率；
- $d$：焦点到准线的距离；
- $ed$：常数，决定曲线大小。

### 例1：$r=\dfrac{2}{1-\cos\theta}$

与标准形式 $r=\dfrac{ed}{1-e\cos\theta}$ 比较：

$$e=1,\quad ed=2\implies d=2$$

因为 $e=1$，这是**抛物线**。

准线：$x=2$；
焦点：极点。

### 例2：$r=\dfrac{6}{2+\cos\theta}$

先化为标准形式，分子分母同除以 2：

$$r=\frac{3}{1+\frac12\cos\theta}$$

与 $r=\dfrac{ed}{1+e\cos\theta}$ 比较：

$$e=\frac12,\quad ed=3\implies d=6$$

因为 $0<e<1$，这是**椭圆**。

准线：$x=-6$。

### 例3：$r=\dfrac{8}{3-2\sin\theta}$

分子分母同除以 3：

$$r=\frac{8/3}{1-\frac23\sin\theta}$$

与 $r=\dfrac{ed}{1-e\sin\theta}$ 比较：

$$e=\frac23,\quad ed=\frac83\implies d=4$$

因为 $0<e<1$，这是**椭圆**。

准线：$y=4$。

### 例4：$r=\dfrac{4}{1+2\cos\theta}$

与 $r=\dfrac{ed}{1+e\cos\theta}$ 比较：

$$e=2,\quad ed=4\implies d=2$$

因为 $e>1$，这是**双曲线**。

准线：$x=-2$。

### 例5：$r=\dfrac{5}{1+\cos\theta}$

$$e=1,\quad ed=5\implies d=5$$

抛物线，准线 $x=-5$。

## 9.5.3 直线

### 过极点的直线

若直线过极点，方程为：

$$\boxed{\theta=\alpha}$$

其中 $\alpha$ 是直线与极轴的夹角。

**例子**：

$$\theta=\frac{\pi}{4}$$

表示从极点出发、倾角为 $\pi/4$ 的射线。

### 不过极点的直线

设直线到极点的距离为 $d$，法线方向与极轴夹角为 $\alpha$。

直线方程：

$$\boxed{r\cos(\theta-\alpha)=d}$$

**特殊情况**：

- 若直线垂直于极轴，且距极点 $d$：

$$r\cos\theta=d\implies r=d\sec\theta$$

- 若直线平行于极轴，且距极点 $d$：

$$r\sin\theta=d\implies r=d\csc\theta$$

**例子**：

$$r=3\sec\theta$$

表示直线 $x=3$。

$$r=2\csc\theta$$

表示直线 $y=2$。

## 9.5.4 圆

### 圆心在极点的圆

$$\boxed{r=a}$$

半径 $a$，圆心在极点。

### 圆心在极轴上，过极点的圆

$$\boxed{r=2a\cos\theta}$$

圆心在 $(a,0)$，半径 $a$。

**推导**：
圆心在 $(a,0)$，半径 $a$ 的直角坐标方程：

$$(x-a)^2+y^2=a^2$$

$$x^2+y^2=2ax$$

用 $x=r\cos\theta$，$r^2=x^2+y^2$：

$$r^2=2ar\cos\theta\implies r=2a\cos\theta$$

### 圆心在 $\theta=\pi/2$ 轴上，过极点的圆

$$\boxed{r=2a\sin\theta}$$

圆心在 $(0,a)$，半径 $a$。

### 一般位置的圆

圆心在 $(r_0,\theta_0)$，半径 $a$：

$$r^2-2rr_0\cos(\theta-\theta_0)+r_0^2=a^2$$

### 例6：$r=4\cos\theta$

$$r=2a\cos\theta\implies 2a=4\implies a=2$$

圆心 $(2,0)$，半径 2。

### 例7：$r=6\sin\theta$

$$r=2a\sin\theta\implies 2a=6\implies a=3$$

圆心 $(0,3)$，半径 3。

## 9.5.5 圆锥曲线的极坐标与直角坐标互化

### 从极坐标到直角坐标

若 $r=\dfrac{ed}{1-e\cos\theta}$，则：

$$r(1-e\cos\theta)=ed$$

$$r-ed\cos\theta=ed$$

$$r=e(d+x)$$

$$r^2=e^2(d+x)^2$$

$$x^2+y^2=e^2(d+x)^2$$

这是直角坐标下的圆锥曲线方程。

### 从直角坐标到极坐标

以焦点为极点，准线垂直于极轴，可以化为标准形式。

### 例8：化 $r=\dfrac{2}{1-\cos\theta}$ 为直角坐标方程

$$r(1-\cos\theta)=2$$

$$r-r\cos\theta=2$$

$$r=2+x$$

$$r^2=(2+x)^2$$

$$x^2+y^2=(2+x)^2$$

$$x^2+y^2=x^2+4x+4$$

$$y^2=4x+4$$

$$y^2=4(x+1)$$

这是顶点在 $(-1,0)$、焦点在原点的抛物线。

## 本节易错点总结

1. 极坐标圆锥曲线方程的标准形式是 $r=\dfrac{ed}{1-e\cos\theta}$，注意分母中的符号。
2. 根据 $e$ 判断曲线类型：$e=1$ 抛物线，$0<e<1$ 椭圆，$e>1$ 双曲线。
3. 准线位置与分母符号有关：分母 $1-e\cos\theta$ 对应准线 $x=d$；分母 $1+e\cos\theta$ 对应准线 $x=-d$。
4. 圆是 $e=0$ 的圆锥曲线，但极坐标中圆有独立形式。
5. 过极点的直线是 $\theta=\alpha$，不过极点的直线是 $r\cos(\theta-\alpha)=d$。
6. 圆心在极轴的圆是 $r=2a\cos\theta$，圆心在 $y$ 轴的圆是 $r=2a\sin\theta$。
7. 化为标准形式时，分子分母要同除以常数。

## 1. 写出圆锥曲线的统一极坐标方程

### 统一极坐标方程

以**焦点**为极点，**准线**垂直于极轴，且位于极点右侧：

$$\boxed{
r=\frac{ed}{1-e\cos\theta}
}$$

其中：

- $e$：离心率（正常数）；
- $d$：焦点到准线的距离（$d>0$）；
- $ed$：常数，决定曲线大小。

### 四种常见形式

| 方程 | 准线位置 | 焦点方向 |
| --- | --- | --- |
| $r=\dfrac{ed}{1-e\cos\theta}$ | $x=d$ | 右焦点 |
| $r=\dfrac{ed}{1+e\cos\theta}$ | $x=-d$ | 左焦点 |
| $r=\dfrac{ed}{1-e\sin\theta}$ | $y=d$ | 上焦点 |
| $r=\dfrac{ed}{1+e\sin\theta}$ | $y=-d$ | 下焦点 |

### 关键理解

- 所有圆锥曲线都可以用这一个统一形式表示；
- 离心率 $e$ 决定曲线类型；
- 准线位置决定分母中的符号和三角函数。

### 例子

$$r=\frac{2}{1-\cos\theta}$$

与标准形式比较：$e=1$，$ed=2\implies d=2$。

这是抛物线，准线 $x=2$。

## 2. 如何根据极坐标方程判断圆锥曲线的类型？

### 步骤

1. **化为标准形式**： $r=\frac{ed}{1\pm e\cos\theta}\quad\text{或}\quad r=\frac{ed}{1\pm e\sin\theta}$
2. **读出离心率 $e$**；
3. **根据 $e$ 判断类型**：

| $e$ | 曲线类型 |
| --- | --- |
| $e=0$ | 圆 |
| $0<e<1$ | 椭圆 |
| $e=1$ | 抛物线 |
| $e>1$ | 双曲线 |

### 例子

**例1**：

$$r=\frac{6}{2+\cos\theta}$$

分子分母同除以 2：

$$r=\frac{3}{1+\frac12\cos\theta}$$

与 $r=\dfrac{ed}{1+e\cos\theta}$ 比较：

$$e=\frac12,\quad ed=3\implies d=6$$

因为 $0<e<1$，这是**椭圆**。

**例2**：

$$r=\frac{4}{1+2\cos\theta}$$

$$e=2,\quad ed=4\implies d=2$$

因为 $e>1$，这是**双曲线**。

**例3**：

$$r=\frac{5}{1+\cos\theta}$$

$$e=1,\quad ed=5\implies d=5$$

这是**抛物线**。

### 关键点

- 必须先化为标准形式，分子分母同除以常数；
- 分母中的符号决定准线方向；
- 离心率 $e$ 是判断依据。

## 3. 写出圆 $r=2a\cos\theta$ 和 $r=2a\sin\theta$ 的圆心和半径

### $r=2a\cos\theta$

**圆心**：$(a,0)$（极轴上）；
**半径**：$a$。

**推导**：

$$r=2a\cos\theta\implies r^2=2ar\cos\theta$$

$$x^2+y^2=2ax$$

$$(x-a)^2+y^2=a^2$$

圆心 $(a,0)$，半径 $a$。

### $r=2a\sin\theta$

**圆心**：$(0,a)$（$\theta=\pi/2$ 方向上）；
**半径**：$a$。

**推导**：

$$r=2a\sin\theta\implies r^2=2ar\sin\theta$$

$$x^2+y^2=2ay$$

$$x^2+(y-a)^2=a^2$$

圆心 $(0,a)$，半径 $a$。

### 对比

| 方程 | 圆心 | 半径 |
| --- | --- | --- |
| $r=2a\cos\theta$ | $(a,0)$ | $a$ |
| $r=2a\sin\theta$ | $(0,a)$ | $a$ |
| $r=a$ | 极点 | $a$ |

### 例子

$$r=4\cos\theta\implies a=2$$

圆心 $(2,0)$，半径 2。

$$r=6\sin\theta\implies a=3$$

圆心 $(0,3)$，半径 3。

## 4. 写出过极点和不过极点的直线极坐标方程

### 过极点的直线

方程为：

$$\boxed{\theta=\alpha}$$

其中 $\alpha$ 是直线与极轴的夹角。

**例子**：

$$\theta=\frac{\pi}{4}$$

表示从极点出发、倾角为 $\pi/4$ 的射线。

### 不过极点的直线

设直线到极点的距离为 $d$，法线方向与极轴夹角为 $\alpha$。

方程为：

$$\boxed{r\cos(\theta-\alpha)=d}$$

**特殊情况**：

**垂直于极轴**，距极点 $d$：

$$r\cos\theta=d\implies r=d\sec\theta$$

**平行于极轴**，距极点 $d$：

$$r\sin\theta=d\implies r=d\csc\theta$$

### 例子

$$r=3\sec\theta\implies x=3$$

竖直线。

$$r=2\csc\theta\implies y=2$$

水平线。

### 关键点

- 过极点的直线是射线或直线，方程为 $\theta=\alpha$；
- 不过极点的直线用 $r\cos(\theta-\alpha)=d$；
- 特殊方向可以用 $\sec$ 或 $\csc$ 简化。

## 5. 把 $r=\dfrac{6}{2+\cos\theta}$ 化为标准形式，并判断曲线类型

### 化为标准形式

分子分母同除以 2：

$$r=\frac{3}{1+\frac12\cos\theta}$$

与 $r=\dfrac{ed}{1+e\cos\theta}$ 比较：

$$e=\frac12,\quad ed=3\implies d=6$$

### 判断曲线类型

因为：

$$0<e=\frac12<1$$

所以这是**椭圆**。

### 准线

分母为 $1+e\cos\theta$，对应准线：

$$x=-d=-6$$

焦点在极点。

### 结论

$$\boxed{\text{椭圆，离心率 }e=\frac12,\text{ 准线 }x=-6}$$

## 6. 把 $r=\dfrac{2}{1-\cos\theta}$ 化为直角坐标方程

### 从极坐标出发

$$r=\frac{2}{1-\cos\theta}$$

$$r(1-\cos\theta)=2$$

$$r-r\cos\theta=2$$

用 $r\cos\theta=x$：

$$r-x=2\implies r=x+2$$

### 平方

$$r^2=(x+2)^2$$

用 $r^2=x^2+y^2$：

$$x^2+y^2=(x+2)^2$$

$$x^2+y^2=x^2+4x+4$$

$$y^2=4x+4$$

$$y^2=4(x+1)$$

### 结论

$$\boxed{y^2=4(x+1)}$$

这是顶点在 $(-1,0)$、焦点在原点的抛物线。

### 验证

与标准形式 $y^2=4p(x-h)$ 比较：

$$4p=4\implies p=1$$

顶点 $(-1,0)$，焦点 $(0,0)$，准线 $x=-2$。

与极坐标形式一致。

## 7. 离心率 $e$ 如何区分圆、椭圆、抛物线和双曲线？

### 离心率定义

$$e=\frac ca$$

其中 $c$ 是焦点到中心的距离，$a$ 是长半轴或实半轴。

### 区分表

| 曲线 | 离心率 |
| --- | --- |
| 圆 | $e=0$ |
| 椭圆 | $0<e<1$ |
| 抛物线 | $e=1$ |
| 双曲线 | $e>1$ |

### 直观理解

- $e$ 越接近 0，椭圆越接近圆；
- $e=1$ 时，椭圆退化为抛物线；
- $e>1$ 时，曲线变成双曲线。

### 统一定义

圆锥曲线可以统一定义为：到焦点距离与到准线距离之比为常数 $e$ 的点的轨迹：

$$\frac{PF}{Pl}=e$$

- $e=1$：抛物线；
- $0<e<1$：椭圆；
- $e>1$：双曲线。

### 在极坐标方程中

$$r=\frac{ed}{1-e\cos\theta}$$

分母中的 $e$ 直接决定曲线类型。

# 二、发散性提问详解

## 1. 为什么极坐标方程 $r=\dfrac{ed}{1-e\cos\theta}$ 能统一描述所有圆锥曲线？它的几何意义是什么？

### 几何意义

以焦点为极点，准线垂直于极轴。圆锥曲线上的点 $P(r,\theta)$ 满足：

$$\frac{PF}{Pl}=e$$

其中：

- $PF=r$（焦点到点的距离）；
- $Pl=d+r\cos\theta$（点到准线的距离）。

代入定义：

$$\frac{r}{d+r\cos\theta}=e$$

解出 $r$：

$$r=\frac{ed}{1-e\cos\theta}$$

### 为什么能统一描述

- 方程只依赖于两个参数：离心率 $e$ 和焦点到准线的距离 $d$；
- 不同的 $e$ 对应不同的曲线类型；
- 所有圆锥曲线都满足同一个焦点-准线定义。

### 几何直观

- $e$ 控制曲线“偏离圆”的程度；
- $d$ 控制曲线的大小；
- 分母中的 $1-e\cos\theta$ 反映了点到准线距离与角度 $\theta$ 的关系。

### 结论

这个方程是圆锥曲线焦点-准线定义在极坐标下的直接表达，统一了所有圆锥曲线。

## 2. 离心率 $e$ 在极坐标方程中扮演什么角色？当 $e=0$ 时，方程变成什么？

### 离心率 $e$ 的角色

- $e$ 决定曲线类型；
- $e$ 决定曲线的形状；
- $e$ 越大，曲线越“张开”。

### 当 $e=0$ 时

$$r=\frac{ed}{1-e\cos\theta}$$

代入 $e=0$：

$$r=\frac{0\cdot d}{1-0}=\frac{0}{1}=0$$

这似乎不对。实际上，当 $e\to0$ 时，$d\to\infty$ 但 $ed$ 保持有限。

令 $ed=a$（常数），则：

$$r=\frac{a}{1-0}=a$$

这是**圆**。

### 更准确的极限

当 $e\to0$ 且 $ed=a$ 时：

$$r=\frac{a}{1-e\cos\theta}\to a$$

所以圆是 $e=0$ 的圆锥曲线，半径为 $a$。

### 结论

- $e=0$：圆；
- $e$ 越大，曲线越扁或越张开；
- 离心率是圆锥曲线的核心参数。

## 3. 在行星轨道中，为什么用极坐标比直角坐标更方便？开普勒定律如何用极坐标表示？

### 为什么用极坐标

- 太阳位于椭圆的一个焦点；
- 极坐标以焦点为极点，直接给出 $r$ 和 $\theta$；
- 轨道方程简单；
- 面积速度、角动量等物理量用极坐标表示自然。

### 开普勒第一定律（椭圆定律）

行星轨道是椭圆，太阳在一个焦点上：

$$r=\frac{p}{1+e\cos\theta}$$

其中 $p=a(1-e^2)$，$e$ 是离心率。

### 开普勒第二定律（等面积定律）

行星与太阳连线在相等时间内扫过相等面积：

$$\frac{dA}{dt}=\frac12 r^2\frac{d\theta}{dt}=\text{常数}$$

用极坐标面积公式：

$$A=\int_{\theta_1}^{\theta_2}\frac12 r^2\,d\theta$$

### 开普勒第三定律（时间-距离定律）

$$T^2=\frac{4\pi^2}{GM}a^3$$

其中 $a$ 是长半轴。

### 结论

极坐标是描述行星轨道的自然语言，开普勒定律在极坐标下形式简洁。

## 4. 极坐标中的直线和圆方程与直角坐标中的方程有什么联系？如何互化？

### 直线的互化

**极坐标**：

$$r\cos(\theta-\alpha)=d$$

**直角坐标**：

$$x\cos\alpha+y\sin\alpha=d$$

**互化**：

- 代入 $x=r\cos\theta$，$y=r\sin\theta$；
- 展开 $r\cos(\theta-\alpha)=r\cos\theta\cos\alpha+r\sin\theta\sin\alpha$。

### 圆的互化

**极坐标**：

$$r=2a\cos\theta$$

**直角坐标**：

$$(x-a)^2+y^2=a^2$$

**互化**：

- 两边乘以 $r$：$r^2=2ar\cos\theta$；
- 代入 $r^2=x^2+y^2$，$r\cos\theta=x$。

### 总结

| 极坐标 | 直角坐标 |
| --- | --- |
| $r=a$ | $x^2+y^2=a^2$ |
| $r=2a\cos\theta$ | $(x-a)^2+y^2=a^2$ |
| $r=2a\sin\theta$ | $x^2+(y-a)^2=a^2$ |
| $r\cos(\theta-\alpha)=d$ | $x\cos\alpha+y\sin\alpha=d$ |
| $\theta=\alpha$ | $y=(\tan\alpha)x$ |

### 结论

极坐标和直角坐标可以通过 $x=r\cos\theta$，$y=r\sin\theta$ 互化。选择哪个取决于图形和问题。

## 5. 在工程中，极坐标圆锥曲线如何用于天线设计、轨道计算、光学仪器？

### 天线设计

- 抛物面天线：平行光聚焦于焦点；
- 卡塞格伦天线：利用双曲面和抛物面组合；
- 极坐标方程用于设计反射面形状。

### 轨道计算

- 卫星轨道、行星轨道用极坐标描述；
- 开普勒定律用极坐标表示；
- 轨道机动、交会对接计算。

### 光学仪器

- 抛物面镜：平行光聚焦；
- 椭球镜：从一个焦点聚焦到另一个焦点；
- 双曲面镜：用于反射望远镜。

### 例子

抛物面天线：

$$r=\frac{2p}{1-\cos\theta}$$

用于卫星通信。

### 结论

圆锥曲线的极坐标方程在工程中用于设计天线、计算轨道、制造光学仪器。

## 6. 圆锥曲线的极坐标方程与直角坐标方程在形式上有何不同？各有什么优缺点？

### 极坐标方程

**形式**：

$$r=\frac{ed}{1-e\cos\theta}$$

**优点**：

- 统一形式，一个方程描述所有圆锥曲线；
- 适合描述中心力场中的运动；
- 行星轨道方程简单；
- 面积和弧长计算方便。

**缺点**：

- 不唯一；
- 微积分运算复杂；
- 直线、多项式方程复杂。

### 直角坐标方程

**形式**：

$$Ax^2+Bxy+Cy^2+Dx+Ey+F=0$$

**优点**：

- 唯一表示；
- 适合代数运算；
- 微积分运算方便；
- 适合直线和多项式。

**缺点**：

- 不同圆锥曲线需要不同方程；
- 旋转和一般位置需要坐标变换；
- 行星轨道方程复杂。

### 选择原则

根据问题的对称性和物理背景选择。

### 结论

两种坐标系互补，极坐标适合旋转对称和中心力场，直角坐标适合代数和一般分析。

## 7. 在计算机图形学中，如何用极坐标方程生成圆锥曲线？

### 生成椭圆

**极坐标方程**：

$$r=\frac{ed}{1-e\cos\theta},\quad 0<e<1$$

**步骤**：

1. 对 $\theta$ 从 0 到 $2\pi$ 采样；
2. 计算 $r$；
3. 转换为直角坐标：

$$x=r\cos\theta,\quad y=r\sin\theta$$

4. 连接点形成椭圆。

### 生成抛物线

$$r=\frac{d}{1-\cos\theta}$$

类似步骤。

### 生成双曲线

$$r=\frac{ed}{1-e\cos\theta},\quad e>1$$

注意双曲线有两支，需要分别处理。

### 生成圆

$$r=a$$

直接生成圆。

### 计算机图形学中的应用

- 3D 建模中的旋转曲面；
- 游戏引擎中的轨道运动；
- CAD 中的曲线设计；
- 虚拟现实中的场景生成。

### 结论

极坐标方程是计算机图形学生成圆锥曲线的自然工具，特别适合旋转对称图形。

# 三、总结

1. 圆锥曲线统一极坐标方程：$r=\dfrac{ed}{1-e\cos\theta}$。
2. 根据 $e$ 判断类型：$e=0$ 圆，$0<e<1$ 椭圆，$e=1$ 抛物线，$e>1$ 双曲线。
3. 圆 $r=2a\cos\theta$ 圆心 $(a,0)$，半径 $a$；$r=2a\sin\theta$ 圆心 $(0,a)$，半径 $a$。
4. 过极点直线 $\theta=\alpha$；不过极点直线 $r\cos(\theta-\alpha)=d$。
5. 极坐标与直角坐标通过 $x=r\cos\theta$，$y=r\sin\theta$ 互化。
6. 极坐标适合行星轨道、天线设计、光学仪器。
7. 极坐标与直角坐标互补，选择取决于问题性质。

这些内容把圆锥曲线的极坐标表示从“方程形式”提升为“物理和工程应用的核心工具”，为参数方程和摆线奠定了基础。

# 第9章 极坐标与圆锥曲线 · 9.6 圆锥曲线与参数方程，摆线

> 前面几节我们学习了圆锥曲线的直角坐标方程和极坐标方程。本节要把圆锥曲线与**参数方程**联系起来，并介绍一条在数学和物理中都非常重要的曲线：**摆线**。
参数方程让我们可以更灵活地描述曲线，尤其是那些不容易用 $y=f(x)$ 或 $r=f(\theta)$ 表示的曲线。
本节核心：抛物线与双曲线的参数方程、摆线的定义与参数方程、捷线与等时线。
>

## 9.6.1 抛物线与双曲线的参数方程

### 抛物线的参数方程

标准抛物线：

$$y^2=4px$$

一个常用的参数化：

$$\boxed{x=pt^2,\quad y=2pt,\quad -\infty<t<\infty}$$

**验证**：

$$y^2=(2pt)^2=4p^2t^2=4p(pt^2)=4px$$

正确。

**参数 $t$ 的几何意义**：
$t$ 与抛物线上点与顶点连线斜率有关。

**例子**：
$y^2=8x$，$4p=8\implies p=2$。

参数方程：

$$x=2t^2,\quad y=4t$$

### 双曲线的参数方程

标准双曲线：

$$\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$$

一个常用的参数化：

$$\boxed{x=a\sec t,\quad y=b\tan t,\quad -\frac{\pi}{2}<t<\frac{\pi}{2}\text{ 或 }\frac{\pi}{2}<t<\frac{3\pi}{2}}$$

**验证**：

$$\frac{x^2}{a^2}-\frac{y^2}{b^2}
=\sec^2t-\tan^2t=1$$

正确。

**另一种参数化**（用双曲函数）：

$$x=a\cosh t,\quad y=b\sinh t,\quad -\infty<t<\infty$$

**验证**：

$$\cosh^2t-\sinh^2t=1$$

**例子**：

$$\frac{x^2}{9}-\frac{y^2}{16}=1$$

参数方程：

$$x=3\sec t,\quad y=4\tan t$$

### 椭圆的参数方程（回顾）

标准椭圆：

$$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$$

参数方程：

$$\boxed{x=a\cos t,\quad y=b\sin t,\quad 0\le t\le2\pi}$$

**验证**：

$$\frac{x^2}{a^2}+\frac{y^2}{b^2}=\cos^2t+\sin^2t=1$$

**参数 $t$ 的几何意义**：
$t$ 是离心角，不是椭圆上点的极角。

### 圆的参数方程

$$x=a\cos t,\quad y=a\sin t,\quad 0\le t\le2\pi$$

## 9.6.2 摆线

### 定义

**摆线**是圆周上一定点在圆沿直线滚动时形成的轨迹。

**描述**：

- 一个半径为 $a$ 的圆沿 $x$ 轴滚动；
- 圆上固定一点 $P$ 的轨迹就是摆线。

### 参数方程

设圆从原点开始滚动，$t$ 是圆滚过的角度。

圆心坐标：

$$(a t,a)$$

点 $P$ 的坐标：

$$\boxed{x=a(t-\sin t),\quad y=a(1-\cos t),\quad -\infty<t<\infty}$$

**推导**：

- 圆心在 $(at,a)$；
- $P$ 相对于圆心的坐标：$(-a\sin t,-a\cos t)$；
- 所以：

$$x=at-a\sin t=a(t-\sin t)$$

$$y=a-a\cos t=a(1-\cos t)$$

### 图形特征

- $y$ 的范围：$0\le y\le2a$；
- $x$ 随 $t$ 增加而增加；
- 每个周期 $2\pi$ 对应一个“拱”；
- 在 $t=0,2\pi,4\pi,\dots$ 处 $y=0$，曲线与 $x$ 轴接触；
- 在 $t=\pi,3\pi,\dots$ 处 $y=2a$，曲线达到最高点。

### 例1：摆线的一拱

$t$ 从 0 到 $2\pi$：

$$x=a(t-\sin t),\quad y=a(1-\cos t)$$

**关键点**：

| $t$ | $x$ | $y$ |
| --- | --- | --- |
| $0$ | $0$ | $0$ |
| $\pi/2$ | $a(\pi/2-1)$ | $a$ |
| $\pi$ | $a\pi$ | $2a$ |
| $3\pi/2$ | $a(3\pi/2+1)$ | $a$ |
| $2\pi$ | $2a\pi$ | $0$ |

### 例2：摆线的弧长

一拱的弧长：

$$L=\int_0^{2\pi}\sqrt{\left(\frac{dx}{dt}\right)^2+\left(\frac{dy}{dt}\right)^2}\,dt$$

计算：

$$\frac{dx}{dt}=a(1-\cos t),\quad \frac{dy}{dt}=a\sin t$$

$$\left(\frac{dx}{dt}\right)^2+\left(\frac{dy}{dt}\right)^2
=a^2(1-\cos t)^2+a^2\sin^2t$$

$$=a^2(2-2\cos t)=4a^2\sin^2\frac t2$$

所以：

$$L=\int_0^{2\pi}2a\sin\frac t2\,dt
=2a\left[-2\cos\frac t2\right]_0^{2\pi}
=8a$$

**结论**：

$$\boxed{\text{摆线一拱的弧长}=8a}$$

### 例3：摆线一拱下的面积

$$A=\int_0^{2\pi}y\,dx=\int_0^{2\pi}a(1-\cos t)\cdot a(1-\cos t)\,dt$$

$$=a^2\int_0^{2\pi}(1-\cos t)^2\,dt$$

$$=a^2\int_0^{2\pi}(1-2\cos t+\cos^2t)\,dt$$

$$=a^2\left[2\pi-0+\pi\right]=3\pi a^2$$

**结论**：

$$\boxed{\text{摆线一拱下的面积}=3\pi a^2}$$

这是半径为 $a$ 的圆面积的三倍。

### 例4：摆线绕 $x$ 轴旋转的体积

$$V=\int_0^{2\pi}\pi y^2\,dx$$

$$=\pi a^3\int_0^{2\pi}(1-\cos t)^3\,dt$$

计算得：

$$V=5\pi^2a^3$$

## 9.6.3 捷线与等时线

### 捷线（最速降线）

**问题**：在重力作用下，一个质点从点 $A$ 滑到点 $B$（不在同一竖直线上），沿什么曲线下滑时间最短？

**答案**：摆线（倒置）。

**历史**：

- 1696 年约翰·伯努利提出；
- 牛顿、莱布尼茨、洛必达等解决；
- 是变分法的起源问题之一。

**结论**：
摆线是重力场中的最速降线。

### 等时线

**问题**：沿什么曲线下滑，质点到最低点的时间与起始位置无关？

**答案**：摆线。

**性质**：

- 摆线是等时曲线；
- 无论从摆线上哪一点开始下滑，到达最低点的时间相同；
- 这个时间等于：

$$T=\pi\sqrt{\frac ag}$$

**应用**：

- 摆钟设计；
- 惠更斯利用摆线的等时性设计精确摆钟。

### 摆线的其他性质

- **渐屈线**：摆线的渐屈线还是摆线；
- **旋转曲面**：摆线绕 $x$ 轴旋转得到摆线曲面；
- **物理应用**：最速降线、等时摆、光学。

## 9.6.4 其他参数曲线

### 内摆线

一个小圆在大圆内部滚动，小圆上一点的轨迹。

**参数方程**（大圆半径 $R$，小圆半径 $r$）：

$$x=(R-r)\cos t+r\cos\left(\frac{R-r}{r}t\right)$$

$$y=(R-r)\sin t-r\sin\left(\frac{R-r}{r}t\right)$$

### 外摆线

一个小圆在大圆外部滚动，小圆上一点的轨迹。

**参数方程**：

$$x=(R+r)\cos t-r\cos\left(\frac{R+r}{r}t\right)$$

$$y=(R+r)\sin t-r\sin\left(\frac{R+r}{r}t\right)$$

### 心形线

当 $R=r$ 时，外摆线退化为心形线。

### 星形线

当 $R=4r$ 时，内摆线退化为星形线：

$$x=a\cos^3t,\quad y=a\sin^3t$$

## 本节易错点总结

1. 抛物线参数方程 $x=pt^2$，$y=2pt$，注意 $p$ 的含义。
2. 双曲线参数方程用 $\sec$ 和 $\tan$，注意定义域。
3. 椭圆参数方程中 $t$ 是离心角，不是极角。
4. 摆线参数方程 $x=a(t-\sin t)$，$y=a(1-\cos t)$。
5. 摆线一拱弧长 $8a$，面积 $3\pi a^2$。
6. 摆线是最速降线和等时线。
7. 内摆线和外摆线的参数方程要区分。
8. 参数方程求导和积分要用链式法则。

# 一、主动回忆问题详解

## 1. 写出抛物线的参数方程

### 标准抛物线

$$y^2=4px$$

### 常用参数方程

$$\boxed{
x=pt^2,\quad y=2pt,\quad -\infty<t<\infty
}$$

### 验证

$$y^2=(2pt)^2=4p^2t^2=4p(pt^2)=4px$$

### 参数 $t$ 的意义

$t$ 与抛物线上点与顶点连线的斜率有关。
当 $t$ 从 $-\infty$ 到 $+\infty$ 变化时，点沿抛物线从下方经过顶点到上方。

### 例子

$$y^2=8x$$

与 $y^2=4px$ 比较，$4p=8\implies p=2$。

参数方程：

$$x=2t^2,\quad y=4t$$

## 2. 写出双曲线的参数方程

### 标准双曲线

$$\frac{x^2}{a^2}-\frac{y^2}{b^2}=1$$

### 参数方程（用 $\sec$ 和 $\tan$）

$$\boxed{
x=a\sec t,\quad y=b\tan t
}$$

其中：

$$-\frac{\pi}{2}<t<\frac{\pi}{2}\quad\text{或}\quad \frac{\pi}{2}<t<\frac{3\pi}{2}$$

### 验证

$$\frac{x^2}{a^2}-\frac{y^2}{b^2}
=\sec^2t-\tan^2t=1$$

### 另一种参数方程（用双曲函数）

$$\boxed{
x=a\cosh t,\quad y=b\sinh t,\quad -\infty<t<\infty
}$$

### 验证

$$\cosh^2t-\sinh^2t=1$$

### 例子

$$\frac{x^2}{9}-\frac{y^2}{16}=1$$

参数方程：

$$x=3\sec t,\quad y=4\tan t$$

## 3. 写出椭圆的参数方程

### 标准椭圆

$$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1$$

### 参数方程

$$\boxed{
x=a\cos t,\quad y=b\sin t,\quad 0\le t\le2\pi
}$$

### 验证

$$\frac{x^2}{a^2}+\frac{y^2}{b^2}
=\cos^2t+\sin^2t=1$$

### 参数 $t$ 的意义

$t$ 是**离心角**，不是椭圆上点的极角。
当 $t$ 从 0 到 $2\pi$ 时，点沿椭圆逆时针一周。

### 圆的参数方程

当 $a=b$ 时，退化为圆：

$$x=a\cos t,\quad y=a\sin t$$

## 4. 什么是摆线？写出其参数方程

### 定义

**摆线**是圆周上一定点在圆沿直线滚动时形成的轨迹。

具体说：

- 一个半径为 $a$ 的圆沿 $x$ 轴滚动；
- 圆上固定一点 $P$ 的轨迹就是摆线。

### 参数方程

$$\boxed{
x=a(t-\sin t),\quad y=a(1-\cos t),\quad -\infty<t<\infty
}$$

### 推导

圆心坐标：

$$(at,a)$$

点 $P$ 相对于圆心的坐标：

$$(-a\sin t,-a\cos t)$$

所以：

$$x=at-a\sin t=a(t-\sin t)$$

$$y=a-a\cos t=a(1-\cos t)$$

### 图形特征

- $y$ 的范围：$0\le y\le2a$；
- 每个周期 $2\pi$ 对应一个“拱”；
- 在 $t=0,2\pi,4\pi,\dots$ 处 $y=0$，曲线与 $x$ 轴接触；
- 在 $t=\pi,3\pi,\dots$ 处 $y=2a$，曲线达到最高点。

## 5. 摆线一拱的弧长和面积是多少？

### 一拱的弧长

一拱对应 $0\le t\le2\pi$。

$$\frac{dx}{dt}=a(1-\cos t),\quad \frac{dy}{dt}=a\sin t$$

$$\left(\frac{dx}{dt}\right)^2+\left(\frac{dy}{dt}\right)^2
=a^2(1-\cos t)^2+a^2\sin^2t
=4a^2\sin^2\frac t2$$

所以：

$$L=\int_0^{2\pi}2a\sin\frac t2\,dt
=8a$$

$$\boxed{\text{摆线一拱的弧长}=8a}$$

### 一拱下的面积

$$A=\int_0^{2\pi}y\,dx
=\int_0^{2\pi}a(1-\cos t)\cdot a(1-\cos t)\,dt$$

$$=a^2\int_0^{2\pi}(1-2\cos t+\cos^2t)\,dt$$

$$=a^2\left[2\pi-0+\pi\right]=3\pi a^2$$

$$\boxed{\text{摆线一拱下的面积}=3\pi a^2}$$

这是半径为 $a$ 的圆面积的三倍。

## 6. 什么是捷线？什么是等时线？

### 捷线（最速降线）

**问题**：在重力作用下，一个质点从点 $A$ 滑到点 $B$（不在同一竖直线上），沿什么曲线下滑时间最短？

**答案**：摆线（倒置）。

**历史**：

- 1696 年约翰·伯努利提出；
- 牛顿、莱布尼茨、洛必达等解决；
- 是变分法的起源问题之一。

### 等时线

**问题**：沿什么曲线下滑，质点到最低点的时间与起始位置无关？

**答案**：摆线。

**性质**：

- 摆线是等时曲线；
- 无论从摆线上哪一点开始下滑，到达最低点的时间相同；
- 这个时间与起始位置无关。

**应用**：

- 摆钟设计；
- 惠更斯利用摆线的等时性设计精确摆钟。

## 7. 写出内摆线和外摆线的参数方程

### 内摆线

一个小圆在大圆内部滚动，小圆上一点的轨迹。

设大圆半径 $R$，小圆半径 $r$。

$$\boxed{
x=(R-r)\cos t+r\cos\left(\frac{R-r}{r}t\right)
}$$

$$\boxed{
y=(R-r)\sin t-r\sin\left(\frac{R-r}{r}t\right)
}$$

### 外摆线

一个小圆在大圆外部滚动，小圆上一点的轨迹。

$$\boxed{
x=(R+r)\cos t-r\cos\left(\frac{R+r}{r}t\right)
}$$

$$\boxed{
y=(R+r)\sin t-r\sin\left(\frac{R+r}{r}t\right)
}$$

### 特例

- 当 $R=4r$ 时，内摆线退化为**星形线**：

$$x=a\cos^3t,\quad y=a\sin^3t$$

- 当 $R=r$ 时，外摆线退化为**心形线**。

# 二、发散性提问详解

## 1. 参数方程与直角坐标方程、极坐标方程各有什么优缺点？为什么某些曲线用参数方程更自然？

### 直角坐标方程

**形式**：$y=f(x)$ 或 $F(x,y)=0$

**优点**：

- 唯一表示；
- 适合代数运算；
- 微积分运算方便；
- 适合直线、多项式。

**缺点**：

- 不能表示多值曲线（如圆）；
- 对旋转对称图形不自然；
- 难以描述运动轨迹。

### 极坐标方程

**形式**：$r=f(\theta)$

**优点**：

- 适合旋转对称图形；
- 圆、心形线、玫瑰线、螺线方程简单；
- 物理中描述中心力场、圆周运动方便。

**缺点**：

- 不唯一；
- 微积分运算复杂；
- 直线、多项式方程复杂。

### 参数方程

**形式**：$x=f(t),\ y=g(t)$

**优点**：

- 灵活，可以表示任意曲线；
- 可以表示多值曲线和闭合曲线；
- 可以描述运动轨迹和方向；
- 参数 $t$ 通常有物理意义（时间、角度等）。

**缺点**：

- 不唯一；
- 消去参数有时困难；
- 微积分运算需要链式法则。

### 为什么某些曲线用参数方程更自然

- 摆线、内摆线、外摆线等本质上是运动轨迹，参数 $t$ 就是滚动角；
- 圆、椭圆、双曲线用参数方程可以避免多值问题；
- 物理中的运动轨迹天然用参数方程描述。

### 结论

三种表示各有优缺点，选择取决于曲线的性质和问题的背景。

## 2. 摆线为什么是最速降线？这个问题的解决如何推动了变分法的发展？

### 最速降线问题

在重力作用下，质点从 $A$ 滑到 $B$，沿什么曲线时间最短？

### 为什么是摆线

设曲线为 $y=y(x)$，质点速度为：

$$v=\sqrt{2gy}$$

时间微元：

$$dt=\frac{ds}{v}
=\frac{\sqrt{1+y'^2}}{\sqrt{2gy}}\,dx$$

总时间：

$$T=\int_{x_A}^{x_B}\frac{\sqrt{1+y'^2}}{\sqrt{2gy}}\,dx$$

要使 $T$ 最小，这是一个**泛函极值问题**。

通过变分法（欧拉-拉格朗日方程）求解，得到：

$$y=a(1-\cos t),\quad x=a(t-\sin t)$$

这正是摆线。

### 推动变分法发展

- 1696 年约翰·伯努利提出最速降线问题；
- 牛顿、莱布尼茨、洛必达、雅各布·伯努利等解决；
- 欧拉和拉格朗日在此基础上发展出**变分法**；
- 变分法成为现代数学和物理的重要分支。

### 结论

最速降线问题直接推动了变分法的诞生，是数学史上的里程碑。

## 3. 摆线的等时性在摆钟设计中如何应用？惠更斯是如何利用这一性质的？

### 摆线的等时性

摆线有一个重要性质：**质点在摆线上滑动到最低点的时间与起始位置无关**。

这意味着：

- 无论从摆线上哪一点开始下滑，到达最低点的时间相同；
- 因此摆线可以作为等时摆的轨迹。

### 惠更斯的摆钟设计

- 惠更斯发现单摆的周期随振幅变化，不够精确；
- 他发现摆线是等时曲线；
- 设计摆线摆钟：用两个摆线挡板限制摆锤的运动轨迹，使摆锤沿摆线运动；
- 这样摆的周期与振幅无关，提高了时钟精度。

### 意义

- 摆线摆钟是 17 世纪最精确的时钟；
- 等时性是数学与工程结合的典范；
- 推动了钟表制造和精密测量。

### 结论

惠更斯利用摆线的等时性设计摆钟，是数学应用于工程的经典案例。

## 4. 在物理学中，参数方程如何用于描述带电粒子在电磁场中的运动？

### 洛伦兹力

带电粒子在电磁场中受力：

$$\mathbf F=q(\mathbf E+\mathbf v\times\mathbf B)$$

运动方程：

$$m\frac{d\mathbf v}{dt}=q(\mathbf E+\mathbf v\times\mathbf B)$$

### 匀强磁场

若 $\mathbf E=0$，$\mathbf B$ 沿 $z$ 轴：

$$m\dot v_x=qv_yB,\quad m\dot v_y=-qv_xB,\quad m\dot v_z=0$$

解为圆周运动：

$$x=R\cos(\omega t),\quad y=R\sin(\omega t),\quad z=v_0t$$

其中：

$$\omega=\frac{qB}{m},\quad R=\frac{mv_\perp}{qB}$$

这是**螺旋线**。

### 匀强电场和磁场

若电场和磁场同时存在，粒子可能做**摆线运动**。

### 应用

- 质谱仪；
- 回旋加速器；
- 磁约束聚变；
- 霍尔效应。

### 结论

参数方程是描述带电粒子在电磁场中运动轨迹的自然工具。

## 5. 在工程中，摆线、内摆线、外摆线如何用于齿轮设计、凸轮设计？

### 摆线齿轮

- 齿廓由摆线组成；
- 优点：磨损小、噪音低、寿命长；
- 用于精密机械、钟表、汽车变速箱。

### 内摆线

- 用于旋转式发动机（汪克尔发动机）转子；
- 转子形状由内摆线生成；
- 优点是结构紧凑、功率密度高。

### 外摆线

- 用于齿廓设计；
- 用于凸轮轮廓；
- 用于旋转泵。

### 凸轮设计

- 凸轮轮廓用极坐标或参数方程表示；
- 摆线运动规律用于设计平滑的从动件运动；
- 避免冲击和振动。

### 结论

摆线、内摆线、外摆线在机械设计中用于生成齿轮齿廓和凸轮轮廓，是精密机械的基础。

## 6. 在计算机图形学中，参数曲线如何用于生成动画和建模？

### 参数曲线

- 贝塞尔曲线；
- B 样条；
- NURBS（非均匀有理 B 样条）。

### 生成动画

- 参数 $t$ 表示时间；
- 控制点决定曲线形状；
- 通过改变控制点实现动画。

### 建模

- 旋转曲面；
- 拉伸曲面；
- 扫掠曲面。

### 应用

- 3D 建模软件（Maya、Blender）；
- 游戏引擎；
- CAD；
- 电影特效。

### 例子

贝塞尔曲线：

$$B(t)=\sum_{i=0}^n \binom{n}{i}(1-t)^{n-i}t^iP_i$$

### 结论

参数曲线是计算机图形学生成动画和建模的核心工具。

## 7. 摆线与椭圆积分、特殊函数有什么关系？如何用级数展开计算摆线的弧长？

### 摆线的弧长

摆线一拱的弧长：

$$L=\int_0^{2\pi}\sqrt{(dx/dt)^2+(dy/dt)^2}\,dt$$

计算得：

$$ds=2a\sin\frac t2\,dt$$

$$L=\int_0^{2\pi}2a\sin\frac t2\,dt=8a$$

这是初等函数，不需要椭圆积分。

### 椭圆积分

椭圆弧长需要椭圆积分：

$$L=\int_0^{2\pi}\sqrt{a^2\sin^2t+b^2\cos^2t}\,dt$$

这是**第二类椭圆积分**。

### 特殊函数

- 椭圆积分；
- 椭圆函数；
- 贝塞尔函数；
- 超几何函数。

### 级数展开

摆线弧长可以展开为级数，但一拱弧长是精确的 $8a$。

更一般的参数曲线弧长可以用级数展开近似。

### 结论

摆线弧长是初等的，但椭圆弧长需要椭圆积分。摆线是连接初等积分与特殊函数的桥梁。

# 三、总结

1. 抛物线参数方程 $x=pt^2,\ y=2pt$。
2. 双曲线参数方程 $x=a\sec t,\ y=b\tan t$ 或双曲函数形式。
3. 椭圆参数方程 $x=a\cos t,\ y=b\sin t$。
4. 摆线参数方程 $x=a(t-\sin t),\ y=a(1-\cos t)$。
5. 摆线一拱弧长 $8a$，面积 $3\pi a^2$。
6. 摆线是最速降线和等时线。
7. 内摆线、外摆线用于齿轮和凸轮设计。
8. 参数方程在物理、工程、计算机图形学中广泛应用。
9. 摆线与变分法、椭圆积分、特殊函数密切相关。
