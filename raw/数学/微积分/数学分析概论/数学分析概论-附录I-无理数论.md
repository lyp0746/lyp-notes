### §1 有理数分割

#### 1. 有理数分割的定义

高木开篇写道：

> 将有理数集 $\mathbb{Q}$ 分为两个非空集合 $A$ 和 $B$：
>
> $$\mathbb{Q} = A \cup B, \quad A \cap B = \emptyset$$
>
> 如果 $A$ 中的每个有理数都小于 $B$ 中的每个有理数，则称 $(A, B)$ 为**有理数分割**。
>

**解读**：

- 有理数分割：把有理数分为下类 $A$ 和上类 $B$；
- $A$ 中每个数小于 $B$ 中每个数；
- 是戴德金分割在有理数范围内的版本。

**条件**：

- $A \neq \emptyset$，$B \neq \emptyset$；
- $A \cup B = \mathbb{Q}$，$A \cap B = \emptyset$；
- 对任意 $a \in A$，$b \in B$，$a < b$。

**解读**：

- 分割的三个条件；
- 非空、不交、有序。

**例子**：

- $A = \{x \in \mathbb{Q} : x < 1\}$，$B = \{x \in \mathbb{Q} : x \ge 1\}$；
- $A = \{x \in \mathbb{Q} : x^2 < 2\}$，$B = \{x \in \mathbb{Q} : x^2 > 2\}$。

**解读**：

- 有理数分割的例子；
- 第一种有边界，第二种无边界。

**应用**：

- **实数理论**：定义实数；
- **数学分析**：实数完备性；
- **数学**：实分析。

#### 2. 三种类型的分割

高木给出三种类型：

> 有理数分割可以分为三种类型：
>
> - **(1°) 跳跃**：$A$ 有最大数，$B$ 有最小数；
> - **(2°) 间隙**：$A$ 无最大数，$B$ 无最小数；
> - **(3°) 连续**：$A$ 无最大数，$B$ 有最小数；或 $A$ 有最大数，$B$ 无最小数。
>

**解读**：

- 跳跃：有间隙，但在有理数中不可能；
- 间隙：无边界，对应无理数；
- 连续：有边界，对应有理数。

**例子**：

- 类型 (1°)：在整数中可能，在有理数中不可能；
- 类型 (2°)：$A = \{x \in \mathbb{Q} : x^2 < 2\}$，$B = \{x \in \mathbb{Q} : x^2 > 2\}$；
- 类型 (3°)：$A = \{x \in \mathbb{Q} : x < 1\}$，$B = \{x \in \mathbb{Q} : x \ge 1\}$。

**解读**：

- 三种类型的例子；
- 整数、有理数、实数。

**应用**：

- **实数理论**：定义实数；
- **数学分析**：实数完备性；
- **数学**：实分析。

#### 3. 有理数分割与实数

高木给出有理数分割与实数的关系：

> 每个有理数分割对应一个实数：
>
> - 类型 (3°) 对应有理数；
> - 类型 (2°) 对应无理数。
>

**解读**：

- 有理数分割定义实数；
- 类型 (3°) 是有理数；
- 类型 (2°) 是无理数。

**构造**：

- 实数定义为有理数分割；
- 分割的序：$(A, B) \le (A', B')$ 当且仅当 $A \subseteq A'$；
- 分割的运算：加法、乘法。

**解读**：

- 实数的构造；
- 序和运算。

**例子**：

- $\sqrt{2}$：$A = \{x \in \mathbb{Q} : x^2 < 2\}$，$B = \{x \in \mathbb{Q} : x^2 > 2\}$；
- $1$：$A = \{x \in \mathbb{Q} : x < 1\}$，$B = \{x \in \mathbb{Q} : x \ge 1\}$。

**解读**：

- 有理数分割定义实数；
- $\sqrt{2}$、$1$。

**应用**：

- **实数理论**：定义实数；
- **数学分析**：实数完备性；
- **数学**：实分析。

## 问题2：绝对值的性质

### 背景

### 详细解释

**证明**：

因此

$$|x + y|^2 \le (|x| + |y|)^2$$

两边开方，

$$|x + y| \le |x| + |y|$$

**（4）应用**

- **实数理论**：定义距离；
- **数学分析**：极限、连续；
- **数学**：实分析。

### 结论

三角不等式：$|x + y| \le |x| + |y|$。证明用平方。

### 1. 数列极限的定义

高木开篇写道：

> 设 $\{a_n\}$ 是实数列，$a$ 是实数。如果对任意 $\epsilon > 0$，存在自然数 $N$，使得当 $n > N$ 时，
>
> $$|a_n - a| < \epsilon$$
>
> 则称 $\{a_n\}$ **收敛**于 $a$，记为
>
> $$\lim_{n \to \infty} a_n = a$$
>

**解读**：

- 实数极限：与正文§4的定义一致；
- 用绝对值定义接近程度；
- 是数学分析的基础。

**例子**：

- $\lim_{n \to \infty} \frac{1}{n} = 0$；
- $\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$。

**解读**：

- 极限的例子；
- $1/n$、$e$。

**应用**：

- **实数理论**：极限；
- **数学分析**：收敛性；
- **数学**：实分析。

### 2. 极限的性质

高木给出性质：

**（1）唯一性**：

> 如果 $\lim a_n = a$ 且 $\lim a_n = b$，则 $a = b$。
>

**（2）有界性**：

> 如果 $\{a_n\}$ 收敛，则 $\{a_n\}$ 有界。
>

**（3）四则运算**：

> 如果 $\lim a_n = a$，$\lim b_n = b$，则
>
> $$\lim (a_n \pm b_n) = a \pm b$$
>
> $$\lim (a_n b_n) = a b$$
>
> $$\lim \frac{a_n}{b_n} = \frac{a}{b} \quad (b \neq 0)$$
>

**解读**：

- 极限的性质；
- 唯一性、有界性、四则运算；
- 与正文§4一致。

**证明**：

> **（2）**：取 $\epsilon = 1$，存在 $N$，使得当 $n > N$ 时，$|a_n - a| < 1$。
因此 $|a_n| < |a| + 1$。
设 $M = \max(|a_1|, \dots, |a_N|, |a| + 1)$，则 $|a_n| < M$。
>

**解读**：

- 证明用绝对值；
- 有界性。

**应用**：

- **实数理论**：极限；
- **数学分析**：收敛性；
- **数学**：实分析。

### 3. 柯西判别法

> **柯西判别法**：实数列 $\{a_n\}$ 收敛的充分必要条件是，对任意 $\epsilon > 0$，存在自然数 $N$，使得当 $m, n > N$ 时，
>
> $$|a_m - a_n| < \epsilon$$
>

**解读**：

- 柯西判别法：数列收敛的充要条件；
- 只涉及数列自身；
- 是实数完备性的核心。

**证明**：

> **必要性**：如果 $a_n \to a$，则 $|a_m - a_n| \le |a_m - a| + |a - a_n| < \epsilon$。
**充分性**：由实数连续性，柯西列收敛。
>

**解读**：

- 证明用实数连续性；
- 柯西判别法。

**例子**：

- $a_n = \frac{1}{n}$：柯西列，收敛；
- $a_n = (-1)^n$：不是柯西列，不收敛。

**解读**：

- 柯西判别法的例子；
- 收敛、不收敛。

**应用**：

- **实数理论**：柯西判别法；
- **数学分析**：收敛性；
- **数学**：实分析。

## 问题1：数列极限的定义

### 背景

定义数列极限。

### 详细解释

**（1）定义**

设 $\{a_n\}$ 是实数列，$a$ 是实数。如果对任意 $\epsilon > 0$，存在自然数 $N$，使得当 $n > N$ 时，

$$|a_n - a| < \epsilon$$

则称 $\{a_n\}$ **收敛**于 $a$，记为

$$\lim_{n \to \infty} a_n = a$$

**（2）几何意义**

- $a_n$ 最终落在 $a$ 的 $\epsilon$ 邻域内；
- $\epsilon$ 任意小；
- $N$ 依赖于 $\epsilon$。

**（3）例子**

- $\lim_{n \to \infty} \frac{1}{n} = 0$；
- $\lim_{n \to \infty} \left(1 + \frac{1}{n}\right)^n = e$。

**（4）应用**

- **实数理论**：极限；
- **数学分析**：收敛性；
- **数学**：实分析。

### 结论

数列极限：对任意 $\epsilon > 0$，存在 $N$，使得当 $n > N$ 时，$|a_n - a| < \epsilon$。

## 问题2：极限的性质

### 背景

证明：收敛数列有界。

### 详细解释

**（1）命题陈述**

如果 $\{a_n\}$ 收敛，则 $\{a_n\}$ 有界。

**（2）证明**

**证明**：

取 $\epsilon = 1$，存在 $N$，使得当 $n > N$ 时，

$$|a_n - a| < 1$$

因此

$$|a_n| < |a| + 1$$

设

$$M = \max(|a_1|, \dots, |a_N|, |a| + 1)$$

则 $|a_n| < M$ 对所有 $n$ 成立。

因此 $\{a_n\}$ 有界。

**（3）其他性质**

- 唯一性：极限唯一；
- 四则运算：$\lim (a_n \pm b_n) = a \pm b$ 等。

**（4）应用**

- **实数理论**：极限；
- **数学分析**：收敛性；
- **数学**：实分析。

### 结论

收敛数列有界。证明用 $\epsilon = 1$ 和最大值的构造。

## 问题3：柯西判别法

### 背景

证明：柯西判别法。

### 详细解释

**（1）命题陈述**

实数列 $\{a_n\}$ 收敛的充分必要条件是，对任意 $\epsilon > 0$，存在自然数 $N$，使得当 $m, n > N$ 时，

$$|a_m - a_n| < \epsilon$$

**（2）证明**

**证明**：

**必要性**：如果 $a_n \to a$，则

$$|a_m - a_n| \le |a_m - a| + |a - a_n| < \epsilon$$

**充分性**：由实数连续性，柯西列收敛。

**（3）关键点**

- 必要性：三角不等式；
- 充分性：实数连续性；
- 柯西判别法。

**（4）应用**

- **实数理论**：柯西判别法；
- **数学分析**：收敛性；
- **数学**：实分析。

### 结论

柯西判别法：数列收敛 ⇔ 柯西列。证明用三角不等式和实数连续性。

## 问题4：柯西判别法的例子

### 背景

举例说明柯西判别法。

### 详细解释

**（1）收敛例子**

$a_n = \frac{1}{n}$：

$$|a_m - a_n| = \left| \frac{1}{m} - \frac{1}{n} \right| \le \frac{1}{m} + \frac{1}{n} < \epsilon$$

柯西列，收敛。

**（2）不收敛例子**

$a_n = (-1)^n$：

$$|a_{n+1} - a_n| = 2$$

不是柯西列，不收敛。

**（3）应用**

- **实数理论**：柯西判别法；
- **数学分析**：收敛性；
- **数学**：实分析。

### 结论

柯西判别法的例子：$1/n$ 收敛，$(-1)^n$ 不收敛。

**（2）用数列极限**

- **数学分析**：连续；

- **物理**：连续量。

## 问题5：指数法则

### 背景

证明：$a^{x+y} = a^x a^y$。

### 详细解释

**（1）命题陈述**

设 $a > 0$，$x, y$ 是实数。则

$$a^{x+y} = a^x a^y$$

**（2）证明**

**证明**：

由实数幂的定义，

$$a^x = \sup \{a^r : r \in \mathbb{Q}, r < x\}$$

$$a^y = \sup \{a^s : s \in \mathbb{Q}, s < y\}$$

对于 $r < x$，$s < y$，$r + s < x + y$，因此

$$a^r a^s = a^{r+s} \le a^{x+y}$$

取上确界，

$$a^x a^y \le a^{x+y}$$

反之，对于 $t < x + y$，存在 $r < x$，$s < y$ 使得 $t < r + s$，因此

$$a^t \le a^{r+s} = a^r a^s \le a^x a^y$$

取上确界，

$$a^{x+y} \le a^x a^y$$

因此

$$a^{x+y} = a^x a^y$$

**（3）关键点**

- 有理数幂的指数法则；
- 上确界；
- 实数幂的指数法则。

**（4）应用**

- **实数理论**：幂运算；
- **数学分析**：指数函数；
- **数学**：实分析。

### 结论

指数法则：$a^{x+y} = a^x a^y$。证明用上确界和有理数幂的指数法则。

## 问题1：紧集的定义

### 背景

定义紧集。

### 详细解释

**（1）定义**

设 $K \subseteq \mathbb{R}^n$。如果 $K$ 的任意开覆盖都有有限子覆盖，则称 $K$ 为**紧集**。

**（2）开覆盖**

一族开集 $\{O_\alpha\}$ 称为 $K$ 的开覆盖，如果

$$K \subseteq \bigcup_\alpha O_\alpha$$

**（3）有限子覆盖**

存在有限个开集 $O_{\alpha_1}, \dots, O_{\alpha_k}$，使得

$$K \subseteq \bigcup_{i=1}^k O_{\alpha_i}$$

**（4）例子**

- 闭区间 $[a, b]$：紧集；
- 开区间 $(a, b)$：不是紧集；
- 单位球：紧集。

**（5）应用**

- **实数理论**：紧性；
- **数学分析**：一致连续、最大值最小值；
- **数学**：拓扑学。

### 结论

紧集是任意开覆盖都有有限子覆盖的集合。

## 问题2：海涅-博雷尔定理

### 背景

证明：海涅-博雷尔定理。

### 详细解释

**（1）命题陈述**

在 $\mathbb{R}^n$ 中，集合 $K$ 是紧集当且仅当 $K$ 是有界闭集。

**（2）证明**

**（⇒）紧集有界且闭**：

**第一步：** 紧集有界。取开覆盖 $\{B(0, n)\}$，由紧性，存在有限子覆盖，因此有界。

**第二步：** 紧集是闭集。设 $x \notin K$，对每点 $y \in K$，取开球 $B(y, \frac{d(x, y)}{2})$ 和 $B(x, \frac{d(x, y)}{2})$，它们不相交。由紧性，存在有限子覆盖。取最小半径，则 $B(x, r) \cap K = \emptyset$。因此 $K$ 是闭集。

**（⇐）有界闭集紧**：

**第一步：** 有界闭集包含在某个闭立方体中。

**第二步：** 闭立方体是紧集（由区间套法或二分法）。

**第三步：** 闭集是紧集的闭子集，因此是紧集。

**（3）关键点**

- 紧集有界且闭；
- 有界闭集紧；
- 海涅-博雷尔定理。

**（4）应用**

- **实数理论**：紧性；
- **数学分析**：一致连续、最大值最小值；
- **数学**：拓扑学。

### 结论

海涅-博雷尔定理：在 $\mathbb{R}^n$ 中，紧集 = 有界闭集。证明用开覆盖和闭集性质。

## 问题2：复数的运算

### 背景

计算 $(1 + 2i)(3 + 4i)$。

### 详细解释

**（1）乘法定义**

$$(a + bi)(c + di) = (ac - bd) + (ad + bc)i$$

**（2）计算**

$$(1 + 2i)(3 + 4i) = 1 \cdot 3 + 1 \cdot 4i + 2i \cdot 3 + 2i \cdot 4i$$

$$= 3 + 4i + 6i + 8i^2 = 3 + 10i - 8 = -5 + 10i$$

**（3）验证**

由定义：
$a = 1, b = 2, c = 3, d = 4$。

$ac - bd = 3 - 8 = -5$；
$ad + bc = 4 + 6 = 10$。

因此

$$(1 + 2i)(3 + 4i) = -5 + 10i$$

**（4）应用**

- **数学**：复数理论；
- **物理**：量子力学；
- **工程**：信号处理。

### 结论

$(1 + 2i)(3 + 4i) = -5 + 10i$。计算用复数乘法定义。

## 问题4：模和辐角

**（5）应用**

### 结论

$z = 1 + i$ 的模为 $\sqrt{2}$，辐角为 $\frac{\pi}{4}$。极坐标形式为 $\sqrt{2} e^{i\pi/4}$。
