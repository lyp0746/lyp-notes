## §105 集合运算

### 1. 集合的基本概念

高木开篇写道：

> 设 $X$ 是某个基本集合（全集）。$X$ 的子集用 $A, B, C, \dots$ 表示。
>
> - $x \in A$：$x$ 属于 $A$；
> - $x \notin A$：$x$ 不属于 $A$；
> - $A \subseteq B$：$A$ 是 $B$ 的子集；
> - $A = B$：$A$ 与 $B$ 相等。
>

**解读**：

- 集合：元素的总体；
- 子集：$A \subseteq B$ 表示 $A$ 中的元素都属于 $B$；
- 相等：$A = B$ 表示 $A \subseteq B$ 且 $B \subseteq A$。

**例子**：

- $X = \mathbb{R}$：全集是实数集；
- $A = [0, 1]$：闭区间；
- $B = \mathbb{Q}$：有理数集。

**解读**：

- 集合的例子；
- 实数集、区间、有理数集。

### 2. 集合的运算

高木给出集合的运算：

**（1）并集**：

> $$A \cup B = \{x : x \in A \text{ 或 } x \in B\}$$
>

**（2）交集**：

> $$A \cap B = \{x : x \in A \text{ 且 } x \in B\}$$
>

**（3）差集**：

> $$A \setminus B = \{x : x \in A \text{ 且 } x \notin B\}$$
>

**（4）补集**：

> $$A^c = X \setminus A = \{x \in X : x \notin A\}$$
>

**解读**：

- 并集、交集、差集、补集；
- 集合的基本运算。

**例子**：

> $A = [0, 1], B = [0.5, 1.5]$。
$A \cup B = [0, 1.5]$；
$A \cap B = [0.5, 1]$；
$A \setminus B = [0, 0.5)$。
>

**解读**：

- 集合运算的例子；
- 区间运算。

### 3. 集合运算的性质

高木给出性质：

**（1）交换律**：

> $$A \cup B = B \cup A, \quad A \cap B = B \cap A$$
>

**（2）结合律**：

> $$(A \cup B) \cup C = A \cup (B \cup C)$$
>
> $$(A \cap B) \cap C = A \cap (B \cap C)$$
>

**（3）分配律**：

> $$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$
>
> $$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$
>

**（4）德摩根律**：

> $$(A \cup B)^c = A^c \cap B^c$$
>
> $$(A \cap B)^c = A^c \cup B^c$$
>

**解读**：

- 集合运算的性质；
- 交换律、结合律、分配律、德摩根律；
- 与逻辑运算类似。

**例子**：

> $A = [0, 1], B = [0.5, 1.5]$。
$(A \cup B)^c = (-\infty, 0) \cup (1.5, \infty)$；
$A^c \cap B^c = ((-\infty, 0) \cup (1, \infty)) \cap ((-\infty, 0.5) \cup (1.5, \infty)) = (-\infty, 0) \cup (1.5, \infty)$。
>

一致。

**解读**：

- 德摩根律的例子；
- 验证。

### 4. 无限集合运算

高木给出无限集合运算：

**（1）无限并集**：

> $$\bigcup_{n=1}^\infty A_n = \{x : \exists n, x \in A_n\}$$
>

**（2）无限交集**：

> $$\bigcap_{n=1}^\infty A_n = \{x : \forall n, x \in A_n\}$$
>

**解读**：

- 无限并集、无限交集；
- 用于测度论。

**德摩根律的推广**：

> $$\left( \bigcup_{n=1}^\infty A_n \right)^c = \bigcap_{n=1}^\infty A_n^c$$
>
> $$\left( \bigcap_{n=1}^\infty A_n \right)^c = \bigcup_{n=1}^\infty A_n^c$$
>

**解读**：

- 德摩根律的推广；
- 用于测度论。

**例子**：

> $A_n = [0, 1/n]$。
>
> $$\bigcap_{n=1}^\infty A_n = \{0\}$$
>
> $$\bigcup_{n=1}^\infty A_n = [0, 1]$$
>

**解读**：

- 无限集合运算的例子；
- 交集、并集。

### 5. 上极限与下极限

高木给出上极限与下极限：

**（1）上极限**：

> $$\limsup_{n \to \infty} A_n = \bigcap_{n=1}^\infty \bigcup_{k=n}^\infty A_k$$
>
> 表示“无穷多个 $A_n$ 发生”。
>

**（2）下极限**：

> $$\liminf_{n \to \infty} A_n = \bigcup_{n=1}^\infty \bigcap_{k=n}^\infty A_k$$
>
> 表示“从某项开始，所有 $A_n$ 都发生”。
>

**解读**：

- 上极限、下极限；
- 用于概率论、测度论。

**关系**：

> $$\liminf_{n \to \infty} A_n \subseteq \limsup_{n \to \infty} A_n$$
>

**解读**：

- 下极限是上极限的子集；
- 用于概率论。

**例子**：

> $A_n = [0, 1/n]$。
>
> $$\limsup_{n \to \infty} A_n = \{0\}$$
>
> $$\liminf_{n \to \infty} A_n = \{0\}$$
>

**解读**：

- 上极限、下极限的例子；
- 交集、并集。

**应用**：

- **概率论**：波莱尔-坎泰利引理；
- **测度论**：集合序列；
- **数学**：实分析。

## 问题1：集合运算

### 背景

证明：德摩根律。

### 详细解释

**（1）德摩根律**

$$(A \cup B)^c = A^c \cap B^c$$

$$(A \cap B)^c = A^c \cup B^c$$

**（2）证明**

**证明**：

**第一式**：

$$x \in (A \cup B)^c \iff x \notin A \cup B \iff x \notin A \text{ 且 } x \notin B \iff x \in A^c \text{ 且 } x \in B^c \iff x \in A^c \cap B^c$$

因此 $(A \cup B)^c = A^c \cap B^c$。

**第二式**：

$$x \in (A \cap B)^c \iff x \notin A \cap B \iff x \notin A \text{ 或 } x \notin B \iff x \in A^c \text{ 或 } x \in B^c \iff x \in A^c \cup B^c$$

因此 $(A \cap B)^c = A^c \cup B^c$。

**（3）无限推广**

$$\left( \bigcup_{n=1}^\infty A_n \right)^c = \bigcap_{n=1}^\infty A_n^c$$

$$\left( \bigcap_{n=1}^\infty A_n \right)^c = \bigcup_{n=1}^\infty A_n^c$$

**（4）应用**

- **数学**：集合论；
- **概率论**：事件运算；
- **测度论**：可测集。

### 结论

德摩根律：$(A \cup B)^c = A^c \cap B^c$，$(A \cap B)^c = A^c \cup B^c$。证明用元素法。

## 问题2：无限集合运算

### 背景

计算 $\bigcap_{n=1}^\infty [0, 1/n]$。

### 详细解释

**（1）集合**

$$A_n = [0, 1/n]$$

**（2）交集**

$$\bigcap_{n=1}^\infty A_n = \{x : \forall n, 0 \le x \le 1/n\}$$

**（3）分析**

- $x = 0$：对所有 $n$，$0 \le 0 \le 1/n$ 成立，所以 $0 \in \bigcap A_n$。
- $x > 0$：取 $n > 1/x$，则 $1/n < x$，所以 $x \notin A_n$，因此 $x \notin \bigcap A_n$。
- $x < 0$：$x \notin A_n$（因为 $A_n \subseteq [0, \infty)$）。

因此

$$\bigcap_{n=1}^\infty A_n = \{0\}$$

**（4）并集**

$$\bigcup_{n=1}^\infty A_n = [0, 1]$$

**（5）应用**

- **数学**：集合论；
- **概率论**：事件运算；
- **测度论**：可测集。

### 结论

$\bigcap_{n=1}^\infty [0, 1/n] = \{0\}$，$\bigcup_{n=1}^\infty [0, 1/n] = [0, 1]$。

## 问题3：上极限与下极限

### 背景

计算 $A_n = [0, 1/n]$ 的上极限和下极限。

### 详细解释

**（1）上极限**

$$\limsup_{n \to \infty} A_n = \bigcap_{n=1}^\infty \bigcup_{k=n}^\infty A_k$$

计算：

$$\bigcup_{k=n}^\infty A_k = [0, 1/n]$$

因此

$$\limsup_{n \to \infty} A_n = \bigcap_{n=1}^\infty [0, 1/n] = \{0\}$$

**（2）下极限**

$$\liminf_{n \to \infty} A_n = \bigcup_{n=1}^\infty \bigcap_{k=n}^\infty A_k$$

计算：

$$\bigcap_{k=n}^\infty A_k = \{0\}$$

因此

$$\liminf_{n \to \infty} A_n = \bigcup_{n=1}^\infty \{0\} = \{0\}$$

**（3）关系**

$$\liminf A_n \subseteq \limsup A_n$$

这里两者相等，都为 $\{0\}$。

**（4）应用**

- **概率论**：波莱尔-坎泰利引理；
- **测度论**：集合序列；
- **数学**：实分析。

### 结论

$A_n = [0, 1/n]$ 的上极限和下极限都为 $\{0\}$。

## 问题4：德摩根律的推广

### 背景

证明：$(\bigcup A_n)^c = \bigcap A_n^c$。

### 详细解释

**（1）命题陈述**

$$\left( \bigcup_{n=1}^\infty A_n \right)^c = \bigcap_{n=1}^\infty A_n^c$$

**（2）证明**

**证明**：

$$x \in \left( \bigcup_{n=1}^\infty A_n \right)^c \iff x \notin \bigcup_{n=1}^\infty A_n \iff \forall n, x \notin A_n \iff \forall n, x \in A_n^c \iff x \in \bigcap_{n=1}^\infty A_n^c$$

因此

$$\left( \bigcup_{n=1}^\infty A_n \right)^c = \bigcap_{n=1}^\infty A_n^c$$

**（3）对偶形式**

$$\left( \bigcap_{n=1}^\infty A_n \right)^c = \bigcup_{n=1}^\infty A_n^c$$

**（4）应用**

- **数学**：集合论；
- **概率论**：事件运算；
- **测度论**：可测集。

### 结论

德摩根律的推广：$(\bigcup A_n)^c = \bigcap A_n^c$。证明用元素法。

## 问题5：集合运算在概率论中的应用

### 背景

用集合运算分析事件。

### 详细解释

**（1）事件**

- 样本空间 $\Omega$；
- 事件 $A \subseteq \Omega$；
- 概率 $P(A)$。

**（2）集合运算**

- 并集：$A \cup B$ 表示“A 或 B”；
- 交集：$A \cap B$ 表示“A 且 B”；
- 补集：$A^c$ 表示“非 A”。

**（3）概率运算**

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

$$P(A^c) = 1 - P(A)$$

**（4）应用**

- **概率论**：事件运算；
- **统计学**：假设检验；
- **机器学习**：分类。

**（5）例子**

掷骰子：

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

### 结论

集合运算在概率论中用于分析事件。集合运算是概率论的基础。

## 问题6：集合运算在测度论中的应用

### 背景

用集合运算分析可测集。

### 详细解释

**（1）可测集**

- σ系：对可数并、可数交、补集封闭；
- 可测集：属于 σ系的集合。

**（2）集合运算**

- 可数并：$\bigcup A_n$；
- 可数交：$\bigcap A_n$；
- 补集：$A^c$。

**（3）测度**

$$m\left( \bigcup_{n=1}^\infty A_n \right) = \sum_{n=1}^\infty m(A_n)$$

（如果 $A_n$ 两两不交）

**（4）应用**

- **测度论**：可测集；
- **概率论**：概率测度；
- **数学**：实分析。

**（5）例子**

勒贝格测度：

$$m([a, b]) = b - a$$

### 结论

集合运算在测度论中用于分析可测集。集合运算是测度论的基础。

## 问题7：集合运算在机器学习中的应用

交叉验证：

### 结论

集合运算在机器学习中用于分析数据集。集合运算是机器学习的基础。

## §106 加法集合类（σ系）

### 1. σ系的定义

高木开篇写道：

> 设 $X$ 是基本集合，$\mathcal{F}$ 是 $X$ 的子集族。如果 $\mathcal{F}$ 满足：
>
> - $(1^\circ)$ $X \in \mathcal{F}$；
> - $(2^\circ)$ 如果 $A \in \mathcal{F}$，则 $A^c \in \mathcal{F}$；
> - $(3^\circ)$ 如果 $A_n \in \mathcal{F}$（$n = 1, 2, \dots$），则 $\bigcup_{n=1}^\infty A_n \in \mathcal{F}$；
则称 $\mathcal{F}$ 为 $X$ 上的**σ系**（σ-代数）。
>

**解读**：

- σ系：对补集和可数并封闭的子集族；
- 三个条件：包含全集、对补集封闭、对可数并封闭；
- 测度论的基础结构。

**等价条件**：

- 对可数交封闭：$\bigcap_{n=1}^\infty A_n \in \mathcal{F}$；
- 对差集封闭：$A \setminus B \in \mathcal{F}$。

**解读**：

- σ系的等价条件；
- 可数交、差集。

**例子**：

- $\mathcal{F} = \{\emptyset, X\}$：最小σ系；
- $\mathcal{F} = \mathcal{P}(X)$：最大σ系（幂集）；
- 博雷尔σ系 $\mathcal{B}(\mathbb{R})$。

**解读**：

- σ系的例子；
- 最小σ系、最大σ系、博雷尔σ系。

### 2. σ系的性质

高木给出性质：

**（1）包含空集**：

> $\emptyset \in \mathcal{F}$。
>

**证明**：$X \in \mathcal{F}$，$X^c = \emptyset \in \mathcal{F}$。

**（2）对可数交封闭**：

> 如果 $A_n \in \mathcal{F}$，则 $\bigcap_{n=1}^\infty A_n \in \mathcal{F}$。
>

**证明**：由德摩根律，$\bigcap A_n = (\bigcup A_n^c)^c \in \mathcal{F}$。

**（3）对差集封闭**：

> 如果 $A, B \in \mathcal{F}$，则 $A \setminus B \in \mathcal{F}$。
>

**证明**：$A \setminus B = A \cap B^c \in \mathcal{F}$。

**（4）对有限并、有限交封闭**：

> 如果 $A_1, \dots, A_n \in \mathcal{F}$，则 $\bigcup_{i=1}^n A_i \in \mathcal{F}$，$\bigcap_{i=1}^n A_i \in \mathcal{F}$。
>

**解读**：

- σ系的性质；
- 空集、可数交、差集、有限并、有限交；
- 与集合运算一致。

**例子**：

> 博雷尔σ系 $\mathcal{B}(\mathbb{R})$：
>
> - 包含所有开集、闭集；
> - 对可数并、可数交、补集封闭。
>

**解读**：

- 博雷尔σ系；
- 包含开集、闭集。

### 3. 生成的σ系

高木给出生成的σ系：

> 设 $\mathcal{A}$ 是 $X$ 的子集族。包含 $\mathcal{A}$ 的最小σ系称为由 $\mathcal{A}$ **生成**的σ系，记为 $\sigma(\mathcal{A})$。
>

**解读**：

- 生成的σ系：包含 $\mathcal{A}$ 的最小σ系；
- $\sigma(\mathcal{A})$ 是良定义的；
- 用于构造博雷尔σ系。

**构造**：

> $\sigma(\mathcal{A})$ 是所有包含 $\mathcal{A}$ 的σ系的交集。
>

**解读**：

- 构造方法：交集；
- 最小σ系。

**例子**：

> 博雷尔σ系 $\mathcal{B}(\mathbb{R})$ 由所有开集生成。
>

**解读**：

- 博雷尔σ系由开集生成；
- 是最重要的σ系。

**应用**：

- **测度论**：博雷尔σ系；
- **概率论**：事件σ系；
- **数学**：实分析。

### 4. 博雷尔集合

高木给出博雷尔集合：

> 由 $\mathbb{R}$ 中的所有开集生成的σ系称为**博雷尔σ系**，记为 $\mathcal{B}(\mathbb{R})$。$\mathcal{B}(\mathbb{R})$ 中的集合称为**博雷尔集合**。
>

**解读**：

- 博雷尔σ系：由开集生成；
- 博雷尔集合：博雷尔σ系中的集合；
- 包含所有开集、闭集、可数并、可数交。

**例子**：

- 开区间、闭区间、半开半闭区间；
- 有理数集、无理数集；
- 康托尔集。

**解读**：

- 博雷尔集合的例子；
- 区间、有理数集、康托尔集。

**性质**：

- $\mathcal{B}(\mathbb{R})$ 包含所有区间；
- $\mathcal{B}(\mathbb{R})$ 包含所有开集、闭集；
- $\mathcal{B}(\mathbb{R})$ 对可数并、可数交、补集封闭。

**解读**：

- 博雷尔σ系的性质；
- 包含区间、开集、闭集。

**应用**：

- **测度论**：勒贝格测度；
- **概率论**：随机变量；
- **数学**：实分析。

## 问题1：σ系的定义

### 背景

定义σ系。

### 详细解释

**（1）σ系的定义**

设 $X$ 是基本集合，$\mathcal{F}$ 是 $X$ 的子集族。如果 $\mathcal{F}$ 满足：

- $(1^\circ)$ $X \in \mathcal{F}$；
- $(2^\circ)$ 如果 $A \in \mathcal{F}$，则 $A^c \in \mathcal{F}$；
- $(3^\circ)$ 如果 $A_n \in \mathcal{F}$（$n = 1, 2, \dots$），则 $\bigcup_{n=1}^\infty A_n \in \mathcal{F}$；

则称 $\mathcal{F}$ 为 $X$ 上的**σ系**（σ-代数）。

**（2）等价条件**

- 对可数交封闭：$\bigcap_{n=1}^\infty A_n \in \mathcal{F}$；
- 对差集封闭：$A \setminus B \in \mathcal{F}$；
- 包含空集：$\emptyset \in \mathcal{F}$。

**（3）例子**

- $\mathcal{F} = \{\emptyset, X\}$：最小σ系；
- $\mathcal{F} = \mathcal{P}(X)$：最大σ系（幂集）；
- 博雷尔σ系 $\mathcal{B}(\mathbb{R})$。

**（4）应用**

- **测度论**：可测集；
- **概率论**：事件σ系；
- **数学**：实分析。

### 结论

σ系是对补集和可数并封闭的子集族。包含全集、对补集封闭、对可数并封闭。

## 问题2：σ系的性质

### 背景

证明：σ系对可数交封闭。

### 详细解释

**（1）命题陈述**

如果 $A_n \in \mathcal{F}$（$n = 1, 2, \dots$），则

$$\bigcap_{n=1}^\infty A_n \in \mathcal{F}$$

**（2）证明**

**证明**：

由 $A_n \in \mathcal{F}$ 和 σ系对补集封闭，$A_n^c \in \mathcal{F}$。

由 σ系对可数并封闭，

$$\bigcup_{n=1}^\infty A_n^c \in \mathcal{F}$$

由 σ系对补集封闭，

$$\left( \bigcup_{n=1}^\infty A_n^c \right)^c \in \mathcal{F}$$

由德摩根律，

$$\left( \bigcup_{n=1}^\infty A_n^c \right)^c = \bigcap_{n=1}^\infty A_n$$

因此

$$\bigcap_{n=1}^\infty A_n \in \mathcal{F}$$

**（3）其他性质**

- 对差集封闭：$A \setminus B = A \cap B^c \in \mathcal{F}$；
- 对有限并封闭：$\bigcup_{i=1}^n A_i \in \mathcal{F}$；
- 对有限交封闭：$\bigcap_{i=1}^n A_i \in \mathcal{F}$。

**（4）应用**

- **数学**：集合论；
- **概率论**：事件运算；
- **测度论**：可测集。

### 结论

σ系对可数交封闭。证明用德摩根律。

## 问题3：生成的σ系

### 背景

解释生成的σ系。

### 详细解释

设 $\mathcal{A}$ 是 $X$ 的子集族。包含 $\mathcal{A}$ 的最小σ系称为由 $\mathcal{A}$ **生成**的σ系，记为 $\sigma(\mathcal{A})$。

## 问题2：M函数的性质

### 背景

证明：可测函数的和是可测函数。

### 详细解释

**（1）命题陈述**

如果 $f, g$ 是可测函数，则 $f + g$ 是可测函数。

**（2）证明**

**证明**：

$$\{f + g > a\} = \bigcup_{r \in \mathbb{Q}} (\{f > r\} \cap \{g > a - r\})$$

由 $f, g$ 可测，$\{f > r\} \in \mathcal{F}$，$\{g > a - r\} \in \mathcal{F}$。

由 σ系对可数交封闭，$\{f > r\} \cap \{g > a - r\} \in \mathcal{F}$。

由 σ系对可数并封闭，

$$\bigcup_{r \in \mathbb{Q}} (\{f > r\} \cap \{g > a - r\}) \in \mathcal{F}$$

因此 $\{f + g > a\} \in \mathcal{F}$，即 $f + g$ 可测。

**（3）关键点**

- 有理数可数；
- σ系对可数并、可数交封闭；
- 可测性。

**（4）应用**

- **测度论**：可测函数；
- **概率论**：随机变量；
- **数学**：实分析。

### 结论

可测函数的和是可测函数。证明用有理数可数和σ系的封闭性。

## 问题5：可测函数的逼近

### 背景

### 详细解释

**（1）命题陈述**

设 $f$ 是非负可测函数。则存在简单函数列 $\{f_n\}$ 使得

$$0 \le f_1 \le f_2 \le \dots \le f$$

且 $f_n \to f$（逐点）。

**（2）证明**

**证明**：

对 $n = 1, 2, \dots$，定义

$$f_n(x) = \begin{cases} \frac{k}{2^n}, & \frac{k}{2^n} \le f(x) < \frac{k+1}{2^n}, k = 0, 1, \dots, n 2^n - 1 \\ n, & f(x) \ge n \end{cases}$$

则 $f_n$ 是简单函数，且 $0 \le f_1 \le f_2 \le \dots \le f$。

由构造，$f_n(x) \to f(x)$ 对所有 $x$ 成立。

**（3）关键点**

- 二分法逼近；
- 单调递增；
- 逐点收敛。

**（4）应用**

- **测度论**：勒贝格积分；
- **概率论**：随机变量；
- **数学**：实分析。

### 结论

可测函数可以用简单函数逼近。证明用二分法构造。

## 问题6：M函数在概率论中的应用

## 问题2：测度的性质

### 背景

证明：测度的单调性。

### 详细解释

**（1）命题陈述**

如果 $A \subseteq B$，则 $m(A) \le m(B)$。

**（2）证明**

**证明**：

由 $A \subseteq B$，$B = A \cup (B \setminus A)$，且 $A \cap (B \setminus A) = \emptyset$。

由可数可加性，

$$m(B) = m(A) + m(B \setminus A)$$

由 $m(B \setminus A) \ge 0$，

$$m(B) \ge m(A)$$

**（3）其他性质**

- **可减性**：如果 $A \subseteq B$ 且 $m(A) < \infty$，则 $m(B \setminus A) = m(B) - m(A)$；
- **次可加性**：$m(\bigcup A_n) \le \sum m(A_n)$；
- **连续性**：如果 $A_n \uparrow A$，则 $m(A_n) \to m(A)$。

**（4）应用**

- **测度论**：测度；
- **概率论**：概率；
- **数学**：实分析。

### 结论

测度的单调性：如果 $A \subseteq B$，则 $m(A) \le m(B)$。证明用可数可加性。

## 问题4：零测集

### 背景

证明：可数集是零测集。

### 详细解释

**（1）命题陈述**

可数集的勒贝格测度为 0。

**（2）证明**

**证明**：

设 $A = \{a_1, a_2, \dots\}$ 是可数集。

对任意 $\epsilon > 0$，用区间 $I_n = (a_n - \epsilon/2^{n+1}, a_n + \epsilon/2^{n+1})$ 覆盖 $a_n$。

则

$$A \subseteq \bigcup_{n=1}^\infty I_n$$

$$m(A) \le \sum_{n=1}^\infty m(I_n) = \sum_{n=1}^\infty \frac{\epsilon}{2^n} = \epsilon$$

由 $\epsilon$ 任意，

$$m(A) = 0$$

**（3）关键点**

- 用区间覆盖；
- 测度的次可加性；
- 零测集。

**（4）应用**

- **测度论**：零测集；
- **概率论**：概率；
- **数学**：实分析。

### 结论

可数集是零测集。证明用区间覆盖和次可加性。

## §109 积分

### 1. 简单函数的积分

高木开篇写道：

> 设 $(X, \mathcal{F}, m)$ 是测度空间。对于简单函数
>
> $$f = \sum_{i=1}^n a_i \chi_{A_i}$$
>
> 定义其积分为
>
> $$\int f \, dm = \sum_{i=1}^n a_i m(A_i)$$
>

**解读**：

- 简单函数：有限个值的函数；
- 积分：值的加权和；
- 权重：测度。

**例子**：

> $f = 2 \chi_{[0, 1]} + 3 \chi_{[1, 2]}$。
>
> $$\int f \, dm = 2 \cdot m([0, 1]) + 3 \cdot m([1, 2]) = 2 + 3 = 5$$
>

**解读**：

- 简单函数的积分；
- 加权和。

**性质**：

- 线性性：$\int (af + bg) = a \int f + b \int g$；
- 单调性：如果 $f \le g$，则 $\int f \le \int g$；
- 可加性：如果 $A \cap B = \emptyset$，则 $\int_{A \cup B} f = \int_A f + \int_B f$。

**解读**：

- 简单函数积分的性质；
- 线性性、单调性、可加性。

**应用**：

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

>

>

- 可能为 $+\infty$。

- 线性性：$\int (af + bg) = a \int f + b \int g$（$a, b \ge 0$）；
- 单调性：如果 $f \le g$，则 $\int f \le \int g$；
- 可加性：$\int_{A \cup B} f = \int_A f + \int_B f$（$A \cap B = \emptyset$）。

**解读**：

- 非负可测函数积分的性质；
- 与简单函数积分类似。

- **测度论**：勒贝格积分；

- **数学**：实分析。

**性质**：

**解读**：

**例子**：

**解读**：

**应用**：

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

**解读**：

## 问题2：非负可测函数的积分

### 背景

定义非负可测函数的积分。

### 详细解释

**（1）定义**

设 $f \ge 0$ 是可测函数。定义

$$\int f \, dm = \sup \left\{ \int g \, dm : 0 \le g \le f, g \text{ 是简单函数} \right\}$$

**（2）性质**

- 线性性：$\int (af + bg) = a \int f + b \int g$（$a, b \ge 0$）；
- 单调性：如果 $f \le g$，则 $\int f \le \int g$；
- 可加性：$\int_{A \cup B} f = \int_A f + \int_B f$（$A \cap B = \emptyset$）。

**（3）例子**

$f(x) = x$ 在 $[0, 1]$ 上：

$$\int_0^1 x \, dm = \frac{1}{2}$$

**（4）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

非负可测函数的积分定义为简单函数积分的上确界。

## 问题3：一般可测函数的积分

### 背景

定义一般可测函数的积分。

### 详细解释

**（1）正部分和负部分**

$$f^+ = \max(f, 0), \quad f^- = \max(-f, 0)$$

**（2）可积性**

如果 $\int f^+ \, dm < \infty$ 且 $\int f^- \, dm < \infty$，则称 $f$ **可积**。

**（3）积分定义**

$$\int f \, dm = \int f^+ \, dm - \int f^- \, dm$$

**（4）性质**

- 线性性：$\int (af + bg) = a \int f + b \int g$；
- 单调性：如果 $f \le g$，则 $\int f \le \int g$；
- 绝对值不等式：$|\int f| \le \int |f|$。

**（5）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

一般可测函数的积分定义为正部分和负部分的差。可积性要求正部分和负部分都可积。

## 问题4：勒贝格积分与黎曼积分

### 背景

比较勒贝格积分与黎曼积分。

### 详细解释

**（1）黎曼积分**

- 分割定义域；
- 用矩形逼近；
- 要求振幅和趋于 0。

**（2）勒贝格积分**

- 分割值域；
- 用简单函数逼近；
- 要求可测。

**（3）关系**

如果 $f$ 在 $[a, b]$ 上黎曼可积，则 $f$ 在 $[a, b]$ 上勒贝格可积，且积分值相同。

**（4）例子**

狄利克雷函数：黎曼不可积，勒贝格可积（积分为 0）。

**（5）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

勒贝格积分比黎曼积分更一般。黎曼可积 ⇒ 勒贝格可积，且积分值相同。

## 问题5：可积性

### 背景

证明：如果 $f$ 可积，则 $|f|$ 可积。

### 详细解释

**（1）命题陈述**

如果 $f$ 可积，则 $|f|$ 可积。

**（2）证明**

**证明**：

由 $f$ 可积，$\int f^+ \, dm < \infty$ 且 $\int f^- \, dm < \infty$。

由 $|f| = f^+ + f^-$，

$$\int |f| \, dm = \int f^+ \, dm + \int f^- \, dm < \infty$$

因此 $|f|$ 可积。

**（3）逆命题不成立**

$|f|$ 可积 ⇏ $f$ 可积。

**例子**：$f = 1$ 在 $\mathbb{Q}$ 上，$f = -1$ 在 $\mathbb{R} \setminus \mathbb{Q}$ 上。$|f| = 1$ 可积，但 $f$ 不可积。

**（4）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

如果 $f$ 可积，则 $|f|$ 可积。证明用正部分和负部分。

## §110 积分的性质

### 1. 基本性质

高木开篇写道：

> 勒贝格积分具有以下基本性质：
>
> - **线性性**：$\int (af + bg) \, dm = a \int f \, dm + b \int g \, dm$；
> - **单调性**：如果 $f \le g$，则 $\int f \, dm \le \int g \, dm$；
> - **可加性**：如果 $A \cap B = \emptyset$，则 $\int_{A \cup B} f \, dm = \int_A f \, dm + \int_B f \, dm$；
> - **绝对值不等式**：$|\int f \, dm| \le \int |f| \, dm$。
>

**解读**：

- 线性性、单调性、可加性、绝对值不等式；
- 与黎曼积分类似；
- 对可测函数成立。

**例子**：

> $\int (2 \chi_{[0, 1]} + 3 \chi_{[1, 2]}) \, dm = 5$。
>

**解读**：

- 线性性；
- 简单函数的积分。

**应用**：

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 2. 单调收敛定理

高木给出单调收敛定理：

> **单调收敛定理**：设 $f_n$ 是非负可测函数，且 $f_n \uparrow f$（逐点）。则
>
> $$\lim_{n \to \infty} \int f_n \, dm = \int f \, dm$$
>

**解读**：

- 单调收敛定理：单调递增的非负可测函数列，积分极限可交换；
- 是勒贝格积分最重要的定理之一；
- 允许交换极限和积分。

**证明**：

> 由 $f_n \le f$，$\int f_n \le \int f$，因此 $\lim \int f_n \le \int f$。
反之，对任意简单函数 $g \le f$，由 $f_n \uparrow f$，可以证明 $\lim \int f_n \ge \int g$。
取上确界，得到 $\lim \int f_n \ge \int f$。
>

**解读**：

- 证明用简单函数逼近；
- 单调收敛定理。

**例子**：

> $f_n = \sum_{k=1}^n \chi_{[k, k+1]}$。
>
> $$\int f_n = n \to \infty = \int f$$
>

**解读**：

- 单调收敛定理的例子；
- 极限交换。

**应用**：

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 3. 法图引理

高木给出法图引理：

> **法图引理**：设 $f_n$ 是非负可测函数。则
>
> $$\int \liminf_{n \to \infty} f_n \, dm \le \liminf_{n \to \infty} \int f_n \, dm$$
>

**解读**：

- 法图引理：下极限的积分 ≤ 积分的下极限；
- 是单调收敛定理的推广；
- 用于证明控制收敛定理。

**证明**：

> 令 $g_n = \inf_{k \ge n} f_k$。则 $g_n \uparrow \liminf f_n$。
由单调收敛定理，
>
> $$\int \liminf f_n = \lim \int g_n \le \liminf \int f_n$$
>

**解读**：

- 证明用单调收敛定理；
- 法图引理。

**例子**：

> $f_n = \chi_{[n, n+1]}$。
>
> $$\int \liminf f_n = 0 \le \liminf \int f_n = 1$$
>

**解读**：

- 法图引理的例子；
- 不等式。

**应用**：

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 4. 控制收敛定理

高木给出控制收敛定理：

> **控制收敛定理**：设 $f_n$ 是可测函数，$f_n \to f$（逐点），且存在可积函数 $g$ 使得 $|f_n| \le g$。则
>
> $$\lim_{n \to \infty} \int f_n \, dm = \int f \, dm$$
>

**解读**：

- 控制收敛定理：被可积函数控制的收敛函数列，积分极限可交换；
- 是勒贝格积分最强大的定理之一；
- 用于交换极限和积分。

**证明**：

> 由 $|f_n| \le g$，$g + f_n \ge 0$，$g - f_n \ge 0$。
对 $g + f_n$ 和 $g - f_n$ 应用法图引理，得到
>
> $$\int f \le \liminf \int f_n \le \limsup \int f_n \le \int f$$
>
> 因此 $\lim \int f_n = \int f$。
>

**解读**：

- 证明用法图引理；
- 控制收敛定理。

**例子**：

> $f_n = \frac{\sin x}{x} \chi_{[0, n]}$，$g = 1$。
>
> $$\lim \int f_n = \int f$$
>

**解读**：

- 控制收敛定理的例子；
- 极限交换。

**应用**：

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

## 问题1：基本性质

### 背景

证明：勒贝格积分的线性性。

### 详细解释

**（1）命题陈述**

$$\int (af + bg) \, dm = a \int f \, dm + b \int g \, dm$$

**（2）证明**

**证明**：

**第一步：对简单函数证明**。

设 $f = \sum a_i \chi_{A_i}$，$g = \sum b_j \chi_{B_j}$。

则

$$af + bg = \sum a a_i \chi_{A_i} + \sum b b_j \chi_{B_j}$$

$$\int (af + bg) = \sum a a_i m(A_i) + \sum b b_j m(B_j) = a \int f + b \int g$$

**第二步：对非负可测函数证明**。

由简单函数逼近，取 $f_n \uparrow f$，$g_n \uparrow g$。

由单调收敛定理，

$$\int (af + bg) = \lim \int (af_n + bg_n) = a \lim \int f_n + b \lim \int g_n = a \int f + b \int g$$

**第三步：对一般可测函数证明**。

分解为正部分和负部分。

**（3）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

勒贝格积分的线性性：$\int (af + bg) = a \int f + b \int g$。证明用简单函数和单调收敛定理。

## 问题2：单调收敛定理

### 背景

证明：单调收敛定理。

### 详细解释

**（1）命题陈述**

设 $f_n$ 是非负可测函数，且 $f_n \uparrow f$（逐点）。则

$$\lim_{n \to \infty} \int f_n \, dm = \int f \, dm$$

**（2）证明**

**证明**：

**第一步：** 由 $f_n \le f$，$\int f_n \le \int f$，因此

$$\lim \int f_n \le \int f$$

**第二步：** 对任意简单函数 $g \le f$，令 $c \in (0, 1)$，定义

$$A_n = \{x : f_n(x) \ge c g(x)\}$$

由 $f_n \uparrow f$，$A_n \uparrow X$。

$$\int f_n \ge \int_{A_n} f_n \ge c \int_{A_n} g$$

由 $A_n \uparrow X$ 和 $g$ 是简单函数，

$$\lim \int_{A_n} g = \int g$$

因此

$$\lim \int f_n \ge c \int g$$

令 $c \to 1$，

$$\lim \int f_n \ge \int g$$

取上确界，

$$\lim \int f_n \ge \int f$$

**（3）结论**

$$\lim \int f_n = \int f$$

**（4）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

单调收敛定理：$\lim \int f_n = \int f$。证明用简单函数逼近。

## 问题3：法图引理

### 背景

证明：法图引理。

### 详细解释

**（1）命题陈述**

设 $f_n$ 是非负可测函数。则

$$\int \liminf_{n \to \infty} f_n \, dm \le \liminf_{n \to \infty} \int f_n \, dm$$

**（2）证明**

**证明**：

令

$$g_n = \inf_{k \ge n} f_k$$

则 $g_n \uparrow \liminf f_n$，且 $g_n \le f_n$。

由单调收敛定理，

$$\int \liminf f_n = \lim \int g_n$$

由 $g_n \le f_n$，

$$\int g_n \le \int f_n$$

因此

$$\lim \int g_n \le \liminf \int f_n$$

即

$$\int \liminf f_n \le \liminf \int f_n$$

**（3）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

法图引理：$\int \liminf f_n \le \liminf \int f_n$。证明用单调收敛定理。

## 问题4：控制收敛定理

### 背景

证明：控制收敛定理。

### 详细解释

**（1）命题陈述**

设 $f_n$ 是可测函数，$f_n \to f$（逐点），且存在可积函数 $g$ 使得 $|f_n| \le g$。则

$$\lim_{n \to \infty} \int f_n \, dm = \int f \, dm$$

**（2）证明**

**证明**：

由 $|f_n| \le g$，$g + f_n \ge 0$，$g - f_n \ge 0$。

对 $g + f_n$ 应用法图引理：

$$\int (g + f) \le \liminf \int (g + f_n) = \int g + \liminf \int f_n$$

因此

$$\int f \le \liminf \int f_n$$

对 $g - f_n$ 应用法图引理：

$$\int (g - f) \le \liminf \int (g - f_n) = \int g - \limsup \int f_n$$

因此

$$\limsup \int f_n \le \int f$$

合并：

$$\int f \le \liminf \int f_n \le \limsup \int f_n \le \int f$$

所以

$$\lim \int f_n = \int f$$

**（3）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

控制收敛定理：$\lim \int f_n = \int f$。证明用法图引理。

### 1. 可加集合函数的定义

高木开篇写道：

可加集合函数是定义在集合族上的函数，满足有限可加性。可数可加集合函数满足可数可加性。

## 问题2：可加集合函数的性质

### 背景

证明：可数可加集合函数的连续性。

### 详细解释

**（1）命题陈述**

设 $\phi$ 是可数可加集合函数，$A_n \uparrow A$。则

$$\phi(A_n) \to \phi(A)$$

**（2）证明**

**证明**：

令 $B_1 = A_1$，$B_n = A_n \setminus A_{n-1}$（$n \ge 2$）。

则 $B_n$ 两两不交，且

$$A = \bigcup_{n=1}^\infty B_n$$

由可数可加性，

$$\phi(A) = \sum_{n=1}^\infty \phi(B_n)$$

部分和：

$$\sum_{k=1}^n \phi(B_k) = \phi(A_n)$$

因此

$$\phi(A) = \lim_{n \to \infty} \phi(A_n)$$

**（3）关键点**

- 构造不交序列；
- 可数可加性；
- 连续性。

**（4）应用**

- **测度论**：测度；
- **概率论**：概率；
- **数学**：实分析。

### 结论

可数可加集合函数的连续性：$A_n \uparrow A$ ⇒ $\phi(A_n) \to \phi(A)$。证明用可数可加性。

## 问题1：绝对连续性

### 背景

解释绝对连续性。

### 详细解释

**（1）定义**

设 $\phi$ 是符号测度，$m$ 是测度。如果

$$m(A) = 0 \implies \phi(A) = 0$$

则称 $\phi$ 关于 $m$ **绝对连续**，记为 $\phi \ll m$。

**（2）例子**

$\phi(A) = \int_A f \, dm$ 关于 $m$ 绝对连续。

**（3）性质**

- 绝对连续是拉东-尼科迪姆定理的条件；
- 绝对连续的符号测度可以表示为积分。

**（4）应用**

- **测度论**：拉东-尼科迪姆定理；
- **概率论**：密度函数；
- **数学**：实分析。

### 结论

绝对连续：零测集的像为 0。绝对连续的符号测度可以表示为积分。

## 问题2：奇异性

### 背景

解释奇异性。

### 详细解释

**（1）定义**

设 $\phi$ 是符号测度，$m$ 是测度。如果存在 $A \in \mathcal{F}$ 使得

$$m(A) = 0, \quad \phi(A^c) = 0$$

则称 $\phi$ 关于 $m$ **奇异**，记为 $\phi \perp m$。

**（2）例子**

狄拉克测度：$\delta_0(A) = 1$ 如果 $0 \in A$，否则 0。$\delta_0 \perp m$。

**（3）性质**

- 奇异测度集中在零测集上；
- 奇异测度与绝对连续测度正交。

**（4）应用**

- **测度论**：勒贝格分解；
- **概率论**：离散分布；
- **数学**：实分析。

### 结论

奇异：集中在零测集上。奇异测度与绝对连续测度正交。

## 问题3：勒贝格分解

### 背景

证明：勒贝格分解定理。

### 详细解释

**（1）命题陈述**

设 $\phi$ 是符号测度，$m$ 是σ-有限测度。则 $\phi$ 可以唯一分解为

$$\phi = \phi_{ac} + \phi_s$$

其中 $\phi_{ac} \ll m$（绝对连续），$\phi_s \perp m$（奇异）。

**（2）证明思路**

**证明**：

**第一步：** 由拉东-尼科迪姆定理，$\phi_{ac}(A) = \int_A f \, dm$。

**第二步：** 定义 $\phi_s = \phi - \phi_{ac}$。

**第三步：** 证明 $\phi_s \perp m$。

**第四步：** 证明唯一性。

**（3）关键点**

- 拉东-尼科迪姆定理；
- 绝对连续部分和奇异部分；
- 唯一性。

**（4）应用**

- **测度论**：勒贝格分解；
- **概率论**：分布分解；
- **数学**：实分析。

### 结论

勒贝格分解：$\phi = \phi_{ac} + \phi_s$。证明用拉东-尼科迪姆定理。

## 问题4：绝对连续函数

### 背景

解释绝对连续函数。

### 详细解释

**（1）定义**

设 $F: [a, b] \to \mathbb{R}$。如果对任意 $\epsilon > 0$，存在 $\delta > 0$，使得对任意有限个不交区间 $(a_i, b_i)$，

$$\sum (b_i - a_i) < \delta \implies \sum |F(b_i) - F(a_i)| < \epsilon$$

则称 $F$ 为**绝对连续函数**。

**（2）性质**

- 绝对连续函数几乎处处可微；
- $F(x) = F(a) + \int_a^x F'(t) dt$；
- 绝对连续函数是有界变差函数。

**（3）例子**

- 连续可微函数；
- 利普希茨函数。

**（4）应用**

- **测度论**：绝对连续函数；
- **概率论**：分布函数；
- **数学**：实分析。

### 结论

绝对连续函数：区间长度和小时，函数值变化和小。绝对连续函数几乎处处可微。

## 问题5：绝对连续函数与微积分基本定理

### 背景

证明：$F(x) = F(a) + \int_a^x F'(t) dt$。

### 详细解释

**（1）命题陈述**

设 $F$ 是绝对连续函数。则

$$F(x) = F(a) + \int_a^x F'(t) dt$$

**（2）证明思路**

**证明**：

**第一步：** 绝对连续函数几乎处处可微。

**第二步：** $F'$ 可积。

**第三步：** 由勒贝格积分，

$$\int_a^x F'(t) dt = F(x) - F(a)$$

**（3）关键点**

- 几乎处处可微；
- 勒贝格积分；
- 微积分基本定理。

**（4）应用**

- **测度论**：绝对连续函数；
- **概率论**：分布函数；
- **数学**：实分析。

### 结论

绝对连续函数满足微积分基本定理：$F(x) = F(a) + \int_a^x F'(t) dt$。证明用几乎处处可微和勒贝格积分。

## 问题6：绝对连续性在概率论中的应用

用绝对连续性分析概率密度。

### 详细解释

**（1）概率密度**

**（2）绝对连续性**

$P \ll m$ 当且仅当存在密度函数 $p$。

**（3）应用**

- **概率论**：概率密度；
- **统计学**：分布；
- **机器学习**：概率模型。

**（4）例子**

正态分布：

$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x - \mu)^2}{2\sigma^2}}$$

### 结论

绝对连续性在概率论中用于分析概率密度。绝对连续性是概率密度的条件。

## 问题5：体积的性质

### 背景

证明：体积的平移不变性。

### 详细解释

**（1）命题陈述**

对任意区间 $I$ 和 $t \in \mathbb{R}^n$，

$$|I + t| = |I|$$

**（2）证明**

**证明**：

设 $I = I_1 \times \dots \times I_n$，其中 $I_i = [a_i, b_i]$。

则

$$I + t = (I_1 + t_1) \times \dots \times (I_n + t_n)$$

其中 $I_i + t_i = [a_i + t_i, b_i + t_i]$。

长度：

$$(b_i + t_i) - (a_i + t_i) = b_i - a_i$$

因此

$$|I + t| = \prod_{i=1}^n (b_i - a_i) = |I|$$

**（3）其他性质**

- 可加性：如果 $I, J$ 不交，则 $|I \cup J| = |I| + |J|$；
- 单调性：如果 $I \subseteq J$，则 $|I| \le |J|$。

**（4）应用**

- **数学**：测度论；
- **物理**：体积；
- **机器学习**：超矩形体积。

### 结论

体积的平移不变性：$|I + t| = |I|$。证明用区间长度的平移不变性。

体积在物理中用于分析质量、质心、转动惯量。体积是力学的重要工具。

## §114 勒贝格测度

### 1. 勒贝格测度的定义

高木开篇写道：

> 在 $\mathbb{R}^n$ 上，定义**勒贝格外测度**：
>
> $$m^*(A) = \inf \left\{ \sum_{k=1}^\infty |I_k| : A \subseteq \bigcup_{k=1}^\infty I_k \right\}$$
>
> 其中 $I_k$ 是区间，$|I_k|$ 是区间体积。
>

**解读**：

- 外测度：覆盖区间的体积和的下确界；
- 用区间覆盖；
- 定义在所有子集上。

**可测集**：

> 如果对任意 $E \subseteq \mathbb{R}^n$，
>
> $$m^*(E) = m^*(E \cap A) + m^*(E \cap A^c)$$
>
> 则称 $A$ 为**勒贝格可测集**。
>

**勒贝格测度**：

## 问题1：勒贝格测度的定义

### 背景

定义勒贝格测度。

### 详细解释

**（1）外测度**

在 $\mathbb{R}^n$ 上，定义**勒贝格外测度**：

$$m^*(A) = \inf \left\{ \sum_{k=1}^\infty |I_k| : A \subseteq \bigcup_{k=1}^\infty I_k \right\}$$

其中 $I_k$ 是区间，$|I_k|$ 是区间体积。

**（2）可测集**

如果对任意 $E \subseteq \mathbb{R}^n$，

$$m^*(E) = m^*(E \cap A) + m^*(E \cap A^c)$$

则称 $A$ 为**勒贝格可测集**。

**（3）勒贝格测度**

对可测集 $A$，定义

$$m(A) = m^*(A)$$

**（4）例子**

- 区间：$m([a, b]) = b - a$；
- 开集、闭集：可测；
- 博雷尔集：可测。

**（5）应用**

- **测度论**：勒贝格测度；
- **概率论**：概率；
- **数学**：实分析。

### 结论

勒贝格测度通过外测度和可测集定义。从区间体积出发，用覆盖构造。

## 问题2：勒贝格测度的性质

### 背景

证明：勒贝格测度的平移不变性。

### 详细解释

**（1）命题陈述**

对任意可测集 $A$ 和 $t \in \mathbb{R}^n$，

$$m(A + t) = m(A)$$

**（2）证明**

**证明**：

由外测度的定义，

$$m^*(A + t) = \inf \left\{ \sum |I_k| : A + t \subseteq \bigcup I_k \right\}$$

令 $J_k = I_k - t$，则 $A \subseteq \bigcup J_k$，且 $|J_k| = |I_k|$。

因此

$$m^*(A + t) = \inf \left\{ \sum |J_k| : A \subseteq \bigcup J_k \right\} = m^*(A)$$

对可测集，$m(A + t) = m(A)$。

**（3）其他性质**

- 可数可加性；
- 单调性；
- 正则性。

**（4）应用**

- **测度论**：勒贝格测度；
- **概率论**：概率；
- **数学**：实分析。

### 结论

勒贝格测度的平移不变性：$m(A + t) = m(A)$。证明用外测度的定义。

## §119 累次积分

### 1. 累次积分的定义

高木开篇写道：

> 设 $(X, \mathcal{F}, \mu)$ 和 $(Y, \mathcal{G}, \nu)$ 是两个测度空间。在乘积空间 $X \times Y$ 上定义乘积测度 $\mu \times \nu$。对于可测函数 $f(x, y)$，定义**累次积分**：
>
> $$\int_X \left( \int_Y f(x, y) \, d\nu(y) \right) d\mu(x)$$
>
> $$\int_Y \left( \int_X f(x, y) \, d\mu(x) \right) d\nu(y)$$
>

**解读**：

- 累次积分：先对一个变量积分，再对另一个变量积分；
- 乘积空间：$X \times Y$；
- 乘积测度：$\mu \times \nu$。

**重积分**：

$$\iint_{X \times Y} f(x, y) \, d(\mu \times \nu)$$

**解读**：

- 重积分：在乘积空间上的积分；
- 与累次积分的关系：富比尼定理。

**例子**：

- $X = Y = \mathbb{R}$，$\mu = \nu = m$（勒贝格测度）；
- $f(x, y) = x y$。

**解读**：

- 累次积分的例子；
- 实数轴、勒贝格测度。

**应用**：

- **测度论**：乘积测度；
- **概率论**：联合分布；
- **数学**：实分析。

### 2. 富比尼定理

高木给出富比尼定理：

> **富比尼定理**：设 $f(x, y)$ 在 $X \times Y$ 上可积（关于 $\mu \times \nu$）。则
>
> $$\iint_{X \times Y} f(x, y) \, d(\mu \times \nu) = \int_X \left( \int_Y f(x, y) \, d\nu(y) \right) d\mu(x) = \int_Y \left( \int_X f(x, y) \, d\mu(x) \right) d\nu(y)$$
>

**解读**：

- 富比尼定理：重积分等于累次积分；
- 可以交换积分顺序；
- 条件：$f$ 可积。

**证明思路**：

> 对简单函数证明，然后由单调收敛定理推广到非负可测函数，最后由控制收敛定理推广到一般可积函数。
>

**解读**：

- 证明用简单函数和收敛定理；
- 富比尼定理。

**例子**：

> $$\int_0^1 \int_0^1 x y \, dx dy = \int_0^1 x dx \int_0^1 y dy = \frac{1}{4}$$
>

**解读**：

- 富比尼定理的例子；
- 交换积分顺序。

**应用**：

- **测度论**：乘积测度；
- **概率论**：期望；
- **数学**：实分析。

### 3. 托内利定理

高木给出托内利定理：

> **托内利定理**：设 $f(x, y) \ge 0$ 是可测函数。则

> $$\iint_{X \times Y} f(x, y) \, d(\mu \times \nu) = \int_X \left( \int_Y f(x, y) \, d\nu(y) \right) d\mu(x) = \int_Y \left( \int_X f(x, y) \, d\mu(x) \right) d\nu(y)$$
>
> 即使积分值为 $+\infty$ 也成立。
>

**解读**：

- 托内利定理：非负可测函数的富比尼定理；
- 不要求可积；
- 允许 $+\infty$。

**证明思路**：

> 对简单函数证明，然后由单调收敛定理推广。
>

**解读**：

- 证明用单调收敛定理；
- 托内利定理。

**例子**：

> $$\int_0^\infty \int_0^\infty e^{-(x+y)} dx dy = 1$$
>

**解读**：

- 托内利定理的例子；
- 非负函数。

**应用**：

- **测度论**：乘积测度；
- **概率论**：期望；
- **数学**：实分析。

## 问题4：交换积分顺序

### 背景

### 详细解释

**（1）计算**

$$\int_0^1 \int_0^1 x y \, dx dy = \int_0^1 \left( \int_0^1 x y \, dy \right) dx$$

内层：

$$\int_0^1 x y \, dy = x \cdot \frac{1}{2}$$

外层：

$$\int_0^1 \frac{x}{2} dx = \frac{1}{4}$$

**（2）交换积分顺序**

$$\int_0^1 \int_0^1 x y \, dy dx = \int_0^1 \left( \int_0^1 x y \, dx \right) dy = \int_0^1 \frac{y}{2} dy = \frac{1}{4}$$

一致。

**（3）应用**

- **测度论**：乘积测度；
- **概率论**：期望；
- **数学**：实分析。

### 结论

$\int_0^1 \int_0^1 x y \, dx dy = \frac{1}{4}$。计算用累次积分。

## 问题5：乘积测度

- **数学**：实分析。

### 结论

乘积测度是定义在乘积σ系上的测度，满足 $(\mu \times \nu)(A \times B) = \mu(A) \nu(B)$。

- 勒贝格积分：横条。

**（4）例子**

狄利克雷函数：黎曼不可积，勒贝格可积。

**（5）应用**

- **测度论**：勒贝格积分；
- **概率论**：期望；
- **数学**：实分析。

### 结论

黎曼积分分割定义域，用矩形逼近；勒贝格积分分割值域，用简单函数逼近。

## 问题2：可积函数类的比较

比较黎曼可积和勒贝格可积函数类。

## 问题3：收敛定理的比较

### 背景

比较黎曼积分和勒贝格积分的收敛定理。

**（2）勒贝格积分**

- 控制收敛定理；

## §121 斯蒂尔切斯积分

### 1. 斯蒂尔切斯积分的定义

高木开篇写道：

> 设 $f$ 是 $[a, b]$ 上的连续函数，$g$ 是 $[a, b]$ 上的有界变差函数。将 $[a, b]$ 分割为
>
> $$a = x_0 < x_1 < \dots < x_n = b$$
>
> 在每个小区间上任取一点 $\xi_i$，作和
>
> $$\sum_{i=1}^n f(\xi_i) (g(x_i) - g(x_{i-1}))$$
>
> 如果当分割的模趋于 0 时，该和的极限存在，则称该极限为 $f$ 关于 $g$ 的**斯蒂尔切斯积分**，记为
>
> $$\int_a^b f(x) \, dg(x)$$
>

**解读**：

- 斯蒂尔切斯积分：$f$ 关于 $g$ 的积分；
- $g$ 是有界变差函数；
- 与黎曼积分类似，但用 $g$ 的增量代替 $x$ 的增量。

**特例**：

- $g(x) = x$：退化为黎曼积分；
- $g$ 是阶梯函数：退化为有限和。

**解读**：

- 斯蒂尔切斯积分的特例；
- 黎曼积分、有限和。

**例子**：

- $\int_0^1 x \, d(x^2) = \int_0^1 2x^2 dx = \frac{2}{3}$。

**解读**：

- 斯蒂尔切斯积分的例子；
- 计算。

**应用**：

- **测度论**：勒贝格-斯蒂尔切斯积分；
- **概率论**：期望；
- **数学**：泛函分析。

### 2. 斯蒂尔切斯积分的性质

高木给出性质：

**（1）线性性**：

> $$\int_a^b (af + bh) \, dg = a \int_a^b f \, dg + b \int_a^b h \, dg$$
>

**（2）可加性**：

> $$\int_a^b f \, dg = \int_a^c f \, dg + \int_c^b f \, dg$$
>

**（3）分部积分**：

> $$\int_a^b f \, dg = [f g]_a^b - \int_a^b g \, df$$
>

**（4）绝对值不等式**：

> $$\left| \int_a^b f \, dg \right| \le \sup |f| \cdot V_a^b(g)$$
>
> 其中 $V_a^b(g)$ 是 $g$ 的全变差。
>

**解读**：

- 斯蒂尔切斯积分的性质；
- 线性性、可加性、分部积分、绝对值不等式；
- 与黎曼积分类似。

**例子**：

> $\int_0^1 x \, d(x^2) = \frac{2}{3}$。
>

**解读**：

- 斯蒂尔切斯积分的例子；
- 计算。

**应用**：

- **测度论**：勒贝格-斯蒂尔切斯积分；
- **概率论**：期望；
- **数学**：泛函分析。

### 3. 勒贝格-斯蒂尔切斯积分

高木给出勒贝格-斯蒂尔切斯积分：

> 设 $\phi$ 是 $[a, b]$ 上的有界变差函数，定义测度 $m_\phi$：
>
> $$m_\phi((a, x]) = \phi(x) - \phi(a)$$
>
> 则勒贝格-斯蒂尔切斯积分为
>
> $$\int_a^b f \, d\phi = \int_a^b f \, dm_\phi$$
>

**解读**：

- 勒贝格-斯蒂尔切斯积分：用勒贝格积分定义；
- $\phi$ 生成测度 $m_\phi$；
- 与斯蒂尔切斯积分一致。

**例子**：

- $\phi(x) = x$：$m_\phi$ 是勒贝格测度；
- $\phi$ 是阶梯函数：$m_\phi$ 是离散测度。

**解读**：

- 勒贝格-斯蒂尔切斯积分的例子；
- 勒贝格测度、离散测度。

**应用**：

- **测度论**：勒贝格-斯蒂尔切斯积分；
- **概率论**：分布函数；
- **数学**：泛函分析。

### 4. 斯蒂尔切斯积分的应用

高木给出应用：

**（2）泛函分析**：

>

**（3）数学**：

**解读**：

- 斯蒂尔切斯积分在概率论、泛函分析、数学中应用；

**例子**：

**解读**：

**应用**：

## 问题1：斯蒂尔切斯积分的定义

### 背景

定义斯蒂尔切斯积分。

### 详细解释

**（1）定义**

设 $f$ 是 $[a, b]$ 上的连续函数，$g$ 是 $[a, b]$ 上的有界变差函数。将 $[a, b]$ 分割为

$$a = x_0 < x_1 < \dots < x_n = b$$

在每个小区间上任取一点 $\xi_i$，作和

$$\sum_{i=1}^n f(\xi_i) (g(x_i) - g(x_{i-1}))$$

如果当分割的模趋于 0 时，该和的极限存在，则称该极限为 $f$ 关于 $g$ 的**斯蒂尔切斯积分**，记为

$$\int_a^b f(x) \, dg(x)$$

**（2）特例**

- $g(x) = x$：退化为黎曼积分；
- $g$ 是阶梯函数：退化为有限和。

**（3）例子**

$$\int_0^1 x \, d(x^2) = \int_0^1 2x^2 dx = \frac{2}{3}$$

**（4）应用**

- **测度论**：勒贝格-斯蒂尔切斯积分；
- **概率论**：期望；
- **数学**：泛函分析。

### 结论

斯蒂尔切斯积分是 $f$ 关于 $g$ 的积分，$g$ 是有界变差函数。用 $g$ 的增量代替 $x$ 的增量。

## 问题2：斯蒂尔切斯积分的性质

### 背景

证明：分部积分公式。

### 详细解释

**（1）命题陈述**

$$\int_a^b f \, dg = [f g]_a^b - \int_a^b g \, df$$

**（2）证明**

**证明**：

由斯蒂尔切斯积分的定义，

$$\sum_{i=1}^n f(\xi_i) (g(x_i) - g(x_{i-1}))$$

由分部求和（阿贝尔变换），

$$\sum_{i=1}^n f(\xi_i) (g(x_i) - g(x_{i-1})) = f(b) g(b) - f(a) g(a) - \sum_{i=1}^n g(x_{i-1}) (f(\xi_i) - f(\xi_{i-1}))$$

取极限，得到

$$\int_a^b f \, dg = [f g]_a^b - \int_a^b g \, df$$

**（3）关键点**

- 分部求和；
- 取极限；
- 分部积分公式。

**（4）应用**

- **测度论**：勒贝格-斯蒂尔切斯积分；
- **概率论**：期望；
- **数学**：泛函分析。

### 结论

分部积分公式：$\int_a^b f \, dg = [f g]_a^b - \int_a^b g \, df$。证明用分部求和。

## 问题4：斯蒂尔切斯积分的例子

### 背景

计算 $\int_0^1 x \, d(x^2)$。

### 详细解释

**（1）计算**

由 $g(x) = x^2$，$dg = 2x dx$。

$$\int_0^1 x \, d(x^2) = \int_0^1 x \cdot 2x \, dx = \int_0^1 2x^2 dx = \frac{2}{3}$$

**（2）验证**

由分部积分，

$$\int_0^1 x \, d(x^2) = [x \cdot x^2]_0^1 - \int_0^1 x^2 dx = 1 - \frac{1}{3} = \frac{2}{3}$$

一致。

**（3）应用**

- **测度论**：勒贝格-斯蒂尔切斯积分；
- **概率论**：期望；
- **数学**：泛函分析。

### 结论

$\int_0^1 x \, d(x^2) = \frac{2}{3}$。计算用 $dg = 2x dx$。

## §122 微分定义

### 1. 测度论中的微分

高木开篇写道：

> 在一元微积分中，导数是差商的极限：
>
> $$F'(x) = \lim_{h \to 0} \frac{F(x + h) - F(x)}{h}$$
>
> 在测度论中，我们用集合的测度代替区间长度，定义微分。
>

**解读**：

- 一元导数：差商的极限；
- 测度论微分：用测度代替长度；
- 推广微积分基本定理。

**定义**：

> 设 $\phi$ 是符号测度，$m$ 是测度。定义 $\phi$ 关于 $m$ 的**微分**为
>
> $$\frac{d\phi}{dm}(x) = \lim_{r \to 0} \frac{\phi(B(x, r))}{m(B(x, r))}$$
>
> 如果极限存在。
>

**解读**：

- 测度论微分：测度比的极限；
- $B(x, r)$ 是以 $x$ 为中心、$r$ 为半径的球；
- 是拉东-尼科迪姆导数的推广。

**例子**：

- 如果 $\phi(A) = \int_A f \, dm$，则 $\frac{d\phi}{dm} = f$。

**解读**：

- 测度论微分的例子；
- 拉东-尼科迪姆导数。

**应用**：

- **测度论**：拉东-尼科迪姆定理；
- **概率论**：密度函数；
- **数学**：实分析。

### 2. 拉东-尼科迪姆导数

高木给出拉东-尼科迪姆导数：

> 设 $\phi$ 是符号测度，$m$ 是σ-有限测度，且 $\phi \ll m$。则存在可测函数 $f$ 使得
>
> $$\phi(A) = \int_A f \, dm$$
>
> 称 $f$ 为 $\phi$ 关于 $m$ 的**拉东-尼科迪姆导数**，记为
>
> $$f = \frac{d\phi}{dm}$$
>

**解读**：

- 拉东-尼科迪姆导数：密度函数；
- 绝对连续的符号测度可以表示为积分；
- 是测度论的核心。

**性质**：

- $\frac{d\phi}{dm}$ 几乎处处唯一；
- 如果 $\phi \ll m$，则 $\frac{d\phi}{dm}$ 存在；
- 链式法则：$\frac{d\phi}{d\nu} = \frac{d\phi}{dm} \frac{dm}{d\nu}$。

**解读**：

- 拉东-尼科迪姆导数的性质；
- 唯一性、存在性、链式法则。

**例子**：

- 概率密度：$P(A) = \int_A p(x) dx$，$p = \frac{dP}{dm}$。

**解读**：

- 概率密度；
- 拉东-尼科迪姆导数。

**应用**：

- **测度论**：拉东-尼科迪姆定理；
- **概率论**：密度函数；
- **数学**：实分析。

### 3. 不定积分的微分

## §123 Vitali覆盖定理

### 1. 维塔利覆盖的定义

高木开篇写道：

> 设 $A \subseteq \mathbb{R}$，$\mathcal{I}$ 是一族区间。如果对每一点 $x \in A$ 和任意 $\epsilon > 0$，存在区间 $I \in \mathcal{I}$，使得
>
> $$x \in I, \quad |I| < \epsilon$$
>
> 则称 $\mathcal{I}$ 为 $A$ 的**维塔利覆盖**。
>

**解读**：

- 维塔利覆盖：每点都可以被任意小的区间覆盖；
- $\mathcal{I}$ 是一族区间；
- 用于逼近集合 $A$。

**例子**：

- $A = [0, 1]$，$\mathcal{I}$ 是所有包含 $A$ 中某点的开区间；
- $A = \mathbb{R}$，$\mathcal{I}$ 是所有有限开区间。

**解读**：

- 维塔利覆盖的例子；
- 开区间族。

**应用**：

- **测度论**：勒贝格微分定理；
- **数学**：实分析；
- **概率论**：密度函数。

### 2. 维塔利覆盖定理

高木给出维塔利覆盖定理：

> **维塔利覆盖定理**：设 $A \subseteq \mathbb{R}$ 且 $m(A) < \infty$，$\mathcal{I}$ 是 $A$ 的维塔利覆盖。则存在可数个不交区间 $I_1, I_2, \dots \in \mathcal{I}$，使得
>
> $$m\left( A \setminus \bigcup_{n=1}^\infty I_n \right) = 0$$
>

**解读**：

- 维塔利覆盖定理：可以用可数个不交区间覆盖 $A$（几乎处处）；
- 区间来自维塔利覆盖；
- 是测度论的核心定理。

**证明思路**：

> **第一步：** 取 $I_1$ 为 $\mathcal{I}$ 中长度最大的区间。
**第二步：** 从 $\mathcal{I}$ 中删去与 $I_1$ 相交的区间。
**第三步：** 取 $I_2$ 为剩余区间中长度最大的。
**第四步：** 重复，得到一列不交区间。
**第五步：** 证明这些区间覆盖 $A$ 几乎处处。
>

**解读**：

- 证明用贪心算法；
- 选择最长区间；
- 不交性；
- 几乎处处覆盖。

**例子**：

> $A = [0, 1]$，$\mathcal{I}$ 是所有开区间。
可以选择可数个不交开区间覆盖 $A$。
>

**解读**：

- 维塔利覆盖定理的例子；
- 开区间。

**应用**：

- **测度论**：勒贝格微分定理；
- **数学**：实分析；
- **概率论**：密度函数。

>

**解读**：

- 用球代替区间；

**例子**：

- 存在可数个不交球覆盖 $A$ 几乎处处。

**解读**：

**应用**：

- **概率论**：密度函数。

### 4. 维塔利覆盖定理的应用

高木给出应用：

**（1）勒贝格微分定理**：

> 设 $f$ 是可积函数。则
>
> $$\lim_{r \to 0} \frac{1}{m(B(x, r))} \int_{B(x, r)} f(y) dy = f(x)$$
>
> 几乎处处成立。
>

**（2）绝对连续性**：

> 绝对连续函数几乎处处可微。
>

**（3）勒贝格分解**：

> 符号测度可以分解为绝对连续部分和奇异部分。

## 问题1：维塔利覆盖的定义

### 背景

定义维塔利覆盖。

### 详细解释

**（1）定义**

设 $A \subseteq \mathbb{R}$，$\mathcal{I}$ 是一族区间。如果对每一点 $x \in A$ 和任意 $\epsilon > 0$，存在区间 $I \in \mathcal{I}$，使得

$$x \in I, \quad |I| < \epsilon$$

则称 $\mathcal{I}$ 为 $A$ 的**维塔利覆盖**。

**（2）直观理解**

- 每点都可以被任意小的区间覆盖；
- 覆盖可以非常精细；
- 用于逼近集合。

**（3）例子**

- $A = [0, 1]$，$\mathcal{I}$ 是所有包含 $A$ 中某点的开区间；
- $A = \mathbb{R}$，$\mathcal{I}$ 是所有有限开区间。

**（4）应用**

- **测度论**：勒贝格微分定理；
- **数学**：实分析；
- **概率论**：密度函数。

### 结论

维塔利覆盖是每点都可以被任意小区间覆盖的区间族。

## 问题2：维塔利覆盖定理

**（4）应用**

- **概率论**：密度函数。

### 结论

维塔利覆盖定理：可以用可数个不交区间覆盖 $A$ 几乎处处。证明用贪心算法。

## 问题1：有界变差函数

### 背景

定义有界变差函数。

### 详细解释

**（1）定义**

设 $F: [a, b] \to \mathbb{R}$。如果 $F$ 的全变差

$$V_a^b(F) = \sup \sum_{i=1}^n |F(x_i) - F(x_{i-1})| < \infty$$

则称 $F$ 为**有界变差函数**。

**（2）性质**

- 有界变差函数可以分解为两个单调递增函数的差；
- 几乎处处可微；
- 对应的集合函数是可数可加符号测度。

**（3）例子**

- 单调函数；
- 利普希茨函数；
- 康托尔函数。

**（4）应用**

- **测度论**：符号测度；
- **概率论**：分布函数；
- **数学**：实分析。

### 结论

有界变差函数是全变差有限的函数。可以分解为单调函数的差，几乎处处可微。

## 问题2：绝对连续函数

### 背景

解释绝对连续函数。

### 详细解释

**（1）定义**

设 $F: [a, b] \to \mathbb{R}$。如果对任意 $\epsilon > 0$，存在 $\delta > 0$，使得对任意有限个不交区间 $(a_i, b_i)$，

$$\sum (b_i - a_i) < \delta \implies \sum |F(b_i) - F(a_i)| < \epsilon$$

则称 $F$ 为**绝对连续函数**。

**（2）性质**

- 绝对连续函数几乎处处可微；
- $F(x) = F(a) + \int_a^x F'(t) dt$；
- 绝对连续函数是有界变差函数。

**（3）例子**

- 连续可微函数；
- 利普希茨函数。

**（4）应用**

- **测度论**：绝对连续函数；
- **概率论**：分布函数；
- **数学**：实分析。

### 结论

绝对连续函数：区间长度和小时，函数值变化和小。几乎处处可微，满足微积分基本定理。

## 问题3：有界变差函数的分解

### 背景

证明：有界变差函数可以分解为绝对连续、奇异连续、离散部分。

### 详细解释

**（1）命题陈述**

设 $F$ 是有界变差函数。则 $F$ 可以唯一分解为

$$F = F_{ac} + F_s + F_d$$

其中：

- $F_{ac}$ 绝对连续；
- $F_s$ 奇异连续；
- $F_d$ 离散（跳跃）。

**（2）证明思路**

**证明**：

**第一步：** 由勒贝格分解，符号测度 $\phi$ 分解为绝对连续部分和奇异部分。

**第二步：** 奇异部分再分解为连续部分和离散部分。

**第三步：** 得到 $F = F_{ac} + F_s + F_d$。

**（3）关键点**

- 勒贝格分解；
- 奇异部分再分解；
- 唯一性。

**（4）应用**

- **测度论**：勒贝格分解；
- **概率论**：分布分解；
- **数学**：实分析。

### 结论

有界变差函数可以分解为绝对连续、奇异连续、离散部分。证明用勒贝格分解。

## 问题4：微积分基本定理

### 背景

证明：微积分基本定理。

### 详细解释

**（1）命题陈述**

如果 $F$ 绝对连续，则

$$F(x) = F(a) + \int_a^x F'(t) dt$$

**（2）证明**

**证明**：

由勒贝格分解，$F = F_{ac} + F_s + F_d$。

如果 $F$ 绝对连续，$F_s = 0$，$F_d = 0$。

因此

$$F(x) = F(a) + \int_a^x F'(t) dt$$

**（3）关键点**

- 勒贝格分解；
- 绝对连续；
- 微积分基本定理。

**（4）应用**

- **测度论**：勒贝格积分；
- **概率论**：分布函数；
- **数学**：实分析。

### 结论

微积分基本定理：$F(x) = F(a) + \int_a^x F'(t) dt$。证明用勒贝格分解。

## 问题5：康托尔函数

### 背景

分析康托尔函数的分解。

### 详细解释

**（1）康托尔函数**

康托尔函数 $C(x)$ 是 $[0, 1]$ 上的连续单调递增函数，从 0 增加到 1，在康托尔集上导数为 0。

**（2）分解**

- $C_{ac} = 0$（绝对连续部分为 0）；
- $C_s = C$（奇异连续部分）；
- $C_d = 0$（离散部分为 0）。

**（3）性质**

- $C'(x) = 0$ 几乎处处；
- $C(1) - C(0) = 1 \neq \int_0^1 C'(t) dt = 0$。

**（4）应用**

- **测度论**：奇异连续函数；
- **概率论**：奇异分布；
- **数学**：实分析。

### 结论

康托尔函数是奇异连续函数，绝对连续部分为 0，离散部分为 0。
