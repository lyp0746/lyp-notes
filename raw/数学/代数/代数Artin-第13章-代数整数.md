在第十二章中，我们研究了因子分解，特别是高斯整数环 $\mathbb{Z}[i]$ 的唯一分解。现在，我们研究更一般的数域：**二次数域**。二次数域是形如 $\mathbb{Q}(\sqrt{d})$ 的域，其中 $d$ 是无平方因子的整数。它们是代数数论中最基本、最重要的例子。本节将研究代数整数、二次数域的整数环、理想的分解、理想类群、实二次域、格等内容。

## 第十三章 第一节：代数整数

### 一、代数数与代数整数

**定义 13.1.1**：复数 $\alpha$ 是**代数数**，如果它是某个非零有理系数多项式的根。

**定义 13.1.2**：代数数 $\alpha$ 是**代数整数**，如果它在 $\mathbb{Q}$ 上的首一既约多项式是整系数的。

**例子**：

- $\sqrt{2}$ 是代数整数，因为 $x^2 - 2$ 是首一整系数多项式。
- $\frac{1}{2}$ 不是代数整数，因为 $x - \frac{1}{2}$ 不是整系数。
- $\omega = e^{2\pi i/3}$ 是代数整数，因为 $x^2 + x + 1$。

**引理 13.1.1**：有理数是代数整数当且仅当它是整数。

### 二、二次数域

**定义**：**二次数域**是形如

$$\mathbb{Q}[\sqrt{d}] = \{a + b\sqrt{d} \mid a, b \in \mathbb{Q}\}$$

的域，其中 $d$ 是无平方因子的非零整数。

**分类**：

- $d > 0$：**实二次数域**。
- $d < 0$：**虚二次数域**。

**例子**：

- $\mathbb{Q}(i) = \mathbb{Q}[\sqrt{-1}]$。
- $\mathbb{Q}(\sqrt{2})$。
- $\mathbb{Q}(\sqrt{-5})$。

### 三、二次数域中的代数整数

**命题 13.1.6**：设 $d$ 无平方因子。$\mathbb{Q}[\sqrt{d}]$ 中的代数整数具有形式 $a + b\sqrt{d}$，其中：

- 若 $d \equiv 2, 3 \pmod 4$，则 $a, b \in \mathbb{Z}$。
- 若 $d \equiv 1 \pmod 4$，则 $a, b$ 都是整数或都是半整数。

**例子**：

- $\mathbb{Q}(i)$：整数是 $a + bi$，$a, b \in \mathbb{Z}$。
- $\mathbb{Q}(\sqrt{-3})$：整数是 $a + b\omega$，$\omega = \frac{1+\sqrt{-3}}{2}$。
- $\mathbb{Q}(\sqrt{5})$：整数是 $a + b\frac{1+\sqrt{5}}{2}$。

**整数环**：记作 $\mathcal{O}_K$ 或 $R$。

## 第十三章 第二节：分解代数整数

### 一、范数

**定义**：对 $\alpha = a + b\sqrt{d}$，**范数**

$$N(\alpha) = \alpha \bar{\alpha} = a^2 - b^2 d.$$

**性质**：

- $N(\alpha \beta) = N(\alpha) N(\beta)$。
- $N(\alpha) = 0$ 当且仅当 $\alpha = 0$。
- $\alpha$ 是单位当且仅当 $N(\alpha) = \pm 1$。

### 二、单位

**命题 13.2.2**：虚二次数域的单位是：

- 一般情形：$\pm 1$。
- $d = -1$：$\pm 1, \pm i$。
- $d = -3$：$\pm 1, \pm \omega, \pm \omega^2$。

**实二次数域**：单位无限多（见第十三章第九节）。

### 三、唯一分解失败

**命题 13.2.4**：若 $d \equiv 3 \pmod 4$ 且 $d < -1$，则 $R$ 不是唯一分解整环。

**例子**：$\mathbb{Z}[\sqrt{-5}]$：

$$6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5}).$$

**定理 13.2.5**：虚二次数域的整数环是唯一分解整环当且仅当

$$d = -1, -2, -3, -7, -11, -19, -43, -67, -163.$$

## 第十三章 第三节：$\mathbb{Z}[\sqrt{-5}]$ 中的理想

### 一、理想是格

**命题 13.3.1**：虚二次数域整数环的非零理想是格。

**例子**：$R = \mathbb{Z}[\sqrt{-5}]$，理想 $A = (2, 1+\sqrt{-5})$ 是格。

### 二、理想的分类

**定理 13.3.3**：令 $R = \mathbb{Z}[\sqrt{-5}]$，$A$ 是非零理想。令 $\alpha$ 是 $A$ 中具有最小范数的非零元。则：

- 若 $A = (\alpha)$，格基是 $(\alpha, \alpha\sqrt{-5})$。
- 否则，格基是 $(\alpha, \frac{1}{2}(\alpha + \alpha\sqrt{-5}))$。

**类数**：$\mathbb{Z}[\sqrt{-5}]$ 的类数是 2。

## 第十三章 第四节：理想的乘法

### 一、理想的积

**定义 13.4.1**：理想 $A, B$ 的积 $AB$ 是由所有有限和

$$\sum \alpha_i \beta_i, \quad \alpha_i \in A, \beta_i \in B$$

生成的理想。

**性质**：

- $AB = BA$。
- $A(BC) = (AB)C$。
- $AR = A$。

### 二、主引理

**引理 13.4.8（主引理）**：令 $R$ 为虚二次数域整数环，$A$ 是非零理想。则

$$\bar{A} A = (n)$$

是由正整数 $n$ 生成的主理想。

**证明**：取 $A$ 的格基 $(\alpha, \beta)$。则 $\bar{A} A$ 由 $\bar{\alpha}\alpha, \bar{\alpha}\beta, \bar{\beta}\alpha, \bar{\beta}\beta$ 生成。其中三个是整数，取最大公约数 $n$。用代数整数证明 $n$ 整除所有生成元。

### 三、消去律

**推论 13.4.9**：
(a) 若 $AB = AC$，则 $B = C$。
(b) $A \supset B$ 当且仅当 $A$ 整除 $B$。

## 第十三章 第五节：分解理想

### 一、素理想

**定义 13.5.1**：理想 $P$ 是**素的**，如果 $R/P$ 是整环。

**命题 13.5.2**：极大理想是素理想。

### 二、唯一分解

**定理 13.5.5**：虚二次数域整数环的每个真理想是素理想的积，且分解唯一。

**证明**：用主引理和消去律。

### 三、理想类群

**定理 13.5.6**：$R$ 是唯一分解整环当且仅当它是主理想整环，当且仅当类群是平凡群。

## 第十三章 第六节：素理想与素整数

### 一、素理想的分类

**定理 13.6.1**：令 $P$ 是 $R$ 的非零素理想，$\bar{P}P = (n)$。则 $n$ 是素数或素数的平方。

**整素数 $p$ 的行为**：

- $p$ 持素：$(p)$ 是素理想。
- $p$ 分裂：$(p) = \bar{P} P$，$P \neq \bar{P}$。
- $p$ 分叉：$(p) = P^2$。

### 二、判别

**定理 13.6.1(c)**：若 $d \equiv 2, 3 \pmod 4$，则 $p$ 持素当且仅当 $d$ 不是模 $p$ 的平方。

## 第十三章 第七节：理想类

### 一、理想的相似

**定义 13.7.1**：理想 $A, A'$ 相似，如果 $A' = \lambda A$ 对某个复数 $\lambda$。

**理想类**：相似类。

### 二、类群

**命题 13.7.3**：理想类构成阿贝尔群 $C$，称为**类群**。

**运算**：$\langle A \rangle \langle B \rangle = \langle AB \rangle$。

**单位元**：主理想类。

**逆元**：$\langle \bar{A} \rangle$。

### 三、类数

**定义**：类群的阶称为**类数**。

**例子**：$\mathbb{Z}[\sqrt{-5}]$ 的类数为 2。

**定理 13.7.10**：类群有限。

## 第十三章 第八节：计算类群

### 一、类群的计算

**方法**：

1. 确定范数上界 $\mu$。
2. 检查素数 $p \le \mu$ 的行为。
3. 确定生成元和关系。
4. 计算类群。

**例子**：

- $d = -5$：类群 $C_2$。
- $d = -26$：类群 $C_6$。

## 第十三章 第九节：实二次域

### 一、单位

**定理 13.9.9**：实二次数域的单位群是无限群。

**证明**：用格和双曲线。

### 二、理想分解

实二次数域的理想也有唯一分解，类群有限。

## 第十三章 第十节：关于格

### 一、格的基本概念

**格**：$\mathbb{R}^2$ 的离散子群。

**格基**：$(v_1, v_2)$。

**指标**：$[M : L]$。

**面积**：$\Delta(L)$。

### 二、格的基本定理

**定理 13.10.6**：$[M : L] = \Delta(L) / \Delta(M)$。

**引理 13.10.8**：格中最短向量的长度平方 $\le \frac{2}{\sqrt{3}} \Delta(L)$。

## 1. 代数整数与代数数有什么区别？为什么代数整数要求首一整系数多项式？

### 代数数

**定义**：复数 $\alpha$ 是**代数数**，如果它是某个非零有理系数多项式的根。

**例子**：$\sqrt{2}$，$i$，$\frac{1}{2}$，$\sqrt{3} + \sqrt{-5}$。

### 代数整数

**定义**：代数数 $\alpha$ 是**代数整数**，如果它在 $\mathbb{Q}$ 上的首一既约多项式是整系数的。

**例子**：

- $\sqrt{2}$：$x^2 - 2$，整系数，是代数整数。
- $\frac{1}{2}$：$x - \frac{1}{2}$，不是整系数，不是代数整数。
- $\omega = e^{2\pi i/3}$：$x^2 + x + 1$，整系数，是代数整数。

### 区别

| 性质 | 代数数 | 代数整数 |
| --- | --- | --- |
| 定义 | 有理系数多项式的根 | 首一整系数多项式的根 |
| 例子 | $\frac{1}{2}, \sqrt{2}, i$ | $\sqrt{2}, i, \omega$ |
| 有理数 | 所有有理数 | 只有整数 |
| 环结构 | 不构成环？构成域 | 构成环 |

### 为什么要求首一整系数多项式？

- 代数整数是整数在代数数域中的推广。
- 首一整系数多项式保证代数整数构成环。
- 若允许任意整系数多项式，则 $\frac{1}{2}$ 会成为代数整数（$2x - 1 = 0$），不符合整数推广的意图。
- 首一条件保证代数整数在加法、乘法下封闭。

### 总结

代数数是任意有理系数多项式的根，代数整数是首一整系数多项式的根。首一条件保证代数整数构成环，是整数的正确推广。

## 2. 二次数域的整数环如何确定？为什么 $d \equiv 1 \pmod 4$ 时有半整数？

### 二次数域

$$\mathbb{Q}[\sqrt{d}] = \{a + b\sqrt{d} \mid a, b \in \mathbb{Q}\}.$$

### 整数环的确定

**命题 13.1.6**：设 $d$ 无平方因子。$\mathbb{Q}[\sqrt{d}]$ 中的代数整数具有形式 $a + b\sqrt{d}$，其中：

- 若 $d \equiv 2, 3 \pmod 4$，则 $a, b \in \mathbb{Z}$。
- 若 $d \equiv 1 \pmod 4$，则 $a, b$ 都是整数或都是半整数。

**例子**：

- $\mathbb{Q}(i)$：$d = -1 \equiv 3 \pmod 4$，整数是 $a + bi$，$a, b \in \mathbb{Z}$。
- $\mathbb{Q}(\sqrt{-3})$：$d = -3 \equiv 1 \pmod 4$，整数是 $a + b\omega$，$\omega = \frac{1+\sqrt{-3}}{2}$。
- $\mathbb{Q}(\sqrt{5})$：$d = 5 \equiv 1 \pmod 4$，整数是 $a + b\frac{1+\sqrt{5}}{2}$。

### 为什么 $d \equiv 1 \pmod 4$ 时有半整数？

设 $\alpha = a + b\sqrt{d}$，$a, b \in \mathbb{Q}$。$\alpha$ 的既约多项式是

$$x^2 - 2a x + (a^2 - b^2 d).$$

$\alpha$ 是代数整数当且仅当 $2a$ 和 $a^2 - b^2 d$ 是整数。

- 若 $a$ 是整数，则 $b^2 d$ 是整数，所以 $b$ 是整数。
- 若 $a$ 是半整数，则 $a^2 \in \mathbb{Z} + \frac{1}{4}$。要使 $a^2 - b^2 d$ 是整数，需要 $b^2 d \in \mathbb{Z} + \frac{1}{4}$。这要求 $4b^2 d$ 是整数，所以 $2b$ 是整数。进一步，$b$ 是半整数，且 $d \equiv 1 \pmod 4$。

### 总结

二次数域的整数环由 $d \bmod 4$ 决定。$d \equiv 2, 3 \pmod 4$ 时，整数是 $a + b\sqrt{d}$，$a, b \in \mathbb{Z}$。$d \equiv 1 \pmod 4$ 时，整数是 $a + b\frac{1+\sqrt{d}}{2}$，$a, b \in \mathbb{Z}$。半整数出现是因为 $d \equiv 1 \pmod 4$ 时 $a^2 - b^2 d$ 可以是整数。

## 3. 为什么 $\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环？理想分解如何修正？

### $\mathbb{Z}[\sqrt{-5}]$

$$\mathbb{Z}[\sqrt{-5}] = \{a + b\sqrt{-5} \mid a, b \in \mathbb{Z}\}.$$

### 唯一分解失败

$$6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5}).$$

- $2, 3, 1+\sqrt{-5}, 1-\sqrt{-5}$ 都是既约元。
- 它们不相伴。
- 所以分解不唯一。

**原因**：既约元 $2$ 不是素元。$2 \mid (1+\sqrt{-5})(1-\sqrt{-5})$，但 $2$ 不整除其中任何一个。

### 理想分解如何修正？

在 $\mathbb{Z}[\sqrt{-5}]$ 中，理想有唯一分解。例如：

$$(6) = (2, 1+\sqrt{-5})^2 (3, 1+\sqrt{-5})(3, 1-\sqrt{-5}).$$

理想分解唯一。

### 类群

$\mathbb{Z}[\sqrt{-5}]$ 的类数为 2。类群 $C_2$ 衡量唯一分解失败的程度。

### 总结

$\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环，因为既约元不是素元。理想分解修正了这一缺陷：理想有唯一分解。类群衡量失败程度。

## 4. 理想类群如何衡量唯一分解失败的程度？类数有什么意义？

### 理想类群

**定义**：理想类群 $C$ 是非零理想的相似类在乘法下构成的阿贝尔群。

**单位元**：主理想类。

**逆元**：$\langle \bar{A} \rangle$。

### 类数

**定义**：类群的阶称为**类数**。

### 意义

- 类数 $= 1$：唯一分解整环。
- 类数 $> 1$：唯一分解失败。
- 类数越大，唯一分解失败越严重。

### 例子

- $\mathbb{Z}[i]$：类数 1，唯一分解。
- $\mathbb{Z}[\sqrt{-5}]$：类数 2，唯一分解失败。
- $\mathbb{Z}[\sqrt{-26}]$：类数 6。

### 总结

理想类群衡量唯一分解失败的程度。类数 1 对应唯一分解整环。类数越大，失败越严重。

## 5. 实二次域的单位群为什么无限？如何用格和双曲线证明？

### 实二次域

$$\mathbb{Q}(\sqrt{d}), \quad d > 0.$$

### 单位群无限

**定理 13.9.9**：实二次数域的单位群是无限群。

**证明**：用格和双曲线。

- 嵌入 $\alpha = a + b\sqrt{d} \mapsto (u, v) = (a + b\sqrt{d}, a - b\sqrt{d})$。
- 范数 $N(\alpha) = uv$。
- 单位对应 $uv = \pm 1$。
- 格点位于双曲线 $uv = \pm 1$ 上。
- 双曲线有无限多个格点，所以单位无限多。

**例子**：$\mathbb{Z}[\sqrt{2}]$ 的单位：$1+\sqrt{2}$，$(1+\sqrt{2})^2 = 3+2\sqrt{2}$，等等。

### 总结

实二次域的单位群无限，因为单位对应双曲线上的格点，双曲线有无限多个格点。

## 6. 二次数域在数论中有什么应用？例如，费马大定理、椭圆曲线、模形式。

### 费马大定理

### 椭圆曲线

- 二次数域用于研究椭圆曲线。

### 模形式

- 例如，模形式的系数。

### 其他应用

- **代数数论**：二次数域是代数数论的基本例子。
- **密码学**：二次数域用于构造密码系统。
- **编码理论**：二次数域用于构造编码。

### 总结

二次数域在数论中应用广泛：费马大定理、椭圆曲线、模形式、代数数论、密码学、编码理论。它是现代数论的核心工具。

在第十二章中，我们研究了因子分解，特别是高斯整数环 $\mathbb{Z}[i]$ 的唯一分解。现在，我们研究更一般的数域：**二次数域**。二次数域是形如 $\mathbb{Q}(\sqrt{d})$ 的域，其中 $d$ 是无平方因子的整数。它们是代数数论中最基本、最重要的例子。本节将研究代数数与代数整数、二次数域的定义、二次数域中的整数环。

## 一、代数数与代数整数

### 代数数

**定义 13.1.1**：复数 $\alpha$ 是**代数数**，如果它是某个非零有理系数多项式的根：

$$f(\alpha) = 0, \quad f(x) \in \mathbb{Q}[x], \quad f \neq 0.$$

**例子**：

- $\sqrt{2}$：$x^2 - 2$ 的根。
- $i$：$x^2 + 1$ 的根。
- $\frac{1}{2}$：$2x - 1$ 的根。
- $\sqrt{3} + \sqrt{-5}$：$x^4 + 4x^2 + 64$ 的根。

### 代数整数

**定义 13.1.2**：代数数 $\alpha$ 是**代数整数**，如果它在 $\mathbb{Q}$ 上的首一既约多项式是整系数的。

**等价定义**：$\alpha$ 是某个首一整系数多项式的根：

$$f(\alpha) = 0, \quad f(x) = x^n + a_{n-1} x^{n-1} + \cdots + a_0, \quad a_i \in \mathbb{Z}.$$

**例子**：

- $\sqrt{2}$：$x^2 - 2$ 首一整系数，是代数整数。
- $\frac{1}{2}$：既约多项式 $x - \frac{1}{2}$ 不是整系数，不是代数整数。
- $\omega = e^{2\pi i/3}$：$x^2 + x + 1$ 首一整系数，是代数整数。
- $\frac{1}{2}(1 + \sqrt{3})$：既约多项式 $x^2 - x - \frac{1}{2}$，不是整系数，不是代数整数。

**引理 13.1.1**：有理数是代数整数当且仅当它是整数。

**证明**：有理数 $\alpha = a/b$ 的既约多项式是 $x - a/b$。它是整系数当且仅当 $b = 1$，即 $\alpha$ 是整数。

## 二、二次数域

**定义 13.1.2**：**二次数域**是形如

$$\mathbb{Q}[\sqrt{d}] = \{a + b\sqrt{d} \mid a, b \in \mathbb{Q}\}$$

的域，其中 $d$ 是无平方因子的非零整数。

**分类**：

- $d > 0$：**实二次数域**。
- $d < 0$：**虚二次数域**。

**例子**：

- $\mathbb{Q}(i) = \mathbb{Q}[\sqrt{-1}]$：虚二次数域。
- $\mathbb{Q}(\sqrt{2})$：实二次数域。
- $\mathbb{Q}(\sqrt{-5})$：虚二次数域。
- $\mathbb{Q}(\sqrt{5})$：实二次数域。

**注意**：$d$ 可以取 $-1, \pm 2, \pm 3, \pm 5, \pm 6, \pm 7, \pm 10, \dots$。

## 三、二次数域中的代数整数

**命题 13.1.6**：设 $d$ 无平方因子。$\mathbb{Q}[\sqrt{d}]$ 中的代数整数具有形式 $a + b\sqrt{d}$，其中：

- 若 $d \equiv 2, 3 \pmod 4$，则 $a, b \in \mathbb{Z}$。
- 若 $d \equiv 1 \pmod 4$，则 $a, b$ 都是整数或都是半整数。

**证明**：

设 $\alpha = a + b\sqrt{d}$，$a, b \in \mathbb{Q}$。$\alpha$ 的既约多项式是

$$x^2 - 2a x + (a^2 - b^2 d).$$

$\alpha$ 是代数整数当且仅当 $2a$ 和 $a^2 - b^2 d$ 是整数。

**情形 1**：$a$ 是整数。则 $b^2 d$ 是整数，所以 $b$ 是整数。

**情形 2**：$a$ 是半整数。则 $a^2 \in \mathbb{Z} + \frac{1}{4}$。要使 $a^2 - b^2 d$ 是整数，需要 $b^2 d \in \mathbb{Z} + \frac{1}{4}$。这要求 $4b^2 d$ 是整数，所以 $2b$ 是整数。进一步，$b$ 是半整数，且 $d \equiv 1 \pmod 4$。

**例子**：

- $\mathbb{Q}(i)$：$d = -1 \equiv 3 \pmod 4$，整数是 $a + bi$，$a, b \in \mathbb{Z}$。
- $\mathbb{Q}(\sqrt{-3})$：$d = -3 \equiv 1 \pmod 4$，整数是 $a + b\omega$，$\omega = \frac{1+\sqrt{-3}}{2}$。
- $\mathbb{Q}(\sqrt{5})$：$d = 5 \equiv 1 \pmod 4$，整数是 $a + b\frac{1+\sqrt{5}}{2}$。
- $\mathbb{Q}(\sqrt{-5})$：$d = -5 \equiv 3 \pmod 4$，整数是 $a + b\sqrt{-5}$，$a, b \in \mathbb{Z}$。

**整数环**：记作 $\mathcal{O}_K$ 或 $R$。

## 四、二次数域中的整数环

### 虚二次数域

**例子**：

- $\mathbb{Z}[i]$：高斯整数环。
- $\mathbb{Z}[\sqrt{-5}]$：$\{a + b\sqrt{-5} \mid a, b \in \mathbb{Z}\}$。
- $\mathbb{Z}[\omega]$：$\omega = \frac{1+\sqrt{-3}}{2}$，艾森斯坦整数环。

**性质**：

- $\mathbb{Z}[i]$ 是欧几里得整环，唯一分解。
- $\mathbb{Z}[\omega]$ 是欧几里得整环，唯一分解。
- $\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环。

### 实二次数域

**例子**：

- $\mathbb{Z}[\sqrt{2}]$：$\{a + b\sqrt{2} \mid a, b \in \mathbb{Z}\}$。
- $\mathbb{Z}[\frac{1+\sqrt{5}}{2}]$：$\{a + b\frac{1+\sqrt{5}}{2} \mid a, b \in \mathbb{Z}\}$。

**性质**：

- 实二次数域的整数环有无限多个单位。
- 有些是唯一分解整环，有些不是。

## 五、小结

- 代数数是任意有理系数多项式的根。
- 代数整数是首一整系数多项式的根。
- 有理数是代数整数当且仅当它是整数。
- 二次数域是 $\mathbb{Q}(\sqrt{d})$，$d$ 无平方因子。
- 整数环由 $d \bmod 4$ 决定：
  - $d \equiv 2, 3 \pmod 4$：$\mathbb{Z}[\sqrt{d}]$。
  - $d \equiv 1 \pmod 4$：$\mathbb{Z}[\frac{1+\sqrt{d}}{2}]$。
- 虚二次数域的整数环有有限多个单位。
- 实二次数域的整数环有无限多个单位。

## 1. 代数整数与代数数有什么区别？为什么代数整数要求首一整系数多项式？

### 代数数

**定义**：复数 $\alpha$ 是**代数数**，如果它是某个非零有理系数多项式的根。

**例子**：$\sqrt{2}$，$i$，$\frac{1}{2}$，$\sqrt{3} + \sqrt{-5}$。

### 代数整数

**定义**：代数数 $\alpha$ 是**代数整数**，如果它在 $\mathbb{Q}$ 上的首一既约多项式是整系数的。

**例子**：

- $\sqrt{2}$：$x^2 - 2$，整系数，是代数整数。
- $\frac{1}{2}$：$x - \frac{1}{2}$，不是整系数，不是代数整数。
- $\omega = e^{2\pi i/3}$：$x^2 + x + 1$，整系数，是代数整数。

### 区别

| 性质 | 代数数 | 代数整数 |
| --- | --- | --- |
| 定义 | 有理系数多项式的根 | 首一整系数多项式的根 |
| 例子 | $\frac{1}{2}, \sqrt{2}, i$ | $\sqrt{2}, i, \omega$ |
| 有理数 | 所有有理数 | 只有整数 |
| 环结构 | 构成域 | 构成环 |

### 为什么要求首一整系数多项式？

- 代数整数是整数在代数数域中的推广。
- 首一整系数多项式保证代数整数构成环。
- 若允许任意整系数多项式，则 $\frac{1}{2}$ 会成为代数整数（$2x - 1 = 0$），不符合整数推广的意图。
- 首一条件保证代数整数在加法、乘法下封闭。

### 总结

代数数是任意有理系数多项式的根，代数整数是首一整系数多项式的根。首一条件保证代数整数构成环，是整数的正确推广。

## 2. 二次数域的整数环如何确定？为什么 $d \equiv 1 \pmod 4$ 时有半整数？

### 二次数域

$$\mathbb{Q}[\sqrt{d}] = \{a + b\sqrt{d} \mid a, b \in \mathbb{Q}\}.$$

### 整数环的确定

**命题 13.1.6**：设 $d$ 无平方因子。$\mathbb{Q}[\sqrt{d}]$ 中的代数整数具有形式 $a + b\sqrt{d}$，其中：

- 若 $d \equiv 2, 3 \pmod 4$，则 $a, b \in \mathbb{Z}$。
- 若 $d \equiv 1 \pmod 4$，则 $a, b$ 都是整数或都是半整数。

**例子**：

- $\mathbb{Q}(i)$：$d = -1 \equiv 3 \pmod 4$，整数是 $a + bi$，$a, b \in \mathbb{Z}$。
- $\mathbb{Q}(\sqrt{-3})$：$d = -3 \equiv 1 \pmod 4$，整数是 $a + b\omega$，$\omega = \frac{1+\sqrt{-3}}{2}$。
- $\mathbb{Q}(\sqrt{5})$：$d = 5 \equiv 1 \pmod 4$，整数是 $a + b\frac{1+\sqrt{5}}{2}$。

### 为什么 $d \equiv 1 \pmod 4$ 时有半整数？

设 $\alpha = a + b\sqrt{d}$，$a, b \in \mathbb{Q}$。$\alpha$ 的既约多项式是

$$x^2 - 2a x + (a^2 - b^2 d).$$

$\alpha$ 是代数整数当且仅当 $2a$ 和 $a^2 - b^2 d$ 是整数。

- 若 $a$ 是整数，则 $b^2 d$ 是整数，所以 $b$ 是整数。
- 若 $a$ 是半整数，则 $a^2 \in \mathbb{Z} + \frac{1}{4}$。要使 $a^2 - b^2 d$ 是整数，需要 $b^2 d \in \mathbb{Z} + \frac{1}{4}$。这要求 $4b^2 d$ 是整数，所以 $2b$ 是整数。进一步，$b$ 是半整数，且 $d \equiv 1 \pmod 4$。

### 总结

二次数域的整数环由 $d \bmod 4$ 决定。$d \equiv 2, 3 \pmod 4$ 时，整数是 $a + b\sqrt{d}$，$a, b \in \mathbb{Z}$。$d \equiv 1 \pmod 4$ 时，整数是 $a + b\frac{1+\sqrt{d}}{2}$，$a, b \in \mathbb{Z}$。半整数出现是因为 $d \equiv 1 \pmod 4$ 时 $a^2 - b^2 d$ 可以是整数。

## 3. 虚二次数域的单位群是什么？为什么只有有限多个单位？

### 虚二次数域

$$\mathbb{Q}(\sqrt{d}), \quad d < 0.$$

### 单位群

**命题 13.2.2**：虚二次数域的单位是：

- 一般情形：$\pm 1$。
- $d = -1$：$\pm 1, \pm i$。
- $d = -3$：$\pm 1, \pm \omega, \pm \omega^2$。

### 为什么只有有限多个单位？

- 单位 $\alpha$ 满足 $N(\alpha) = \pm 1$。
- 范数 $N(\alpha) = a^2 - b^2 d$。对于虚二次域，$d < 0$，所以 $N(\alpha) = a^2 + |d| b^2 \ge 0$。
- $N(\alpha) = 1$ 给出方程 $a^2 + |d| b^2 = 1$。
- 这个方程只有有限多个整数解：$(\pm 1, 0)$，以及特殊情形 $d = -1$ 时的 $(0, \pm 1)$，$d = -3$ 时的额外解。
- 所以虚二次域的单位有限。

### 总结

虚二次域的单位群是有限的：一般是 $\{\pm 1\}$，$d = -1$ 时有 4 个单位，$d = -3$ 时有 6 个单位。因为范数方程只有有限多个解。

## 4. 实二次数域的单位群为什么无限？如何用 Pell 方程证明？

### 实二次数域

$$\mathbb{Q}(\sqrt{d}), \quad d > 0.$$

### 单位群无限

**定理 13.9.9**：实二次数域的单位群是无限群。

### 用 Pell 方程证明

- 单位 $\alpha = a + b\sqrt{d}$ 满足 $N(\alpha) = \pm 1$。
- 范数 $N(\alpha) = a^2 - b^2 d$。
- 方程 $a^2 - d b^2 = \pm 1$ 是 **Pell 方程**。
- Pell 方程有无穷多个整数解。
- 所以实二次域的单位无限多。

**例子**：$\mathbb{Z}[\sqrt{2}]$ 的单位：

$$1+\sqrt{2}, \quad (1+\sqrt{2})^2 = 3+2\sqrt{2}, \quad (1+\sqrt{2})^3 = 7+5\sqrt{2}, \dots$$

对应 Pell 方程 $a^2 - 2b^2 = \pm 1$。

### 几何解释

- 嵌入 $\alpha \mapsto (u, v) = (a + b\sqrt{d}, a - b\sqrt{d})$。
- 范数 $N(\alpha) = uv$。
- 单位对应双曲线 $uv = \pm 1$ 上的格点。
- 双曲线有无限多个格点。

### 总结

实二次域的单位群无限，因为单位对应 Pell 方程的无限多个解。几何上，单位对应双曲线上的无限多个格点。

## 5. 二次数域的整数环什么时候是唯一分解整环？类数有什么意义？

### 唯一分解整环

**定理 13.5.6**：$R$ 是唯一分解整环当且仅当它是主理想整环，当且仅当类群是平凡群。

### 虚二次域的唯一分解

**定理 13.2.5**：虚二次数域的整数环是唯一分解整环当且仅当

$$d = -1, -2, -3, -7, -11, -19, -43, -67, -163.$$

### 类数

**定义**：类群的阶称为**类数**。

### 意义

- 类数 $= 1$：唯一分解整环。
- 类数 $> 1$：唯一分解失败。
- 类数越大，唯一分解失败越严重。

### 例子

- $\mathbb{Z}[i]$：类数 1，唯一分解。
- $\mathbb{Z}[\sqrt{-5}]$：类数 2，唯一分解失败。
- $\mathbb{Z}[\sqrt{-26}]$：类数 6。

### 总结

二次数域的整数环是唯一分解整环当且仅当类数为 1。类数衡量唯一分解失败的程度。虚二次域只有 9 个唯一分解整环。

## 一、范数

**定义 13.2.1**：设 $R$ 是虚二次数域 $\mathbb{Q}[\sqrt{d}]$ 的整数环。对 $\alpha = a + b\sqrt{d}$，其共轭是 $\bar{\alpha} = a - b\sqrt{d}$。**范数**定义为

$$N(\alpha) = \alpha \bar{\alpha} = a^2 - b^2 d.$$

**性质**：

- $N(\alpha)$ 是整数。
- $N(\alpha \beta) = N(\alpha) N(\beta)$。
- $N(\alpha) = 0$ 当且仅当 $\alpha = 0$。
- $N(\alpha) = \pm 1$ 当且仅当 $\alpha$ 是单位。

**例子**：

- $\mathbb{Z}[i]$：$N(a+bi) = a^2 + b^2$。
- $\mathbb{Z}[\sqrt{-5}]$：$N(a+b\sqrt{-5}) = a^2 + 5b^2$。
- $\mathbb{Z}[\omega]$：$\omega = \frac{1+\sqrt{-3}}{2}$，$N(a+b\omega) = a^2 + ab + b^2$。

## 二、单位

**命题 13.2.2**：虚二次数域 $\mathbb{Q}[\sqrt{d}]$ 的整数环 $R$ 的单位是：

- 一般情形：$\pm 1$。
- $d = -1$：$\pm 1, \pm i$。
- $d = -3$：$\pm 1, \pm \omega, \pm \omega^2$。

**证明**：

- $\alpha$ 是单位当且仅当 $N(\alpha) = 1$。
- $N(\alpha) = a^2 + |d| b^2 = 1$。
- 解方程得上述单位。

**实二次数域**：单位无限多（见第十三章第九节）。

## 三、既约元与素元

**定义**：

- **既约元**：不是单位，且没有真因子。
- **素元**：不是单位，且若 $p \mid \alpha \beta$，则 $p \mid \alpha$ 或 $p \mid \beta$。

**性质**：

- 素元是既约元。
- 既约元不一定是素元。

**例子**：

- $\mathbb{Z}[i]$：既约元 = 素元（因为唯一分解）。
- $\mathbb{Z}[\sqrt{-5}]$：既约元 $2$ 不是素元。

## 四、唯一分解失败

**命题 13.2.4**：若 $d \equiv 3 \pmod 4$ 且 $d < -1$，则 $R$ 不是唯一分解整环。

**例子**：$\mathbb{Z}[\sqrt{-5}]$：

$$6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5}).$$

- $2, 3, 1+\sqrt{-5}, 1-\sqrt{-5}$ 都是既约元。
- 它们不相伴。
- 所以分解不唯一。

**原因**：既约元 $2$ 不是素元。$2 \mid (1+\sqrt{-5})(1-\sqrt{-5})$，但 $2$ 不整除其中任何一个。

**验证既约性**：

- $N(2) = 4$。
- 若 $2 = \alpha \beta$，则 $N(\alpha) N(\beta) = 4$。
- 可能的范数：1, 2, 4。范数 1 是单位。范数 2 的元素不存在（因为 $a^2 + 5b^2 = 2$ 无解）。
- 所以 $2$ 既约。

**验证非素性**：

- $2 \mid 6 = (1+\sqrt{-5})(1-\sqrt{-5})$。
- 但 $2 \nmid 1+\sqrt{-5}$，$2 \nmid 1-\sqrt{-5}$。
- 所以 $2$ 不是素元。

## 五、唯一分解整环的判别

**定理 13.2.5**：虚二次数域 $\mathbb{Q}[\sqrt{d}]$ 的整数环是唯一分解整环当且仅当

$$d = -1, -2, -3, -7, -11, -19, -43, -67, -163.$$

**证明**：

- 这些 $d$ 对应的整数环是唯一分解整环（高斯、Baker、Heegner、Stark）。
- 其他 $d$ 不是唯一分解整环。

**意义**：虚二次域只有 9 个唯一分解整环。这个定理是代数数论的经典结果。

## 六、用理想修正

**理想分解**：

- 在 $\mathbb{Z}[\sqrt{-5}]$ 中，理想有唯一分解。
- 例如，$(6) = (2, 1+\sqrt{-5})^2 (3, 1+\sqrt{-5})(3, 1-\sqrt{-5})$。
- 理想类群衡量唯一分解失败的程度。

**类数**：

- $\mathbb{Z}[\sqrt{-5}]$ 的类数为 2。
- 类数 1 对应唯一分解整环。

## 七、小结

- 范数是代数整数的基本工具。
- 单位满足 $N(\alpha) = \pm 1$。
- 虚二次域的单位有限。
- $\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环。
- 虚二次域只有 9 个唯一分解整环。
- 理想分解修正唯一分解失败。
- 类群衡量唯一分解失败的程度。

## 1. 范数有什么性质？它如何用于判断单位、既约元？

### 范数的定义

设 $R$ 是二次数域 $\mathbb{Q}[\sqrt{d}]$ 的整数环。对 $\alpha = a + b\sqrt{d}$，其共轭是 $\bar{\alpha} = a - b\sqrt{d}$。范数定义为

$$N(\alpha) = \alpha \bar{\alpha} = a^2 - b^2 d.$$

### 范数的性质

1. **整数性**：$N(\alpha) \in \mathbb{Z}$。
2. **乘法性**：$N(\alpha \beta) = N(\alpha) N(\beta)$。
3. **非负性**：虚二次域 $d < 0$ 时，$N(\alpha) = a^2 + |d| b^2 \ge 0$。
4. **零性**：$N(\alpha) = 0$ 当且仅当 $\alpha = 0$。

### 用于判断单位

- $\alpha$ 是单位当且仅当 $N(\alpha) = \pm 1$。
- 因为若 $\alpha \beta = 1$，则 $N(\alpha) N(\beta) = 1$，所以 $N(\alpha) = \pm 1$。
- 反之，若 $N(\alpha) = \pm 1$，则 $\bar{\alpha}$ 或 $-\bar{\alpha}$ 是 $\alpha$ 的逆。

### 用于判断既约元

- 若 $\alpha$ 既约，则 $N(\alpha)$ 不能分解为两个非单位范数的乘积。
- 若 $N(\alpha)$ 是素数，则 $\alpha$ 既约。
- 若 $N(\alpha)$ 可分解，则 $\alpha$ 可能既约，也可能可约。需要具体分析。

### 例子

- $\mathbb{Z}[i]$：$N(a+bi) = a^2 + b^2$。
- $\mathbb{Z}[\sqrt{-5}]$：$N(a+b\sqrt{-5}) = a^2 + 5b^2$。
- $\mathbb{Z}[\omega]$：$N(a+b\omega) = a^2 + ab + b^2$。

### 总结

范数是代数整数的基本工具，具有整数性、乘法性。单位对应 $N = \pm 1$，既约元对应 $N$ 不能分解为两个非单位范数。

## 2. 虚二次数域的单位群是什么？为什么只有有限多个单位？

### 虚二次数域的单位群

**命题 13.2.2**：虚二次数域 $\mathbb{Q}[\sqrt{d}]$ 的整数环 $R$ 的单位是：

- 一般情形：$\pm 1$。
- $d = -1$：$\pm 1, \pm i$。
- $d = -3$：$\pm 1, \pm \omega, \pm \omega^2$，其中 $\omega = \frac{1+\sqrt{-3}}{2}$。

### 为什么只有有限多个单位？

- 单位 $\alpha$ 满足 $N(\alpha) = 1$。
- 范数 $N(\alpha) = a^2 + |d| b^2 = 1$。
- 因为 $a, b \in \mathbb{Z}$，方程 $a^2 + |d| b^2 = 1$ 只有有限多个解：
  - $b = 0$，$a = \pm 1$。
  - $d = -1$ 时，$b = \pm 1$，$a = 0$。
  - $d = -3$ 时，额外解。
- 所以虚二次域的单位有限。

### 几何解释

- 虚二次域的整数环是复平面上的格。
- 单位是格中范数为 1 的点。
- 范数为 1 的格点只有有限多个。

### 总结

虚二次域的单位群有限：一般 $\{\pm 1\}$，$d = -1$ 时有 4 个单位，$d = -3$ 时有 6 个单位。因为范数方程只有有限多个解。

## 3. $\mathbb{Z}[\sqrt{-5}]$ 为什么不是唯一分解整环？如何验证既约元和素元？

### $\mathbb{Z}[\sqrt{-5}]$

$$\mathbb{Z}[\sqrt{-5}] = \{a + b\sqrt{-5} \mid a, b \in \mathbb{Z}\}.$$

### 唯一分解失败

$$6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5}).$$

### 验证既约元

**$2$ 既约**：

- $N(2) = 4$。
- 若 $2 = \alpha \beta$，则 $N(\alpha) N(\beta) = 4$。
- 可能的范数：1, 2, 4。范数 1 是单位。范数 2 的元素不存在（$a^2 + 5b^2 = 2$ 无解）。
- 所以 $2$ 既约。

**$3$ 既约**：

- $N(3) = 9$。
- 可能的范数：1, 3, 9。范数 3 的元素不存在。
- 所以 $3$ 既约。

**$1+\sqrt{-5}$ 既约**：

- $N(1+\sqrt{-5}) = 6$。
- 可能的范数：1, 2, 3, 6。范数 2, 3 的元素不存在。
- 所以既约。

**$1-\sqrt{-5}$ 既约**：同理。

### 验证非素元

**$2$ 不是素元**：

- $2 \mid 6 = (1+\sqrt{-5})(1-\sqrt{-5})$。
- 但 $2 \nmid 1+\sqrt{-5}$，$2 \nmid 1-\sqrt{-5}$。
- 所以 $2$ 不是素元。

### 总结

$\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环，因为 $6$ 有两种不同的既约分解。既约元 $2$ 不是素元。

## 4. 虚二次域有哪些唯一分解整环？为什么只有 9 个？

### 唯一分解整环

**定理 13.2.5**：虚二次数域 $\mathbb{Q}[\sqrt{d}]$ 的整数环是唯一分解整环当且仅当

$$d = -1, -2, -3, -7, -11, -19, -43, -67, -163.$$

### 为什么只有 9 个？

- 这个问题由高斯提出，称为**高斯类数问题**。
- 高斯猜想只有这 9 个虚二次域有类数 1。
- 20 世纪，Baker、Heegner、Stark 独立证明了这个问题。
- 证明用模形式、椭圆曲线、复乘等深刻工具。

### 意义

- 虚二次域只有 9 个唯一分解整环。
- 这个定理是代数数论的经典结果。

### 总结

虚二次域只有 9 个唯一分解整环，对应 $d = -1, -2, -3, -7, -11, -19, -43, -67, -163$。这是高斯类数问题的答案。

## 5. 理想分解如何修正唯一分解失败？类群如何衡量失败程度？

### 理想分解

在 $\mathbb{Z}[\sqrt{-5}]$ 中，理想有唯一分解。例如：

$$(6) = (2, 1+\sqrt{-5})^2 (3, 1+\sqrt{-5})(3, 1-\sqrt{-5}).$$

理想分解唯一。

### 类群

**定义**：类群 $C$ 是非零理想的相似类在乘法下构成的阿贝尔群。

**类数**：类群的阶。

### 如何衡量失败程度？

- 类数 $= 1$：唯一分解整环。
- 类数 $> 1$：唯一分解失败。
- 类数越大，失败越严重。

### 例子

- $\mathbb{Z}[i]$：类数 1，唯一分解。
- $\mathbb{Z}[\sqrt{-5}]$：类数 2，唯一分解失败。
- $\mathbb{Z}[\sqrt{-26}]$：类数 6。

### 总结

理想分解修正唯一分解失败。类群衡量失败程度：类数 1 对应唯一分解整环，类数越大失败越严重。

## 6. 实二次数域的因子分解有什么不同？单位无限如何影响分解？

### 实二次数域

$$\mathbb{Q}(\sqrt{d}), \quad d > 0.$$

### 单位无限

**定理 13.9.9**：实二次数域的单位群是无限群。

### 对因子分解的影响

### 总结

实二次域的单位无限，使得因子分解中的相伴更复杂。有些实二次域是唯一分解整环，有些不是。类群衡量失败程度。

在上一节中，我们看到 $\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环，元素 $6$ 有两种不同的既约分解。为了修正这一缺陷，戴德金引入了**理想**的概念：在 $\mathbb{Z}[\sqrt{-5}]$ 中，虽然元素的分解不唯一，但理想的分解是唯一的。本节将研究 $\mathbb{Z}[\sqrt{-5}]$ 中的理想，把理想看作复平面上的格，并证明理想分解定理。

## 一、理想是格

**命题 13.3.1**：令 $R$ 是虚二次数域上的整数环。$R$ 的每个非零理想是格 $R$ 的子格。

**证明**：

- 非零理想 $A$ 包含非零元素 $\alpha$。
- $(\alpha, \alpha\delta)$ 是 $R$ 上无关的集合。
- $A$ 是离散的（因为它是格 $R$ 的子格）。
- 由第六章第五节，$A$ 是一个格。

**例子**：$R = \mathbb{Z}[\sqrt{-5}]$，理想 $A = (2, 1+\sqrt{-5})$ 是复平面上的格。

## 二、理想的格基

**引理 13.3.2**：令 $R = \mathbb{Z}[\delta]$，其中 $\delta^2 = -5$。则 $2$ 和 $1+\delta$ 的整数组合的格 $A$ 是一个理想。

**证明**：

- 格 $A$ 在加法和整数乘法下封闭。
- 需要证明 $A$ 在乘以 $\delta$ 下封闭。
- $\delta \cdot 2 = 2\delta$，$\delta \cdot (1+\delta) = \delta + \delta^2 = \delta - 5 = -5 + \delta$。
- 这些是 $2$ 和 $1+\delta$ 的整数组合： $2\delta = -2(1+\delta) + 2 \cdot 1? \quad \text{需要验证。}$ 实际上，$2\delta = 2(1+\delta) - 2$，所以 $2\delta \in A$。 $-5 + \delta = -(1+\delta) - 4? \quad \text{需要验证。}$ 实际上，$-5 + \delta = (1+\delta) - 6$，所以 $-5 + \delta \in A$。
- 因此 $A$ 是理想。

**图 13.3.4** 展示了这个理想。

## 三、理想的分类

**定理 13.3.3**：令 $R = \mathbb{Z}[\delta]$，其中 $\delta = \sqrt{-5}$，$A$ 是 $R$ 的非零理想。令 $\alpha$ 是 $A$ 中具有最小范数的非零元。则：

- 集合 $(\alpha, \alpha\delta)$ 是 $A$ 的格基，且 $A$ 是主理想 $(\alpha)$，或者
- 集合 $\left(\alpha, \frac{1}{2}(\alpha + \alpha\delta)\right)$ 是 $A$ 的格基，且 $A$ 不是主理想。

**几何解释**：

- 主理想 $(\alpha)$ 的格基是 $(\alpha, \alpha\delta)$。
- 第二种类型的理想是类似图 13.3.4 的格。

**类数**：$\mathbb{Z}[\sqrt{-5}]$ 的类数是 2。

## 四、理想类

**定义 13.7.1**：理想 $A$ 和 $A'$ 是**相似的**，如果 $A' = \lambda A$ 对某个复数 $\lambda$。

**理想类**：相似类。

**引理 13.7.2**：单位理想类 $\langle R \rangle$ 由所有主理想构成。

**命题 13.7.3**：理想类构成阿贝尔群 $C$，称为**类群**。

**运算**：$\langle A \rangle \langle B \rangle = \langle AB \rangle$。

**单位元**：主理想类。

**逆元**：$\langle \bar{A} \rangle$。

**例子**：$\mathbb{Z}[\sqrt{-5}]$ 有两个理想类：主理想类和非主理想类。

## 五、理想的乘法

**定义 13.4.1**：理想 $A, B$ 的积 $AB$ 是由所有有限和

$$\sum \alpha_i \beta_i, \quad \alpha_i \in A, \beta_i \in B$$

生成的理想。

**性质**：

- $AB = BA$。
- $A(BC) = (AB)C$。
- $AR = A$。

**例子**：在 $\mathbb{Z}[\sqrt{-5}]$ 中，

$$A = (2, 1+\delta), \quad \bar{A} = (2, 1-\delta).$$

$$A\bar{A} = (4, 2(1+\delta), 2(1-\delta), 6) = (2).$$

所以 $A\bar{A} = (2)$。

## 六、主引理

**引理 13.4.8（主引理）**：令 $R$ 为虚二次数域整数环，$A$ 是非零理想。则

$$\bar{A} A = (n)$$

是由正整数 $n$ 生成的主理想。

**证明**：

- 取 $A$ 的格基 $(\alpha, \beta)$。
- $\bar{A} A$ 由 $\bar{\alpha}\alpha, \bar{\alpha}\beta, \bar{\beta}\alpha, \bar{\beta}\beta$ 生成。
- 其中三个是整数，取最大公约数 $n$。
- 用代数整数证明 $n$ 整除所有生成元。

**例子**：$\mathbb{Z}[\sqrt{-5}]$ 中，$A\bar{A} = (2)$，所以 $N(A) = 2$。

## 七、理想分解

**定理 13.5.5**：虚二次数域整数环的每个真理想是素理想的积，且分解唯一。

**证明**：用主引理和消去律。

**例子**：在 $\mathbb{Z}[\sqrt{-5}]$ 中，

$$(6) = (2, 1+\delta)^2 (3, 1+\delta)(3, 1-\delta).$$

理想分解唯一。

## 八、小结

- 虚二次数域的理想是格。
- 理想有格基 $(\alpha, \alpha\delta)$ 或 $(\alpha, \frac{1}{2}(\alpha+\alpha\delta))$。
- 理想类构成类群。
- 主引理：$\bar{A} A = (n)$。
- 理想分解唯一。
- $\mathbb{Z}[\sqrt{-5}]$ 的类数是 2。

## 2. 理想的格基如何确定？主理想和非主理想的格基有什么区别？

### 理想的格基

**定理 13.3.3**：令 $R = \mathbb{Z}[\delta]$，其中 $\delta = \sqrt{-5}$，$A$ 是 $R$ 的非零理想。令 $\alpha$ 是 $A$ 中具有最小范数的非零元。则：

- 集合 $(\alpha, \alpha\delta)$ 是 $A$ 的格基，且 $A$ 是主理想 $(\alpha)$，或者
- 集合 $\left(\alpha, \frac{1}{2}(\alpha + \alpha\delta)\right)$ 是 $A$ 的格基，且 $A$ 不是主理想。

### 主理想和非主理想的格基区别

| 类型 | 格基 | 几何形状 |
| --- | --- | --- |
| 主理想 $(\alpha)$ | $(\alpha, \alpha\delta)$ | 与 $R$ 相似的格 |
| 非主理想 | $\left(\alpha, \frac{1}{2}(\alpha + \alpha\delta)\right)$ | 不同的格 |

**几何解释**：

- 主理想的格基是 $R$ 的格基乘以 $\alpha$。
- 非主理想的格基是 $R$ 的格基乘以 $\alpha$ 后加上平移。

### 例子

$\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\sqrt{-5})$ 是非主理想，格基是 $(2, 1+\sqrt{-5})$。

### 总结

理想的格基由最小范数元素 $\alpha$ 决定。主理想的格基是 $(\alpha, \alpha\delta)$，非主理想的格基是 $(\alpha, \frac{1}{2}(\alpha+\alpha\delta))$。

## 3. 理想类群如何定义？类群如何衡量唯一分解失败？

## 4. 主引理如何证明？为什么 $\bar{A} A$ 是主理想？

### 主引理

**引理 13.4.8**：令 $R$ 为虚二次数域整数环，$A$ 是非零理想。则

$$\bar{A} A = (n)$$

是由正整数 $n$ 生成的主理想。

### 证明

- 取 $A$ 的格基 $(\alpha, \beta)$。
- $\bar{A} A$ 由 $\bar{\alpha}\alpha, \bar{\alpha}\beta, \bar{\beta}\alpha, \bar{\beta}\beta$ 生成。
- 其中三个是整数： $\bar{\alpha}\alpha = N(\alpha) \in \mathbb{Z},$ $\bar{\beta}\beta = N(\beta) \in \mathbb{Z},$ $\bar{\alpha}\beta + \bar{\beta}\alpha \in \mathbb{Z}.$
- 取这些整数的最大公约数 $n$。
- 用代数整数证明 $n$ 整除所有生成元。
- 所以 $\bar{A} A = (n)$。

### 为什么是主理想？

因为 $\bar{A} A$ 由单个整数 $n$ 生成。

### 例子

$\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\delta)$，$\bar{A} = (2, 1-\delta)$。

$$A\bar{A} = (4, 2(1+\delta), 2(1-\delta), 6) = (2).$$

所以 $N(A) = 2$。

### 总结

主引理用格基证明 $\bar{A} A$ 是主理想 $(n)$。$n$ 是生成元的最大公约数。

## 5. 理想分解为什么唯一？消去律如何工作？

### 理想分解唯一性

**定理 13.5.5**：虚二次数域整数环的每个真理想是素理想的积，且分解唯一。

### 消去律

**推论 13.4.9**：
(a) 若 $AB = AC$，则 $B = C$。
(b) $A \supset B$ 当且仅当 $A$ 整除 $B$。

**证明**：

- 用主引理：$\bar{A} A = (n)$。
- 若 $AB = AC$，乘以 $\bar{A}$： $\bar{A} A B = \bar{A} A C \Rightarrow (n) B = (n) C \Rightarrow B = C.$

### 理想分解唯一性证明

1. 若理想 $B$ 是极大理想，则它是素理想。
2. 否则，存在理想 $A$ 真包含 $B$。则 $A$ 整除 $B$，$B = A C$。
3. 继续分解 $A$ 和 $C$。因为只有有限多个理想包含 $B$，分解终止。
4. 分解唯一性由消去律和素理想的性质证明。

### 总结

理想分解唯一性由消去律保证。消去律用主引理 $\bar{A} A = (n)$ 证明。

## 6. $\mathbb{Z}[\sqrt{-5}]$ 的理想分解是什么？如何用理想分解修正 $6$ 的分解？

### $\mathbb{Z}[\sqrt{-5}]$ 的理想分解

$$(6) = (2, 1+\delta)^2 (3, 1+\delta)(3, 1-\delta).$$

其中 $\delta = \sqrt{-5}$。

### 如何用理想分解修正 $6$ 的分解？

- 元素分解：$6 = 2 \cdot 3 = (1+\delta)(1-\delta)$。
- 理想分解： $(2) = (2, 1+\delta)^2,$ $(3) = (3, 1+\delta)(3, 1-\delta),$ $(1+\delta) = (2, 1+\delta)(3, 1+\delta),$ $(1-\delta) = (2, 1-\delta)(3, 1-\delta).$
- 所以 $(6) = (2, 1+\delta)^2 (3, 1+\delta)(3, 1-\delta).$

### 理想分解唯一的含义

- 元素分解不唯一，但理想分解唯一。
- 理想分解提供了公共加细。

### 总结

$\mathbb{Z}[\sqrt{-5}]$ 中，$6$ 的元素分解不唯一，但理想分解唯一。理想分解修正了唯一分解失败。

## 一、理想的乘法

**定义 13.4.1**：设 $A, B$ 是环 $R$ 的理想。它们的**积** $AB$ 是由所有有限和

$$\sum \alpha_i \beta_i, \quad \alpha_i \in A, \beta_i \in B$$

生成的理想。

**等价定义**：$AB$ 是包含所有乘积 $\alpha \beta$ 的最小理想。

**性质**：

- $AB = BA$。
- $A(BC) = (AB)C$。
- $AR = RA = A$。
- $A(B + C) = AB + AC$。

**例子**：

- 在 $\mathbb{Z}$ 中，$(a)(b) = (ab)$。
- 在 $\mathbb{Z}[\sqrt{-5}]$ 中，$(2, 1+\delta)(2, 1-\delta) = (2)$。

## 二、主理想的积

**命题 13.4.2**：主理想的积是主理想：

$$(a)(b) = (ab).$$

**证明**：

- $(a)(b)$ 由所有 $a r \cdot b s = a b (r s)$ 生成。
- 所以 $(a)(b) = (ab)$。

**推论**：若 $A = (a)$ 是主理想，$B$ 是任意理想，则

$$AB = aB = \{a \beta \mid \beta \in B\}.$$

**例子**：

- 在 $\mathbb{Z}$ 中，$(2)(3) = (6)$。
- 在 $\mathbb{Z}[\sqrt{-5}]$ 中，$(2)(3) = (6)$。

## 三、理想的乘法在 $\mathbb{Z}[\sqrt{-5}]$ 中的应用

**例子 13.4.4**：在 $R = \mathbb{Z}[\sqrt{-5}]$ 中，$\delta = \sqrt{-5}$。

**理想**：

$$A = (2, 1+\delta), \quad \bar{A} = (2, 1-\delta).$$

$$B = (3, 1+\delta), \quad \bar{B} = (3, 1-\delta).$$

**计算 $A\bar{A}$**：

- $A\bar{A}$ 由四个乘积生成： $4, \quad 2(1-\delta), \quad 2(1+\delta), \quad (1+\delta)(1-\delta) = 6.$
- 这些生成元都被 $2$ 整除。
- $2 = 6 - 4 \in A\bar{A}$。
- 所以 $A\bar{A} = (2)$。

**计算 $AB$**：

- $AB$ 由四个乘积生成： $6, \quad 2(1+\delta), \quad 3(1+\delta), \quad (1+\delta)^2.$
- 这些生成元都被 $1+\delta$ 整除。
- $1+\delta = 3(1+\delta) - 2(1+\delta) \in AB$。
- 所以 $AB = (1+\delta)$。

**计算 $B\bar{B}$**：

- $B\bar{B} = (3)$。

**理想分解**：

$$(6) = (2)(3) = (A\bar{A})(B\bar{B}) = (A B)(\bar{A}\bar{B}) = (1+\delta)(1-\delta).$$

理想分解唯一。

## 四、消去律

**推论 13.4.9**：
(a) 若 $AB = AC$，则 $B = C$。
(b) $A \supset B$ 当且仅当 $A$ 整除 $B$。

**证明 (a)**：

- 用主引理：$\bar{A} A = (n)$。
- 若 $AB = AC$，乘以 $\bar{A}$： $\bar{A} A B = \bar{A} A C \Rightarrow (n) B = (n) C \Rightarrow B = C.$

**证明 (b)**：

- 若 $A \supset B$，则 $A$ 整除 $B$。
- 用主引理：$\bar{A} A = (n)$。
- $(n) = \bar{A} A \supset \bar{A} B$。
- 所以存在理想 $C$ 使得 $\bar{A} B = (n) C = \bar{A} A C$。
- 由消去律，$B = A C$。

**意义**：消去律使得理想构成一个交换幺半群，且满足消去律。这是理想分解唯一性的基础。

## 五、主引理

**引理 13.4.8（主引理）**：令 $R$ 为虚二次数域整数环，$A$ 是非零理想。则

$$\bar{A} A = (n)$$

是由正整数 $n$ 生成的主理想。

**证明**：

- 取 $A$ 的格基 $(\alpha, \beta)$。
- $\bar{A} A$ 由 $\bar{\alpha}\alpha, \bar{\alpha}\beta, \bar{\beta}\alpha, \bar{\beta}\beta$ 生成。
- 其中三个是整数： $\bar{\alpha}\alpha = N(\alpha), \quad \bar{\beta}\beta = N(\beta), \quad \bar{\alpha}\beta + \bar{\beta}\alpha.$
- 取最大公约数 $n$。
- 用代数整数证明 $n$ 整除所有生成元。
- 所以 $\bar{A} A = (n)$。

**推论**：理想的范数 $N(A) = n$。

**例子**：在 $\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\delta)$，$N(A) = 2$。

## 六、小结

- 理想的积 $AB$ 由所有乘积 $\alpha \beta$ 生成。
- 主理想的积是主理想：$(a)(b) = (ab)$。
- 在 $\mathbb{Z}[\sqrt{-5}]$ 中，$A\bar{A} = (2)$，$AB = (1+\delta)$。
- 消去律：$AB = AC \Rightarrow B = C$。

- 理想乘法是理想分解的基础。

## 1. 理想的乘法如何定义？为什么用有限和而不是所有乘积？

### 理想的乘法

**定义 13.4.1**：设 $A, B$ 是环 $R$ 的理想。它们的积 $AB$ 是由所有有限和

$$\sum \alpha_i \beta_i, \quad \alpha_i \in A, \beta_i \in B$$

生成的理想。

### 为什么用有限和而不是所有乘积？

- **理想必须对加法封闭**：所有乘积的集合不一定对加法封闭，可能不是理想。
- **有限和保证理想结构**：有限和的集合对加法封闭，对乘法吸收。
- **理想由生成元生成**：$AB$ 是包含所有乘积 $\alpha \beta$ 的最小理想。
- **无限和没有意义**：在一般环中，无限和没有定义。

### 例子

在 $\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\delta)$，$B = (2, 1-\delta)$。

$$AB = (4, 2(1+\delta), 2(1-\delta), 6).$$

这是有限和生成的理想。

### 总结

理想乘法用有限和定义，因为有限和对加法封闭，构成理想。所有乘积的集合不一定对加法封闭。

## 2. 主理想的积为什么是主理想？这个性质有什么好处？

### 主理想的积

**命题 13.4.2**：主理想的积是主理想：

$$(a)(b) = (ab).$$

### 证明

- $(a)(b)$ 由所有 $a r \cdot b s = a b (r s)$ 生成。
- 所以 $(a)(b) = (ab)$。

### 好处

1. **简化计算**：主理想的积仍然是主理想，由 $ab$ 生成。
2. **元素分解与理想分解一致**：主理想的积对应元素的积。
3. **消去律**：主理想的积满足消去律。
4. **类群**：主理想类在类群中是单位元。
5. **理想分解**：主理想的分解对应元素的分解。

### 例子

在 $\mathbb{Z}$ 中，$(2)(3) = (6)$。
在 $\mathbb{Z}[\sqrt{-5}]$ 中，$(2)(3) = (6)$。

### 总结

主理想的积是主理想，由 $ab$ 生成。这个性质简化计算，使得元素分解与理想分解一致。

## 3. 消去律如何证明？主引理如何用于证明消去律？

### 消去律

**推论 13.4.9**：
(a) 若 $AB = AC$，则 $B = C$。
(b) $A \supset B$ 当且仅当 $A$ 整除 $B$。

### 证明 (a)

- 用主引理：$\bar{A} A = (n)$。
- 若 $AB = AC$，乘以 $\bar{A}$： $\bar{A} A B = \bar{A} A C \Rightarrow (n) B = (n) C \Rightarrow B = C.$

### 证明 (b)

- 若 $A \supset B$，则 $A$ 整除 $B$。
- 用主引理：$\bar{A} A = (n)$。
- $(n) = \bar{A} A \supset \bar{A} B$。
- 所以存在理想 $C$ 使得 $\bar{A} B = (n) C = \bar{A} A C$。
- 由消去律，$B = A C$。

### 主引理的作用

主引理 $\bar{A} A = (n)$ 把理想的积转化为主理想。消去律用主理想的性质证明。

### 总结

消去律用主引理证明。主引理把理想转化为 $(n)$，消去 $\bar{A}$ 得到 $B = C$。

## 4. 主引理如何证明？为什么 $\bar{A} A$ 是主理想？

### 主引理

**引理 13.4.8**：令 $R$ 为虚二次数域整数环，$A$ 是非零理想。则

$$\bar{A} A = (n)$$

是由正整数 $n$ 生成的主理想。

### 证明

- 取 $A$ 的格基 $(\alpha, \beta)$。
- $\bar{A} A$ 由 $\bar{\alpha}\alpha, \bar{\alpha}\beta, \bar{\beta}\alpha, \bar{\beta}\beta$ 生成。
- 其中三个是整数： $\bar{\alpha}\alpha = N(\alpha), \quad \bar{\beta}\beta = N(\beta), \quad \bar{\alpha}\beta + \bar{\beta}\alpha.$
- 取最大公约数 $n$。
- 用代数整数证明 $n$ 整除所有生成元。
- 所以 $\bar{A} A = (n)$。

### 为什么是主理想？

- $\bar{A} A$ 由单个整数 $n$ 生成。
- 整数 $n$ 在 $R$ 中生成主理想 $(n)$。
- 所以 $\bar{A} A$ 是主理想。

### 例子

在 $\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\delta)$。

$$A\bar{A} = (4, 2(1+\delta), 2(1-\delta), 6) = (2).$$

所以 $N(A) = 2$。

### 总结

主引理用格基证明 $\bar{A} A = (n)$。因为 $n$ 是整数，生成主理想，所以 $\bar{A} A$ 是主理想。

## 5. 理想的范数如何定义？它与元素的范数有什么关系？

### 理想的范数

**定义 13.7.5**：理想 $A$ 的范数 $N(A)$ 是正整数 $n$ 使得

$$\bar{A} A = (n).$$

### 与元素的范数的关系

- 若 $A = (\alpha)$ 是主理想，则 $\bar{A} A = (\bar{\alpha})(\alpha) = (\bar{\alpha}\alpha) = (N(\alpha)).$ 所以 $N(A) = N(\alpha)$。
- 一般理想 $A$ 的范数 $N(A)$ 是元素范数的推广。
- 范数有乘法性： $N(AB) = N(A) N(B).$

### 例子

- $\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\delta)$，$N(A) = 2$。
- 主理想 $(2)$ 的范数 $N((2)) = 4$。

### 总结

理想的范数定义为 $\bar{A} A = (n)$ 中的 $n$。主理想的范数等于元素的范数。范数有乘法性。

## 6. 理想乘法在 $\mathbb{Z}[\sqrt{-5}]$ 中如何应用？如何用理想乘法修正 $6$ 的分解？

### 理想乘法在 $\mathbb{Z}[\sqrt{-5}]$ 中的应用

**理想**：

$$A = (2, 1+\delta), \quad \bar{A} = (2, 1-\delta),$$

$$B = (3, 1+\delta), \quad \bar{B} = (3, 1-\delta).$$

**计算**：

- $A\bar{A} = (2)$。
- $B\bar{B} = (3)$。
- $AB = (1+\delta)$。
- $\bar{A}\bar{B} = (1-\delta)$。

### 如何用理想乘法修正 $6$ 的分解？

- 元素分解：$6 = 2 \cdot 3 = (1+\delta)(1-\delta)$。
- 理想分解： $(6) = (2)(3) = (A\bar{A})(B\bar{B}) = (AB)(\bar{A}\bar{B}) = (1+\delta)(1-\delta).$
- 理想分解唯一。

### 总结

理想乘法在 $\mathbb{Z}[\sqrt{-5}]$ 中用于分解理想。$6$ 的元素分解不唯一，但理想分解唯一。理想分解修正了唯一分解失败。

在上一节中，我们研究了理想的乘法，并看到了消去律和主引理。现在，我们证明戴德金理想理论的核心定理：**虚二次数域整数环中的每个非零理想可以唯一分解为素理想的乘积**。这个定理修正了元素分解可能不唯一的缺陷，是代数数论的基础。

## 一、素理想

**定义 13.5.1**：环 $R$ 的理想 $\mathcal{P}$ 是**素的**，如果：

- $\mathcal{P} \neq R$。
- 若 $a, b \in R$ 且 $ab \in \mathcal{P}$，则 $a \in \mathcal{P}$ 或 $b \in \mathcal{P}$。

**等价条件**：$R/\mathcal{P}$ 是整环。

**命题 13.5.2**：极大理想是素理想。

**证明**：若 $M$ 极大，则 $R/M$ 是域，域是整环，所以 $M$ 是素理想。

**例子**：

- $\mathbb{Z}$ 中，$(p)$ 是素理想，$p$ 素数。
- $\mathbb{Z}[\sqrt{-5}]$ 中，$(2, 1+\sqrt{-5})$ 是素理想。

## 二、素理想的性质

**推论 13.5.3**：令 $R$ 为虚二次数域整数环，$A, B$ 是 $R$ 的理想，$\mathcal{P}$ 是非零素理想。若 $\mathcal{P}$ 整除 $AB$，则 $\mathcal{P}$ 整除 $A$ 或 $\mathcal{P}$ 整除 $B$。

**证明**：

- $\mathcal{P} \mid AB$ 意味着 $AB \subset \mathcal{P}$。
- 因为 $\mathcal{P}$ 是素理想，$A \subset \mathcal{P}$ 或 $B \subset \mathcal{P}$。
- 由消去律（推论 13.4.9(b)），$\mathcal{P} \mid A$ 或 $\mathcal{P} \mid B$。

**意义**：素理想具有素元的性质，这是理想唯一分解的基础。

## 三、理想的有限性

**引理 13.5.4**：令 $R$ 为虚二次数域整数环，$B$ 是非零理想。则：
(a) $B$ 在 $R$ 中有有限指标。
(b) $R$ 中存在有限多个包含 $B$ 的理想。
(c) $B$ 包含在一个极大理想中。
(d) $B$ 是素理想当且仅当它是极大理想。

**证明**：
(a) 因为 $B$ 是格，$R/B$ 是有限群。
(b) 由对应定理，包含 $B$ 的理想对应 $R/B$ 的理想。有限环只有有限多个理想。
(c) 在有限多个包含 $B$ 的理想中，存在极大理想。
(d) 若 $B$ 是素理想，则 $R/B$ 是有限整环。有限整环是域，所以 $B$ 极大。反之，极大理想是素理想。

**意义**：这些性质保证理想分解的终止性。

## 四、理想分解定理

**定理 13.5.5**：令 $R$ 为虚二次数域 $F$ 上的整数所构成的环。$R$ 的每个真理想是素理想的积。一个理想除去因子的次序之外唯一地分解为素理想的积。

**证明**：

**存在性**：

- 若理想 $B$ 是极大理想，则它是素理想，完成。
- 否则，存在理想 $A$ 真包含 $B$。则 $A$ 整除 $B$，$B = A C$。
- 继续分解 $A$ 和 $C$。因为只有有限多个理想包含 $B$（引理 13.5.4(b)），分解终止。
- 终止时所有因子都是极大理想，从而是素理想。

**唯一性**：

- 假设 $\mathcal{P}_1 \cdots \mathcal{P}_r = \mathcal{Q}_1 \cdots \mathcal{Q}_s$，其中 $\mathcal{P}_i, \mathcal{Q}_j$ 是素理想。
- $\mathcal{P}_1$ 整除右边的乘积，所以 $\mathcal{P}_1$ 整除某个 $\mathcal{Q}_j$（推论 13.5.3）。
- 因为 $\mathcal{Q}_j$ 是极大理想，$\mathcal{P}_1 = \mathcal{Q}_j$。
- 消去 $\mathcal{P}_1$，继续归纳，得到 $r = s$ 且因子匹配。

**意义**：理想分解唯一，修正了元素分解可能不唯一的缺陷。

## 五、理想类群

**定理 13.5.6**：虚二次数域的整数所构成的环 $R$ 是唯一分解整环当且仅当它是主理想整环，当且仅当 $R$ 的类群是平凡群。

**证明**：

- 主理想整环是唯一分解整环。
- 反之，若 $R$ 是唯一分解整环，则每个素理想是主理想。
- 因为理想分解唯一，每个理想是主理想的积，所以是主理想。
- 所以 $R$ 是主理想整环。
- 类群平凡当且仅当所有理想是主理想。

**意义**：类群衡量唯一分解失败的程度。

## 六、例子

### $\mathbb{Z}[\sqrt{-5}]$ 中的理想分解

$$(6) = (2, 1+\delta)^2 (3, 1+\delta)(3, 1-\delta).$$

- $\mathcal{P}_1 = (2, 1+\delta)$，$\mathcal{P}_2 = (3, 1+\delta)$，$\mathcal{P}_3 = (3, 1-\delta)$。
- $\mathcal{P}_1^2 = (2)$，$\mathcal{P}_2 \mathcal{P}_3 = (3)$。

- $R$ 是唯一分解整环当且仅当它是主理想整环，当且仅当类群平凡。

## 1. 素理想与素元有什么关系？为什么素理想具有素元的性质？

### 素元

**定义**：环 $R$ 中的非零非单位元素 $p$ 是**素元**，如果

$$p \mid ab \Rightarrow p \mid a \text{ 或 } p \mid b.$$

### 素理想

**定义**：理想 $\mathcal{P}$ 是**素的**，如果

$$ab \in \mathcal{P} \Rightarrow a \in \mathcal{P} \text{ 或 } b \in \mathcal{P}.$$

### 关系

- **主理想**：若 $p$ 是素元，则主理想 $(p)$ 是素理想。
  - 因为 $ab \in (p)$ 意味着 $p \mid ab$，所以 $p \mid a$ 或 $p \mid b$，即 $a \in (p)$ 或 $b \in (p)$。
- **一般素理想**：素理想是素元的推广。
  - 素理想不一定由单个元素生成（非主理想）。
  - 但素理想具有素元的性质：若乘积在理想中，则因子之一在理想中。

### 为什么素理想具有素元的性质？

- 素理想的定义正是模仿素元的性质。
- $R/\mathcal{P}$ 是整环，没有零因子。
- 若 $ab \in \mathcal{P}$，则 $\overline{a} \overline{b} = 0$ 在 $R/\mathcal{P}$ 中，所以 $\overline{a} = 0$ 或 $\overline{b} = 0$。

### 例子

- $\mathbb{Z}$ 中，$(p)$ 是素理想，$p$ 是素元。
- $\mathbb{Z}[\sqrt{-5}]$ 中，$(2, 1+\sqrt{-5})$ 是素理想，但不是主理想。

### 总结

素理想是素元的推广。主理想 $(p)$ 是素理想当且仅当 $p$ 是素元。一般素理想不一定主，但具有素元的性质。

## 2. 理想分解的存在性如何证明？有限性如何保证分解终止？

### 存在性

**定理 13.5.5**：每个非零理想是素理想的积。

### 证明

1. 若理想 $B$ 是极大理想，则它是素理想，完成。
2. 否则，存在理想 $A$ 真包含 $B$。则 $A$ 整除 $B$，$B = A C$。
3. 继续分解 $A$ 和 $C$。
4. 因为只有有限多个理想包含 $B$（引理 13.5.4(b)），分解终止。
5. 终止时所有因子都是极大理想，从而是素理想。

### 有限性如何保证分解终止？

- 引理 13.5.4(b)：包含 $B$ 的理想只有有限多个。
- 每次分解 $B = A C$，$A$ 和 $C$ 都真包含 $B$。
- 所以理想链 $B \subset A \subset \cdots$ 是严格升链。
- 因为只有有限多个理想包含 $B$，链必须终止。
- 终止时，所有因子都是极大理想。

### 总结

理想分解的存在性用有限性证明。包含 $B$ 的理想有限，所以分解终止。终止时因子是极大理想，即素理想。

## 3. 理想分解的唯一性如何证明？素理想的性质如何工作？

### 唯一性

**定理 13.5.5**：理想分解唯一。

### 证明

假设

$$\mathcal{P}_1 \cdots \mathcal{P}_r = \mathcal{Q}_1 \cdots \mathcal{Q}_s,$$

其中 $\mathcal{P}_i, \mathcal{Q}_j$ 是素理想。

1. $\mathcal{P}_1$ 整除右边的乘积。
2. 由素理想的性质（推论 13.5.3），$\mathcal{P}_1$ 整除某个 $\mathcal{Q}_j$。

4. 消去 $\mathcal{P}_1$，继续归纳。
5. 得到 $r = s$ 且因子匹配。

### 素理想的性质如何工作？

- 素理想 $\mathcal{P}$ 满足：若 $\mathcal{P} \mid AB$，则 $\mathcal{P} \mid A$ 或 $\mathcal{P} \mid B$。

- 它保证分解可以逐项匹配。

### 总结

理想分解的唯一性用素理想的性质证明。素理想整除乘积蕴含整除因子，所以分解可以逐项匹配。

## 1. 整素数 $p$ 在 $R$ 中有哪三种行为？如何区分？

### 三种行为

设 $R$ 是二次数域 $\mathbb{Q}[\sqrt{d}]$ 的整数环，$p$ 是整素数。主理想 $(p)$ 有三种可能：

1. **持素**：$(p)$ 是素理想。
2. **分裂**：$(p) = \mathcal{P} \bar{\mathcal{P}}$，其中 $\mathcal{P} \neq \bar{\mathcal{P}}$ 是共轭素理想。
3. **分叉**：$(p) = \mathcal{P}^2$，其中 $\mathcal{P} = \bar{\mathcal{P}}$。

### 如何区分？

**判别方法**：

- **持素**：$p$ 不整除判别式，且 $d$ 不是模 $p$ 的平方。

**判别式**：

$$\Delta = \begin{cases}

d, & d \equiv 1 \pmod 4.
\end{cases}$$

**例子**：

- $\mathbb{Z}[i]$：$p = 2$ 分叉，$p \equiv 1 \pmod 4$ 分裂，$p \equiv 3 \pmod 4$ 持素。
- $\mathbb{Z}[\sqrt{-5}]$：$p = 2$ 分叉，$p = 3$ 分裂，$p = 7$ 持素。

### 总结

整素数 $p$ 在 $R$ 中有持素、分裂、分叉三种行为。区分方法：分叉当且仅当 $p$ 整除判别式；否则，$p$ 持素当且仅当 $d$ 不是模 $p$ 的平方。

## 2. 为什么 $p$ 持素当且仅当 $d$ 不是模 $p$ 的平方？这个判别如何证明？

### 判别

当 $d \equiv 2, 3 \pmod 4$ 时，$R = \mathbb{Z}[\sqrt{d}]$。$p$ 持素当且仅当 $d$ 不是模 $p$ 的平方。

### 证明

**关键同构**：

$$R/(p) \cong \mathbb{F}_p[x]/(x^2 - d).$$

- $(p)$ 是素理想当且仅当 $R/(p)$ 是整环。
- $R/(p)$ 是整环当且仅当 $x^2 - d$ 在 $\mathbb{F}_p[x]$ 中既约。
- $x^2 - d$ 既约当且仅当 $d$ 不是模 $p$ 的平方。

**为什么？**

- 若 $d$ 是模 $p$ 的平方，设 $d \equiv a^2 \pmod p$，则 $x^2 - d = (x-a)(x+a)$ 在 $\mathbb{F}_p[x]$ 中分解。
- 若 $d$ 不是模 $p$ 的平方，则 $x^2 - d$ 没有根，因此既约（二次多项式无根即既约）。

**例子**：

- $\mathbb{Z}[\sqrt{-5}]$，$p = 7$：$-5 \equiv 2 \pmod 7$，2 不是模 7 的平方，所以 $p = 7$ 持素。
- $\mathbb{Z}[\sqrt{-5}]$，$p = 3$：$-5 \equiv 1 \pmod 3$，1 是平方，所以 $p = 3$ 分裂。

### 总结

$p$ 持素当且仅当 $d$ 不是模 $p$ 的平方。证明用同构 $R/(p) \cong \mathbb{F}_p[x]/(x^2 - d)$。$d$ 是平方时，$x^2 - d$ 分解，$(p)$ 分裂。

## 3. $d \equiv 1 \pmod 4$ 时判别为什么用 $x^2 - x + h$？这个多项式如何得到？

### $d \equiv 1 \pmod 4$

此时 $R = \mathbb{Z}[\frac{1+\sqrt{d}}{2}]$。

令

$$h = \frac{1}{4}(1-d).$$

则

$$R \cong \mathbb{Z}[x]/(x^2 - x + h).$$

### 多项式如何得到？

设 $\omega = \frac{1+\sqrt{d}}{2}$。则 $\omega$ 满足

$$\omega^2 - \omega + h = 0,$$

其中

$$h = \frac{1}{4}(1-d).$$

验证：

$$\omega^2 = \frac{1 + 2\sqrt{d} + d}{4} = \frac{1+d}{4} + \frac{\sqrt{d}}{2},$$

$$\omega^2 - \omega = \frac{1+d}{4} + \frac{\sqrt{d}}{2} - \frac{1+\sqrt{d}}{2} = \frac{d-1}{4} = -h.$$

所以 $\omega^2 - \omega + h = 0$。

### 判别

- $p$ 持素 $\iff x^2 - x + h$ 在 $\mathbb{F}_p[x]$ 中既约。
- $p$ 分裂 $\iff x^2 - x + h$ 有不同根。
- $p$ 分叉 $\iff x^2 - x + h$ 有重根。

### 例子

$\mathbb{Z}[\sqrt{5}]$，$d = 5$，$h = \frac{1}{4}(1-5) = -1$。
多项式 $x^2 - x - 1$。

- $p = 11$：$x^2 - x - 1$ 在 $\mathbb{F}_{11}$ 中分解，$p$ 分裂。

### 总结

$d \equiv 1 \pmod 4$ 时，用 $x^2 - x + h$ 判别，其中 $h = \frac{1}{4}(1-d)$。这个多项式来自 $\omega = \frac{1+\sqrt{d}}{2}$ 的既约多项式。

## 4. 分叉条件为什么是 $p \mid d$ 或 $p = 2$？如何用判别式解释？

### 分叉条件

$p$ 分叉当且仅当 $p$ 整除判别式 $\Delta$。

**判别式**：

$$\Delta = \begin{cases}
4d, & d \equiv 2, 3 \pmod 4, \\
d, & d \equiv 1 \pmod 4.
\end{cases}$$

### 为什么是 $p \mid d$ 或 $p = 2$？

- 若 $d \equiv 2, 3 \pmod 4$，$\Delta = 4d$。所以 $p \mid \Delta$ 当且仅当 $p \mid d$ 或 $p = 2$。
- 若 $d \equiv 1 \pmod 4$，$\Delta = d$。所以 $p \mid \Delta$ 当且仅当 $p \mid d$。

### 判别式解释

- 判别式是 $x^2 - d$ 或 $x^2 - x + h$ 的判别式。
- $p$ 分叉当且仅当 $x^2 - d$（或 $x^2 - x + h$）有重根。
- 重根条件：判别式 $\equiv 0 \pmod p$。

### 例子

- $\mathbb{Z}[i]$，$d = -1$，$\Delta = -4$。$p = 2$ 分叉。
- $\mathbb{Z}[\sqrt{-5}]$，$d = -5$，$\Delta = -20$。$p = 2, 5$ 分叉。

### 总结

分叉条件 $p \mid \Delta$。判别式 $\Delta = 4d$（$d \equiv 2, 3 \pmod 4$）或 $\Delta = d$（$d \equiv 1 \pmod 4$）。所以分叉当且仅当 $p \mid d$ 或 $p = 2$。

## 一、理想的相似

**定义 13.7.1**：环 $R$ 的两个非零理想 $A$ 和 $A'$ 是**相似的**，如果存在非零复数 $\lambda$ 使得

$$A' = \lambda A.$$

**几何解释**：

- 理想是复平面上的格。
- 相似意味着格是相似的几何图形（旋转和伸缩）。
- 主理想都是相似的（因为 $(\alpha) = \alpha R$）。

**等价条件**：$A$ 和 $A'$ 相似当且仅当存在非零理想 $C$ 使得 $AC$ 和 $A'C$ 都是主理想。

**例子**：

- 在 $\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\sqrt{-5})$ 和 $\bar{A} = (2, 1-\sqrt{-5})$ 相似。
- 主理想 $(2)$ 和 $(3)$ 相似。

## 二、理想类

**定义 13.7.2**：理想 $A$ 的**理想类**是 $A$ 的相似类，记作 $\langle A \rangle$。

**引理 13.7.2**：单位理想类 $\langle R \rangle$ 由所有主理想构成。

**证明**：

- 若 $\langle A \rangle = \langle R \rangle$，则 $A = \lambda R$ 对某个 $\lambda$。
- 因为 $1 \in R$，$\lambda \in A$。
- 所以 $A = (\lambda)$ 是主理想。
- 反之，主理想 $(\alpha) = \alpha R$，所以 $\langle (\alpha) \rangle = \langle R \rangle$。

## 三、类群

**命题 13.7.3**：理想类构成阿贝尔群 $C$，称为**类群**。

**运算**：

$$\langle A \rangle \langle B \rangle = \langle AB \rangle.$$

**验证**：

- 良定义：若 $A' = \lambda A$，$B' = \mu B$，则 $A'B' = \lambda \mu AB$，所以 $\langle A'B' \rangle = \langle AB \rangle$。
- 结合律：来自理想乘法的结合律。
- 交换律：来自理想乘法的交换律。
- 单位元：$\langle R \rangle$。
- 逆元：$\langle \bar{A} \rangle$，因为 $\bar{A} A = (n)$ 是主理想，所以 $\langle \bar{A} \rangle \langle A \rangle = 1$。

**类数**：类群的阶，记作 $h$。

**例子**：

- $\mathbb{Z}[i]$：类数 1。
- $\mathbb{Z}[\sqrt{-5}]$：类数 2。
- $\mathbb{Z}[\sqrt{-26}]$：类数 6。

## 四、类群与唯一分解整环

**定理 13.5.6**：虚二次数域的整数所构成的环 $R$ 是唯一分解整环当且仅当它是主理想整环，当且仅当类群 $C$ 是平凡群。

**证明**：

- 主理想整环是唯一分解整环。
- 反之，若 $R$ 是唯一分解整环，则每个素理想是主理想。
- 因为理想分解唯一，每个理想是主理想的积，所以是主理想。
- 所以 $R$ 是主理想整环。
- 类群平凡当且仅当所有理想是主理想。

**意义**：类数 $h = 1$ 对应唯一分解整环。类数越大，唯一分解失败越严重。

## 五、类数的计算

**方法**：

1. 确定范数上界 $\mu$： $\mu = \begin{cases}

\frac{1}{\sqrt{3}} \sqrt{|d|}, & d \equiv 1 \pmod 4.
\end{cases}$
2. 检查素数 $p \le \mu$ 的行为（持素、分裂、分叉）。
3. 确定生成元和关系。
4. 计算类群。

**例子**：$\mathbb{Z}[\sqrt{-5}]$

**例子**：$\mathbb{Z}[\sqrt{-26}]$

- $\mu \approx 5.89$。
- 检查 $p = 2, 3, 5$。
- 类群 $C_6$，类数 6。

## 1. 理想的相似如何定义？几何意义是什么？

### 理想的相似

**定义 13.7.1**：环 $R$ 的两个非零理想 $A$ 和 $A'$ 是**相似的**，如果存在非零复数 $\lambda$ 使得

$$A' = \lambda A.$$

### 几何意义

- 理想是复平面上的格。
- 相似意味着格是相似的几何图形（旋转和伸缩）。
- 具体地，若 $A$ 是格，则 $\lambda A$ 是 $A$ 经过旋转和伸缩得到的格。
- 主理想都是相似的：$(\alpha) = \alpha R$，所以 $(\alpha)$ 和 $R$ 相似。

**例子**：

- 在 $\mathbb{Z}[\sqrt{-5}]$ 中，$A = (2, 1+\sqrt{-5})$ 和 $\bar{A} = (2, 1-\sqrt{-5})$ 相似。
- 主理想 $(2)$ 和 $(3)$ 相似。

### 等价条件

$A$ 和 $A'$ 相似当且仅当存在非零理想 $C$ 使得 $AC$ 和 $A'C$ 都是主理想。

### 总结

理想相似是格相似的代数描述。几何上，相似意味着格经过旋转和伸缩后重合。主理想都相似。

## 2. 理想类群如何定义？为什么它是阿贝尔群？

### 理想类群

**定义**：理想 $A$ 的**理想类**是相似类 $\langle A \rangle$。

**运算**：

$$\langle A \rangle \langle B \rangle = \langle AB \rangle.$$

**类群**：所有理想类的集合 $C$ 在乘法下构成阿贝尔群。

### 为什么它是阿贝尔群？

1. **封闭性**：$\langle A \rangle \langle B \rangle = \langle AB \rangle$ 是理想类。
2. **结合律**：来自理想乘法的结合律。
3. **交换律**：来自理想乘法的交换律。
4. **单位元**：$\langle R \rangle$，即主理想类。
5. **逆元**：$\langle \bar{A} \rangle$，因为 $\bar{A} A = (n)$ 是主理想，所以 $\langle \bar{A} \rangle \langle A \rangle = 1$。

### 良定义

- 若 $A' = \lambda A$，$B' = \mu B$，则 $A'B' = \lambda \mu AB$，所以 $\langle A'B' \rangle = \langle AB \rangle$。
- 运算不依赖于代表元的选取。

### 总结

理想类群是理想相似类在乘法下构成的阿贝尔群。单位元是主理想类，逆元是共轭理想类。

## 3. 类群与唯一分解整环有什么关系？类数 1 对应什么？

### 关系

**定理 13.5.6**：虚二次数域的整数环 $R$ 是唯一分解整环当且仅当它是主理想整环，当且仅当类群 $C$ 是平凡群。

### 类数 > 1

- 类数越大，失败越严重。

## 一、计算类群的一般步骤

1. **确定范数上界 $\mu$**： $\mu = \begin{cases}
\frac{2}{\sqrt{3}} \sqrt{|d|}, & d \equiv 2, 3 \pmod 4, \\
\frac{1}{\sqrt{3}} \sqrt{|d|}, & d \equiv 1 \pmod 4.
\end{cases}$ 每个理想类都有一个范数不超过 $\mu$ 的理想。
2. **检查素数 $p \le \mu$ 的行为**：
  - **持素**：$(p)$ 是素理想，类是平凡的，忽略。
  - **分裂**：$(p) = \mathcal{P} \bar{\mathcal{P}}$，$\mathcal{P}$ 和 $\bar{\mathcal{P}}$ 是生成元。
  - **分叉**：$(p) = \mathcal{P}^2$，$\mathcal{P}$ 是生成元。
3. **确定生成元和关系**：
  - 每个分裂或分叉的素数给出一个生成元。
  - 用范数计算元素，找到生成元之间的关系。
4. **计算类群**：
  - 用生成元和关系确定类群的结构。
  - 类群的阶就是类数。

## 二、例子：$d = -5$

### 1. 范数上界

$d = -5 \equiv 3 \pmod 4$，所以

$$\mu = \frac{2}{\sqrt{3}} \sqrt{5} \approx 2.58.$$

检查 $p \le 2.58$，即 $p = 2$。

### 2. 检查 $p = 2$

$d = -5 \equiv 3 \pmod 4$，$2 \mid d$，所以 $p = 2$ 分叉：

$$(2) = \mathcal{P}^2, \quad \mathcal{P} = (2, 1+\sqrt{-5}).$$

$\mathcal{P}$ 的范数 $N(\mathcal{P}) = 2$。

### 3. 确定生成元和关系

$\mathcal{P}$ 是唯一的生成元。

计算 $\mathcal{P}^2 = (2)$ 是主理想，所以

$$\langle \mathcal{P} \rangle^2 = 1.$$

$\mathcal{P}$ 不是主理想，所以 $\langle \mathcal{P} \rangle$ 的阶为 2。

### 4. 类群

$$C \cong C_2.$$

类数 $h = 2$。

## 三、例子：$d = -26$

### 1. 范数上界

$d = -26 \equiv 2 \pmod 4$，所以

$$\mu = \frac{2}{\sqrt{3}} \sqrt{26} \approx 5.89.$$

检查 $p \le 5.89$，即 $p = 2, 3, 5$。

### 2. 检查 $p = 2, 3, 5$

- $p = 2$：$d = -26 \equiv 2 \pmod 4$，$2 \mid d$，分叉： $(2) = \mathcal{P}^2, \quad \mathcal{P} = (2, \sqrt{-26}).$
- $p = 3$：$d = -26 \equiv 1 \pmod 3$，$1$ 是平方，分裂： $(3) = \mathcal{Q} \bar{\mathcal{Q}}.$
- $p = 5$：$d = -26 \equiv -1 \equiv 4 \pmod 5$，$4$ 是平方，分裂： $(5) = \mathcal{S} \bar{\mathcal{S}}.$

### 3. 确定生成元和关系

生成元：$\mathcal{P}, \mathcal{Q}, \mathcal{S}$。

计算范数：

- $N(1+\sqrt{-26}) = 27 = 3^3$，所以 $(1+\sqrt{-26}) = \mathcal{Q}^3$ 或 $\bar{\mathcal{Q}}^3$。
- $N(2+\sqrt{-26}) = 30 = 2 \cdot 3 \cdot 5$，所以 $(2+\sqrt{-26}) = \mathcal{P} \mathcal{Q} \mathcal{S}$ 或类似。
- $N(13+\sqrt{-26}) = 243 = 3^5$，所以 $\langle \mathcal{Q} \rangle^5 = 1$。

### 4. 类群

关系：

$$\langle \mathcal{P} \rangle^2 = 1, \quad \langle \mathcal{Q} \rangle^3 = 1, \quad \langle \mathcal{P} \rangle \langle \mathcal{Q} \rangle \langle \mathcal{S} \rangle = 1.$$

这些关系给出 $\langle \mathcal{S} \rangle$ 的阶为 6，类群 $C_6$。

类数 $h = 6$。

## 四、例子：$d = -163$

$$\mu = \frac{1}{\sqrt{3}} \sqrt{163} \approx 7.37.$$

检查 $p \le 7.37$，即 $p = 2, 3, 5, 7$。

### 2. 检查 $p = 2, 3, 5, 7$

- $d = -163 \equiv 1 \pmod 4$，用 $x^2 - x + 41$ 判别。
- 对于 $p = 2, 3, 5, 7$，多项式 $x^2 - x + 41$ 在 $\mathbb{F}_p$ 中既约。
- 所以 $p = 2, 3, 5, 7$ 都持素。

### 3. 类群

没有分裂或分叉的素数，所以类群平凡：

$$C \cong \{1\}.$$

类数 $h = 1$。

$\mathbb{Z}[\sqrt{-163}]$ 是唯一分解整环。

## 一、实二次域的整数环

**定义 13.9.1**：设 $d > 0$ 是无平方因子的正整数。**实二次数域**是

$$\mathbb{Q}(\sqrt{d}) = \{a + b\sqrt{d} \mid a, b \in \mathbb{Q}\}.$$

**整数环**：与虚二次域类似，整数环由 $d \bmod 4$ 决定：

- 若 $d \equiv 2, 3 \pmod 4$，则整数环是 $R = \mathbb{Z}[\sqrt{d}] = \{a + b\sqrt{d} \mid a, b \in \mathbb{Z}\}.$
- 若 $d \equiv 1 \pmod 4$，则整数环是 $R = \mathbb{Z}\left[\frac{1+\sqrt{d}}{2}\right] = \left\{a + b\frac{1+\sqrt{d}}{2} \mid a, b \in \mathbb{Z}\right\}.$

**例子**：

- $d = 2$：$R = \mathbb{Z}[\sqrt{2}]$。
- $d = 3$：$d \equiv 3 \pmod 4$，$R = \mathbb{Z}[\sqrt{3}]$。
- $d = 5$：$d \equiv 1 \pmod 4$，$R = \mathbb{Z}[\frac{1+\sqrt{5}}{2}]$。

## 二、范数

**定义 13.9.2**：对 $\alpha = a + b\sqrt{d}$，其共轭是 $\bar{\alpha} = a - b\sqrt{d}$。**范数**定义为

$$N(\alpha) = \alpha \bar{\alpha} = a^2 - b^2 d.$$

**注意**：与虚二次域不同，实二次域的范数**不一定是正数**。它可以是负数。

**性质**：

- $N(\alpha \beta) = N(\alpha) N(\beta)$。
- $N(\alpha) = 0$ 当且仅当 $\alpha = 0$。
- $\alpha$ 是单位当且仅当 $N(\alpha) = \pm 1$。

**例子**：

- $N(1+\sqrt{2}) = 1 - 2 = -1$。
- $N(3+2\sqrt{2}) = 9 - 8 = 1$。

## 三、单位群

**定理 13.9.3**：实二次域的单位群是无限群。

**证明思路**：

- 单位 $\alpha$ 满足 $N(\alpha) = \pm 1$。
- 方程 $a^2 - d b^2 = \pm 1$ 是 **Pell 方程**。
- Pell 方程有无穷多个整数解。
- 所以实二次域的单位无限多。

**例子**：$\mathbb{Z}[\sqrt{2}]$ 的单位：

$$1+\sqrt{2}, \quad (1+\sqrt{2})^2 = 3+2\sqrt{2}, \quad (1+\sqrt{2})^3 = 7+5\sqrt{2}, \dots$$

对应 Pell 方程 $a^2 - 2b^2 = \pm 1$。

**单位群的结构**：

**定理 13.9.4**：实二次域 $R$ 的单位群 $U$ 是

$$U \cong \{\pm 1\} \times \mathbb{Z}.$$

即 $U$ 由一个有限群 $\{\pm 1\}$ 和一个无限循环群生成。

**基本单位**：生成无限循环群的元素称为**基本单位**。例如，$\mathbb{Z}[\sqrt{2}]$ 的基本单位是 $1+\sqrt{2}$。

## 四、Pell 方程

**定义 13.9.5**：**Pell 方程**是

$$x^2 - d y^2 = 1, \quad d > 0 \text{ 无平方因子}.$$

**定理 13.9.6**：Pell 方程 $x^2 - d y^2 = 1$ 有无穷多个正整数解。

**证明思路**：

- 用连分数展开 $\sqrt{d}$。
- 连分数的收敛给出 Pell 方程的解。
- 最小正解 $(x_1, y_1)$ 给出基本单位 $x_1 + y_1\sqrt{d}$。

**例子**：

- $d = 2$：$x^2 - 2y^2 = 1$。最小解 $(3, 2)$，对应 $3+2\sqrt{2} = (1+\sqrt{2})^2$。
- $d = 3$：$x^2 - 3y^2 = 1$。最小解 $(2, 1)$，对应 $2+\sqrt{3}$。
- $d = 5$：$x^2 - 5y^2 = 1$。最小解 $(9, 4)$，对应 $9+4\sqrt{5}$。

**负 Pell 方程**：$x^2 - d y^2 = -1$。不一定有解。若有解，则基本单位的范数为 $-1$。

## 五、实二次域的类群

**定理 13.9.7**：实二次域的整数环的理想有唯一分解为素理想的积，且类群有限。

**与虚二次域的对比**：

| 性质 | 虚二次域 | 实二次域 |
| --- | --- | --- |
| 单位群 | 有限 | 无限 |
| 范数 | 正定 | 不定 |
| Pell 方程 | 无 | 有 |
| 类群 | 有限 | 有限 |
| 唯一分解 | 只有 9 个 | 猜想无限多个 |

**例子**：$d = 2$，$R = \mathbb{Z}[\sqrt{2}]$ 是唯一分解整环，类数 1。

## 1. 为什么实二次域的单位群无限？如何用 Pell 方程证明？

### 单位群的定义

实二次域 $K = \mathbb{Q}(\sqrt{d})$（$d > 0$ 无平方因子）的整数环 $R$ 中，**单位**是满足 $N(\alpha) = \pm 1$ 的元素。范数定义为

$$N(a + b\sqrt{d}) = a^2 - d b^2.$$

### 为什么单位群无限？

**关键**：单位对应方程

$$a^2 - d b^2 = \pm 1$$

的整数解 $(a, b)$。这个方程就是 **Pell 方程**。

**Pell 方程有无穷多个解**：

- 方程 $x^2 - d y^2 = 1$ 总有非平凡解。
- 最小正解 $(x_1, y_1)$ 称为**基本解**。
- 所有解由 $x_n + y_n \sqrt{d} = (x_1 + y_1 \sqrt{d})^n, \quad n \in \mathbb{Z}$ 给出。
- 因为 $x_1 + y_1 \sqrt{d} > 1$，所以 $(x_1 + y_1 \sqrt{d})^n$ 随 $n$ 增大而无限增大，给出无穷多个不同的单位。

**例子**：$d = 2$，基本解 $(3, 2)$，对应单位 $3 + 2\sqrt{2}$。所有单位：

$$(3 + 2\sqrt{2})^n, \quad n \in \mathbb{Z}.$$

这些单位无限多。

### 用 Pell 方程证明

**定理**：Pell 方程 $x^2 - d y^2 = 1$ 有无穷多个正整数解。

**证明思路**：

1. **连分数**：$\sqrt{d}$ 的连分数展开是周期的。
2. **收敛**：连分数的收敛 $p_n / q_n$ 满足 $p_n^2 - d q_n^2 = (-1)^{n+1} k_n$ 对某个有界整数 $k_n$。
3. **鸽笼原理**：因为 $k_n$ 只有有限多个可能值，存在 $k$ 使得无穷多个收敛满足 $p_n^2 - d q_n^2 = k$。
4. **构造解**：从这些收敛中，可以构造出 Pell 方程的解。
5. **无限性**：由基本解 $(x_1, y_1)$，通过 $(x_1 + y_1 \sqrt{d})^n$ 生成无穷多个解。

### 几何解释

- 将 $\alpha = a + b\sqrt{d}$ 映射到 $(u, v) = (a + b\sqrt{d}, a - b\sqrt{d})$。
- 范数 $N(\alpha) = uv$。
- 单位对应双曲线 $uv = \pm 1$ 上的格点。
- 双曲线有无限多个格点，所以单位无限多。

### 总结

实二次域的单位群无限，因为单位对应 Pell 方程 $a^2 - d b^2 = \pm 1$ 的解，而 Pell 方程有无穷多个解。基本解生成所有解，给出无限多个单位。

## 2. 基本单位如何计算？连分数展开如何给出 Pell 方程的解？

### 基本单位的定义

**基本单位**是实二次域 $R$ 中大于 1 的最小单位。它生成单位群的无限循环部分：

$$U = \{\pm 1\} \times \langle \varepsilon \rangle,$$

其中 $\varepsilon > 1$ 是基本单位。

### 连分数展开

**步骤**：

1. **计算 $\sqrt{d}$ 的连分数**： $\sqrt{d} = [a_0; \overline{a_1, a_2, \dots, a_r}],$ 其中 $a_0 = \lfloor \sqrt{d} \rfloor$，周期为 $r$。
2. **计算收敛 $p_n / q_n$**： $p_0 = a_0, \quad q_0 = 1,$ $p_1 = a_0 a_1 + 1, \quad q_1 = a_1,$ $p_n = a_n p_{n-1} + p_{n-2}, \quad q_n = a_n q_{n-1} + q_{n-2}.$
3. **找到 Pell 方程的解**：
  - 若周期 $r$ 为偶数，则 $p_{r-1}^2 - d q_{r-1}^2 = 1$。
  - 若周期 $r$ 为奇数，则 $p_{2r-1}^2 - d q_{2r-1}^2 = 1$。
4. **基本单位**： $\varepsilon = p + q \sqrt{d},$ 其中 $(p, q)$ 是 Pell 方程 $x^2 - d y^2 = 1$ 的最小正解。

### 例子：$d = 2$

**连分数**：

$$\sqrt{2} = [1; \overline{2}].$$

周期 $r = 1$（奇数）。

**收敛**：

$$p_0 / q_0 = 1/1, \quad p_1 / q_1 = 3/2, \quad p_2 / q_2 = 7/5, \dots$$

**Pell 方程**：

$$3^2 - 2 \cdot 2^2 = 9 - 8 = 1.$$

所以基本解 $(3, 2)$，基本单位

$$\varepsilon = 3 + 2\sqrt{2}.$$

**验证**：$N(3 + 2\sqrt{2}) = 9 - 8 = 1$。

### 例子：$d = 3$

**连分数**：

$$\sqrt{3} = [1; \overline{1, 2}].$$

周期 $r = 2$（偶数）。

**收敛**：

$$p_0 / q_0 = 1/1, \quad p_1 / q_1 = 2/1, \quad p_2 / q_2 = 5/3, \dots$$

**Pell 方程**：

$$2^2 - 3 \cdot 1^2 = 4 - 3 = 1.$$

所以基本解 $(2, 1)$，基本单位

$$\varepsilon = 2 + \sqrt{3}.$$

### 例子：$d = 5$

**连分数**：

$$\sqrt{5} = [2; \overline{4}].$$

周期 $r = 1$（奇数）。

**收敛**：

$$p_0 / q_0 = 2/1, \quad p_1 / q_1 = 9/4, \dots$$

**Pell 方程**：

$$9^2 - 5 \cdot 4^2 = 81 - 80 = 1.$$

所以基本解 $(9, 4)$，基本单位

$$\varepsilon = 9 + 4\sqrt{5}.$$

### 总结

基本单位通过 $\sqrt{d}$ 的连分数展开计算。连分数的收敛给出 Pell 方程的解，最小正解对应基本单位。

## 3. 实二次域的类群如何计算？与虚二次域有什么不同？

### 类群的定义

实二次域 $R$ 的理想类群 $C$ 是非零理想的相似类在乘法下构成的阿贝尔群。类数是类群的阶。

### 计算步骤

1. **确定范数上界 $\mu$**： $\mu = \frac{2}{\sqrt{3}} \sqrt{d} \quad \text{或} \quad \frac{1}{\sqrt{3}} \sqrt{d}.$ 每个理想类都有一个范数不超过 $\mu$ 的理想。
2. **检查素数 $p \le \mu$ 的行为**：
  - **持素**：$(p)$ 是素理想，类是平凡的。
  - **分裂**：$(p) = \mathcal{P} \bar{\mathcal{P}}$，$\mathcal{P}$ 是生成元。
  - **分叉**：$(p) = \mathcal{P}^2$，$\mathcal{P}$ 是生成元。
3. **确定生成元和关系**：
  - 用范数计算元素，找到生成元之间的关系。
  - 需要处理**单位**的影响：因为单位无限多，两个理想可能相似但不相等。
4. **计算类群**：
  - 用生成元和关系确定类群的结构。

### 与虚二次域的不同

| 性质 | 虚二次域 | 实二次域 |
| --- | --- | --- |
| 单位群 | 有限 | 无限 |
| 范数 | 正定 | 不定 |
| 理想相似 | 简单 | 需要处理单位 |
| 类群计算 | 较简单 | 较复杂 |
| 调节子 | 无 | 有 |

**关键区别**：

- **单位无限**：实二次域的单位无限多，导致理想的相似类更复杂。两个理想 $A$ 和 $B$ 相似，如果 $A = \lambda B$ 对某个 $\lambda \in K$。因为单位无限多，$\lambda$ 可以乘以任意单位，所以相似类更难确定。
- **调节子**：实二次域的类群计算需要用到**调节子**（regulator），它衡量单位群的“密度”。
- **类数公式**：实二次域的类数公式包含调节子，而虚二次域的类数公式不包含。

### 例子：$d = 2$

$R = \mathbb{Z}[\sqrt{2}]$ 是唯一分解整环，类数 1。

**验证**：

- 范数上界 $\mu = \frac{2}{\sqrt{3}} \sqrt{2} \approx 1.63$。
- 检查 $p = 2$：$d = 2 \equiv 2 \pmod 4$，$2 \mid d$，分叉。
- $(2) = (\sqrt{2})^2$，$\sqrt{2}$ 是主理想。
- 没有非主理想，类群平凡。

### 总结

实二次域的类群计算比虚二次域更复杂，因为单位无限多，需要处理调节子。但基本步骤相同：确定范数上界，检查素数行为，确定生成元和关系。

- 格点的分布：格点在双曲线上无限延伸。
- 单位群的无限性：双曲线无限延伸，格点无限多。

### 总结

实二次域的几何与虚二次域不同：实二次域嵌入 $\mathbb{R}^2$，范数不定，单位对应双曲线上的格点。双曲线无限延伸，所以单位无限多。

在上一节中，我们研究了实二次域，并看到单位群对应双曲线上的格点。现在，我们系统地总结**格**的理论。格是复平面或 $\mathbb{R}^n$ 中的离散子群，它在二次数域、椭圆曲线、模形式、密码学中都有核心应用。本节将研究格的定义、格基、指标、面积、格点定理，以及它们在二次数域中的应用。

## 一、格的定义

**定义 13.10.1**：$\mathbb{R}^n$ 的一个**格** $L$ 是 $\mathbb{R}^n$ 的一个离散子群，即：

- $L$ 是 $\mathbb{R}^n$ 的加法子群。
- $L$ 是离散的：存在 $\epsilon > 0$，使得 $L$ 中任何非零向量的长度至少为 $\epsilon$。

**例子**：

- $\mathbb{Z}^n$ 是 $\mathbb{R}^n$ 中的格。
- 高斯整数 $\mathbb{Z}[i]$ 是 $\mathbb{R}^2 \cong \mathbb{C}$ 中的格。
- 二次数域的整数环是 $\mathbb{R}^2$ 中的格。

**格基**：格 $L$ 的一组**格基**是 $L$ 中的向量组 $(v_1, \dots, v_n)$，使得每个 $l \in L$ 可以唯一地写成

$$l = a_1 v_1 + \cdots + a_n v_n, \quad a_i \in \mathbb{Z}.$$

**定理 13.10.2**：$\mathbb{R}^n$ 的每个格都有格基，且任意两组格基有相同的元素个数。

## 二、平行四边形的面积

**定义 13.10.3**：设 $B = (v_1, \dots, v_n)$ 是格 $L$ 的格基。**基本平行四边形**是

$$\Pi(B) = \left\{ \sum_{i=1}^n r_i v_i \mid 0 \le r_i \le 1 \right\}.$$

**面积**：

$$\Delta(L) = |\det(v_1, \dots, v_n)|.$$

**命题 13.10.4**：$\Delta(L)$ 与格基的选择无关。

**证明**：若 $B' = BP$ 是另一组格基，其中 $P$ 是可逆整数矩阵，则

$$\Delta(L') = |\det(BP)| = |\det B| \cdot |\det P| = \Delta(L) \cdot 1 = \Delta(L).$$

因为 $P$ 是可逆整数矩阵，$|\det P| = 1$。

## 三、指标

**定义 13.10.5**：若 $L \subset M$ 是格，**指标** $[M : L]$ 是 $L$ 在 $M$ 中的陪集个数。

**命题 13.10.6**：

$$[M : L] = \frac{\Delta(L)}{\Delta(M)}.$$

**证明**：基本平行四边形 $\Pi(B_M)$ 包含 $[M : L]$ 个 $L$ 的格点。面积比等于指标。

**推论 13.10.7**：$[M : L]$ 是有限的。

**例子**：在 $\mathbb{Z}^2$ 中，子格 $L = 2\mathbb{Z} \times 3\mathbb{Z}$ 的指标是 6。

## 四、格点定理

**引理 13.10.8**：设 $v$ 是格 $L$ 中长度最小的非零向量。则

$$|v|^2 \le \frac{2}{\sqrt{3}} \Delta(L).$$

**证明**：

- 取 $L$ 中最小长度的非零向量 $v_1$。
- 取 $v_2$ 使得 $(v_1, v_2)$ 是格基。
- 通过调整 $v_2$，可以假设 $v_2$ 在 $v_1$ 方向的投影在 $[-|v_1|/2, |v_1|/2]$ 内。
- 由最小性，$|v_2| \ge |v_1|$。
- 计算得 $\Delta(L) \ge \frac{\sqrt{3}}{2} |v_1|^2$。
- 所以 $|v_1|^2 \le \frac{2}{\sqrt{3}} \Delta(L)$。

**几何意义**：格中最短向量的长度平方不超过基本平行四边形面积的 $\frac{2}{\sqrt{3}}$ 倍。等号在等边三角形格时成立。

## 五、格在二次数域中的应用

### 1. 理想是格

**命题 13.10.9**：二次数域整数环 $R$ 的非零理想是 $\mathbb{R}^2$ 中的格。

**例子**：$\mathbb{Z}[\sqrt{-5}]$ 中的理想 $(2, 1+\sqrt{-5})$ 是格。

### 2. 理想的范数

**定义 13.10.10**：理想 $A$ 的**范数**是

$$N(A) = [R : A] = \frac{\Delta(A)}{\Delta(R)}.$$

**命题 13.10.11**：

$$N(AB) = N(A) N(B).$$

### 3. 主引理

**引理 13.10.12（主引理）**：令 $R$ 为虚二次数域整数环，$A$ 是非零理想。则

$$\bar{A} A = (n)$$

是由正整数 $n$ 生成的主理想。

**证明**：用格基证明 $\bar{A} A$ 由单个整数 $n$ 生成。

### 4. 类群有限

**定理 13.10.13**：二次数域的类群有限。

**证明**：用格点定理证明每个理想类都有一个范数不超过 $\mu$ 的理想，而范数不超过 $\mu$ 的理想只有有限多个。

## 六、Pick 定理

**定理 13.10.14（Pick 定理）**：设 $P$ 是 $\mathbb{R}^2$ 中顶点在整数格 $\mathbb{Z}^2$ 上的多边形。则

$$\text{面积}(P) = a + \frac{b}{2} - 1,$$

其中 $a$ 是 $P$ 内部的格点数，$b$ 是 $P$ 边界上的格点数。

**例子**：单位正方形：$a = 0$，$b = 4$，面积 $= 0 + 2 - 1 = 1$。

**应用**：Pick 定理用于计算格多边形的面积，与格点计数相关。

## 1. 为什么格的基本平行四边形面积与格基无关？这个事实在几何上意味着什么？

### 基本平行四边形面积

设 $L$ 是 $\mathbb{R}^n$ 中的格，$B = (v_1, \dots, v_n)$ 是一组格基。基本平行四边形为

$$\Pi(B) = \left\{ \sum_{i=1}^n r_i v_i \mid 0 \le r_i \le 1 \right\}.$$

其面积（或体积）为

$$\Delta(L) = |\det(v_1, \dots, v_n)|.$$

### 为什么与格基无关？

设 $B' = (v_1', \dots, v_n')$ 是另一组格基。因为两组基生成同一个格 $L$，存在整数矩阵 $P = (p_{ij})$ 使得

$$v_j' = \sum_{i=1}^n v_i p_{ij},$$

即 $B' = BP$。同理，存在整数矩阵 $Q$ 使得 $B = B'Q$。因此 $P$ 和 $Q$ 互为逆矩阵，且都是整数矩阵。所以

$$\det(P) \det(Q) = 1.$$

因为 $\det(P)$ 和 $\det(Q)$ 都是整数，所以

$$\det(P) = \pm 1.$$

于是

$$\Delta(L') = |\det(B')| = |\det(BP)| = |\det(B)| \cdot |\det(P)| = \Delta(L) \cdot 1 = \Delta(L).$$

所以面积与格基的选择无关。

### 几何意义

- $\Delta(L)$ 是格 $L$ 的**基本体积**，表示每个格点“平均占据”的体积。
- 它是格的内在属性，不依赖于如何选择格基。
- 在二维情形，$\Delta(L)$ 是基本平行四边形的面积。
- 格点的密度为 $1 / \Delta(L)$。

### 总结

格的基本平行四边形面积与格基无关，因为不同格基之间相差一个行列式为 $\pm 1$ 的整数矩阵。几何上，$\Delta(L)$ 是格的内在体积，表示格点的密度。

## 2. 指标 $[M : L] = \Delta(L) / \Delta(M)$ 如何用于计算理想的范数？

### 指标公式

设 $L \subset M$ 是格。指标 $[M : L]$ 是 $L$ 在 $M$ 中的陪集个数。公式为

$$[M : L] = \frac{\Delta(L)}{\Delta(M)}.$$

**证明思路**：

- 基本平行四边形 $\Pi(B_M)$ 的体积为 $\Delta(M)$。
- 每个 $L$ 的陪集在 $\Pi(B_M)$ 中有一个代表元。
- 所以 $\Pi(B_M)$ 包含 $[M : L]$ 个 $L$ 的格点。
- 这些格点将 $\Pi(B_M)$ 分成 $[M : L]$ 个基本平行四边形，每个体积为 $\Delta(L)$。
- 所以 $\Delta(M) = [M : L] \cdot \Delta(L)$，即 $[M : L] = \Delta(L) / \Delta(M)$。

### 用于计算理想的范数

在二次数域整数环 $R$ 中，非零理想 $A$ 是格。**理想的范数**定义为

$$N(A) = [R : A] = \frac{\Delta(A)}{\Delta(R)}.$$

**例子**：$\mathbb{Z}[\sqrt{-5}]$ 中，$R = \mathbb{Z}[\sqrt{-5}]$，理想 $A = (2, 1+\sqrt{-5})$。

- $R$ 的格基是 $(1, \sqrt{-5})$，$\Delta(R) = |\det \begin{bmatrix} 1 & 0 \\ 0 & \sqrt{5} \end{bmatrix}| = \sqrt{5}$。
- $A$ 的格基是 $(2, 1+\sqrt{-5})$，$\Delta(A) = |\det \begin{bmatrix} 2 & 1 \\ 0 & \sqrt{5} \end{bmatrix}| = 2\sqrt{5}$。
- 所以 $N(A) = \Delta(A) / \Delta(R) = 2\sqrt{5} / \sqrt{5} = 2$。

**验证**：$A \bar{A} = (2)$，$N(A) = 2$。

### 总结

指标公式 $[M : L] = \Delta(L) / \Delta(M)$ 用于计算理想的范数 $N(A) = [R : A] = \Delta(A) / \Delta(R)$。这是理想范数的几何解释。

## 3. 格点定理如何用于证明类群有限？为什么范数上界给出有限多个理想？

### 格点定理

**引理 13.10.8**：设 $v$ 是格 $L$ 中长度最小的非零向量。则

$$|v|^2 \le \frac{2}{\sqrt{3}} \Delta(L).$$

**几何意义**：格中最短向量的长度平方不超过基本平行四边形面积的 $\frac{2}{\sqrt{3}}$ 倍。

### 用于证明类群有限

**步骤**：

1. **范数上界**：对任意理想类 $\langle A \rangle$，存在一个理想 $C \in \langle A \rangle$，使得 $N(C) \le \mu,$ 其中 $\mu = \frac{2}{\sqrt{3}} \sqrt{|d|}$（$d \equiv 2, 3 \pmod 4$）或 $\frac{1}{\sqrt{3}} \sqrt{|d|}$（$d \equiv 1 \pmod 4$）。
2. **证明范数上界**：
  - 取 $A$ 中具有最小范数的非零元 $\alpha$。
  - 由格点定理，$N(\alpha) \le \mu N(A)$。
  - 因为 $(\alpha) \subset A$，所以 $A$ 整除 $(\alpha)$，即 $(\alpha) = A C$。
  - 取范数：$N(\alpha) = N(A) N(C)$。
  - 所以 $N(C) \le \mu$。
3. **有限多个理想**：
  - 范数 $N(C) \le \mu$ 的理想 $C$ 只有有限多个。
  - 因为 $N(C) = [R : C]$，而指标有限的理想只有有限多个。
  - 所以每个理想类都有一个范数不超过 $\mu$ 的代表元。
  - 因此类群有限。

### 为什么范数上界给出有限多个理想？

- 理想的范数 $N(C) = [R : C]$ 是正整数。
- 若 $N(C) \le \mu$，则 $N(C)$ 只能取有限多个值。
- 对每个 $n \le \mu$，范数为 $n$ 的理想只有有限多个。
- 所以总共有有限多个理想。

### 总结

格点定理用于证明每个理想类都有一个范数不超过 $\mu$ 的代表元。范数上界 $\mu$ 给出有限多个理想，因此类群有限。

## 4. Pick 定理如何证明？它与格点计数有什么关系？

### Pick 定理

**定理 13.10.14（Pick 定理）**：设 $P$ 是 $\mathbb{R}^2$ 中顶点在整数格 $\mathbb{Z}^2$ 上的多边形。则

$$\text{面积}(P) = a + \frac{b}{2} - 1,$$

其中 $a$ 是 $P$ 内部的格点数，$b$ 是 $P$ 边界上的格点数。

### 证明思路

**方法一：用格点计数**

1. **基本三角形**：考虑顶点为 $(0,0)$，$(1,0)$，$(0,1)$ 的三角形。面积 $= 1/2$，$a = 0$，$b = 3$。验证：$0 + 3/2 - 1 = 1/2$。
2. **三角形分解**：任何格多边形可以分解为基本三角形。Pick 定理对基本三角形成立，且对三角形的并也成立（面积和格点计数都满足可加性）。
3. **归纳法**：通过不断添加基本三角形，证明 Pick 定理对任意格多边形成立。

**方法二：用 Euler 公式**

1. **三角剖分**：将 $P$ 三角剖分为 $T$ 个三角形，顶点在格点上。
2. **Euler 公式**：$V - E + T = 1$，其中 $V$ 是顶点数，$E$ 是边数，$T$ 是三角形数。
3. **计数**：$V = a + b$，$E = 3T/2 + b/2$。
4. **面积**：每个三角形面积为 $1/2$，所以面积 $= T/2$。
5. **代入**：$T = 2A$，$V - E + T = 1$ 给出 $a + b - (3T/2 + b/2) + T = 1$。
6. **化简**：$a + b/2 - T/2 = 1$，即 $A = a + b/2 - 1$。

### 与格点计数的关系

- Pick 定理把面积与格点数联系起来。
- 面积是连续的，格点数是离散的。
- 定理说明：格多边形的面积由内部格点数和边界格点数完全决定。
- 这是格点几何的基本定理，用于计算格多边形的面积和格点数。

### 例子

单位正方形：$a = 0$，$b = 4$，面积 $= 0 + 2 - 1 = 1$。

三角形 $(0,0)$，$(1,0)$，$(0,1)$：$a = 0$，$b = 3$，面积 $= 0 + 1.5 - 1 = 0.5$。

### 总结

Pick 定理通过三角剖分和 Euler 公式证明。它把格多边形的面积与内部和边界格点数联系起来，是格点几何的基本定理。

## 5. 格在密码学中有什么应用？例如，格基约化、最短向量问题。

### 格基约化

**问题**：给定格 $L$ 的一组基，找到一组“好”的基（短向量、近似正交）。

**LLL 算法**（Lenstra-Lenstra-Lovász）：在多项式时间内找到一组近似最短的格基。

**应用**：

- **密码分析**：LLL 算法用于破解基于格的密码系统。
- **整数规划**：LLL 用于求解整数线性规划。
- **多项式因子分解**：LLL 用于分解整系数多项式。

### 最短向量问题（SVP）

**问题**：给定格 $L$，找到 $L$ 中最短的非零向量。

**困难性**：SVP 是 NP-困难的（在随机归约下）。

**应用**：

- **格密码**：基于 SVP 的困难性构造密码系统。
- **NTRU**：基于格的公钥密码系统。
- **Learning With Errors (LWE)**：基于格的密码系统，用于后量子密码学。

### 格密码

**优势**：

- **后量子安全**：格密码被认为能抵抗量子计算机攻击。
- **效率**：格密码的加密和解密速度快。
- **多样性**：基于格可以构造加密、签名、密钥交换等。

**例子**：

- **NTRU**：1996 年提出，基于格的最短向量问题。
- **LWE**：2010 年提出，用于全同态加密。
- **Kyber**：NIST 后量子密码标准化候选。

### 总结

格在密码学中应用广泛：LLL 算法用于格基约化，SVP 用于构造格密码。格密码是后量子密码学的重要方向。

## 6. 格在模形式、椭圆曲线中有什么应用？例如，复环面、模空间。

### 复环面

**定义**：设 $L$ 是 $\mathbb{C}$ 中的格。商 $\mathbb{C} / L$ 是一个**复环面**，即椭圆曲线。

**椭圆曲线**：每个椭圆曲线同构于 $\mathbb{C} / L$ 对某个格 $L$。

**应用**：

- **椭圆曲线密码**：基于椭圆曲线上的离散对数。
- **模形式**：模形式是格上的函数。

### 模形式

**定义**：模形式是上半平面上的全纯函数，满足

$$f\left(\frac{az+b}{cz+d}\right) = (cz+d)^k f(z)$$

对 $\begin{bmatrix} a & b \\ c & d \end{bmatrix} \in SL_2(\mathbb{Z})$。

**与格的关系**：

- 格 $L = \mathbb{Z} + \mathbb{Z}\tau$，其中 $\tau$ 在上半平面。
- 模形式是格上的函数，满足某种齐次性。
- 模形式与椭圆曲线、模空间密切相关。

### 模空间

**定义**：模空间是参数化数学对象（如椭圆曲线、格）的空间。

**例子**：

- 椭圆曲线的模空间是 $SL_2(\mathbb{Z}) \backslash \mathbb{H}$。
- 格的模空间是 $SL_2(\mathbb{Z}) \backslash \mathbb{H}$。

**应用**：

- **模形式**：模形式是模空间上的函数。
- **椭圆曲线**：模空间参数化椭圆曲线。
- **数论**：模形式用于证明费马大定理。

### 总结

格在模形式、椭圆曲线中应用广泛：复环面是椭圆曲线，模形式是格上的函数，模空间参数化格和椭圆曲线。这些是数论和代数几何的核心对象。

## 第十三章 练习选讲

### 第一节：代数整数

**练习 1.1**：$\frac{1}{2}(1+\sqrt{5})$ 是代数整数吗？

**解答**：
令 $\alpha = \frac{1}{2}(1+\sqrt{5})$。则

$$2\alpha - 1 = \sqrt{5}.$$

平方得

$$(2\alpha - 1)^2 = 5 \quad \Rightarrow \quad 4\alpha^2 - 4\alpha + 1 = 5 \quad \Rightarrow \quad 4\alpha^2 - 4\alpha - 4 = 0.$$

即

$$\alpha^2 - \alpha - 1 = 0.$$

这是首一整系数多项式，所以 $\alpha$ 是代数整数。

**练习 1.2**：证明 $\mathbb{Q}[\sqrt{d}]$ 中的整数形成一个环。

**解答**：
设 $\alpha, \beta$ 是 $\mathbb{Q}[\sqrt{d}]$ 中的代数整数。需要证明 $\alpha + \beta$，$\alpha \beta$，$-\alpha$ 也是代数整数。

- 若 $\alpha$ 是首一整系数多项式 $f$ 的根，$\beta$ 是首一整系数多项式 $g$ 的根，则 $\alpha + \beta$ 和 $\alpha \beta$ 是多项式 $f$ 和 $g$ 的结式的根，结式是整系数多项式。所以 $\alpha + \beta$ 和 $\alpha \beta$ 是代数整数。
- $-\alpha$ 是 $f(-x)$ 的根，$f(-x)$ 也是首一整系数多项式。

所以整数形成环。

**练习 1.3**：
(a) 令 $\alpha$ 是一个复数，它是一个首一的整多项式的根，这个多项式不必是既约的。证明 $\alpha$ 是代数整数。

**解答**：
设 $f(x)$ 是首一整系数多项式，$f(\alpha) = 0$。令 $g(x)$ 是 $\alpha$ 在 $\mathbb{Q}$ 上的既约多项式。则 $g$ 整除 $f$。因为 $f$ 是首一整系数的，$g$ 也是首一整系数的（由高斯引理）。所以 $\alpha$ 是代数整数。

(b) 令 $\alpha$ 是代数数，它是一个整多项式 $f(x) = a_n x^n + \cdots + a_0$ 的根。证明 $a_n \alpha$ 是代数整数。

**解答**：
令 $\beta = a_n \alpha$。则 $\alpha = \beta / a_n$。代入 $f$：

$$a_n (\beta / a_n)^n + a_{n-1} (\beta / a_n)^{n-1} + \cdots + a_0 = 0.$$

乘以 $a_n^{n-1}$：

$$\beta^n + a_{n-1} \beta^{n-1} + a_{n-2} a_n \beta^{n-2} + \cdots + a_0 a_n^{n-1} = 0.$$

这是首一整系数多项式，所以 $\beta = a_n \alpha$ 是代数整数。

(c) 令 $\alpha$ 是代数整数，它是多项式 $x^n + a_{n-1} x^{n-1} + \cdots + a_0$ 的根。证明 $\alpha^{-1}$ 是代数整数当且仅当 $a_0 = \pm 1$。

**解答**：
若 $\alpha^{-1}$ 是代数整数，则 $\alpha \alpha^{-1} = 1$ 是代数整数。$\alpha$ 的范数 $N(\alpha) = (-1)^n a_0$ 是整数。因为 $\alpha$ 是单位，$N(\alpha) = \pm 1$，所以 $a_0 = \pm 1$。

反之，若 $a_0 = \pm 1$，则

$$\alpha^n + a_{n-1} \alpha^{n-1} + \cdots + a_1 \alpha + a_0 = 0.$$

除以 $\alpha^n$：

$$1 + a_{n-1} \alpha^{-1} + \cdots + a_0 \alpha^{-n} = 0.$$

即

$$a_0 \alpha^{-n} + a_1 \alpha^{-(n-1)} + \cdots + a_{n-1} \alpha^{-1} + 1 = 0.$$

因为 $a_0 = \pm 1$，这是 $\alpha^{-1}$ 的首一整系数多项式。所以 $\alpha^{-1}$ 是代数整数。

**练习 1.4**：令 $d$ 和 $d'$ 是整数。何时域 $\mathbb{Q}(\sqrt{d})$ 和 $\mathbb{Q}(\sqrt{d'})$ 是不同的？

**解答**：
$\mathbb{Q}(\sqrt{d}) = \mathbb{Q}(\sqrt{d'})$ 当且仅当 $d' / d$ 是有理数的平方。即 $d$ 和 $d'$ 的平方因子部分相同。

例如，$\mathbb{Q}(\sqrt{2}) = \mathbb{Q}(\sqrt{8})$，因为 $8 = 4 \cdot 2$，$8/2 = 4 = 2^2$。

### 第二节：分解代数整数

**练习 2.1**：证明 $2$，$3$ 和 $1 \pm \sqrt{-5}$ 是环 $R = \mathbb{Z}[\sqrt{-5}]$ 的既约元，且这个环的单位为 $\pm 1$。

**解答**：
$R$ 的范数 $N(a + b\sqrt{-5}) = a^2 + 5b^2$。

**单位**：$N(\alpha) = 1$ 给出 $a^2 + 5b^2 = 1$。只有 $b = 0$，$a = \pm 1$。所以单位是 $\pm 1$。

**$2$ 既约**：$N(2) = 4$。若 $2 = \alpha \beta$，则 $N(\alpha) N(\beta) = 4$。可能的范数：$1, 2, 4$。范数 $2$ 的元素不存在（$a^2 + 5b^2 = 2$ 无解）。所以 $2$ 既约。

**$3$ 既约**：$N(3) = 9$。可能的范数：$1, 3, 9$。范数 $3$ 的元素不存在。所以 $3$ 既约。

**$1+\sqrt{-5}$ 既约**：$N(1+\sqrt{-5}) = 6$。可能的范数：$1, 2, 3, 6$。范数 $2, 3$ 的元素不存在。所以既约。

**$1-\sqrt{-5}$ 既约**：同理。

**练习 2.2**：对哪个负整数 $d \equiv 2 \pmod 4$ 是环 $\mathbb{Q}[\sqrt{d}]$ 中整数环的唯一分解？

**解答**：
$d \equiv 2 \pmod 4$ 且 $d < 0$。唯一分解的虚二次域只有

$$d = -1, -2, -3, -7, -11, -19, -43, -67, -163.$$

其中 $d \equiv 2 \pmod 4$ 的是 $d = -2$。所以只有 $d = -2$。

### 第三节：$\mathbb{Z}[\sqrt{-5}]$ 中的理想

**练习 3.1**：令 $\alpha$ 是环 $R = \mathbb{Z}[\delta]$，$\delta = \sqrt{-5}$ 中的一个元素，且令 $\gamma = \frac{1}{2}(\alpha + \alpha \delta)$。在什么情况下以 $(\alpha, \gamma)$ 作为基的格是一个理想？

**解答**：
格 $A = (\alpha, \gamma)$ 是理想当且仅当 $\delta A \subset A$。

- $\delta \alpha = \alpha \delta$。需要 $\alpha \delta \in A$。因为 $A$ 由 $\alpha$ 和 $\gamma$ 生成，$\alpha \delta = 2\gamma - \alpha \in A$。所以 $\delta \alpha \in A$。
- $\delta \gamma = \delta \cdot \frac{1}{2}(\alpha + \alpha \delta) = \frac{1}{2}(\alpha \delta + \alpha \delta^2) = \frac{1}{2}(\alpha \delta - 5\alpha) = \frac{1}{2}\alpha \delta - \frac{5}{2}\alpha$。
需要 $\delta \gamma \in A$。因为 $\frac{1}{2}\alpha \delta = \gamma - \frac{1}{2}\alpha$，所以 $\delta \gamma = \gamma - \frac{1}{2}\alpha - \frac{5}{2}\alpha = \gamma - 3\alpha \in A.$ 所以 $\delta \gamma \in A$。

因此 $(\alpha, \gamma)$ 总是理想。

**练习 3.2**：令 $\delta = \sqrt{-5}$。确定给定向量的任意整数组合的格是否是一个理想：
(a) $(5, 1+\delta)$
(b) $(7, 1+\delta)$
(c) $(4-2\delta, 2+2\delta, 6+4\delta)$

**解答**：
(a) 格 $A = (5, 1+\delta)$。检查 $\delta A \subset A$：

- $\delta \cdot 5 = 5\delta = 5(1+\delta) - 5 \in A$。
- $\delta(1+\delta) = \delta + \delta^2 = \delta - 5 = (1+\delta) - 6 \in A$。
所以 $A$ 是理想。

(b) 格 $B = (7, 1+\delta)$。检查 $\delta B \subset B$：

- $\delta \cdot 7 = 7\delta = 7(1+\delta) - 7 \in B$。
- $\delta(1+\delta) = \delta - 5 = (1+\delta) - 6$。需要 $6 \in B$。但 $6$ 不是 $7$ 和 $1+\delta$ 的整数组合（因为 $6$ 和 $7$ 的最大公约数是 $1$，但 $1+\delta$ 的系数需要为 $0$）。所以 $6 \notin B$。因此 $B$ 不是理想。

(c) 格 $C = (4-2\delta, 2+2\delta, 6+4\delta)$。检查 $\delta C \subset C$：

- $\delta(4-2\delta) = 4\delta - 2\delta^2 = 4\delta + 10 = 4\delta + 10$。需要表示为生成元的整数组合。
- 计算：$4\delta + 10 = 2(2+2\delta) + 6$。需要 $6 \in C$。
- $6 = (6+4\delta) - 2(2+2\delta) + 4-2\delta$？计算：$(6+4\delta) - 2(2+2\delta) = 6+4\delta - 4 - 4\delta = 2$。所以 $2 \in C$。则 $6 = 3 \cdot 2 \in C$。
所以 $C$ 是理想。

**练习 3.3**：令 $A$ 是虚二次域的整数环 $R$ 的一个理想。证明存在 $A$ 的一组格基，其中一个元素是通常的正整数。

**解答**：
取 $A$ 中具有最小正实部的非零元 $\alpha$。考虑 $A$ 中所有元素的实部，它们是离散的，所以有最小正实部。设这个元素为 $\alpha$。则 $\alpha$ 的实部是正整数。取 $\alpha$ 和另一个元素 $\beta$ 使得 $(\alpha, \beta)$ 是格基。可以调整 $\beta$ 使得 $\beta$ 的实部在 $[0, \text{Re}(\alpha))$ 内。若 $\beta$ 的实部为 $0$，则 $\beta$ 是纯虚数，可以取 $\beta$ 为纯虚数。否则，$\beta$ 的实部是正整数。通过适当的整数组合，可以得到一个格基，其中一个元素是正整数。

### 第四节：理想的乘法

**练习 4.1**：令 $R = \mathbb{Z}[\sqrt{-6}]$。求积理想 $AB$ 的格基，其中 $A = (2, \delta)$，$B = (3, \delta)$。

**解答**：
$\delta = \sqrt{-6}$。

$AB$ 由 $2 \cdot 3 = 6$，$2 \cdot \delta = 2\delta$，$\delta \cdot 3 = 3\delta$，$\delta \cdot \delta = \delta^2 = -6$ 生成。

所以 $AB = (6, 2\delta, 3\delta, -6) = (6, 2\delta, 3\delta)$。

因为 $3\delta - 2\delta = \delta$，所以 $AB = (6, \delta)$。

格基：$(6, \delta)$。

**练习 4.2**：令 $R$ 是环 $\mathbb{Z}[\delta]$，其中 $\delta = \sqrt{-5}$，令 $A$ 表示由下面的元素生成的理想：
(a) $3+5\delta$，$2+2\delta$
(b) $4+\delta$，$1+2\delta$
确定给定的生成元是否形成 $A$ 的格基，并确定理想 $\bar{A} A$。

**解答**：
(a) $A = (3+5\delta, 2+2\delta)$。
计算范数：

- $N(3+5\delta) = 9 + 25 \cdot 5 = 9 + 125 = 134$。
- $N(2+2\delta) = 4 + 4 \cdot 5 = 4 + 20 = 24$。
检查是否形成格基：需要看它们的整数组合是否能生成整个理想。因为 $\gcd(134, 24) = 2$，所以 $N(A) = 2$。
$\bar{A} A = (2)$。

(b) $A = (4+\delta, 1+2\delta)$。
计算范数：

- $N(4+\delta) = 16 + 5 = 21$。
- $N(1+2\delta) = 1 + 4 \cdot 5 = 1 + 20 = 21$。
检查格基：行列式 $= \det \begin{bmatrix} 4 & 1 \\ 1 & 2 \end{bmatrix} = 8 - 1 = 7$。所以 $N(A) = 7$。
$\bar{A} A = (7)$。

**练习 4.3**：令 $R$ 是环 $\mathbb{Z}[\delta]$，其中 $\delta = \sqrt{-5}$，令 $A$ 与 $B$ 是形如 $A = (\alpha, \frac{1}{2}(\alpha + \alpha \delta))$，$B = (\beta, \frac{1}{2}(\beta + \beta \delta))$ 的理想。通过求生成元证明 $AB$ 是主理想。

**解答**：
$A = (\alpha, \frac{1}{2}\alpha(1+\delta))$，$B = (\beta, \frac{1}{2}\beta(1+\delta))$。

$AB$ 由 $\alpha \beta$，$\alpha \cdot \frac{1}{2}\beta(1+\delta)$，$\frac{1}{2}\alpha(1+\delta) \cdot \beta$，$\frac{1}{2}\alpha(1+\delta) \cdot \frac{1}{2}\beta(1+\delta)$ 生成。

即由 $\alpha \beta$，$\frac{1}{2}\alpha \beta(1+\delta)$，$\frac{1}{4}\alpha \beta(1+\delta)^2$ 生成。

因为 $(1+\delta)^2 = 1 + 2\delta + \delta^2 = 1 + 2\delta - 5 = -4 + 2\delta = 2(-2+\delta)$。

所以 $\frac{1}{4}\alpha \beta(1+\delta)^2 = \frac{1}{2}\alpha \beta(-2+\delta)$。

这些生成元都是 $\alpha \beta$ 的倍数。所以 $AB = (\alpha \beta)$ 是主理想。

### 第五节：分解理想

**练习 5.1**：令 $R = \mathbb{Z}[\sqrt{-5}]$。
(a) 确定 $11$ 是否为 $R$ 的一个既约元，$(11)$ 是否为 $R$ 的一个素理想。

**解答**：
$N(11) = 121$。若 $11 = \alpha \beta$，则 $N(\alpha) N(\beta) = 121$。可能的范数：$1, 11, 121$。范数 $11$ 的元素：$a^2 + 5b^2 = 11$。解：$b = 0$，$a^2 = 11$ 无解；$b = \pm 1$，$a^2 = 6$ 无解。所以范数 $11$ 的元素不存在。因此 $11$ 既约。

$(11)$ 是素理想当且仅当 $11$ 是素元。检查 $11$ 是否整除乘积：

$$11 \mid (1+\sqrt{-5})(1-\sqrt{-5}) = 6?$$

不，$6$ 不被 $11$ 整除。需要找 $11 \mid \alpha \beta$ 但 $11 \nmid \alpha$ 和 $11 \nmid \beta$。

实际上，$11$ 在 $R$ 中分裂还是持素？$d = -5 \equiv 3 \pmod 4$。$11$ 持素当且仅当 $-5$ 不是模 $11$ 的平方。$-5 \equiv 6 \pmod{11}$。平方模 $11$：$1, 4, 9, 5, 3$。$6$ 不在其中。所以 $11$ 持素。$(11)$ 是素理想。

**练习 5.2**：令 $\delta = \sqrt{-3}$ 且 $R = \mathbb{Z}[\delta]$。这不是虚二次数域 $\mathbb{Q}[\delta]$ 上的整数环。令 $A$ 是理想 $(2, 1+\delta)$。
(a) 证明 $A$ 是一个极大理想，并确定商环 $R/A$。
(b) 证明 $\bar{A} A$ 不是主理想，主引理对于这个环不成立。
(c) 证明 $A$ 包含主理想 $(2)$，但是 $A$ 不整除 $(2)$。

**解答**：
(a) $R = \mathbb{Z}[\sqrt{-3}]$，$A = (2, 1+\delta)$。
$R/A \cong \mathbb{Z}[\delta]/(2, 1+\delta) \cong \mathbb{F}_2[\delta]/(1+\delta) \cong \mathbb{F}_2$。所以 $A$ 极大。

(b) $\bar{A} = (2, 1-\delta)$。$\bar{A} A = (4, 2(1-\delta), 2(1+\delta), (1+\delta)(1-\delta)) = (4, 2-2\delta, 2+2\delta, 4) = (4, 2-2\delta, 2+2\delta)$。
因为 $2 = (2+2\delta) - 2\delta$？计算：$(2+2\delta) - (2-2\delta) = 4\delta$。所以 $4\delta \in \bar{A} A$。
$2 = (2+2\delta) - 2\delta$。需要 $2\delta \in \bar{A} A$。$2\delta = (2+2\delta) - 2$。所以 $2 \in \bar{A} A$ 当且仅当 $2\delta \in \bar{A} A$。
实际上，$\bar{A} A = (4, 2+2\delta, 2-2\delta)$。计算 $2$：$(2+2\delta) + (2-2\delta) = 4$。所以 $4 \in \bar{A} A$。$2$ 不在 $\bar{A} A$ 中，因为所有生成元的系数都是偶数。所以 $\bar{A} A$ 不是主理想。

(c) $A$ 包含 $(2)$，因为 $2 \in A$。但 $A$ 不整除 $(2)$，因为若 $(2) = A B$，则 $N((2)) = 4 = N(A) N(B)$。$N(A) = 2$，所以 $N(B) = 2$。但 $R$ 中没有范数为 $2$ 的理想。所以 $A$ 不整除 $(2)$。

### 第六节：素理想与素整数

**练习 6.1**：令 $d = -14$。对于下面每一个素数 $p = 2, 3, 5, 7, 11$ 和 $13$，确定 $p$ 在 $R$ 中是否分裂或分叉。如果是的话，求 $(p)$ 的素理想因子的格基。

**解答**：
$d = -14 \equiv 2 \pmod 4$，$R = \mathbb{Z}[\sqrt{-14}]$。

- $p = 2$：$2 \mid d$，分叉。$(2) = (2, \sqrt{-14})^2$。
- $p = 3$：$-14 \equiv 1 \pmod 3$，$1$ 是平方，分裂。$(3) = (3, 1+\sqrt{-14})(3, 1-\sqrt{-14})$。
- $p = 5$：$-14 \equiv 1 \pmod 5$，$1$ 是平方，分裂。
- $p = 7$：$7 \mid d$，分叉。
- $p = 11$：$-14 \equiv -3 \equiv 8 \pmod{11}$。平方模 $11$：$1, 4, 9, 5, 3$。$8$ 不是平方，持素。
- $p = 13$：$-14 \equiv -1 \equiv 12 \pmod{13}$。平方模 $13$：$1, 4, 9, 3, 12, 10$。$12$ 是平方，分裂。

**练习 6.2**：假设 $d$ 是一个负整数，且 $d \equiv 1 \pmod 4$。分析 $2$ 在模 $8$ 同余的条件下是否是持素的。

**解答**：
$d \equiv 1 \pmod 4$，$R = \mathbb{Z}[\frac{1+\sqrt{d}}{2}]$。

$2$ 的行为由 $x^2 - x + h$ 在 $\mathbb{F}_2$ 上的既约性决定，其中 $h = (1-d)/4$。

- 若 $d \equiv 1 \pmod 8$，则 $h = (1-d)/4 \equiv 0 \pmod 2$。$x^2 - x + 0 = x(x-1)$ 在 $\mathbb{F}_2$ 上分裂。所以 $2$ 分裂。
- 若 $d \equiv 5 \pmod 8$，则 $h = (1-d)/4 \equiv 1 \pmod 2$。$x^2 - x + 1$ 在 $\mathbb{F}_2$ 上既约（因为 $0^2 - 0 + 1 = 1 \neq 0$，$1^2 - 1 + 1 = 1 \neq 0$）。所以 $2$ 持素。

**练习 6.3**：令 $R$ 是虚二次域的整数环。
(a) 假设一个整素数 $p$ 在 $R$ 上是持素的。证明 $R/(p)$ 是具有 $p^2$ 个元素的域。
(b) 证明如果 $p$ 分裂但不分叉，则 $R/(p)$ 同构于积环 $\mathbb{F}_p \times \mathbb{F}_p$。

**解答**：
(a) 若 $p$ 持素，则 $(p)$ 是素理想。$R/(p)$ 是整环。因为 $R$ 是二维 $\mathbb{Z}$-模，$R/(p)$ 是 $p^2$ 个元素的有限整环。有限整环是域。所以 $R/(p)$ 是 $p^2$ 个元素的域。

(b) 若 $p$ 分裂，$(p) = \mathcal{P} \bar{\mathcal{P}}$，$\mathcal{P} \neq \bar{\mathcal{P}}$。由中国剩余定理，$R/(p) \cong R/\mathcal{P} \times R/\bar{\mathcal{P}}$。因为 $\mathcal{P}$ 和 $\bar{\mathcal{P}}$ 是极大理想，$R/\mathcal{P} \cong \mathbb{F}_p$，$R/\bar{\mathcal{P}} \cong \mathbb{F}_p$。所以 $R/(p) \cong \mathbb{F}_p \times \mathbb{F}_p$。

### 第七节：理想类

**练习 7.1**：令 $R = \mathbb{Z}[\sqrt{-5}]$，且令 $B = (3, 1+\delta)$。求主理想 $B^2$ 的生成元。

**解答**：
$B = (3, 1+\delta)$。$B^2 = (9, 3(1+\delta), (1+\delta)^2)$。

计算：

- $9$。
- $3(1+\delta) = 3+3\delta$。
- $(1+\delta)^2 = 1 + 2\delta + \delta^2 = 1 + 2\delta - 5 = -4 + 2\delta$。

$B^2$ 由 $9$，$3+3\delta$，$-4+2\delta$ 生成。

因为 $3+3\delta - (-4+2\delta) = 7+\delta$。所以 $B^2 = (9, 3+3\delta, -4+2\delta)$。

可以化简：$9 - 2(-4+2\delta) = 9 + 8 - 4\delta = 17 - 4\delta$。继续化简。

实际上，$B^2 = (1+\delta)$？验证：$N(B) = 3$，$N(B^2) = 9$。$(1+\delta)$ 的范数是 $6$，不是 $9$。所以不对。

$B^2$ 是主理想，生成元是 $3$？$B^2 = (3)$？检查：$B \bar{B} = (3)$。$B^2$ 和 $B \bar{B}$ 不同。$B^2$ 的范数是 $9$。$(3)$ 的范数是 $9$。所以 $B^2 = (3)$？

验证：$B^2 = (9, 3+3\delta, -4+2\delta)$。$3 = (3+3\delta) - 3\delta$。需要 $3\delta \in B^2$。$3\delta = (3+3\delta) - 3$。所以 $3 \in B^2$。因此 $B^2 = (3)$。

**练习 7.2**：证明虚二次域上的整数环上的两个非零理想 $A$ 和 $A'$ 相似的充分必要条件是存在非零理想 $C$ 使得 $AC$ 和 $A'C$ 是主理想。

**解答**：
**（⇒）** 若 $A \sim A'$，则 $A' = \lambda A$ 对某个 $\lambda \in K$。取 $C = \bar{A}$。则 $AC = A \bar{A} = (n)$ 是主理想。$A'C = \lambda A \bar{A} = (\lambda n)$ 是主理想。

**（⇐）** 若存在 $C$ 使得 $AC = (\alpha)$，$A'C = (\beta)$ 是主理想。则 $A' = (\beta) C^{-1}$，$A = (\alpha) C^{-1}$。所以 $A' = (\beta / \alpha) A$。因此 $A \sim A'$。

**练习 7.3**：令 $d = -26$。对于下列整数 $n$，确定 $n$ 是否是 $R$ 中元素 $\alpha$ 的范数。如果是，求 $\alpha$：$n = 75, 250, 375, 5^6$。

**解答**：
$R = \mathbb{Z}[\sqrt{-26}]$，$N(a+b\sqrt{-26}) = a^2 + 26b^2$。

- $n = 75$：$a^2 + 26b^2 = 75$。$b = 0$：$a^2 = 75$ 无解。$b = \pm 1$：$a^2 = 49$，$a = \pm 7$。所以 $\alpha = 7 + \sqrt{-26}$。
- $n = 250$：$a^2 + 26b^2 = 250$。$b = 0$：$a^2 = 250$ 无解。$b = \pm 1$：$a^2 = 224$ 无解。$b = \pm 2$：$a^2 = 250 - 104 = 146$ 无解。$b = \pm 3$：$a^2 = 250 - 234 = 16$，$a = \pm 4$。所以 $\alpha = 4 + 3\sqrt{-26}$。
- $n = 375$：$a^2 + 26b^2 = 375$。$b = \pm 1$：$a^2 = 349$ 无解。$b = \pm 2$：$a^2 = 271$ 无解。$b = \pm 3$：$a^2 = 141$ 无解。$b = \pm 4$：$a^2 = 375 - 416 = -41$ 无解。所以 $375$ 不是范数。
- $n = 5^6 = 15625$：$a^2 + 26b^2 = 15625$。$b = 0$：$a = \pm 125$。所以 $\alpha = 125$。

### 第八节：计算类群

**练习 8.1**：参考例 13.8.6，由于 $\langle P \rangle = \langle S \rangle^3$ 和 $\langle Q \rangle = \langle S \rangle^2$，因此引理 13.8.7 预言存在范数为 $2 \cdot 5^3$ 和 $3^2 \cdot 5^2$ 的元素。求这些元素。

**解答**：
$d = -26$。$P = (2, \sqrt{-26})$，$Q = (3, 1+\sqrt{-26})$，$S = (5, 1+\sqrt{-26})$。

$\langle P \rangle = \langle S \rangle^3$ 意味着 $P \sim S^3$。所以 $P S^{-3}$ 是主理想。范数为 $2 \cdot 5^3 = 250$ 的元素对应 $P S^3$ 或类似。

从练习 7.3，$250$ 是 $4 + 3\sqrt{-26}$ 的范数。

$\langle Q \rangle = \langle S \rangle^2$ 意味着 $Q \sim S^2$。范数为 $3^2 \cdot 5^2 = 225$ 的元素。$N(a+b\sqrt{-26}) = a^2 + 26b^2 = 225$。$b = 0$：$a = \pm 15$。所以 $\alpha = 15$。

**练习 8.2**：参考例 13.8.8，解释为什么 $N(4+\delta)$ 和 $N(14+\delta)$ 不能导致矛盾的结论。

**解答**：
$d = -74$。$N(4+\delta) = 90 = 2 \cdot 3^2 \cdot 5$。$N(14+\delta) = 270 = 2 \cdot 3^3 \cdot 5$。

这些范数给出关系：

- $N(4+\delta)$ 给出 $\langle P \rangle \langle Q \rangle^2 \langle S \rangle = 1$ 或类似。
- $N(14+\delta)$ 给出 $\langle P \rangle \langle Q \rangle^3 \langle S \rangle = 1$ 或类似。

两个关系相除得到 $\langle Q \rangle = 1$，即 $Q$ 是主理想。但 $Q$ 不是主理想，所以需要小心选择哪个素因子。实际上，两个关系可能给出 $\langle Q \rangle = 1$ 或 $\langle Q \rangle = \langle \bar{Q} \rangle$，后者总是成立。所以不矛盾。

### 第九节：实二次域

**练习 9.1**：证明 $1+\sqrt{2}$ 在 $\mathbb{Z}[\sqrt{2}]$ 的单位的群中是无限阶的元素。

**解答**：
$N(1+\sqrt{2}) = 1 - 2 = -1$，所以是单位。

假设 $(1+\sqrt{2})^n = 1$ 对某个 $n > 0$。则 $1+\sqrt{2}$ 是单位根。但 $1+\sqrt{2} \approx 2.414 > 1$，所以 $(1+\sqrt{2})^n > 1$ 对 $n > 0$。矛盾。所以是无限阶。

**练习 9.2**：确定方程 $x^2 - d y^2 = 1$ 的解，其中 $d$ 是一个正整数。

**解答**：
这是 Pell 方程。解由基本解 $(x_1, y_1)$ 生成：

$$x_n + y_n \sqrt{d} = (x_1 + y_1 \sqrt{d})^n, \quad n \in \mathbb{Z}.$$

基本解通过 $\sqrt{d}$ 的连分数展开计算。

**练习 9.3**：
(a) 证明度量函数 $\sigma(\alpha) = |N(\alpha)|$ 把环 $\mathbb{Z}[\sqrt{2}]$ 变成欧几里得整环，且这个环有唯一分解。

**解答**：
$\sigma(a+b\sqrt{2}) = |a^2 - 2b^2|$。

带余除法：给定 $\alpha, \beta \in \mathbb{Z}[\sqrt{2}]$，$\beta \neq 0$。考虑 $\alpha / \beta \in \mathbb{Q}(\sqrt{2})$。取 $q \in \mathbb{Z}[\sqrt{2}]$ 使得 $|N(\alpha/\beta - q)| < 1$。则 $\alpha = \beta q + r$，$|N(r)| < |N(\beta)|$。

所以 $\mathbb{Z}[\sqrt{2}]$ 是欧几里得整环，因此是唯一分解整环。

(b) 在图 13.9.6 嵌入的描述中，做一个简图展示 $R = \mathbb{Z}[\sqrt{2}]$ 的主理想 $(\sqrt{2})$。

**解答**：
$(\sqrt{2})$ 由 $\sqrt{2}$ 生成。在 $(u, v)$ 平面上，$\sqrt{2}$ 对应 $(\sqrt{2}, -\sqrt{2})$。理想 $(\sqrt{2})$ 是格，由 $(\sqrt{2}, -\sqrt{2})$ 和 $(\sqrt{2} \cdot \sqrt{2}, -\sqrt{2} \cdot \sqrt{2}) = (2, 2)$ 生成。

**练习 9.4**：令 $R$ 是实二次数域的整数环。$R$ 的单位群的可能结构是什么？

**解答**：
单位群 $U \cong \{\pm 1\} \times \mathbb{Z}$。即由一个有限群 $\{\pm 1\}$ 和一个无限循环群生成。

**练习 9.5**：令 $R$ 是实二次数域的整数环，令 $U_0$ 表示嵌入 (13.9.2) 中位于第一象限的 $R$ 的单位的集合。
(a) 证明 $U_0$ 是单位群的一个无限循环子群。
(b) 当 $d = 3$ 和 $d = 5$ 时，求 $U_0$ 的一个生成元。

**解答**：
(a) 第一象限的单位对应 $u > 0$，$v > 0$。这些单位由基本单位 $\varepsilon > 1$ 生成。$\varepsilon^n$ 对应 $(u_n, v_n)$，都在第一象限。所以 $U_0 = \langle \varepsilon \rangle$ 是无限循环群。

(b) $d = 3$：基本单位 $2+\sqrt{3}$。$d = 5$：基本单位 $9+4\sqrt{5}$。

### 第十节：关于格

**练习 10.1**：令 $M$ 是 $\mathbb{R}^2$ 上的整数格，令 $L$ 为以 $((2,3)^t, (3,6)^t)$ 为基的格。确定指标 $[M : L]$。

**解答**：
$M = \mathbb{Z}^2$，$\Delta(M) = 1$。
$L$ 的格基是 $(2,3)$，$(3,6)$。

$$\Delta(L) = |\det \begin{bmatrix} 2 & 3 \\ 3 & 6 \end{bmatrix}| = |12 - 9| = 3.$$

所以 $[M : L] = \Delta(L) / \Delta(M) = 3$。

**练习 10.2**：令 $L \subset M$ 是分别以 $B$ 和 $C$ 为基的格，令 $A$ 是使得 $BA = C$ 的整数矩阵。证明 $[M : L] = |\det A|$。

**解答**：
$C = BA$。$\Delta(M) = |\det C| = |\det B| \cdot |\det A| = \Delta(L) \cdot |\det A|$。
所以 $[M : L] = \Delta(L) / \Delta(M) = 1 / |\det A|$？不，$[M : L] = \Delta(L) / \Delta(M)$，其中 $L \subset M$。这里 $L$ 以 $B$ 为基，$M$ 以 $C$ 为基。$C = BA$，所以 $\Delta(M) = |\det C| = |\det B| \cdot |\det A| = \Delta(L) \cdot |\det A|$。
因此 $[M : L] = \Delta(L) / \Delta(M) = 1 / |\det A|$。但指标应该是整数，所以 $|\det A| = 1 / [M : L]$。实际上，$[M : L] = |\det A|$。

验证：$M = \mathbb{Z}^2$，$L$ 以 $B$ 为基。$C = I$。$B A = I$，所以 $A = B^{-1}$。$[M : L] = \Delta(L) / \Delta(M) = |\det B| / 1 = |\det B|$。而 $|\det A| = 1 / |\det B|$。所以 $[M : L] = 1 / |\det A|$。矛盾。

正确的公式：若 $L \subset M$，$L$ 以 $B$ 为基，$M$ 以 $C$ 为基，则 $B = C A$ 对某个整数矩阵 $A$。则 $\Delta(L) = |\det B| = |\det C| \cdot |\det A| = \Delta(M) \cdot |\det A|$。所以 $[M : L] = \Delta(L) / \Delta(M) = |\det A|$。

在题目中，$BA = C$，所以 $B = C A^{-1}$。则 $\Delta(L) = |\det B| = |\det C| \cdot |\det A^{-1}| = \Delta(M) / |\det A|$。所以 $[M : L] = \Delta(L) / \Delta(M) = 1 / |\det A|$。但 $A$ 是整数矩阵，$|\det A|$ 必须是 $1$ 的因子，所以 $|\det A| = 1$？这不对。

实际上，题目中的 $A$ 是使得 $BA = C$ 的矩阵。若 $B$ 和 $C$ 都是格基，则 $A$ 是可逆整数矩阵，$|\det A| = 1$。所以 $[M : L] = 1$。这显然不对。

正确的理解：$L$ 以 $B$ 为基，$M$ 以 $C$ 为基。$L \subset M$ 意味着 $B$ 的列是 $C$ 的列的整数组合，即 $B = C A$ 对某个整数矩阵 $A$。则 $\Delta(L) = |\det B| = |\det C| \cdot |\det A| = \Delta(M) \cdot |\det A|$。所以 $[M : L] = \Delta(L) / \Delta(M) = |\det A|$。

题目中 $BA = C$，所以 $B = C A^{-1}$。则 $\Delta(L) = \Delta(M) / |\det A|$。所以 $[M : L] = 1 / |\det A|$。但 $A$ 是整数矩阵，$A^{-1}$ 不一定是整数矩阵。所以 $B = C A^{-1}$ 不一定成立。正确的应该是 $B = C A$。所以题目可能有误。我们假设 $B = C A$，则 $[M : L] = |\det A|$。
