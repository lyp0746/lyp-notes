## 第十二章 第一节：整数的因子分解

### 一、带余除法

**定理 12.1.1**：设 $a, b \in \mathbb{Z}$，$a > 0$。则存在唯一 $q, r \in \mathbb{Z}$ 使得

$$b = a q + r, \quad 0 \le r < a.$$

### 二、整数环的性质

**定理 12.1.2**：

(a) $\mathbb{Z}$ 的每个理想是主理想。

(b) 最大公约数 $d = \gcd(a, b)$ 满足：

- $d$ 整除 $a$ 和 $b$。
- 若 $e$ 整除 $a$ 和 $b$，则 $e$ 整除 $d$。
- 存在 $r, s$ 使得 $d = ra + sb$。

(c) 若素数 $p$ 整除 $ab$，则 $p$ 整除 $a$ 或 $b$。

(d) **算术基本定理**：每个正整数 $a \neq 1$ 可以唯一分解为素数的乘积。

## 第十二章 第二节：唯一分解整环

### 一、基本概念

**定义 12.2.1**：设 $R$ 是整环。

- **单位**：有乘法逆元的元素。
- **整除**：$a \mid b$ 如果 $b = aq$ 对某个 $q \in R$。
- **真因子**：$a$ 是 $b$ 的真因子，如果 $b = aq$ 且 $a, q$ 都不是单位。
- **相伴**：$a$ 和 $b$ 相伴，如果 $b = ua$，$u$ 是单位。
- **既约元**：不是单位且没有真因子。
- **素元**：不是单位，且若 $p \mid ab$，则 $p \mid a$ 或 $p \mid b$。

**主理想语言**：

- $a$ 整除 $b \iff (b) \subset (a)$。
- $a$ 是 $b$ 的真因子 $\iff (b) < (a) < (1)$。
- $a$ 和 $b$ 相伴 $\iff (a) = (b)$。
- $a$ 既约 $\iff (a) < (1)$ 且没有主理想 $(c)$ 使得 $(a) < (c) < (1)$。

### 二、欧几里得整环

**定义 12.2.4**：整环 $R$ 是**欧几里得整环**，如果存在尺度函数 $\sigma: R \setminus \{0\} \to \mathbb{N}$，使得对任意 $a, b \neq 0$，存在 $q, r$ 使

$$b = a q + r, \quad r = 0 \text{ 或 } \sigma(r) < \sigma(a).$$

**例子**：

- $\mathbb{Z}$：$\sigma(n) = |n|$。
- $F[x]$：$\sigma(f) = \deg f$。
- $\mathbb{Z}[i]$：$\sigma(a) = |a|^2$。

**命题 12.2.5**：欧几里得整环是主理想整环。

**证明**：取理想 $I$ 中 $\sigma$ 最小的非零元 $a$，证明 $I = (a)$。

### 三、主理想整环

**定义**：每个理想都是主理想的整环。

**命题 12.2.8**：主理想整环中最大公约数存在，且可表示为线性组合。

**推论 12.2.9**：
(a) 互素元有线性组合 $1 = ra + sb$。
(b) 既约元是素元。
(c) 极大理想是既约元生成的主理想。

### 四、唯一分解整环

**定义 12.2.12**：整环 $R$ 是**唯一分解整环**，如果：

- 分解终止：没有无限严格升链 $(a_1) < (a_2) < \cdots$。
- 分解唯一：既约分解在相伴意义下唯一。

**命题 12.2.13**：分解终止等价于没有无限严格升链。

**命题 12.2.14**：
(a) 若分解终止，则 $R$ 是唯一分解整环当且仅当每个既约元是素元。
(b) 主理想整环是唯一分解整环。
(c) $\mathbb{Z}$、$\mathbb{Z}[i]$、$F[x]$ 是唯一分解整环。

**例子**：$\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环：

$$6 = 2 \cdot 3 = (1+\sqrt{-5})(1-\sqrt{-5}).$$

## 第十二章 第三节：高斯引理

### 一、本原多项式

**定义**：整系数多项式是本原的，如果系数的最大公约数为 1。

**引理 12.3.3**：本原多项式等价于不能被任何素数整除。

### 二、高斯引理

**命题 12.3.4**：
(a) 整数是 $\mathbb{Z}[x]$ 的素元当且仅当它是素数。
(b) 本原多项式的积是本原的。

### 三、$\mathbb{Z}[x]$ 的因子分解

**定理 12.3.6**：
(a) 本原多项式在 $\mathbb{Q}[x]$ 中整除 $g$ 蕴含在 $\mathbb{Z}[x]$ 中整除 $g$。
(b) 两个整多项式在 $\mathbb{Q}[x]$ 中有非常数公因子蕴含在 $\mathbb{Z}[x]$ 中有非常数公因子。

**定理 12.3.8**：$\mathbb{Z}[x]$ 是唯一分解整环。

**例子**：

$$6x^3 + 9x^2 + 9x + 3 = 3(2x+1)(x^2+x+1).$$

## 第十二章 第四节：整多项式的分解

### 一、有理根

**引理 12.4.2**：

- 若 $b_1 x + b_0$ 整除 $f$，则 $b_1 \mid a_n$，$b_0 \mid a_0$。
- 有理根 $\alpha = -b_0/b_1$。

### 二、模 $p$ 约化

**命题 12.4.3**：若 $f$ 模 $p$ 的剩余不可约，则 $f$ 在 $\mathbb{Q}[x]$ 上不可约。

### 三、艾森斯坦准则

**命题 12.4.6**：若素数 $p$ 满足：

- $p \nmid a_n$。
- $p \mid a_{n-1}, \dots, a_0$。
- $p^2 \nmid a_0$。
则 $f$ 在 $\mathbb{Q}[x]$ 上不可约。

**例子**：$x^4 + 25x^2 + 30x + 20$ 不可约。

### 四、分圆多项式

**定理 12.4.9**：$\Phi_p(x) = x^{p-1} + \dots + x + 1$ 在 $\mathbb{Q}$ 上不可约。

## 第十二章 第五节：高斯素数

### 一、高斯整数

$\mathbb{Z}[i] = \{a + bi \mid a, b \in \mathbb{Z}\}$。

**范数**：$N(a+bi) = a^2 + b^2$。

### 二、高斯素数

**定理 12.5.2**：
(a) 高斯素数 $\pi$ 的范数 $\pi \bar{\pi}$ 是素数或素数的平方。
(b) 整素数 $p$ 要么是高斯素数，要么是两个共轭高斯素数的积。
(c) $p \equiv 3 \pmod 4$ 时是高斯素数。
(d) $p = 2$ 或 $p \equiv 1 \pmod 4$ 时是两个共轭高斯素数的积。

**例子**：

- $5 = (2+i)(2-i)$。
- $3$ 是高斯素数。

### 三、平方和

**推论**：整素数 $p$ 可表示为两个平方和当且仅当 $p = 2$ 或 $p \equiv 1 \pmod 4$。

## 1. 唯一分解整环与主理想整环有什么关系？为什么主理想整环是唯一分解整环？

### 定义

- **唯一分解整环 (UFD)**：整环，其中每个非零非单位元素可以唯一分解为既约元的乘积（在相伴和顺序意义下）。
- **主理想整环 (PID)**：整环，其中每个理想都是主理想。

### 关系

**定理**：主理想整环是唯一分解整环。

**证明**：

1. **分解终止**：PID 中不存在无限严格升链 $(a_1) < (a_2) < \cdots$。因为若存在这样的链，其并是理想，由 PID 是主理想 $(a)$，则 $a$ 属于某个 $(a_n)$，链终止。
2. **既约元是素元**：在 PID 中，既约元生成极大理想，因此是素元。
3. **唯一性**：由分解终止和既约元是素元，得到唯一分解。

### 逆不成立

UFD 不一定是 PID。例如，$\mathbb{Z}[x]$ 是 UFD，但不是 PID。理想 $(2, x)$ 不是主理想。

### 总结

主理想整环是唯一分解整环。证明用分解终止和既约元是素元。逆不成立，$\mathbb{Z}[x]$ 是 UFD 但不是 PID。

## 2. 欧几里得整环与主理想整环有什么关系？为什么欧几里得整环是主理想整环？

### 定义

- **欧几里得整环 (ED)**：整环 $R$，存在尺度函数 $\sigma: R \setminus \{0\} \to \mathbb{N}$，使得对任意 $a, b \neq 0$，存在 $q, r$ 使 $b = aq + r, \quad r = 0 \text{ 或 } \sigma(r) < \sigma(a).$
- **主理想整环 (PID)**：每个理想都是主理想的整环。

### 关系

**定理**：欧几里得整环是主理想整环。

**证明**：
设 $I$ 是 ED $R$ 的理想。若 $I = (0)$，平凡。否则取 $I$ 中 $\sigma$ 最小的非零元 $a$。对任意 $b \in I$，做带余除法：

$$b = aq + r, \quad \sigma(r) < \sigma(a).$$

因为 $r = b - aq \in I$，由 $a$ 的最小性，$r = 0$。所以 $b \in (a)$，即 $I = (a)$。

### 例子

- $\mathbb{Z}$：$\sigma(n) = |n|$，是 ED，因此是 PID。
- $F[x]$：$\sigma(f) = \deg f$，是 ED，因此是 PID。
- $\mathbb{Z}[i]$：$\sigma(a) = |a|^2$，是 ED，因此是 PID。

### 总结

欧几里得整环是主理想整环。证明用带余除法和 $\sigma$ 的最小性。ED 是 PID 的特例。

## 3. 高斯引理如何工作？为什么 $\mathbb{Z}[x]$ 是唯一分解整环？

### 高斯引理

**定义**：整系数多项式是本原的，如果系数的最大公约数为 1。

**高斯引理**：本原多项式的积是本原的。

**证明**：用模 $p$ 约化。若 $f, g$ 本原，则对任意素数 $p$，$\overline{f}, \overline{g} \neq 0$。因为 $\mathbb{F}_p[x]$ 是整环，$\overline{f} \overline{g} \neq 0$。所以 $fg$ 本原。

### $\mathbb{Z}[x]$ 是唯一分解整环

**定理 12.3.8**：$\mathbb{Z}[x]$ 是唯一分解整环。

**证明**：

1. **分解终止**：$\mathbb{Z}[x]$ 中不存在无限严格升链。
2. **既约元是素元**：
  - 素整数是素元。
  - 本原既约多项式在 $\mathbb{Q}[x]$ 中既约，因此是素元。
3. **唯一性**：由高斯引理，$\mathbb{Z}[x]$ 中的分解与 $\mathbb{Q}[x]$ 中的分解一致。

**推论**：$\mathbb{Z}[x_1, \dots, x_n]$ 是唯一分解整环。

### 总结

高斯引理说明本原多项式的积本原。$\mathbb{Z}[x]$ 是唯一分解整环，因为分解终止且既约元是素元。

## 4. 艾森斯坦准则如何判断不可约性？它的证明思路是什么？

### 艾森斯坦准则

**命题 12.4.6**：设 $f(x) = a_n x^n + \cdots + a_0$ 是整多项式。若素数 $p$ 满足：

- $p \nmid a_n$。
- $p \mid a_{n-1}, \dots, a_0$。
- $p^2 \nmid a_0$。
则 $f$ 在 $\mathbb{Q}[x]$ 上不可约。

### 证明思路

假设 $f = gh$ 在 $\mathbb{Q}[x]$ 上可约。由高斯引理，可假设 $g, h \in \mathbb{Z}[x]$。

模 $p$ 约化：

$$\overline{f} = \overline{g} \overline{h}.$$

因为 $p \mid a_{n-1}, \dots, a_0$，$\overline{f} = \overline{a}_n x^n$。

因为 $\mathbb{F}_p[x]$ 是整环，$\overline{g}$ 和 $\overline{h}$ 必须是单项式。所以 $g$ 和 $h$ 的所有非首项系数都被 $p$ 整除。

特别地，$p \mid b_0$ 和 $p \mid c_0$，其中 $b_0, c_0$ 是 $g, h$ 的常数项。所以 $p^2 \mid b_0 c_0 = a_0$，与 $p^2 \nmid a_0$ 矛盾。

所以 $f$ 不可约。

### 例子

$x^4 + 25x^2 + 30x + 20$：取 $p = 5$，$5 \nmid 1$，$5 \mid 25, 30, 20$，$25 \nmid 20$。所以不可约。

### 总结

艾森斯坦准则用模 $p$ 约化证明不可约性。条件是 $p$ 整除所有非首项系数，但 $p^2$ 不整除常数项。

## 5. 高斯素数如何分类？为什么 $p \equiv 1 \pmod 4$ 可表示为平方和？

### 高斯素数

**定义**：高斯整数 $\mathbb{Z}[i]$ 中的素元。

### 分类

**定理 12.5.2**：

- $p = 2$：$2 = (1+i)(1-i)$，不是高斯素数。
- $p \equiv 1 \pmod 4$：$p = \pi \bar{\pi}$，是两个共轭高斯素数的积。
- $p \equiv 3 \pmod 4$：$p$ 是高斯素数。

### 为什么 $p \equiv 1 \pmod 4$ 可表示为平方和？

**费马平方和定理**：奇素数 $p$ 可表示为两个平方和当且仅当 $p \equiv 1 \pmod 4$。

**证明**：

- 若 $p = a^2 + b^2$，则 $p = (a+bi)(a-bi)$。
- 反之，若 $p \equiv 1 \pmod 4$，则 $-1$ 是模 $p$ 的平方。设 $x^2 \equiv -1 \pmod p$。则 $p \mid x^2 + 1 = (x+i)(x-i)$。
- 因为 $p$ 不是高斯素数（否则 $p \mid x+i$ 或 $p \mid x-i$，不可能），所以 $p$ 分解为两个共轭高斯素数的积。
- 取范数得到 $p = a^2 + b^2$。

### 例子

- $5 = 1^2 + 2^2 = (1+2i)(1-2i)$。
- $13 = 2^2 + 3^2 = (2+3i)(2-3i)$。
- $3$ 是高斯素数，不能表示为平方和。

### 总结

高斯素数分类：$p = 2$ 分解，$p \equiv 1 \pmod 4$ 分解为共轭高斯素数，$p \equiv 3 \pmod 4$ 是高斯素数。$p \equiv 1 \pmod 4$ 可表示为平方和。

在第十一章中，我们研究了环、理想、商环、分式、极大理想、代数几何。现在，我们开始研究环中元素的**因子分解**。因子分解是数论和代数的基础：整数有唯一分解定理，多项式也有唯一分解。本节先复习整数环 $\mathbb{Z}$ 的因子分解性质，并把这些性质用环论的语言重新表述，为后续推广到一般整环做准备。

## 一、带余除法

**定理 12.1.1（带余除法）**：设 $a, b \in \mathbb{Z}$，且 $a > 0$。则存在唯一整数 $q, r$ 使得

$$b = a q + r, \quad 0 \le r < a.$$

**术语**：

- $q$ 是商。
- $r$ 是余数。

**例子**：

- $b = 17$，$a = 5$：$17 = 5 \cdot 3 + 2$，$q = 3$，$r = 2$。
- $b = -17$，$a = 5$：$-17 = 5 \cdot (-4) + 3$，$q = -4$，$r = 3$。

**意义**：带余除法是整数因子分解的基础。它保证我们可以用欧几里得算法求最大公约数。

## 二、整数环的理想

**定理 12.1.2(a)**：整数环 $\mathbb{Z}$ 的每个理想是主理想。

**证明**：
设 $I$ 是 $\mathbb{Z}$ 的理想。若 $I = (0)$，平凡。否则，取 $I$ 中最小正整数 $a$。对任意 $b \in I$，做带余除法：

$$b = a q + r, \quad 0 \le r < a.$$

因为 $r = b - a q \in I$，由 $a$ 的最小性，$r = 0$。所以 $b = a q \in (a)$。因此 $I = (a)$。

**推论**：$\mathbb{Z}$ 是主理想整环。

**例子**：

- $(2) = \{0, \pm 2, \pm 4, \dots\}$。
- $(3) = \{0, \pm 3, \pm 6, \dots\}$。
- $(0) = \{0\}$。
- $(1) = \mathbb{Z}$。

## 三、最大公约数

**定理 12.1.2(b)**：设 $a, b$ 是不全为零的整数。它们的**最大公约数** $d = \gcd(a, b)$ 是满足以下性质的正整数：

(i) $d$ 整除 $a$ 和 $b$。

(ii) 若整数 $e$ 整除 $a$ 和 $b$，则 $e$ 整除 $d$。

(iii) 存在整数 $r, s$ 使得

$$d = r a + s b.$$

(iv) $\mathbb{Z} d = \mathbb{Z} a + \mathbb{Z} b$。

**证明**：
考虑由 $a, b$ 生成的理想 $(a, b) = \mathbb{Z} a + \mathbb{Z} b$。因为 $\mathbb{Z}$ 是主理想整环，存在 $d$ 使得 $(a, b) = (d)$。这个 $d$ 就是最大公约数。

**例子**：

- $\gcd(12, 18) = 6$，$6 = (-1) \cdot 12 + 1 \cdot 18$。
- $\gcd(314, 136) = 2$，$2 = 13 \cdot 314 - 30 \cdot 136$。

**欧几里得算法**：反复做带余除法，直到余数为零。最后一个非零余数就是最大公约数。

## 四、互素

**定义**：两个非零整数 $a, b$ 称为**互素的**，如果 $\gcd(a, b) = 1$。

**推论 12.1.3**：$a, b$ 互素当且仅当存在整数 $r, s$ 使得

$$r a + s b = 1.$$

**证明**：由最大公约数的线性组合表示。

**例子**：

- $\gcd(3, 5) = 1$，$1 = 2 \cdot 3 - 1 \cdot 5$。
- $\gcd(7, 11) = 1$。

**推论**：若 $a$ 和 $b$ 互素，且 $a \mid b c$，则 $a \mid c$。

**证明**：由 $r a + s b = 1$，乘以 $c$ 得 $r a c + s b c = c$。因为 $a \mid b c$，所以 $a \mid c$。

## 五、素数与唯一分解

**定义**：整数 $p > 1$ 是**素数**，如果它的正因子只有 $1$ 和 $p$。

**定理 12.1.2(c)**：若素数 $p$ 整除 $a b$，则 $p$ 整除 $a$ 或 $p$ 整除 $b$。

**证明**：若 $p$ 不整除 $a$，则 $\gcd(a, p) = 1$。存在 $r, s$ 使得 $r a + s p = 1$。乘以 $b$ 得 $r a b + s p b = b$。因为 $p \mid a b$，所以 $p \mid b$。

**定理 12.1.2(d)（算术基本定理）**：每个正整数 $a \neq 1$ 可以写成

$$a = p_1 p_2 \cdots p_k,$$

其中 $p_i$ 是素数。除了素因子的次序外，这个分解是唯一的。

**例子**：

- $12 = 2^2 \cdot 3$。
- $360 = 2^3 \cdot 3^2 \cdot 5$。

**意义**：算术基本定理是整数因子分解的核心。它说明 $\mathbb{Z}$ 是唯一分解整环。

## 六、小结

- 带余除法是整数因子分解的基础。
- $\mathbb{Z}$ 的每个理想是主理想。
- 最大公约数可以表示为线性组合。
- 互素元有线性组合等于 1。
- 素数整除乘积蕴含整除因子。
- 算术基本定理：唯一分解为素数。

这些性质将推广到一般整环，定义唯一分解整环、欧几里得整环、主理想整环。

## 1. 带余除法为什么重要？它如何用于欧几里得算法？

### 带余除法

**定理 12.1.1**：设 $a, b \in \mathbb{Z}$，$a > 0$。则存在唯一 $q, r$ 使得

$$b = a q + r, \quad 0 \le r < a.$$

### 为什么重要？

1. **基础工具**：带余除法是整数因子分解的基础。
2. **欧几里得算法**：用于求最大公约数。
3. **理想结构**：证明 $\mathbb{Z}$ 的每个理想是主理想。
4. **推广**：推广到多项式环、欧几里得整环。

### 欧几里得算法

**步骤**：

1. 给定 $a, b$（$a > b > 0$）。
2. 反复做带余除法： $a = q_1 b + r_1,$ $b = q_2 r_1 + r_2,$ $r_1 = q_3 r_2 + r_3,$ $\vdots$
3. 直到余数为 0。最后一个非零余数就是 $\gcd(a, b)$。

**例子**：$\gcd(314, 136)$：

$$314 = 2 \cdot 136 + 42,$$

$$136 = 3 \cdot 42 + 10,$$

$$42 = 4 \cdot 10 + 2,$$

$$10 = 5 \cdot 2 + 0.$$

所以 $\gcd(314, 136) = 2$。

### 总结

带余除法是欧几里得算法的基础。欧几里得算法通过反复带余除法求最大公约数。带余除法是整数因子分解的核心工具。

## 2. 最大公约数的线性组合表示如何证明？它与理想有什么关系？

### 线性组合表示

**定理 12.1.2(b)**：存在 $r, s$ 使得

$$d = \gcd(a, b) = r a + s b.$$

### 证明

考虑由 $a, b$ 生成的理想

$$(a, b) = \mathbb{Z} a + \mathbb{Z} b = \{ r a + s b \mid r, s \in \mathbb{Z} \}.$$

因为 $\mathbb{Z}$ 是主理想整环，存在 $d$ 使得

$$(a, b) = (d).$$

则 $d \in (a, b)$，所以存在 $r, s$ 使得 $d = r a + s b$。

### 与理想的关系

- 理想 $(a, b)$ 由 $a, b$ 的所有线性组合构成。
- $(a, b) = (d)$，其中 $d = \gcd(a, b)$。
- 所以 $d$ 是 $a, b$ 的线性组合。
- 这个事实推广到主理想整环：最大公约数生成理想 $(a, b)$。

### 总结

最大公约数的线性组合表示由理想 $(a, b) = (d)$ 得到。理想的语言使得证明简洁。

## 3. 互素元的性质如何用于证明素数整除乘积？

### 互素元

**定义**：$a, b$ 互素，如果 $\gcd(a, b) = 1$。

**性质**：存在 $r, s$ 使得

$$r a + s b = 1.$$

### 素数整除乘积

**定理 12.1.2(c)**：若素数 $p$ 整除 $a b$，则 $p$ 整除 $a$ 或 $p$ 整除 $b$。

**证明**：
若 $p$ 不整除 $a$，则 $\gcd(a, p) = 1$。存在 $r, s$ 使得

$$r a + s p = 1.$$

乘以 $b$：

$$r a b + s p b = b.$$

因为 $p \mid a b$，所以 $p \mid r a b$。又 $p \mid s p b$。所以 $p \mid b$。

### 总结

互素元有线性组合等于 1。这个性质用于证明素数整除乘积的定理。

## 4. 算术基本定理如何推广到一般整环？什么是唯一分解整环？

### 算术基本定理

**定理 12.1.2(d)**：每个正整数 $a \neq 1$ 可以唯一分解为素数的乘积。

### 推广到一般整环

**唯一分解整环 (UFD)**：整环 $R$，其中每个非零非单位元素可以唯一分解为既约元的乘积（在相伴和顺序意义下）。

**定义 12.2.12**：

- 分解终止：没有无限严格升链 $(a_1) < (a_2) < \cdots$。
- 分解唯一：既约分解在相伴意义下唯一。

**命题 12.2.14**：
(a) 若分解终止，则 $R$ 是 UFD 当且仅当每个既约元是素元。
(b) 主理想整环是 UFD。
(c) $\mathbb{Z}$、$\mathbb{Z}[i]$、$F[x]$ 是 UFD。

### 例子

- $\mathbb{Z}$：UFD。
- $F[x]$：UFD。
- $\mathbb{Z}[i]$：UFD。
- $\mathbb{Z}[\sqrt{-5}]$：不是 UFD。

### 总结

算术基本定理推广为唯一分解整环。UFD 要求分解终止和分解唯一。主理想整环是 UFD。

## 5. 整数环与多项式环有什么相似之处？为什么它们都是欧几里得整环？

### 相似之处

| 性质 | $\mathbb{Z}$ | $F[x]$ |
| --- | --- | --- |
| 元素 | 整数 | 多项式 |
| 带余除法 | $b = aq + r$，$0 \le r < a$ | $g = fq + r$，$\deg r < \deg f$ |
| 理想 | 每个理想是主理想 $(n)$ | 每个理想是主理想 $(f)$ |
| 素元 | 素数 | 不可约多项式 |
| 唯一分解 | 算术基本定理 | 唯一分解为不可约多项式之积 |
| 最大公约数 | 欧几里得算法 | 欧几里得算法 |
| 单位 | $\pm 1$ | 非零常数 |

### 为什么都是欧几里得整环？

**欧几里得整环**：整环 $R$，存在尺度函数 $\sigma: R \setminus \{0\} \to \mathbb{N}$，使得对任意 $a, b \neq 0$，存在 $q, r$ 使

$$b = a q + r, \quad r = 0 \text{ 或 } \sigma(r) < \sigma(a).$$

- $\mathbb{Z}$：$\sigma(n) = |n|$。
- $F[x]$：$\sigma(f) = \deg f$。

带余除法在两个环中都成立，所以它们都是欧几里得整环。

### 总结

整数环与多项式环在带余除法、理想、唯一分解等方面高度相似。它们都是欧几里得整环，因此共享许多数论性质。

## 6. 唯一分解失败的例子是什么？例如，$\mathbb{Z}[\sqrt{-5}]$。

### $\mathbb{Z}[\sqrt{-5}]$

**定义**：

$$\mathbb{Z}[\sqrt{-5}] = \{a + b\sqrt{-5} \mid a, b \in \mathbb{Z}\}.$$

**范数**：

$$N(a + b\sqrt{-5}) = a^2 + 5b^2.$$

### 唯一分解失败

**例子**：

$$6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5}).$$

验证：

- $2$ 和 $3$ 是既约元。
- $1 + \sqrt{-5}$ 和 $1 - \sqrt{-5}$ 是既约元。
- 它们不相伴。
- 所以 $6$ 有两种不同的既约分解。

### 为什么失败？

- $2$ 是既约元，但不是素元。因为 $2 \mid (1+\sqrt{-5})(1-\sqrt{-5})$，但 $2$ 不整除 $1+\sqrt{-5}$ 或 $1-\sqrt{-5}$。
- 所以 $\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环。

### 修正

- 用理想代替元素：理想有唯一分解。
- 理想类群衡量唯一分解失败的程度。
- $\mathbb{Z}[\sqrt{-5}]$ 的类数为 2。

### 总结

$\mathbb{Z}[\sqrt{-5}]$ 是唯一分解失败的经典例子：$6$ 有两种不同的既约分解。失败的原因是既约元不是素元。修正用理想分解。

## 一、基本概念

**定义 12.2.1**：设 $R$ 是整环。

- **单位**：有乘法逆元的元素。
- **整除**：$a \mid b$ 如果 $b = a q$ 对某个 $q \in R$。
- **真因子**：$a$ 是 $b$ 的真因子，如果 $b = a q$ 且 $a, q$ 都不是单位。
- **相伴**：$a$ 和 $b$ 相伴，如果 $b = u a$，$u$ 是单位。
- **既约元**：不是单位且没有真因子。
- **素元**：不是单位，且若 $p \mid a b$，则 $p \mid a$ 或 $p \mid b$。

**主理想语言**：

- $a$ 整除 $b \iff (b) \subset (a)$。
- $a$ 是 $b$ 的真因子 $\iff (b) < (a) < (1)$。
- $a$ 和 $b$ 相伴 $\iff (a) = (b)$。
- $a$ 既约 $\iff (a) < (1)$ 且没有主理想 $(c)$ 使得 $(a) < (c) < (1)$。
- $p$ 素元 $\iff a b \in (p)$ 蕴含 $a \in (p)$ 或 $b \in (p)$。

**例子**：

- $\mathbb{Z}$：单位 $\pm 1$，既约元素数，素元素数。
- $F[x]$：单位非零常数，既约元不可约多项式，素元不可约多项式。
- $\mathbb{Z}[i]$：单位 $\pm 1, \pm i$，既约元高斯素数。

## 二、欧几里得整环

**定义 12.2.4**：整环 $R$ 是**欧几里得整环**，如果存在尺度函数

$$\sigma: R \setminus \{0\} \to \mathbb{N},$$

使得对任意 $a, b \neq 0$，存在 $q, r$ 使

$$b = a q + r, \quad r = 0 \text{ 或 } \sigma(r) < \sigma(a).$$

**例子**：

- $\mathbb{Z}$：$\sigma(n) = |n|$。
- $F[x]$：$\sigma(f) = \deg f$。
- $\mathbb{Z}[i]$：$\sigma(a) = |a|^2$。

**命题 12.2.5**：欧几里得整环是主理想整环。

**证明**：取理想 $I$ 中 $\sigma$ 最小的非零元 $a$，证明 $I = (a)$。

**推论**：欧几里得整环是唯一分解整环。

## 三、主理想整环

**定义**：每个理想都是主理想的整环。

**命题 12.2.8**：主理想整环中最大公约数存在，且可表示为线性组合。

**推论 12.2.9**：
(a) 互素元有线性组合 $1 = r a + s b$。
(b) 既约元是素元。
(c) 极大理想是既约元生成的主理想。

**证明 (b)**：设 $p$ 是既约元。若 $p \mid a b$，考虑理想 $(p, a)$。因为 $R$ 是 PID，$(p, a) = (d)$。$d$ 整除 $p$ 和 $a$。因为 $p$ 既约，$d$ 是单位或与 $p$ 相伴。若 $d$ 与 $p$ 相伴，则 $p \mid a$。若 $d$ 是单位，则 $1 = r p + s a$，乘以 $b$ 得 $b = r p b + s a b$。因为 $p \mid a b$，所以 $p \mid b$。

## 四、唯一分解整环

**定义 12.2.12**：整环 $R$ 是**唯一分解整环**，如果：

- 分解终止：没有无限严格升链 $(a_1) < (a_2) < \cdots$。
- 分解唯一：既约分解在相伴意义下唯一。

**命题 12.2.13**：分解终止等价于没有无限严格升链。

**证明**：

- 若存在无限严格升链 $(a_1) < (a_2) < \cdots$，则 $a_{i+1}$ 是 $a_i$ 的真因子，分解不终止。
- 反之，若分解不终止，则得到无限严格升链。

**命题 12.2.14**：
(a) 若分解终止，则 $R$ 是唯一分解整环当且仅当每个既约元是素元。
(b) 主理想整环是唯一分解整环。
(c) $\mathbb{Z}$、$\mathbb{Z}[i]$、$F[x]$ 是唯一分解整环。

**证明 (b)**：

- 主理想整环中分解终止，因为理想升链终止。
- 主理想整环中既约元是素元（推论 12.2.9(b)）。
- 所以主理想整环是唯一分解整环。

**例子**：

- $\mathbb{Z}$：UFD。
- $F[x]$：UFD。
- $\mathbb{Z}[i]$：UFD。
- $\mathbb{Z}[\sqrt{-5}]$：不是 UFD。

## 五、唯一分解失败的例子

- $2, 3, 1+\sqrt{-5}, 1-\sqrt{-5}$ 都是既约元。

**修正**：用理想代替元素。$\mathbb{Z}[\sqrt{-5}]$ 中理想有唯一分解。

## 1. 单位、相伴、既约元、素元如何用主理想语言描述？这种描述有什么好处？

### 主理想语言

- **单位**：$u$ 是单位 $\iff (u) = (1)$。
- **整除**：$a \mid b \iff (b) \subset (a)$。
- **真因子**：$a$ 是 $b$ 的真因子 $\iff (b) < (a) < (1)$。
- **相伴**：$a$ 和 $b$ 相伴 $\iff (a) = (b)$。
- **既约元**：$a$ 既约 $\iff (a) < (1)$ 且没有主理想 $(c)$ 使得 $(a) < (c) < (1)$。
- **素元**：$p$ 素元 $\iff ab \in (p)$ 蕴含 $a \in (p)$ 或 $b \in (p)$。

### 好处

1. **统一语言**：用理想描述，统一了元素和理想的因子分解。
2. **推广**：理想分解在更一般的环中成立（如戴德金整环）。
3. **几何直观**：理想对应代数簇的子簇。
4. **简化证明**：理想运算比元素运算更灵活。
5. **修正唯一分解失败**：在 $\mathbb{Z}[\sqrt{-5}]$ 中，理想有唯一分解。

### 总结

主理想语言用理想描述单位、整除、相伴、既约元、素元。这种描述统一了因子分解，推广到更一般的环，并修正唯一分解失败。

## 2. 欧几里得整环为什么是主理想整环？带余除法如何用于证明？

### 证明

设 $R$ 是欧几里得整环，尺度函数 $\sigma$。设 $I$ 是 $R$ 的理想。

- 若 $I = (0)$，平凡。
- 否则，取 $I$ 中 $\sigma$ 最小的非零元 $a$。
- 对任意 $b \in I$，做带余除法： $b = a q + r, \quad r = 0 \text{ 或 } \sigma(r) < \sigma(a).$
- 因为 $r = b - a q \in I$，由 $a$ 的最小性，$r = 0$。
- 所以 $b = a q \in (a)$。因此 $I = (a)$。

### 带余除法的作用

带余除法保证可以用 $a$ 除 $b$，余数 $r$ 在 $I$ 中且 $\sigma(r) < \sigma(a)$。由 $a$ 的最小性，$r = 0$。所以 $b$ 是 $a$ 的倍数，即 $I = (a)$。

### 总结

欧几里得整环是主理想整环，因为带余除法保证每个理想由 $\sigma$ 最小的元素生成。

## 3. 主理想整环为什么是唯一分解整环？既约元是素元如何保证唯一性？

### 证明

**第一步：分解终止**

主理想整环中不存在无限严格升链 $(a_1) < (a_2) < \cdots$。因为若存在这样的链，其并是理想 $(a)$，则 $a$ 属于某个 $(a_n)$，链终止。

**第二步：既约元是素元**

在 PID 中，既约元生成极大理想，因此是素元（推论 12.2.9(b)）。

**第三步：唯一性**

由分解终止和既约元是素元，得到唯一分解。证明用归纳法：若 $p_1 \cdots p_m = q_1 \cdots q_n$，则 $p_1$ 是素元，整除某个 $q_i$。因为 $q_i$ 既约，$p_1$ 与 $q_i$ 相伴。消去后归纳。

### 既约元是素元如何保证唯一性？

- 素元整除乘积蕴含整除因子。
- 这使得分解可以逐项匹配。
- 没有素元性质，分解可能不唯一（如 $\mathbb{Z}[\sqrt{-5}]$）。

### 总结

主理想整环是唯一分解整环，因为分解终止且既约元是素元。素元性质保证分解唯一。

## 4. 唯一分解整环与主理想整环有什么关系？逆命题成立吗？

### 关系

**定理**：主理想整环是唯一分解整环。

**逆不成立**：唯一分解整环不一定是主理想整环。

**例子**：$\mathbb{Z}[x]$ 是唯一分解整环，但不是主理想整环。理想 $(2, x)$ 不是主理想。

### 层次结构

$$\text{欧几里得整环} \subset \text{主理想整环} \subset \text{唯一分解整环} \subset \text{整环}.$$

### 总结

主理想整环是唯一分解整环，但逆不成立。$\mathbb{Z}[x]$ 是唯一分解整环但不是主理想整环。

## 5. $\mathbb{Z}[\sqrt{-5}]$ 为什么不是唯一分解整环？如何用理想修正？

### 为什么不是唯一分解整环？

$$6 = 2 \cdot 3 = (1 + \sqrt{-5})(1 - \sqrt{-5}).$$

- $2, 3, 1+\sqrt{-5}, 1-\sqrt{-5}$ 都是既约元。
- 它们不相伴。
- 所以分解不唯一。

**原因**：既约元 $2$ 不是素元。$2 \mid (1+\sqrt{-5})(1-\sqrt{-5})$，但 $2$ 不整除其中任何一个。

### 用理想修正

- 在 $\mathbb{Z}[\sqrt{-5}]$ 中，理想有唯一分解。
- 例如，理想 $(6)$ 分解为素理想的积： $(6) = (2, 1+\sqrt{-5})^2 (3, 1+\sqrt{-5})(3, 1-\sqrt{-5}).$
- 理想类群衡量唯一分解失败的程度。

### 总结

$\mathbb{Z}[\sqrt{-5}]$ 不是唯一分解整环，因为既约元不是素元。用理想分解修正。

- **代数整数**：代数整数环的因子分解。

## 一、本原多项式

**定义 12.3.1**：一个整系数多项式

$$f(x) = a_n x^n + \cdots + a_1 x + a_0$$

称为**本原的**，如果它的系数的最大公约数为 1，且首项系数 $a_n > 0$。

**例子**：

- $2x + 1$ 本原。
- $x^2 + x + 1$ 本原。
- $2x^2 + 4x + 2$ 不是本原（系数最大公约数为 2）。

**引理 12.3.3**：下列条件等价：

- $f$ 本原。
- $f$ 不能被任何素数 $p$ 整除（即存在系数不被 $p$ 整除）。
- 对每个素数 $p$，$\overline{f} \neq 0$ 在 $\mathbb{F}_p[x]$ 中。

**证明**：若 $f$ 本原，则系数最大公约数为 1，所以没有素数整除所有系数。反之亦然。

## 二、高斯引理

**命题 12.3.4（高斯引理）**：

(a) 整数 $p$ 是 $\mathbb{Z}[x]$ 的素元当且仅当 $p$ 是素数。

(b) **本原多项式的积是本原的**。

**证明 (a)**：

- 若 $p$ 是素数，$p \mid f g$ 当且仅当 $\overline{f} \overline{g} = 0$ 在 $\mathbb{F}_p[x]$ 中。
- 因为 $\mathbb{F}_p[x]$ 是整环，$\overline{f} \overline{g} = 0$ 蕴含 $\overline{f} = 0$ 或 $\overline{g} = 0$。
- 所以 $p \mid f$ 或 $p \mid g$。

**证明 (b)**：

- 假设 $f, g$ 本原。对任意素数 $p$，$\overline{f}, \overline{g} \neq 0$。
- 因为 $\mathbb{F}_p[x]$ 是整环，$\overline{f} \overline{g} \neq 0$。
- 所以 $fg$ 不能被任何素数整除，即 $fg$ 本原。

**例子**：

- $(2x+1)(x^2+x+1) = 2x^3 + 3x^2 + 3x + 1$ 本原。
- $(2x+2)(x+1) = 2x^2 + 4x + 2$ 不是本原。

## 三、$\mathbb{Z}[x]$ 的因子分解

**定理 12.3.6**：

(a) 若本原多项式 $f_0$ 在 $\mathbb{Q}[x]$ 中整除 $g \in \mathbb{Z}[x]$，则 $f_0$ 在 $\mathbb{Z}[x]$ 中整除 $g$。

(b) 若两个整多项式 $f, g$ 在 $\mathbb{Q}[x]$ 中有非常数公因子，则它们在 $\mathbb{Z}[x]$ 中有非常数公因子。

**证明 (a)**：

- 设 $g = f_0 q$，其中 $q \in \mathbb{Q}[x]$。
- 写 $g = c g_0$，$q = c' q_0$，其中 $g_0, q_0$ 本原。
- 则 $c g_0 = c' f_0 q_0$。由高斯引理，$f_0 q_0$ 本原。
- 由唯一性，$c = c'$，$g_0 = f_0 q_0$。
- 因为 $g$ 整系数，$c$ 是整数。所以 $q = c q_0$ 整系数。

**证明 (b)**：

- 设 $h$ 是 $f, g$ 在 $\mathbb{Q}[x]$ 中的非常数公因子。
- 写 $h = c h_0$，$h_0$ 本原。
- 由 (a)，$h_0$ 在 $\mathbb{Z}[x]$ 中整除 $f$ 和 $g$。

## 四、$\mathbb{Z}[x]$ 是唯一分解整环

**定理 12.3.8**：$\mathbb{Z}[x]$ 是唯一分解整环。

**证明**：

1. **分解终止**：$\mathbb{Z}[x]$ 中不存在无限严格升链。
2. **既约元是素元**：
  - 素整数是素元（命题 12.3.4(a)）。
  - 本原既约多项式在 $\mathbb{Q}[x]$ 中既约，因此是素元。
3. **唯一性**：由高斯引理，$\mathbb{Z}[x]$ 中的分解与 $\mathbb{Q}[x]$ 中的分解一致。

**每个非零非单位多项式 $f \in \mathbb{Z}[x]$ 可以唯一分解为**

$$f = \pm p_1 \cdots p_m q_1(x) \cdots q_n(x),$$

其中 $p_i$ 是素数，$q_i$ 是本原既约多项式。

**推论**：$\mathbb{Z}[x_1, \dots, x_n]$ 是唯一分解整环。

## 五、例子

**例子 12.3.9**：

$$6x^3 + 9x^2 + 9x + 3 = 3(2x+1)(x^2+x+1).$$

- $3$ 是素数。
- $2x+1$ 本原既约。
- $x^2+x+1$ 本原既约。

**例子**：$\mathbb{Z}[x, y]$ 是唯一分解整环。

$$x^2 - y^2 = (x-y)(x+y).$$

- 本原多项式是系数最大公约数为 1 的多项式。

## 1. 本原多项式的定义为什么要求首项系数为正？这个条件有什么作用？

### 本原多项式的定义

**定义 12.3.1**：整系数多项式

$$f(x) = a_n x^n + \cdots + a_1 x + a_0$$

称为**本原的**，如果系数的最大公约数为 1，且首项系数 $a_n > 0$。

### 为什么要求首项系数为正？

要求 $a_n > 0$ 是为了**消除符号歧义**。因为若 $f$ 本原，则 $-f$ 的系数最大公约数也是 1，但 $-f$ 和 $f$ 只差一个单位 $-1$。在唯一分解中，我们通常希望把符号分离出来，即把分解写成

$$f = \pm p_1 \cdots p_m q_1 \cdots q_n,$$

其中 $q_i$ 是本原多项式且首项系数为正。这样，符号 $\pm$ 单独处理，本原多项式的首项系数为正，保证了唯一性表述的简洁。

### 作用

1. **唯一性**：在唯一分解中，符号单独处理，本原部分首项系数为正，避免重复计数。
2. **标准化**：每个非零多项式可以唯一写成 $c f_0$，其中 $c \in \mathbb{Z}$（或 $\mathbb{Q}$），$f_0$ 本原且首项系数为正。
3. **高斯引理**：本原多项式的积本原，首项系数为正保证积的首项系数也为正。

### 总结

要求首项系数为正，是为了消除符号歧义，使本原多项式的表示唯一。符号单独处理，唯一分解的表述更简洁。

## 2. 高斯引理如何证明？模 $p$ 约化如何工作？

### 高斯引理

**命题 12.3.4(b)**：本原多项式的积是本原的。

### 证明

设 $f, g \in \mathbb{Z}[x]$ 本原。要证 $fg$ 本原。

**方法：模 $p$ 约化**

- 对任意素数 $p$，考虑模 $p$ 约化同态 $\psi_p: \mathbb{Z}[x] \to \mathbb{F}_p[x], \quad \psi_p(f) = \overline{f}.$
- 因为 $f$ 本原，存在系数不被 $p$ 整除，所以 $\overline{f} \neq 0$。
- 同理 $\overline{g} \neq 0$。
- 因为 $\mathbb{F}_p[x]$ 是整环，$\overline{f} \overline{g} \neq 0$。
- 但 $\overline{f} \overline{g} = \overline{f g}$。所以 $\overline{f g} \neq 0$，即 $fg$ 不能被 $p$ 整除。
- 这对所有素数 $p$ 成立，所以 $fg$ 本原。

### 模 $p$ 约化的作用

模 $p$ 约化把整系数多项式映到有限域上的多项式。因为 $\mathbb{F}_p[x]$ 是整环，没有零因子，所以本原性得以保持。

### 总结

高斯引理用模 $p$ 约化证明：若 $f, g$ 本原，则对任意 $p$，$\overline{f}, \overline{g} \neq 0$，所以 $\overline{f g} \neq 0$，即 $fg$ 本原。

## 3. $\mathbb{Z}[x]$ 为什么是唯一分解整环？高斯引理如何用于证明？

### 证明 $\mathbb{Z}[x]$ 是唯一分解整环

**第一步：分解终止**

$\mathbb{Z}[x]$ 中不存在无限严格升链。因为 $\mathbb{Z}$ 是诺特环，$\mathbb{Z}[x]$ 也是诺特环（希尔伯特基定理）。

**第二步：既约元是素元**

- **素整数**：$p$ 是 $\mathbb{Z}[x]$ 的素元（命题 12.3.4(a)）。
- **本原既约多项式**：若 $q \in \mathbb{Z}[x]$ 本原且既约，则 $q$ 在 $\mathbb{Q}[x]$ 中既约。因为 $\mathbb{Q}[x]$ 是 PID，$q$ 是 $\mathbb{Q}[x]$ 的素元。由高斯引理，$q$ 是 $\mathbb{Z}[x]$ 的素元。

**第三步：唯一性**

由分解终止和既约元是素元，得到唯一分解。

### 高斯引理的作用

高斯引理把 $\mathbb{Z}[x]$ 中的因子分解与 $\mathbb{Q}[x]$ 中的因子分解联系起来。它保证本原既约多项式在 $\mathbb{Z}[x]$ 中也是素元。

### 总结

$\mathbb{Z}[x]$ 是唯一分解整环，因为分解终止且既约元是素元。高斯引理保证本原既约多项式的素元性质。

## 4. $\mathbb{Z}[x]$ 与 $\mathbb{Q}[x]$ 的因子分解有什么关系？为什么本原多项式的因子在 $\mathbb{Z}[x]$ 中？

### 总结

$\mathbb{Z}[x]$ 与 $\mathbb{Q}[x]$ 的因子分解一致（本原部分）。本原多项式的因子在 $\mathbb{Z}[x]$ 中，因为高斯引理保证唯一性。

## 一、有理根

**引理 12.4.2**：设

$$f(x) = a_n x^n + \cdots + a_1 x + a_0$$

是整系数多项式。

(a) 若整系数线性多项式 $b_1 x + b_0$ 在 $\mathbb{Z}[x]$ 中整除 $f$，则 $b_1 \mid a_n$，$b_0 \mid a_0$。

(b) 本原线性多项式 $b_1 x + b_0$ 在 $\mathbb{Z}[x]$ 中整除 $f$ 当且仅当有理数 $-b_0/b_1$ 是 $f$ 的根。

(c) 首一整多项式 $f$ 的有理根是整数。

**证明**：
(a) 乘积 $(b_1 x + b_0)(q_{n-1} x^{n-1} + \cdots + q_0)$ 的首项系数是 $b_1 q_{n-1}$，常数项是 $b_0 q_0$。

(b) 由高斯引理，$\mathbb{Z}[x]$ 中的整除等价于 $\mathbb{Q}[x]$ 中的整除。

(c) 若 $\alpha = a/b$ 是根，$\gcd(a, b) = 1$，则 $b x - a$ 整除 $f$。因为 $f$ 首一，$b = 1$。

**例子**：$f(x) = x^3 - 2x^2 - 5x + 6$。可能的有理根：$\pm 1, \pm 2, \pm 3, \pm 6$。测试得 $x = 1$ 是根，所以 $f = (x-1)(x^2 - x - 6) = (x-1)(x-3)(x+2)$。

## 二、模 $p$ 约化

**命题 12.4.3**：设 $f(x) = a_n x^n + \cdots + a_0$ 是整多项式，$p$ 是不整除首项系数 $a_n$ 的素数。若 $f$ 模 $p$ 的剩余 $\overline{f}$ 在 $\mathbb{F}_p[x]$ 中既约，则 $f$ 在 $\mathbb{Q}[x]$ 中既约。

**证明**：
假设 $f = g h$ 在 $\mathbb{Q}[x]$ 中可约。由高斯引理，可假设 $g, h \in \mathbb{Z}[x]$，且次数为正。

模 $p$ 约化：

$$\overline{f} = \overline{g} \overline{h}.$$

因为 $p \nmid a_n$，$\deg \overline{f} = \deg f$。所以 $\deg \overline{g} = \deg g$，$\deg \overline{h} = \deg h$。因此 $\overline{f}$ 可约，矛盾。

**例子**：$f(x) = x^5 - 64x^4 + 127x^3 - 200x + 99$。模 2 约化得 $x^5 + x^3 + 1$，在 $\mathbb{F}_2[x]$ 中既约。所以 $f$ 在 $\mathbb{Q}[x]$ 中既约。

**注意**：存在既约整多项式，对所有素数 $p$ 模 $p$ 可约。例如，$x^4 - 10x^2 + 1$。

## 三、艾森斯坦准则

**命题 12.4.6（艾森斯坦准则）**：设

$$f(x) = a_n x^n + \cdots + a_0$$

是整多项式。若素数 $p$ 满足：

- $p \nmid a_n$。
- $p \mid a_{n-1}, \dots, a_0$。
- $p^2 \nmid a_0$。
则 $f$ 在 $\mathbb{Q}[x]$ 中既约。

**证明**：
假设 $f = g h$ 在 $\mathbb{Q}[x]$ 中可约。由高斯引理，可假设 $g, h \in \mathbb{Z}[x]$。

模 $p$ 约化：

$$\overline{f} = \overline{g} \overline{h}.$$

因为 $p \mid a_{n-1}, \dots, a_0$，$\overline{f} = \overline{a}_n x^n$。

因为 $\mathbb{F}_p[x]$ 是整环，$\overline{g}$ 和 $\overline{h}$ 必须是单项式。所以 $g$ 和 $h$ 的所有非首项系数都被 $p$ 整除。

特别地，$p \mid b_0$ 和 $p \mid c_0$，其中 $b_0, c_0$ 是 $g, h$ 的常数项。所以 $p^2 \mid b_0 c_0 = a_0$，与 $p^2 \nmid a_0$ 矛盾。

**例子**：$x^4 + 25x^2 + 30x + 20$ 不可约（取 $p = 5$）。

## 四、分圆多项式

**定义**：分圆多项式

$$\Phi_p(x) = x^{p-1} + x^{p-2} + \cdots + x + 1 = \frac{x^p - 1}{x - 1}.$$

**定理 12.4.9**：$\Phi_p(x)$ 在 $\mathbb{Q}$ 上既约。

**证明**：

- 令 $x = y + 1$，展开： $\Phi_p(y+1) = \frac{(y+1)^p - 1}{y} = y^{p-1} + \binom{p}{1} y^{p-2} + \cdots + \binom{p}{p-1}.$
- 由艾森斯坦准则，取 $p$，所有非首项系数被 $p$ 整除，常数项 $\binom{p}{p-1} = p$ 不被 $p^2$ 整除。
- 所以 $\Phi_p(y+1)$ 既约，因此 $\Phi_p(x)$ 既约。

**例子**：$\Phi_3(x) = x^2 + x + 1$ 既约。

## 五、系数的估计

**定理 12.4.10（柯西）**：设

$$f(x) = x^n + a_{n-1} x^{n-1} + \cdots + a_0$$

是首一复系数多项式。令 $r$ 是系数绝对值的最大值。则 $f$ 的根的绝对值小于 $r + 1$。

**证明**：

- 若 $|x| \ge r + 1$，则 $|x|^n > r(|x|^{n-1} + \cdots + 1) \ge |a_{n-1} x^{n-1} + \cdots + a_0|.$
- 所以 $f(x) \neq 0$。

**应用**：用于计算机代数中的因子分解算法，估计系数的大小。

## 六、小结

- 有理根：可能的有理根是 $\pm a_0 / b_1$ 的形式。
- 模 $p$ 约化：若 $\overline{f}$ 既约，则 $f$ 既约。
- 艾森斯坦准则：用素数 $p$ 判断既约性。
- 分圆多项式：$\Phi_p(x)$ 既约。
- 系数估计：柯西定理用于估计根的大小。
- 这些方法用于整多项式的因子分解。

## 1. 有理根定理如何用于分解整多项式？它的证明思路是什么？

### 有理根定理

**引理 12.4.2**：设

$$f(x) = a_n x^n + \cdots + a_1 x + a_0$$

是整系数多项式。

(a) 若整系数线性多项式 $b_1 x + b_0$ 在 $\mathbb{Z}[x]$ 中整除 $f$，则 $b_1 \mid a_n$，$b_0 \mid a_0$。

(b) 本原线性多项式 $b_1 x + b_0$ 在 $\mathbb{Z}[x]$ 中整除 $f$ 当且仅当有理数 $-b_0/b_1$ 是 $f$ 的根。

(c) 首一整多项式 $f$ 的有理根是整数。

### 用于分解整多项式

**步骤**：

1. 列出可能的有理根：$\pm p/q$，其中 $p \mid a_0$，$q \mid a_n$。
2. 测试每个候选根，找到根后做带余除法。
3. 重复直到完全分解。

**例子**：$f(x) = x^3 - 2x^2 - 5x + 6$。

- 可能的有理根：$\pm 1, \pm 2, \pm 3, \pm 6$。
- 测试 $x = 1$：$1 - 2 - 5 + 6 = 0$，是根。
- 带余除法：$f = (x-1)(x^2 - x - 6) = (x-1)(x-3)(x+2)$。

### 证明思路

(a) 乘积 $(b_1 x + b_0)(q_{n-1} x^{n-1} + \cdots + q_0)$ 的首项系数是 $b_1 q_{n-1}$，常数项是 $b_0 q_0$。

(b) 由高斯引理，$\mathbb{Z}[x]$ 中的整除等价于 $\mathbb{Q}[x]$ 中的整除。

(c) 若 $\alpha = a/b$ 是根，$\gcd(a, b) = 1$，则 $b x - a$ 整除 $f$。因为 $f$ 首一，$b = 1$。

### 总结

有理根定理用于寻找整多项式的有理根。可能的有理根是 $\pm p/q$，其中 $p \mid a_0$，$q \mid a_n$。找到根后做带余除法。

## 2. 模 $p$ 约化如何判断既约性？为什么要求 $p \nmid a_n$？

### 模 $p$ 约化

**命题 12.4.3**：设 $f(x) = a_n x^n + \cdots + a_0$ 是整多项式，$p$ 是不整除首项系数 $a_n$ 的素数。若 $f$ 模 $p$ 的剩余 $\overline{f}$ 在 $\mathbb{F}_p[x]$ 中既约，则 $f$ 在 $\mathbb{Q}[x]$ 中既约。

### 如何判断既约性？

1. 选择素数 $p$，$p \nmid a_n$。
2. 计算 $\overline{f} \in \mathbb{F}_p[x]$。
3. 若 $\overline{f}$ 在 $\mathbb{F}_p[x]$ 中既约，则 $f$ 在 $\mathbb{Q}[x]$ 中既约。

**例子**：$f(x) = x^5 - 64x^4 + 127x^3 - 200x + 99$。模 2 约化得 $x^5 + x^3 + 1$，在 $\mathbb{F}_2[x]$ 中既约。所以 $f$ 既约。

### 为什么要求 $p \nmid a_n$？

- 若 $p \mid a_n$，则 $\deg \overline{f} < \deg f$。
- 这可能使得 $\overline{f}$ 的既约性与 $f$ 的既约性不一致。
- 例如，$f = 2x + 1$，模 2 约化得 $1$，不可约，但 $f$ 可约。

### 总结

模 $p$ 约化判断既约性：若 $\overline{f}$ 既约，则 $f$ 既约。要求 $p \nmid a_n$ 保证 $\deg \overline{f} = \deg f$。

## 3. 艾森斯坦准则如何工作？它的证明思路是什么？

### 艾森斯坦准则

**命题 12.4.6**：设

$$f(x) = a_n x^n + \cdots + a_0$$

是整多项式。若素数 $p$ 满足：

- $p \nmid a_n$。
- $p \mid a_{n-1}, \dots, a_0$。
- $p^2 \nmid a_0$。
则 $f$ 在 $\mathbb{Q}[x]$ 中既约。

### 证明思路

假设 $f = g h$ 在 $\mathbb{Q}[x]$ 中可约。由高斯引理，可假设 $g, h \in \mathbb{Z}[x]$。

模 $p$ 约化：

$$\overline{f} = \overline{g} \overline{h}.$$

因为 $p \mid a_{n-1}, \dots, a_0$，$\overline{f} = \overline{a}_n x^n$。

因为 $\mathbb{F}_p[x]$ 是整环，$\overline{g}$ 和 $\overline{h}$ 必须是单项式。所以 $g$ 和 $h$ 的所有非首项系数都被 $p$ 整除。

特别地，$p \mid b_0$ 和 $p \mid c_0$，其中 $b_0, c_0$ 是 $g, h$ 的常数项。所以 $p^2 \mid b_0 c_0 = a_0$，与 $p^2 \nmid a_0$ 矛盾。

### 例子

$x^4 + 25x^2 + 30x + 20$：取 $p = 5$，$5 \nmid 1$，$5 \mid 25, 30, 20$，$25 \nmid 20$。所以不可约。

### 总结

艾森斯坦准则用模 $p$ 约化证明不可约性。条件是 $p$ 整除所有非首项系数，但 $p^2$ 不整除常数项。

## 4. 分圆多项式为什么既约？它如何用艾森斯坦准则证明？

### 分圆多项式

**定义**：分圆多项式

$$\Phi_p(x) = x^{p-1} + x^{p-2} + \cdots + x + 1 = \frac{x^p - 1}{x - 1}.$$

### 定理 12.4.9

$\Phi_p(x)$ 在 $\mathbb{Q}$ 上既约。

### 证明

令 $x = y + 1$，展开：

$$\Phi_p(y+1) = \frac{(y+1)^p - 1}{y} = y^{p-1} + \binom{p}{1} y^{p-2} + \cdots + \binom{p}{p-1}.$$

- 所有非首项系数 $\binom{p}{k}$ 被 $p$ 整除（引理 12.4.8）。
- 常数项 $\binom{p}{p-1} = p$ 不被 $p^2$ 整除。
- 由艾森斯坦准则，$\Phi_p(y+1)$ 既约。
- 因为 $x \mapsto y+1$ 是环同构，$\Phi_p(x)$ 既约。

### 例子

$\Phi_3(x) = x^2 + x + 1$ 既约。

### 总结

分圆多项式 $\Phi_p(x)$ 既约，通过替换 $x = y+1$ 后用艾森斯坦准则证明。

## 5. 柯西定理如何估计根的大小？它在因子分解中有什么应用？

### 柯西定理

**定理 12.4.10**：设

$$f(x) = x^n + a_{n-1} x^{n-1} + \cdots + a_0$$

是首一复系数多项式。令 $r$ 是系数绝对值的最大值。则 $f$ 的根的绝对值小于 $r + 1$。

### 证明

- 若 $|x| \ge r + 1$，则 $|x|^n > r(|x|^{n-1} + \cdots + 1) \ge |a_{n-1} x^{n-1} + \cdots + a_0|.$
- 所以 $f(x) \neq 0$。

### 在因子分解中的应用

- 用于计算机代数中的因子分解算法。
- 估计系数的大小，决定何时停止搜索。
- 例如，Berlekamp 算法用模 $p$ 分解和系数估计。

### 总结

柯西定理估计根的大小：根的绝对值小于 $r + 1$。它用于因子分解算法中估计系数范围。

在上一节中，我们研究了整多项式的分解。现在，我们研究一个具体的唯一分解整环：**高斯整数环 $\mathbb{Z}[i]$**。高斯整数是形如 $a+bi$ 的复数，其中 $a,b\in\mathbb{Z}$。$\mathbb{Z}[i]$ 是欧几里得整环，因此是唯一分解整环。它的素元称为**高斯素数**。高斯素数的分类与整素数的平方和表示密切相关。本节将研究高斯整数的范数、高斯素数的分类、平方和定理，以及高斯整数在数论中的应用。

## 一、高斯整数环

**定义 12.5.1**：高斯整数环是

$$\mathbb{Z}[i] = \{a + bi \mid a, b \in \mathbb{Z}\}.$$

这是复数域 $\mathbb{C}$ 的子环。

**范数**：

$$N(a + bi) = a^2 + b^2 = (a+bi)(a-bi).$$

**性质**：

- $N(\alpha \beta) = N(\alpha) N(\beta)$。
- $N(\alpha) = 0$ 当且仅当 $\alpha = 0$。
- $N(\alpha) = 1$ 当且仅当 $\alpha$ 是单位：$\pm 1, \pm i$。

**引理 12.5.1**：

- 作为实数的高斯整数是整数。
- 整数 $d$ 在 $\mathbb{Z}[i]$ 中整除 $a+bi$ 当且仅当 $d$ 在 $\mathbb{Z}$ 中整除 $a$ 和 $b$。

**欧几里得整环**：$\mathbb{Z}[i]$ 是欧几里得整环，尺度函数 $\sigma(\alpha) = N(\alpha)$。因此是唯一分解整环。

## 二、高斯素数的分类

**定义**：高斯素数是 $\mathbb{Z}[i]$ 中的素元。

**定理 12.5.2**：

(a) 设 $\pi$ 是高斯素数，$\pi \bar{\pi}$ 是整素数或整素数的平方。

(b) 整素数 $p$ 要么是高斯素数，要么是两个共轭高斯素数的积：

$$p = \pi \bar{\pi}.$$

(c) 整素数 $p \equiv 3 \pmod 4$ 时是高斯素数。

(d) 整素数 $p = 2$ 或 $p \equiv 1 \pmod 4$ 时是两个共轭高斯素数的积。

**证明思路**：

**(a)** $\pi \bar{\pi} = N(\pi) \in \mathbb{Z}$。在 $\mathbb{Z}$ 中分解 $N(\pi) = p_1 \cdots p_k$。因为 $\mathbb{Z}[i]$ 是唯一分解整环，$\pi$ 与某个 $p_i$ 相伴，所以 $k \le 2$。

**(b)** 设 $p$ 是整素数。若 $p$ 不是高斯素数，则 $p = \pi \pi'$，其中 $\pi, \pi'$ 是高斯素数。取范数得 $p^2 = N(\pi) N(\pi')$。所以 $N(\pi) = N(\pi') = p$，即 $p = \pi \bar{\pi}$。

**(c)** 若 $p \equiv 3 \pmod 4$，则 $-1$ 不是模 $p$ 的平方。若 $p$ 不是高斯素数，则 $p = \pi \bar{\pi}$，取范数得 $p = a^2 + b^2$。但 $p \equiv 3 \pmod 4$ 不能表示为平方和，矛盾。

**(d)** 若 $p \equiv 1 \pmod 4$，则 $-1$ 是模 $p$ 的平方。存在 $x$ 使得 $p \mid x^2 + 1 = (x+i)(x-i)$。因为 $p$ 不整除 $x+i$ 或 $x-i$，所以 $p$ 不是高斯素数。

## 三、平方和定理

**定理 12.5.3（费马平方和定理）**：奇素数 $p$ 可表示为两个平方和当且仅当 $p \equiv 1 \pmod 4$。

**证明**：

- 若 $p = a^2 + b^2$，则 $p = (a+bi)(a-bi)$。
- 反之，若 $p \equiv 1 \pmod 4$，则 $-1$ 是模 $p$ 的平方。设 $x^2 \equiv -1 \pmod p$。则 $p \mid x^2 + 1 = (x+i)(x-i)$。
- 因为 $p$ 不是高斯素数，所以 $p$ 分解为两个共轭高斯素数的积。
- 取范数得到 $p = a^2 + b^2$。

**例子**：

- $5 = 1^2 + 2^2 = (1+2i)(1-2i)$。
- $13 = 2^2 + 3^2 = (2+3i)(2-3i)$。
- $3$ 是高斯素数，不能表示为平方和。

## 四、高斯素数的例子

**分类**：

1. **$p = 2$**： $2 = (1+i)(1-i) = -i(1+i)^2.$ $1+i$ 是高斯素数。
2. **$p \equiv 1 \pmod 4$**： $p = \pi \bar{\pi}.$ 例如，$5 = (2+i)(2-i)$，$13 = (3+2i)(3-2i)$。
3. **$p \equiv 3 \pmod 4$**：
$p$ 是高斯素数。
例如，$3, 7, 11, 19$。

**高斯素数的具体形式**：

- $1+i$。
- $a+bi$ 其中 $a^2+b^2$ 是素数。
- 整素数 $p \equiv 3 \pmod 4$。

## 五、应用

### 1. 平方和

每个正整数可以表示为平方和的充要条件是：在素因子分解中，$p \equiv 3 \pmod 4$ 的素因子的指数为偶数。

### 2. 数论

- 高斯整数用于研究二次剩余、平方和。
- 费马大定理的某些情形用高斯整数证明。

### 3. 代数几何

- 高斯整数环是代数整数环的例子。
- 用于研究椭圆曲线、模形式。

### 4. 密码学

- 高斯整数在密码学中有应用。

## 六、小结

- 高斯整数环 $\mathbb{Z}[i]$ 是欧几里得整环，因此是唯一分解整环。
- 高斯素数的分类：
  - $1+i$（对应 $p=2$）。
  - $a+bi$ 其中 $a^2+b^2$ 是 $p \equiv 1 \pmod 4$ 的素数。
  - 整素数 $p \equiv 3 \pmod 4$。
- 费马平方和定理：$p \equiv 1 \pmod 4$ 可表示为平方和。
- 高斯素数在数论、代数几何、密码学中应用。

## 1. 高斯整数环为什么是欧几里得整环？带余除法如何工作？

### 高斯整数环

$$\mathbb{Z}[i] = \{a + bi \mid a, b \in \mathbb{Z}\}.$$

**范数**：$N(a+bi) = a^2 + b^2 = (a+bi)(a-bi)$。

### 为什么是欧几里得整环？

**尺度函数**：$\sigma(\alpha) = N(\alpha)$，取值非负整数。

**带余除法**：对任意 $\alpha, \beta \in \mathbb{Z}[i]$，$\beta \neq 0$，要找到 $q, r \in \mathbb{Z}[i]$ 使得

$$\alpha = \beta q + r, \quad N(r) < N(\beta).$$

**构造**：考虑复数 $\alpha / \beta$。这是一个复数。选取最近的格点 $q \in \mathbb{Z}[i]$，使得

$$\left| \frac{\alpha}{\beta} - q \right| < 1.$$

令 $r = \alpha - \beta q$。则

$$N(r) = N(\beta) \cdot N\left( \frac{\alpha}{\beta} - q \right) < N(\beta).$$

所以带余除法成立。

**几何解释**：$\mathbb{Z}[i]$ 是复平面上的正方形格。任意复数离某个格点的距离小于 1（实际上小于 $\sqrt{2}/2 < 1$）。所以可以找到 $q$ 使得余数 $r$ 的范数小于 $\beta$ 的范数。

### 总结

$\mathbb{Z}[i]$ 是欧几里得整环，尺度函数为范数。带余除法通过选取最近的格点实现。因此 $\mathbb{Z}[i]$ 是主理想整环，也是唯一分解整环。

## 2. 高斯素数如何分类？为什么 $p \equiv 3 \pmod 4$ 是高斯素数？

### 高斯素数的分类

**定理 12.5.2**：

1. **$p = 2$**： $2 = (1+i)(1-i) = -i(1+i)^2.$ $1+i$ 是高斯素数。
2. **$p \equiv 1 \pmod 4$**： $p = \pi \bar{\pi}.$ 例如，$5 = (2+i)(2-i)$，$13 = (3+2i)(3-2i)$。
3. **$p \equiv 3 \pmod 4$**：
$p$ 是高斯素数。

### 为什么 $p \equiv 3 \pmod 4$ 是高斯素数？

**证明**：假设 $p$ 不是高斯素数。则 $p = \pi \pi'$，其中 $\pi, \pi'$ 是高斯素数。取范数：

$$p^2 = N(\pi) N(\pi').$$

所以 $N(\pi) = N(\pi') = p$。设 $\pi = a + bi$，则

$$p = a^2 + b^2.$$

即 $p$ 是两个平方和。但 $p \equiv 3 \pmod 4$ 不能表示为两个平方和（因为平方模 4 只能是 0 或 1，两个平方和模 4 只能是 0, 1, 2，不能是 3）。矛盾。所以 $p$ 是高斯素数。

### 总结

高斯素数分类：$1+i$（对应 $p=2$），$a+bi$ 其中 $a^2+b^2$ 是 $p \equiv 1 \pmod 4$ 的素数，整素数 $p \equiv 3 \pmod 4$。$p \equiv 3 \pmod 4$ 是高斯素数，因为它不能表示为平方和。

## 3. 费马平方和定理如何证明？高斯素数如何用于证明？

### 费马平方和定理

**定理 12.5.3**：奇素数 $p$ 可表示为两个平方和当且仅当 $p \equiv 1 \pmod 4$。

### 证明

**（⇒）** 若 $p = a^2 + b^2$，则 $p = (a+bi)(a-bi)$。因为 $p$ 是素数，$p \equiv 1 \pmod 4$（因为平方和模 4 只能是 0, 1, 2，奇素数 $p$ 若表示为平方和，必为 $1 \pmod 4$）。

**（⇐）** 若 $p \equiv 1 \pmod 4$，则 $-1$ 是模 $p$ 的平方。存在 $x$ 使得

$$x^2 \equiv -1 \pmod p.$$

则 $p \mid x^2 + 1 = (x+i)(x-i)$。

因为 $p$ 不整除 $x+i$ 或 $x-i$（否则 $p$ 整除 $1$），所以 $p$ 不是高斯素数。因此 $p$ 分解为两个共轭高斯素数的积：

$$p = \pi \bar{\pi}.$$

取范数得 $p = a^2 + b^2$。

### 高斯素数的作用

高斯素数的分类直接给出费马平方和定理：$p \equiv 1 \pmod 4$ 时，$p$ 分解为共轭高斯素数，取范数得到平方和。

### 总结

费马平方和定理用高斯素数证明：$p \equiv 1 \pmod 4$ 时，$p$ 不是高斯素数，分解为共轭高斯素数的积，取范数得到平方和。

### 第一节：整数的因子分解

**练习 1.1**：证明一个不是整数的平方的正整数 $n$ 不是一个有理数的平方。

**解答**：
假设 $n = (a/b)^2$，其中 $\gcd(a,b)=1$。则 $n b^2 = a^2$。因为 $\gcd(a,b)=1$，$b^2 \mid n$。但 $n$ 不是整数平方，矛盾。所以 $n$ 不是有理数平方。

**练习 1.2（部分分式）**：
(a) 将分式 $7/24$ 写成 $a/8 + b/3$ 的形式。
(b) 证明：如果 $n = uv$，其中 $u, v$ 互素，则任意分式 $q = m/n$ 均可写成 $q = a/u + b/v$ 的形式。

**解答**：
(a) $7/24 = a/8 + b/3$。乘以 24：$7 = 3a + 8b$。取 $a = -3, b = 2$：$-9 + 16 = 7$。所以 $7/24 = -3/8 + 2/3$。

(b) 因为 $\gcd(u,v)=1$，存在 $r, s$ 使得 $ru + sv = 1$。则

$$\frac{m}{uv} = \frac{m(ru + sv)}{uv} = \frac{mr}{v} + \frac{ms}{u}.$$

取 $a = ms, b = mr$。

**练习 1.3（中国剩余定理）**：
(a) 设 $n, m$ 为互素的整数，$a, b$ 任意。证明存在整数 $x$ 满足 $x \equiv a \pmod m$，$x \equiv b \pmod n$。
(b) 求所有解。

**解答**：
(a) 因为 $\gcd(m,n)=1$，存在 $r, s$ 使得 $rm + sn = 1$。取 $x = a sn + b rm$。则 $x \equiv a \pmod m$，$x \equiv b \pmod n$。

(b) 所有解为 $x + kmn$，$k \in \mathbb{Z}$。

### 第二节：唯一分解整环

**练习 2.1**：在 $\mathbb{F}_p[x]$ 上分解下列多项式为既约因子之积。

**解答**：用筛法或试除法。

**练习 2.4**：证明 $F[x]$ 中存在无限多个首一既约多项式。

**解答**：类似欧几里得证明素数无限。假设只有有限多个 $p_1, \dots, p_k$。考虑 $p_1 \cdots p_k + 1$。它的既约因子不在列表中，矛盾。

**练习 2.6**：证明 $\mathbb{Z}[i]$ 和 $\mathbb{Z}[\sqrt{-2}]$ 是欧几里得整环。

**解答**：

- $\mathbb{Z}[i]$：范数 $N(a+bi) = a^2 + b^2$。
- $\mathbb{Z}[\sqrt{-2}]$：范数 $N(a+b\sqrt{-2}) = a^2 + 2b^2$。

两者都是欧几里得整环。

### 第三节：高斯引理

**练习 3.1**：令 $\phi$ 表示同态 $\mathbb{Z}[x] \to \mathbb{R}$，定义为 $\phi(x) = 1 + \sqrt{2}$ 或 $\phi(x) = \frac{1}{2} + \sqrt{2}$。求 $\phi$ 的核，判断是否主理想。

**解答**：

- $\phi(x) = 1 + \sqrt{2}$：核是 $(x - (1+\sqrt{2}))$，主理想。
- $\phi(x) = \frac{1}{2} + \sqrt{2}$：核是 $(2x - 1 - 2\sqrt{2})$，不是主理想（因为 $2\sqrt{2}$ 不是整数）。

**练习 3.5**：
(a) $\phi: \mathbb{C}[x, y] \to \mathbb{C}[t]$，$f(x, y) \mapsto f(t^2, t^3)$。证明像是满足 $p'(0) = 0$ 的多项式。
(b) $\phi: \mathbb{C}[x, y] \to \mathbb{C}[t]$，$f(x, y) \mapsto f(t^2 - t, t^3 - t^2)$。证明核是主理想，并求生成元。

**解答**：
(a) 像是 $\mathbb{C}[t^2, t^3]$，即偶次项和三次以上项的多项式。
(b) 核是 $(y^2 - x^3 - x^2)$？计算得生成元为 $y^2 - x^2(x+1)$。

### 第四节：整多项式的分解

**练习 4.1**：
(a) 在 $\mathbb{F}_3[x]$ 中分解 $x^3 - x$ 和 $x^9 - 1$。
(b) 在 $\mathbb{F}_2[x]$ 中分解 $x^{16} - x$。

**解答**：
(a) $x^3 - x = x(x-1)(x+1)$ 在 $\mathbb{F}_3$ 中。$x^9 - 1 = (x-1)(x^2+x+1)(x^6+x^3+1)$ 等。
(b) $x^{16} - x = x(x-1)(x^2+x+1)(x^4+x^3+x^2+x+1)(x^4+x^3+1)(x^4+x+1)$。

**练习 4.10**：在 $\mathbb{Q}[x]$ 上分解下列多项式。

**解答**：
(a) $x^2 + 2351x + 125$：试有理根。
(b) $x^3 + 2x^2 + 3x + 1$：可能的有理根 $\pm 1$，测试得无有理根，既约。
(c) $x^4 + 2x^3 + 2x^2 + 2x + 2$：艾森斯坦 $p=2$，既约。
(d) $x^4 + 2x^3 + 3x^2 + 2x + 1 = (x^2+x+1)^2$。
(e) $x^4 + 2x^3 + x^2 + 2x + 1 = (x^2+1)(x^2+2x+1) = (x^2+1)(x+1)^2$。
(f) $x^4 + 2x^2 + x + 1$：可能的有理根 $\pm 1$，测试得无有理根，既约。
(g) $x^5 + x^6 + x^4 + x^2 + 1$：排序 $x^6 + x^5 + x^4 + x^2 + 1$，可能的有理根 $\pm 1$，测试得无有理根。
(h) $x^6 - 2x^5 - 3x^2 + 9x - 3$：艾森斯坦 $p=3$，既约。
(i) $x^4 + x^2 + 1 = (x^2+x+1)(x^2-x+1)$。
(j) $3x^5 + 6x^4 + 9x^3 + 3x^2 - 1$：艾森斯坦 $p=3$。
(k) $x^5 + x^6 + x^4 + x + 2$：可能的有理根 $\pm 1, \pm 2$。

**练习 4.14**：通过分析轨迹 $x^2 + y^2 = 1$，证明 $x^2 + y^2 - 1$ 在 $\mathbb{C}[x, y]$ 上既约。

**解答**：
若 $f = gh$，则轨迹 $f = 0$ 是 $g = 0$ 和 $h = 0$ 的并。但 $x^2 + y^2 = 1$ 是圆，不可约。

### 第五节：高斯素数

**练习 5.1**：在 $\mathbb{Z}[i]$ 上分解下列各数为素数的积：
(a) $1-3i$
(b) $10$
(c) $6+9i$
(d) $7+i$

**解答**：
(a) $1-3i = (1-i)(2-i)$？计算范数 $N(1-3i) = 10 = 2 \cdot 5$。分解为 $(1-i)(2-i)$。
(b) $10 = 2 \cdot 5 = (1+i)(1-i)(2+i)(2-i)$。
(c) $6+9i = 3(2+3i)$。
(d) $7+i$：范数 $50 = 2 \cdot 5^2$。分解为 $(1+i)(2+i)^2$ 等。

**练习 5.5**：设 $\pi$ 为高斯素数。证明 $\pi$ 与 $\bar{\pi}$ 相伴当且仅当 $\pi$ 和一个整数数相伴或者 $\pi \bar{\pi} = 2$。

**解答**：

- 若 $\pi$ 是整数数 $p \equiv 3 \pmod 4$，则 $\pi = \bar{\pi}$。
- 若 $\pi \bar{\pi} = 2$，则 $\pi = 1+i$，$\bar{\pi} = 1-i = -i(1+i)$，相伴。
- 反之，若 $\pi$ 与 $\bar{\pi}$ 相伴，则 $\pi / \bar{\pi}$ 是单位。分析得上述情形。

**练习 5.6**：令 $R = \mathbb{Z}[\sqrt{-3}]$。证明整数数 $p$ 是 $R$ 中的素元当且仅当多项式 $x^2 + 3$ 在 $\mathbb{F}_p[x]$ 中是不可约的。

**解答**：
类似高斯素数的分析。$p$ 在 $R$ 中分解当且仅当 $-3$ 是模 $p$ 的平方。
