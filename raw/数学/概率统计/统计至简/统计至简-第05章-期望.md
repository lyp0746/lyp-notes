# 第5章 期望 —— 线性性的力量

## 📘 本节概览

期望 $E[X] = \int X\,dP$ 是概率论中最重要的泛函。其核心性质——**线性性**——不依赖独立性，是最强大的工具。

## 📐 1. 期望的定义

离散：$E[X] = \sum x_i p(x_i)$；连续：$E[X] = \int x f(x)\,dx$；一般：$E[X] = \int X\,dP$（Lebesgue积分）

**线性性**：$E[aX+bY] = aE[X]+bE[Y]$——**无论 $X,Y$ 是否独立**

> 🔍 **证明思路**：从简单函数（有限值域）开始，线性性显然。通过单调收敛定理推广到非负可测函数，再推广到一般可积函数。关键：积分的线性性来自测度的可加性。

## 📐 2. 关键不等式

| 不等式 | 条件 | 结论 |
|--------|------|------|
| Markov | $X \geq 0$ | $P(X \geq a) \leq E[X]/a$ |
| Chebyshev | — | $P(|X-\mu| \geq a) \leq \text{Var}(X)/a^2$ |
| Jensen | $g$ 凸 | $g(E[X]) \leq E[g(X)]$ |
| Cauchy-Schwarz | — | $E[|XY|] \leq \sqrt{E[X^2]E[Y^2]}$ |

> 🔍 **Jensen不等式证明思路**：$g$ 凸→$g(x) \geq g(E[X]) + g'(E[X])(x-E[X])$（切线在下方）。取期望：$E[g(X)] \geq g(E[X]) + g'(E[X])\cdot 0 = g(E[X])$。

## 📝 本节要点

1. 期望=Lebesgue积分——线性性是最强大的工具。
2. Jensen不等式：凸函数"期望≥期望的函数"。
3. Markov/Chebyshev给出尾部概率的上界。

### 🤔 问题 1：塔性质

$E[E[X|Y]] = E[X]$：条件期望是"部分平均"，再对条件全平均=全平均。证明：$E[E[X|Y]] = \int E[X|Y=y]\,dP_Y(y) = \int \int x\,dP_{X|Y}(x|y)\,dP_Y(y) = \int x\,dP_X(x) = E[X]$（Fubini定理）。鞅论中：若 $X_n$ 是鞅，则 $E[X_n|\mathcal{F}_m] = X_m$（$m \leq n$）——塔性质保证 $E[X_n] = E[X_m] = E[X_0]$（期望守恒）。

### 🤔 问题 2：特征函数总存在

$|e^{itX}| = 1$（单位圆上），所以 $|E[e^{itX}]| \leq E[|e^{itX}|] = 1$——有界性保证积分收敛。矩母函数 $E[e^{tX}]$ 中 $e^{tX}$ 可能无界（重尾分布时积分发散），但 $e^{itX}$ 总有界。
