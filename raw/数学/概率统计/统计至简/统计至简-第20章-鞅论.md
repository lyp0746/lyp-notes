# 第20章 鞅论 —— 公平博弈的数学

## 📘 本节概览

鞅是"未来期望等于现在"的过程——"没有趋势"的数学表述。鞅论是概率论的"微积分"。

## 📐 1. 鞅的定义

$\{M_n, \mathcal{F}_n\}$ 是鞅 ⟺ (1) $E[|M_n|] < \infty$；(2) $E[M_{n+1}|\mathcal{F}_n] = M_n$

**下鞅**：$E[M_{n+1}|\mathcal{F}_n] \geq M_n$（倾向上升）
**上鞅**：$E[M_{n+1}|\mathcal{F}_n] \leq M_n$（倾向下降）

> 🔍 **例**：$S_n = \sum_{i=1}^n X_i$（$X_i$ 零均值独立）是鞅。$S_n^2 - n\sigma^2$ 是鞅（验证：$E[S_{n+1}^2|\mathcal{F}_n] = E[(S_n+X_{n+1})^2|\mathcal{F}_n] = S_n^2 + \sigma^2$）。$M_n = E[Y|\mathcal{F}_n]$（$Y$ 可积）是鞅（塔性质）。

## 📐 2. Doob停止定理

若 $\tau$ 是停时（$\{\tau \leq n\} \in \mathcal{F}_n$）且满足某些正则条件，则 $E[M_\tau] = E[M_0]$。

> 💡 直觉：**你不能通过"选择何时停止"来战胜公平游戏**。赌博策略（如"输了加倍"的Martingale策略）看起来有效但实际上不——因为停时不满足正则条件（资金有限→被迫停止时亏损巨大）。

## 📐 3. 鞅的分解

**Doob分解**：任何下鞅 $X_n$ 可唯一分解为 $X_n = M_n + A_n$，其中 $M_n$ 是鞅，$A_n$ 是可料递增过程。

> 🔍 **证明思路**：归纳定义 $A_0 = 0$，$A_{n+1} = A_n + E[X_{n+1}-X_n|\mathcal{F}_n]$（可料增量），$M_n = X_n - A_n$。验证 $M$ 是鞅：$E[M_{n+1}|\mathcal{F}_n] = E[X_{n+1}|\mathcal{F}_n] - A_{n+1} = X_n + A_{n+1} - A_n - A_{n+1} = X_n - A_n = M_n$。

## 📝 本节要点

1. 鞅="未来期望=现在"——公平博弈的数学。
2. Doob停止定理：不能通过选择停止时机获得优势。
3. Doob分解：下鞅=鞅+可料增过程——分离"随机"和"系统"成分。

### 🤔 问题 1：可选停止的条件

充分条件之一：$\tau$ 有界（$\tau \leq K$ a.s. 对某常数 $K$）。或：$E[\tau] < \infty$ 且 $|M_{n+1}-M_n| \leq C$（有界增量）。赌博策略失败的原因：虽然 $E[\tau] < \infty$ 通常满足，但 $|M_{n+1}-M_n|$ 无界（亏损可能指数增长）→条件不满足→$E[M_\tau] \neq E[M_0]$（实际上 $E[M_\tau] < E[M_0]$）。

### 🤔 问题 2：鞅与无套利定价

**第一基本定理**：市场无套利 ⟺ 存在等价鞅测度（EMM）$Q$，使得折现价格过程 $S_t/B_t$ 是 $Q$-鞅。衍生品定价：$V_0 = B_0 E_Q[V_T/B_T]$（风险中性期望）。Black-Scholes：$Q$ 下资产收益率 $r$（无风险利率）→几何Brown运动的Girsanov变换。
