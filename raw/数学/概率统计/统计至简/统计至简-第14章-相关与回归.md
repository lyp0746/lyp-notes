# 第14章 相关与回归 —— 线性关系的建模

## 📘 本节概览

相关系数度量线性关联强度；回归模型量化 $Y$ 如何依赖 $X$。

## 📐 1. 相关系数

$\rho_{XY} = \text{Cov}(X,Y)/\sqrt{\text{Var}(X)\text{Var}(Y)} \in [-1,1]$

样本相关：$r = \sum(x_i-\bar{x})(y_i-\bar{y}) / \sqrt{\sum(x_i-\bar{x})^2 \sum(y_i-\bar{y})^2}$

> 🔍 **Cauchy-Schwarz证明 $|\rho| \leq 1$**：$|\text{Cov}(X,Y)| = |E[(X-\mu_X)(Y-\mu_Y)]| \leq \sqrt{E[(X-\mu_X)^2]E[(Y-\mu_Y)^2]} = \sqrt{\text{Var}(X)\text{Var}(Y)}$。等号 ⟺ $Y-\mu_Y = c(X-\mu_X)$ a.s.（完美线性关系）。

## 📐 2. 简单线性回归

模型：$Y = \beta_0 + \beta_1 X + \epsilon$, $\epsilon \sim N(0, \sigma^2)$

**OLS估计**：$\hat{\beta}_1 = S_{XY}/S_{XX}$, $\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1\bar{X}$

> 🔍 **推导（正规方程）**：$Q(\beta) = \sum(Y_i - \beta_0 - \beta_1 X_i)^2$。$\partial Q/\partial\beta_0 = 0$ → $\sum Y_i = n\beta_0 + \beta_1 \sum X_i$。$\partial Q/\partial\beta_1 = 0$ → $\sum X_i Y_i = \beta_0 \sum X_i + \beta_1 \sum X_i^2$。解线性方程组得OLS。

**Gauss-Markov定理**：在BLUE假定下，OLS是最优线性无偏估计（BLUE）。

## 📐 3. 判定系数 $R^2$

$R^2 = 1 - SS_{res}/SS_{tot} = SSR/SST$（总变异中被解释的比例）

> 💡 $R^2=1$：完美拟合；$R^2=0$：$X$ 不提供任何预测力。注意：$R^2$ 高不代表因果关系！

## 📝 本节要点

1. 相关系数度量线性关联——Cauchy-Schwarz保证 $|\rho| \leq 1$。
2. OLS通过最小化残差平方和得到——正规方程求解。
3. $R^2$ 衡量拟合优度——但不等于因果强度。

### 🤔 问题 1：非线性关联检测

**Spearman秩相关**：将数据排序后计算Pearson相关——捕捉单调关系。
**距离相关（dCor）**：$dCor(X,Y)=0$ ⟺ $X,Y$ 独立（不仅是不相关）——能检测任意依赖关系。
**Hilbert-Schmidt独立性准则（HSIC）**：基于核方法的独立性检验——对非线性关系敏感。
**可视化**：散点图+LOESS曲线——最直观的方法。

### 🤔 问题 2：多重共线性的处理

**VIF（方差膨胀因子）**：$\text{VIF}_j = 1/(1-R_j^2)$，$R_j^2$ 是 $X_j$ 对其他 $X$ 回归的 $R^2$。VIF>10表示严重共线性。
**Ridge回归**：$\hat{\beta} = (X^TX+\lambda I)^{-1}X^TY$——加入 $\lambda I$ 使矩阵可逆，牺牲无偏性换取稳定性。
**Lasso回归**：$\min \|Y-X\beta\|^2 + \lambda\|\beta\|_1$——L1惩罚产生稀疏解（自动变量选择）。
