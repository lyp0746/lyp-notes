# 第4章 随机变量 —— 从样本空间到实数

## 📘 本节概览

随机变量 $X: \Omega \to \mathbb{R}$ 将样本空间的抽象结果映射为实数，使得可以用微积分研究概率。

## 📐 1. 随机变量的定义

$X$ 是随机变量 ⟺ $\{\omega : X(\omega) \leq x\} \in \mathcal{F}$ 对所有 $x$（**可测性**）

**CDF**：$F(x) = P(X \leq x)$——单调递增、右连续、$F(-\infty)=0$、$F(+\infty)=1$

**离散**：PMF $p(x_i) = P(X=x_i)$；**连续**：PDF $f(x) = F'(x)$

## 📐 2. 变量变换

若 $Y = g(X)$，则 $F_Y(y) = P(g(X) \leq y) = \int_{\{x: g(x) \leq y\}} f_X(x)\,dx$

$g$ 单调可微时：$f_Y(y) = f_X(g^{-1}(y)) \cdot |(g^{-1})'(y)|$

> 🔍 **推导**：$F_Y(y) = P(X \leq g^{-1}(y)) = F_X(g^{-1}(y))$（$g$ 递增时）。求导：$f_Y(y) = f_X(g^{-1}(y)) \cdot (g^{-1})'(y)$。

## 📝 本节要点

1. 随机变量=可测函数——将概率问题转化为分析问题。
2. CDF完全刻画分布——PMF/PDF是特殊情况。
3. 变量变换的Jacobian因子来自链式法则。

### 🤔 问题 1：联合CDF的相容性

联合CDF $F(x,y)$ 必须满足：(1) 每个变量的边缘CDF $F_X(x) = F(x,+\infty)$ 是合法CDF；(2) **2-增量非负**：$\Delta_{x_1,x_2}\Delta_{y_1,y_2}F \geq 0$（矩形概率非负）。条件(2)不是自动满足的——例：$F(x,y) = \max(0, F_X(x)+F_Y(y)-1)$（Fréchet下界）在某些情况下不满足(2)。

### 🤔 问题 2：特征函数与收敛

特征函数的优势：(1) **卷积变乘积**：$\varphi_{X+Y}(t) = \varphi_X(t)\varphi_Y(t)$（独立时）；(2) **收敛定理**：$X_n \xrightarrow{d} X$ ⟺ $\varphi_{X_n}(t) \to \varphi_X(t)$ 逐点（Lévy连续性定理）；(3) **矩与导数**：$E[X^k] = i^{-k}\varphi^{(k)}(0)$。Fourier分析将概率问题转化为代数问题（乘法代替卷积）——这是中心极限定理证明的关键。
