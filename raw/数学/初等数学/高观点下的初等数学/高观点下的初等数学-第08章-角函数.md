## 第八章 角函数

### §8.1 角函数理论

### 一、克莱因的切入方式：从中学课程讲起

克莱因在这一章开头没有单独写引言，而是直接进入 §8.1 角函数理论。按照他在第七章开头所说，这一章要讨论的是“初等超越函数”中的第二类——三角函数（角函数）。他说：

> 我们所要讨论的最重要的部分是初等超越函数，即对数函数和指数函数，还有三角函数，因为它们在中学教学中起着重要的作用。
>

所以，第八章的主题是**角函数**（三角函数），重点仍然是：

1. 中学里是怎么讲的？
2. 历史发展是怎样的？
3. 函数论的观点是什么？
4. 如何用“高观点”来审视中学的角函数教学？

### 二、中学里的角函数：从几何比例出发

克莱因首先回顾中学里角函数的引入方式。中学里通常是从**直角三角形**出发：

- 在直角三角形中，定义正弦、余弦、正切等为边长之比。
- 例如：$\sin \alpha = \frac{\text{对边}}{\text{斜边}}$，$\cos \alpha = \frac{\text{邻边}}{\text{斜边}}$，$\tan \alpha = \frac{\text{对边}}{\text{邻边}}$。
- 然后推广到任意角，用单位圆定义。
- 再引入弧度制，把角函数看作实数到实数的函数。

克莱因指出，这种讲法是**几何的**、**直观的**，但也是**局部的**、**分割的**。它把角函数与几何图形绑定，但没有揭示角函数与指数函数、对数函数的深刻联系。

### 三、角函数的历史发展

克莱因说，角函数的历史发展与对数函数不同。对数函数是从计算需要出发，而角函数是从**天文观测**和**几何测量**出发。

#### 1. 古希腊：弦表

古希腊天文学家（如喜帕恰斯、托勒密）为了天文计算，制作了**弦表**。弦表给出圆心角所对的弦长。这可以看作是正弦函数的雏形。

托勒密的《天文学大成》中包含了详细的弦表，相当于从 $0^\circ$ 到 $180^\circ$ 每隔 $0.5^\circ$ 的弦长。

#### 2. 印度：半弦

印度数学家（如阿耶波多）引入了**半弦**的概念，即我们现在所说的正弦。他们用半弦代替全弦，使计算更方便。

#### 3. 阿拉伯：正切与余切

阿拉伯数学家引入了**正切**和**余切**的概念，用于日晷和天文观测。

#### 4. 欧洲：三角学独立

欧洲文艺复兴时期，三角学逐渐从天文观测中独立出来，成为一门独立的数学分支。雷格蒙塔努斯、哥白尼等人都有重要贡献。

#### 5. 欧拉：角函数作为函数

克莱因说，到了欧拉，角函数才真正被看作**函数**，而不是几何比例。欧拉建立了：

$$e^{ix} = \cos x + i\sin x,$$

把角函数与指数函数统一起来。这是角函数理论的**转折点**。

### 四、角函数的分析定义

克莱因说，从函数论的观点看，角函数可以用**级数**定义：

$$\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots$$

$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots$$

这两个级数对所有实数（甚至复数）都收敛。用级数定义角函数，可以完全脱离几何直观，使角函数成为**纯分析的函数**。

克莱因指出，这种分析定义与几何定义是**等价**的，但分析定义更深刻，因为它揭示了角函数与指数函数的关系：

$$e^{ix} = \cos x + i\sin x.$$

### 五、角函数与指数函数的关系

克莱因说，角函数与指数函数的关系是数学中最重要的关系之一。欧拉公式：

$$e^{ix} = \cos x + i\sin x$$

把指数函数、三角函数、虚数单位统一起来。由此可以推出：

$$\cos x = \frac{e^{ix} + e^{-ix}}{2}, \quad \sin x = \frac{e^{ix} - e^{-ix}}{2i}.$$

这两个公式把角函数表示为指数函数的组合，使角函数的理论可以完全纳入指数函数的理论。

克莱因说：

> 借此我们认识了初等分析中出现的种种函数之间的关系。
>

**关键点**：欧拉公式是角函数理论的**核心**。它把角函数与指数函数统一起来，使初等超越函数的理论成为一个整体。

### 六、角函数的几何解释

克莱因说，从几何上看，$e^{ix}$ 对应复平面上的单位圆上的点，辐角为 $x$。所以：

- $\cos x$ 是单位圆上点的横坐标。
- $\sin x$ 是单位圆上点的纵坐标。
- $e^{ix}$ 是单位圆上的点。

乘法 $e^{ix} \cdot e^{iy} = e^{i(x+y)}$ 对应旋转的复合：辐角相加。

所以，角函数与**旋转**密切相关。这也是角函数在物理、工程中广泛应用的原因。

### 七、角函数的周期性

克莱因说，角函数是**周期函数**：

$$\sin(x + 2\pi) = \sin x, \quad \cos(x + 2\pi) = \cos x.$$

这个周期性来自 $e^{ix}$ 的周期性：

$$e^{i(x + 2\pi)} = e^{ix}.$$

所以，角函数的周期性与指数函数的周期性密切相关。

### 八、克莱因的批评与建议

克莱因批评中学里的角函数教学：

1. **从几何比例出发**：只讲边长之比，不讲函数关系。
2. **与指数函数分割**：不揭示角函数与指数函数的关系。
3. **缺乏分析定义**：不讲级数定义，不讲复数域中的角函数。
4. **缺乏历史动机**：不讲角函数的历史发展。

克莱因建议：

1. **从函数观点讲角函数**：角函数是函数，不是几何比例。
2. **揭示与指数函数的关系**：用欧拉公式统一角函数与指数函数。
3. **引入分析定义**：用级数定义角函数，使角函数成为纯分析的函数。
4. **讲历史动机**：从天文观测和几何测量出发，讲角函数的历史发展。
5. **用几何直观**：用单位圆和旋转解释角函数的几何意义。

### 九、本节的核心要点总结

1. **中学里的角函数**：从几何比例出发，推广到任意角，用单位圆定义。
2. **历史发展**：古希腊弦表 → 印度半弦 → 阿拉伯正切 → 欧洲三角学 → 欧拉函数。
3. **分析定义**：用级数定义 $\sin x$ 和 $\cos x$。
4. **欧拉公式**：$e^{ix} = \cos x + i\sin x$，把角函数与指数函数统一起来。
5. **几何解释**：$e^{ix}$ 对应单位圆上的点，乘法对应旋转。
6. **周期性**：角函数的周期性来自 $e^{ix}$ 的周期性。
7. **克莱因的批评**：中学角函数教学是几何的、分割的、缺乏动机的。
8. **克莱因的建议**：从函数观点讲角函数，揭示与指数函数的关系，引入分析定义，讲历史动机，用几何直观。

## 问题一：角函数的引入

**核心问题**：中学里从几何比例出发引入角函数。这个讲法是否自然？有没有更好的引入方式？

**展开分析**：

1. **中学里的引入方式**：
  - 从直角三角形出发，定义正弦、余弦、正切为边长之比。
  - 例如：$\sin \alpha = \frac{\text{对边}}{\text{斜边}}$。
  - 然后推广到任意角，用单位圆定义。
  - 再引入弧度制，把角函数看作实数到实数的函数。
2. **这个讲法是否自然？**
  - **部分自然**：
    - 几何比例是直观的，学生容易理解。
    - 直角三角形是学生熟悉的图形。
    - 单位圆定义可以推广到任意角。
  - **部分不自然**：
    - 角函数被绑定在几何图形上，难以脱离几何。
    - 角函数与指数函数的关系被掩盖。
    - 角函数的分析性质（级数、周期性）难以揭示。
    - 学生不知道为什么角函数是“函数”。
3. **有没有更好的引入方式？**
  - **从旋转出发**：角函数描述单位圆上的旋转。用旋转引入角函数，更自然。
  - **从函数出发**：角函数是周期函数，用周期现象（如声波、光波）引入。
  - **从分析出发**：用级数定义 $\sin x$ 和 $\cos x$，使角函数成为纯分析的函数。
  - **从历史出发**：从天文观测和几何测量出发，讲角函数的历史发展。
  - **从欧拉公式出发**：用 $e^{ix} = \cos x + i\sin x$ 统一角函数与指数函数。
4. **克莱因的立场**：
  - 他批评中学角函数教学是“几何的”“分割的”“缺乏动机的”。
  - 他主张从函数观点讲角函数，揭示与指数函数的关系。
  - 他建议用级数定义角函数，使角函数成为纯分析的函数。
5. **教学建议**：
  - 先用几何比例引入角函数，作为直观起点。
  - 再用单位圆和旋转推广到任意角。
  - 再用级数定义角函数，揭示分析性质。
  - 最后用欧拉公式统一角函数与指数函数。
  - 让学生理解：角函数既是几何的，也是分析的，更是统一的。

## 问题二：历史发展

**核心问题**：角函数的历史发展是从天文观测和几何测量出发的。教学是否应该遵循历史发展？如何选择历史中的关键步骤？

**展开分析**：

1. **角函数的历史发展**：
  - **古希腊**：弦表（喜帕恰斯、托勒密），用于天文计算。
  - **印度**：半弦（阿耶波多），即现在的正弦。
  - **阿拉伯**：正切与余切，用于日晷和天文观测。
  - **欧洲**：三角学独立（雷格蒙塔努斯、哥白尼）。
  - **欧拉**：角函数作为函数，建立欧拉公式。
2. **教学是否应该遵循历史发展？**
  - **支持**：
    - 历史发展是自然的、有动机的。
    - 学生认知发展与人类认知历史相应。
    - 历史故事可以激发兴趣。
  - **反对**：
    - 历史太漫长，教学时间有限。
    - 有些历史阶段可以跳过。
    - 历史中的错误和弯路不必重复。
  - **折中**：
    - 教学应**借鉴**历史，但不**重复**历史。
    - 应选择历史中的关键步骤，设计教学序列。
    - 例如：天文观测（动机）→ 弦表（直观）→ 单位圆（统一）→ 欧拉公式（分析）。
3. **如何选择历史中的关键步骤？**
  - **动机**：选择能激发学生兴趣的历史背景（如天文观测）。
  - **直观**：选择有几何直观的历史定义（如弦表、单位圆）。
  - **统一**：选择能统一不同概念的历史进展（如欧拉公式）。
  - **简洁**：选择能简化教学的历史方法（如半弦代替全弦）。
  - **例子**：托勒密的弦表可以作为引入正弦的起点。
4. **克莱因的立场**：
  - 他说：“你们会看到历史情况和上面提到的讲法截然不同。”
  - 他主张教学应大体遵循历史发展。
  - 他认为历史发展是自然的、有动机的，而教材讲法是形式化的。
5. **教学建议**：
  - 引入角函数时，先讲天文观测和几何测量的历史。
  - 用弦表引入正弦，用日晷引入正切。
  - 用单位圆统一角函数的定义。
  - 用欧拉公式统一角函数与指数函数。

## 问题三：分析定义

**核心问题**：用级数定义 $\sin x$ 和 $\cos x$ 是纯分析的。这个定义是否比几何定义更深刻？中学教学是否应该引入分析定义？

**展开分析**：

1. **级数定义**：
  - $\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots$。
  - $\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots$。
  - 这两个级数对所有实数（甚至复数）都收敛。
2. **这个定义是否比几何定义更深刻？**
  - **更深刻**：
    - 它揭示了角函数与指数函数的关系（欧拉公式）。
    - 它使角函数成为纯分析的函数，脱离几何直观。
    - 它可以推广到复数域。
    - 它揭示了角函数的分析性质（周期性、可微性）。
  - **但不如几何定义直观**：
    - 学生难以从级数中理解角函数的几何意义。
    - 级数定义需要先讲收敛性、泰勒级数。
    - 中学课时有限，难以系统讲级数定义。
3. **中学教学是否应该引入分析定义？**
  - **支持**：
    - 分析定义揭示了角函数的本质。
    - 它可以帮助学生理解角函数与指数函数的关系。
    - 它可以为大学数学打基础。
  - **反对**：
    - 分析定义太抽象，超出中学生的认知水平。
    - 中学课时有限，不可能系统讲级数定义。
    - 学生可以在大学阶段学习分析定义。
  - **折中**：
    - 在中学，可以简单介绍级数定义。
    - 不必讲严格证明，只讲基本思想。
    - 对优秀学生，可以介绍欧拉公式的级数推导。
4. **克莱因的立场**：
  - 他说：“从函数论的观点看，角函数可以用级数定义。”
  - 他主张用级数定义角函数，使角函数成为纯分析的函数。
  - 他认为分析定义与几何定义是等价的，但分析定义更深刻。
5. **教学建议**：
  - 在高中，可以简单介绍级数定义。
  - 用级数推导欧拉公式。
  - 对优秀学生，可以介绍复数域中的角函数。
  - 在大学，系统讲角函数的分析定义。

## 问题四：欧拉公式

**核心问题**：欧拉公式 $e^{ix} = \cos x + i\sin x$ 把角函数与指数函数统一起来。这个公式在今天的教学中是否被充分重视？如何引入？

**展开分析**：

1. **欧拉公式的内容**：
  - $e^{ix} = \cos x + i\sin x$。
  - 当 $x = \pi$ 时，$e^{i\pi} + 1 = 0$。
  - 它把指数函数、三角函数、虚数单位统一起来。
2. **在今天的教学中是否被充分重视？**
  - **部分重视**：
    - 许多教材引入欧拉公式，展示其美。
    - 欧拉公式在复数、三角函数、指数函数的教学中被提及。
    - 欧拉公式在物理、工程中有应用。
  - **仍然不足**：
    - 欧拉公式往往被形式地给出，缺乏动机。
    - 学生不知道为什么指数函数和三角函数有关系。
    - 欧拉公式的几何意义往往被忽视。
3. **如何引入？**
  - **从级数出发**：用泰勒级数展开 $e^{ix}$，$\cos x$，$\sin x$。
  - **从几何出发**：用复平面上的单位圆展示 $e^{ix}$。
  - **从微分方程出发**：$e^{ix}$ 满足 $y' = iy$，$\cos x + i\sin x$ 也满足。
  - **从历史出发**：讲欧拉的发现过程。
  - **从应用出发**：讲欧拉公式在电学、信号处理中的应用。
4. **克莱因的立场**：
  - 他说：“1748年，欧拉建立了下述奇妙的关系：$e^{ix} = \cos x + i\sin x$。借此我们认识了初等分析中出现的种种函数之间的关系。”
  - 他认为欧拉公式是角函数理论的核心。
  - 他主张用进程B（几何化、统一化）来讲欧拉公式，而非进程A（形式化、分割化）。
5. **教学建议**：
  - 先用几何解释引入欧拉公式：$e^{ix}$ 对应单位圆上的点。
  - 再用泰勒级数推导欧拉公式。
  - 用欧拉恒等式 $e^{i\pi} + 1 = 0$ 展示数学的美。
  - 介绍欧拉公式在物理、工程中的应用。

## 问题五：几何解释

**核心问题**：$e^{ix}$ 对应单位圆上的点，乘法对应旋转。这个几何解释是否直观？学生能否从中理解角函数的本质？

**展开分析**：

1. **几何解释**：
  - $e^{ix}$ 对应复平面上的单位圆上的点，辐角为 $x$。
  - $\cos x$ 是单位圆上点的横坐标。
  - $\sin x$ 是单位圆上点的纵坐标。
  - 乘法 $e^{ix} \cdot e^{iy} = e^{i(x+y)}$ 对应旋转的复合：辐角相加。
2. **这个几何解释是否直观？**
  - **直观**：
    - 单位圆是学生熟悉的图形。
    - 旋转是学生熟悉的运动。
    - 辐角相加是直观的。
    - 学生可以看到 $\cos x$ 和 $\sin x$ 的几何意义。
  - **但不完全直观**：
    - $e^{ix}$ 本身是抽象的。
    - 学生需要理解复数、指数函数、欧拉公式。
    - 旋转的复合需要一定的抽象能力。
3. **学生能否从中理解角函数的本质？**
  - **优秀学生**：可以理解。他们能看到 $e^{ix}$ 的几何意义。
  - **普通学生**：可能需要更多引导。复数、指数函数、欧拉公式需要复习。
  - 克莱因说：“从几何上看，$e^{ix}$ 对应复平面上的单位圆上的点，辐角为 $x$。”
4. **克莱因的立场**：
  - 他用单位圆和旋转解释角函数的几何意义。
  - 他认为几何解释是理解角函数的重要工具。
  - 他主张用几何解释引入欧拉公式。
5. **教学建议**：
  - 先用单位圆引入 $\cos x$ 和 $\sin x$。
  - 再用旋转引入 $e^{ix}$。
  - 用欧拉公式统一角函数与指数函数。
  - 让学生看到：角函数描述旋转，指数函数描述增长，欧拉公式统一两者。

## 问题六：周期性

**核心问题**：角函数的周期性来自 $e^{ix}$ 的周期性。这个关系在今天的教学中是否被充分揭示？

**展开分析**：

1. **角函数的周期性**：
  - $\sin(x + 2\pi) = \sin x$。
  - $\cos(x + 2\pi) = \cos x$。
  - 周期性来自 $e^{ix}$ 的周期性：$e^{i(x + 2\pi)} = e^{ix}$。
2. **在今天的教学中是否被充分揭示？**
  - **部分揭示**：
    - 许多教材讲角函数的周期性，用单位圆解释。
    - 有些教材用欧拉公式解释周期性。
    - 周期性在物理、工程中有应用。
  - **仍然不足**：
    - 周期性往往被孤立地讲，不与指数函数联系。
    - 学生不知道为什么角函数是周期函数。
    - $e^{ix}$ 的周期性往往被忽视。
3. **如何揭示这个关系？**
  - **从欧拉公式出发**：$e^{i(x + 2\pi)} = e^{ix} \cdot e^{2\pi i} = e^{ix}$。
  - **从单位圆出发**：旋转 $2\pi$ 后回到原点。
  - **从级数出发**：$\sin x$ 和 $\cos x$ 的级数在 $x + 2\pi$ 处相同。
  - **从微分方程出发**：$y'' = -y$ 的解是周期函数。
4. **克莱因的立场**：
  - 他说：“角函数的周期性与指数函数的周期性密切相关。”
  - 他用 $e^{ix}$ 的周期性来解释角函数的周期性。
  - 他认为周期性是角函数的核心性质之一。
5. **教学建议**：
  - 先用单位圆引入角函数的周期性。
  - 再用欧拉公式解释周期性。
  - 用物理应用（如声波、光波）展示周期性的重要性。
  - 让学生理解：角函数的周期性来自 $e^{ix}$ 的周期性。

## 问题七：克莱因的批评

**核心问题**：克莱因批评中学角函数教学是几何的、分割的、缺乏动机的。这个批评在今天是否仍然适用？

**展开分析**：

1. **克莱因的批评**：
  - **几何的**：只讲边长之比，不讲函数关系。
  - **分割的**：不揭示角函数与指数函数的关系。
  - **缺乏动机的**：不讲角函数的历史发展。
2. **这个批评在今天是否仍然适用？**
  - **部分适用**：
    - 许多中学教材仍然从几何比例出发引入角函数。
    - 角函数与指数函数的关系往往被忽视。
    - 角函数的历史发展往往不讲。
  - **部分改进**：
    - 有些教材引入单位圆和旋转，更注重函数观点。
    - 有些教材引入欧拉公式，揭示角函数与指数函数的关系。
    - 有些教材讲角函数的历史和应用。
3. **克莱因的批评的核心**：
  - 不是反对教角函数，而是反对**分割地**、**缺乏动机地**教角函数。
  - 学生不知道为什么角函数是函数，为什么与指数函数有关系。
  - 这种讲法把数学变成“魔术”，学生只能死记硬背。
4. **今天的改进方向**：
  - **从函数出发**：角函数是函数，不是几何比例。
  - **从统一出发**：用欧拉公式统一角函数与指数函数。
  - **从历史出发**：讲角函数的历史发展。
  - **从应用出发**：讲角函数在物理、工程中的应用。
5. **克莱因的立场**：
  - 他说：“中学的数学教学早已受到进程A方法的片面控制。”
  - 他主张“引入直观启发的教学方法，更注重空间观念本身，特别是函数观念”。
  - 他认为教师应了解角函数的高等数学背景。
6. **教学建议**：
  - 从函数观点讲角函数，揭示与指数函数的关系。
  - 引入分析定义，使角函数成为纯分析的函数。
  - 讲历史动机，从天文观测和几何测量出发。
  - 用几何直观，用单位圆和旋转解释角函数的几何意义。

## 问题八：克莱因的建议

**核心问题**：克莱因建议从函数观点讲角函数，揭示与指数函数的关系。这个建议在今天是否可行？如何设计教学？

**展开分析**：

1. **克莱因的建议**：
  - 从函数观点讲角函数：角函数是函数，不是几何比例。
  - 揭示与指数函数的关系：用欧拉公式统一角函数与指数函数。
  - 引入分析定义：用级数定义角函数，使角函数成为纯分析的函数。
  - 讲历史动机：从天文观测和几何测量出发，讲角函数的历史发展。
  - 用几何直观：用单位圆和旋转解释角函数的几何意义。
2. **这个建议在今天是否可行？**
  - **可行**：
    - 现代教材更注重函数观点、几何直观、应用。
    - 欧拉公式在高中选修课中引入。
    - 级数定义在大学课程中引入。
  - **挑战**：
    - 中学课时有限，难以系统讲分析定义。
    - 学生可能不熟悉复数、级数。
    - 高考导向可能限制教学改革。
3. **如何设计教学？**
  - **初中**：用直角三角形引入角函数，用单位圆推广到任意角。
  - **高中**：用旋转引入 $e^{ix}$，用欧拉公式统一角函数与指数函数。
  - **高中选修**：用级数定义角函数，揭示分析性质。
  - **大学**：系统讲角函数的分析定义、复数域、黎曼曲面。
4. **克莱因的立场**：
  - 他主张从函数观点讲角函数，揭示与指数函数的关系。
  - 他认为教师应了解角函数的高等数学背景。
  - 他认为教学应遵循历史发展。
5. **教学建议**：
  - 先用几何比例引入角函数，作为直观起点。
  - 再用单位圆和旋转推广到任意角。
  - 再用欧拉公式统一角函数与指数函数。
  - 最后用级数定义角函数，揭示分析性质。
  - 让学生理解：角函数既是几何的，也是分析的，更是统一的。

## 问题九：角函数与指数函数的统一

**核心问题**：欧拉公式把角函数与指数函数统一起来。这个统一在数学中有什么意义？它如何帮助理解初等超越函数？

**展开分析**：

1. **欧拉公式的统一**：
  - $e^{ix} = \cos x + i\sin x$。
  - $\cos x = \frac{e^{ix} + e^{-ix}}{2}$，$\sin x = \frac{e^{ix} - e^{-ix}}{2i}$。
  - 角函数与指数函数统一为复指数函数。
2. **在数学中的意义**：
  - **统一性**：把初等超越函数统一为复指数函数。
  - **简洁性**：用复指数函数可以简化三角恒等式。
  - **深刻性**：揭示了角函数与指数函数的本质联系。
  - **应用性**：在物理、工程、信号处理中有广泛应用。
3. **如何帮助理解初等超越函数？**
  - **统一框架**：初等超越函数可以用复指数函数统一表示。
  - **微分方程**：$y'' = -y$ 的解是角函数，$y' = y$ 的解是指数函数。
  - **级数展开**：角函数和指数函数的级数展开有相似结构。
  - **复数域**：在复数域中，角函数和指数函数是同一函数的不同表现。
4. **克莱因的立场**：
  - 他说：“借此我们认识了初等分析中出现的种种函数之间的关系。”
  - 他认为欧拉公式是角函数理论的核心。
  - 他主张用欧拉公式统一角函数与指数函数。
5. **教学建议**：
  - 用欧拉公式统一角函数与指数函数。
  - 用复指数函数简化三角恒等式。
  - 介绍欧拉公式在物理、工程中的应用。
  - 让学生理解：初等超越函数是一个统一的整体。

## §8.2 三角函数表

### 一、克莱因的切入方式：从“表”谈起

克莱因在这一节开头说：

> 现在我们来讨论三角函数表。每个中学生都熟悉三角函数表，并且学会在计算中使用它们。但是，恐怕很少有人知道这些表是怎么造出来的。这种“不问究竟的态度”是可鄙的实用主义，它藐视任何一种比较高级的教学原则。
>

这句话与他在第七章中对“对数表”的批评如出一辙。克莱因的核心观点是：**学生不仅要知道怎么用表，更要知道表是怎么造的**。因为制表的过程本身，就是数学分析的核心内容——插值法、级数展开、数值计算。

### 二、三角函数表的制造：三种方法

克莱因说，三角函数表的制造，本质上依赖于三种方法：

1. **几何方法**：利用特殊角（如 $30^\circ, 45^\circ, 60^\circ$）和半角公式、和差公式，逐步构造更精细的角。
2. **分析方法**：利用三角函数的级数展开，计算任意角的函数值。
3. **插值方法**：利用已知角度的函数值，通过插值计算中间角度的函数值。

克莱因说，这三种方法在历史上依次出现，但**最深刻的是分析方法和插值方法**，因为它们揭示了三角函数表的**数学本质**。

### 三、几何方法：从特殊角出发

#### 1. 特殊角的值

克莱因说，最简单的出发点是特殊角：

$$\sin 30^\circ = \frac{1}{2}, \quad \sin 45^\circ = \frac{\sqrt{2}}{2}, \quad \sin 60^\circ = \frac{\sqrt{3}}{2}.$$

这些值可以从等边三角形和正方形中直接得到。

#### 2. 和差公式

利用和差公式：

$$\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta,$$

$$\cos(\alpha \pm \beta) = \cos \alpha \cos \beta \mp \sin \alpha \sin \beta.$$

可以从已知角的值计算新角的值。例如，从 $30^\circ$ 和 $45^\circ$ 可以计算 $75^\circ$ 和 $15^\circ$。

#### 3. 半角公式

利用半角公式：

$$\sin \frac{\alpha}{2} = \sqrt{\frac{1 - \cos \alpha}{2}}, \quad \cos \frac{\alpha}{2} = \sqrt{\frac{1 + \cos \alpha}{2}}.$$

可以从已知角计算半角的值。例如，从 $30^\circ$ 可以计算 $15^\circ$。

#### 4. 几何方法的局限

克莱因指出，几何方法只能计算**特殊角**的值，不能计算任意角的值。要计算任意角的值，必须使用**分析方法**。

### 四、分析方法：级数展开

#### 1. 三角函数的级数

克莱因说，三角函数的级数展开是：

$$\sin x = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots$$

$$\cos x = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots$$

这两个级数对所有实数（甚至复数）都收敛。用级数可以计算任意角的三角函数值。

#### 2. 级数计算的步骤

克莱因给出了用级数计算 $\sin x$ 的步骤：

1. 把 $x$ 化为弧度。
2. 计算 $x, x^3, x^5, \dots$。
3. 计算 $x/1!, x^3/3!, x^5/5!, \dots$。
4. 交替相加减。

例如，计算 $\sin 0.5$：

$$\sin 0.5 = 0.5 - \frac{0.125}{6} + \frac{0.03125}{120} - \dots \approx 0.4794.$$

#### 3. 级数的收敛性

克莱因指出，级数的收敛性依赖于 $x$ 的大小。当 $x$ 较大时，级数收敛较慢，需要计算很多项。所以，实际制表时，通常先用**归约公式**把角化到较小范围（如 $0^\circ$ 到 $45^\circ$），再用级数计算。

#### 4. 归约公式

归约公式包括：

$$\sin(180^\circ - x) = \sin x, \quad \cos(180^\circ - x) = -\cos x,$$

$$\sin(90^\circ - x) = \cos x, \quad \cos(90^\circ - x) = \sin x.$$

用这些公式，可以把任意角化到 $0^\circ$ 到 $45^\circ$ 的范围。

### 五、插值方法：从已知到未知

#### 1. 插值的基本思想

克莱因说，插值法是制表的核心方法。它的基本思想是：已知某些角度的函数值，通过这些值推算中间角度的函数值。

#### 2. 线性插值

最简单的插值是**线性插值**。如果已知 $f(x_0)$ 和 $f(x_1)$，则对 $x_0 < x < x_1$：

$$f(x) \approx f(x_0) + \frac{f(x_1) - f(x_0)}{x_1 - x_0} (x - x_0).$$

线性插值的误差是 $O((x_1 - x_0)^2)$，当区间足够小时，误差可以忽略。

#### 3. 二次插值

更精确的插值是**二次插值**。如果已知 $f(x_0), f(x_1), f(x_2)$，则可以用二次多项式插值：

$$f(x) \approx f(x_0) + \frac{f(x_1) - f(x_0)}{x_1 - x_0} (x - x_0) + \frac{f(x_2) - f(x_1)}{x_2 - x_1} (x - x_1).$$

二次插值的误差是 $O((x_1 - x_0)^3)$。

#### 4. 牛顿插值公式

克莱因特别提到了**牛顿插值公式**：

$$f(x) = f(x_0) + (x - x_0) f[x_0, x_1] + (x - x_0)(x - x_1) f[x_0, x_1, x_2] + \dots,$$

其中 $f[x_0, x_1], f[x_0, x_1, x_2], \dots$ 是**差商**。

牛顿插值公式的优点是：可以逐步增加插值节点，而不必重新计算所有系数。

#### 5. 插值法的应用

克莱因说，插值法不仅用于制表，还用于**数值积分**、**数值微分**、**解微分方程**等。它是数值分析的核心方法。

### 六、三角函数表的精度

克莱因说，三角函数表的精度取决于两个因素：

1. **级数展开的精度**：级数展开的项数越多，精度越高。
2. **插值的精度**：插值节点的间距越小，精度越高。

他举例说，如果用级数计算到 $x^5$ 项，精度可以达到 $10^{-5}$；如果用二次插值，精度可以达到 $10^{-6}$。

克莱因强调，制表的过程是**数学分析**和**数值计算**的结合。它不仅是“计算”，更是“理解”。

### 七、三角函数表在中学教学中的地位

克莱因说：

> 每个中学生都熟悉三角函数表，并且学会在计算中使用它们。但是，恐怕很少有人知道这些表是怎么造出来的。
>

他认为，中学教学应该：

1. **不只是教用表**：还要教表是怎么造的。
2. **不只是教几何方法**：还要教分析方法和插值方法。
3. **不只是教计算**：还要教数学分析的核心思想。

克莱因说：

> 这种“不问究竟的态度”是可鄙的实用主义，它藐视任何一种比较高级的教学原则，对它必须严厉谴责。
>

### 八、克莱因的批评与建议

克莱因批评中学三角函数教学：

1. **只教用表，不教制表**：学生不知道表是怎么造的。
2. **只教几何方法，不教分析方法**：学生不知道级数展开、插值法。
3. **只教计算，不教理解**：学生不知道三角函数表的数学本质。

克莱因建议：

1. **教制表的过程**：从特殊角出发，用和差公式、半角公式、级数展开、插值法。
2. **教分析方法和插值方法**：这些是数值分析的核心。
3. **教数学分析的核心思想**：级数、收敛、插值、误差。
4. **用历史和应用**：讲三角函数表的历史发展，讲它在天文、航海、工程中的应用。

### 九、本节的核心要点总结

1. **三角函数表的制造**：三种方法——几何方法、分析方法、插值方法。
2. **几何方法**：从特殊角出发，用和差公式、半角公式。
3. **分析方法**：用级数展开计算任意角的函数值。
4. **插值方法**：用已知角度的函数值推算中间角度的函数值。
5. **精度**：取决于级数展开的项数和插值的节点间距。
6. **克莱因的批评**：中学只教用表，不教制表；只教几何方法，不教分析方法。
7. **克莱因的建议**：教制表的过程，教分析方法和插值方法，教数学分析的核心思想。

## 问题一：三角函数表的制造

**核心问题**：克莱因说，制表的过程是数学分析和数值计算的结合。在计算器和计算机时代，制表的过程是否还有必要教？如果需要，如何简化？

**展开分析**：

1. **克莱因时代的制表**：
  - 制表是手工计算，需要大量时间和精力。
  - 制表过程涉及和差公式、半角公式、级数展开、插值法。
  - 学生学会用表，但不知道表是怎么造的。
2. **计算器和计算机时代**：
  - 计算器和计算机可以瞬间计算三角函数值。
  - 三角函数表已经不再是必需的工具。
  - 但数值计算的基本原理仍然重要。
3. **制表过程是否还有必要教？**
  - **不必要**：计算器可以替代三角函数表。
  - **但数值计算原理仍有必要**：
    - 学生应了解三角函数表的制造原理（级数展开、插值）。
    - 学生应了解数值计算的误差和精度。
    - 学生应了解计算器和计算机的局限性。
4. **如何简化？**
  - **级数展开**：用 $\sin x = x - x^3/3! + x^5/5! - \dots$ 计算。
  - **插值法**：用已知角度的函数值插值。
  - **计算器**：用计算器验证结果。
  - **编程**：用Python或Excel实现简单的制表程序。
  - **例子**：计算 $\sin 0.5$ 的近似值。
5. **克莱因的立场**：
  - 他说：“这种‘不问究竟的态度’是可鄙的实用主义。”
  - 他认为学生应了解三角函数表的制造原理。
  - 他认为数值计算是数学的重要部分。
6. **教学建议**：
  - 在中学，可以介绍三角函数表的制造原理。
  - 用级数展开计算三角函数的近似值。
  - 用计算器验证结果。
  - 让学生理解：数值计算不是“魔术”，而是有原理的。

## 问题二：几何方法

**核心问题**：从特殊角出发，用和差公式、半角公式。这个方法是否足够？它能否计算任意角的函数值？

**展开分析**：

1. **几何方法的内容**：
  - 特殊角：$30^\circ, 45^\circ, 60^\circ$。
  - 和差公式：$\sin(\alpha \pm \beta) = \sin \alpha \cos \beta \pm \cos \alpha \sin \beta$。
  - 半角公式：$\sin(\alpha/2) = \sqrt{(1 - \cos \alpha)/2}$。
2. **这个方法是否足够？**
  - **部分足够**：
    - 可以计算特殊角及其组合。
    - 可以计算半角、倍角。
    - 可以计算某些代数角（如 $15^\circ, 75^\circ$）。
  - **不够**：
    - 不能计算任意角（如 $1^\circ$）。
    - 需要无限次半角才能逼近任意角。
    - 计算过程复杂，误差累积。
3. **能否计算任意角的函数值？**
  - **不能直接计算**：几何方法只能计算特殊角。
  - **可以逼近**：通过反复使用半角公式，可以逼近任意角，但计算量大。
  - **需要分析方法**：要计算任意角，必须使用级数展开。
4. **克莱因的立场**：
  - 他说：“几何方法只能计算特殊角的值，不能计算任意角的值。”
  - 他认为几何方法是制表的起点，但不是终点。
  - 他主张用分析方法计算任意角。
5. **教学建议**：
  - 先用几何方法引入特殊角的值。
  - 再用和差公式、半角公式计算更多角。
  - 最后用级数展开计算任意角。
  - 让学生理解：几何方法是直观的，但分析方法是普遍的。

## 问题三：分析方法

**核心问题**：用级数展开计算任意角的函数值。级数展开的收敛性如何？如何提高收敛速度？

**展开分析**：

1. **级数展开**：
  - $\sin x = x - x^3/3! + x^5/5! - \dots$。
  - $\cos x = 1 - x^2/2! + x^4/4! - \dots$。
  - 对所有实数（甚至复数）都收敛。
2. **收敛性**：
  - 级数对所有 $x$ 都收敛，但收敛速度取决于 $x$ 的大小。
  - 当 $x$ 较小时，级数收敛很快。
  - 当 $x$ 较大时，级数收敛较慢，需要计算很多项。
  - 例如，计算 $\sin 10$ 需要很多项。
3. **如何提高收敛速度？**
  - **归约公式**：把角化到 $0^\circ$ 到 $45^\circ$ 的范围。
  - **泰勒展开**：用 $\sin x$ 在 $x = 0$ 处的泰勒展开。
  - **切比雪夫逼近**：用切比雪夫多项式逼近三角函数。
  - **帕德逼近**：用有理函数逼近三角函数。
  - **查表**：用已知值插值。
4. **克莱因的立场**：
  - 他说：“级数的收敛性依赖于 $x$ 的大小。”
  - 他建议用归约公式把角化到较小范围。
  - 他认为级数展开是制表的核心方法。
5. **教学建议**：
  - 先用级数展开计算小角的函数值。
  - 再用归约公式把任意角化到小角。
  - 用计算器验证结果。
  - 对优秀学生，可以介绍切比雪夫逼近、帕德逼近。

## 问题四：插值方法

**核心问题**：插值法是制表的核心方法。线性插值、二次插值、牛顿插值公式各有什么优缺点？在今天的数值分析中，插值法有什么应用？

**展开分析**：

1. **线性插值**：
  - $f(x) \approx f(x_0) + \frac{f(x_1) - f(x_0)}{x_1 - x_0} (x - x_0)$。
  - 优点：简单，容易计算。
  - 缺点：误差较大，$O((x_1 - x_0)^2)$。
2. **二次插值**：
  - 用二次多项式插值。
  - 优点：误差较小，$O((x_1 - x_0)^3)$。
  - 缺点：计算较复杂。
3. **牛顿插值公式**：
  - $f(x) = f(x_0) + (x - x_0) f[x_0, x_1] + (x - x_0)(x - x_1) f[x_0, x_1, x_2] + \dots$。
  - 优点：可以逐步增加插值节点，不必重新计算所有系数。
  - 缺点：需要计算差商。
4. **在今天的数值分析中的应用**：
  - **数值积分**：用插值法构造数值积分公式（如梯形法、辛普森法）。
  - **数值微分**：用插值法构造数值微分公式。
  - **解微分方程**：用插值法构造数值解（如龙格-库塔法）。
  - **数据拟合**：用插值法拟合实验数据。
  - **计算机图形学**：用插值法生成平滑曲线。
5. **克莱因的立场**：
  - 他说：“插值法不仅用于制表，还用于数值积分、数值微分、解微分方程。”
  - 他认为插值法是数值分析的核心方法。
  - 他特别提到了牛顿插值公式。
6. **教学建议**：
  - 在中学，可以介绍线性插值和二次插值。
  - 用具体例子展示插值的误差。
  - 对优秀学生，可以介绍牛顿插值公式。
  - 在大学，系统讲插值法及其应用。

## 问题五：归约公式

**核心问题**：归约公式把任意角化到 $0^\circ$ 到 $45^\circ$ 的范围。这个技巧在今天的教学中是否被充分重视？

**展开分析**：

1. **归约公式**：
  - $\sin(180^\circ - x) = \sin x$。
  - $\cos(180^\circ - x) = -\cos x$。
  - $\sin(90^\circ - x) = \cos x$。
  - $\cos(90^\circ - x) = \sin x$。
2. **在今天的教学中是否被充分重视？**
  - **部分重视**：
    - 许多教材讲归约公式，用单位圆解释。
    - 归约公式在解三角形、化简表达式中有应用。
    - 归约公式在计算器内部算法中有应用。
  - **仍然不足**：
    - 归约公式往往被孤立地讲，不与级数展开联系。
    - 学生不知道为什么需要归约公式。
    - 归约公式在数值计算中的作用往往被忽视。
3. **如何充分重视？**
  - **从计算出发**：讲归约公式在制表中的作用。
  - **从单位圆出发**：用单位圆解释归约公式。
  - **从级数出发**：讲归约公式如何提高级数收敛速度。
  - **从应用出发**：讲归约公式在物理、工程中的应用。
4. **克莱因的立场**：
  - 他说：“用这些公式，可以把任意角化到 $0^\circ$ 到 $45^\circ$ 的范围。”
  - 他认为归约公式是制表的核心技巧。
  - 他认为归约公式是理解三角函数的重要工具。
5. **教学建议**：
  - 先用单位圆引入归约公式。
  - 再用归约公式把任意角化到小角。
  - 用级数展开计算小角的函数值。
  - 让学生理解：归约公式是数值计算的重要工具。

## 问题六：精度

**核心问题**：三角函数表的精度取决于级数展开的项数和插值的节点间距。在今天的教学中，如何教学生理解数值计算的误差？

  - **数值实验**：用计算器或计算机做数值实验，观察误差。

3. **克莱因的立场**：
  - 他说：“三角函数表的精度取决于两个因素：级数展开的项数和插值的节点间距。”
  - 他认为制表的过程是数学分析和数值计算的结合。

4. **教学建议**：

## 问题九：数值分析

**展开分析**：

  - **支持**：
    - 数值分析是应用数学的核心。

  - **反对**：

  - **折中**：
    - 在中学，可以简单介绍二分法、牛顿法。

3. **如何简化？**
  - **二分法**：求方程根的简单方法。
  - **牛顿法**：求方程根的快速方法。
  - **梯形法**：数值积分的简单方法。
  - **欧拉法**：解微分方程的简单方法。
  - **例子**：用二分法求 $\sqrt{2}$ 的近似值。
4. **克莱因的立场**：
  - 他说：“插值法不仅用于制表，还用于数值积分、数值微分、解微分方程。”
  - 他认为数值分析是数学的重要部分。
  - 他主张在中学教学中引入数值方法。
5. **教学建议**：
  - 在中学，可以介绍二分法、牛顿法。
  - 用计算器或计算机实现数值方法。
  - 让学生理解：数值方法是解决实际问题的工具。
  - 对优秀学生，可以介绍龙格-库塔法。

## §8.3 角函数的应用

### 一、克莱因的切入方式：从“用”谈起

克莱因在这一节开头说：

> 角函数在数学、物理、工程中有广泛的应用。中学里也讲角函数的应用，但通常只限于解三角形和简单的物理问题。这种讲法是片面的，因为它没有揭示角函数与复数、指数函数的深刻联系，也没有揭示角函数在分析中的核心地位。
>

克莱因的这一节，正是要**揭示角函数的广泛应用**，并**统一角函数与复数、指数函数的关系**。

### 二、角函数在几何中的应用

#### 1. 解三角形

克莱因说，角函数最直接的应用是**解三角形**。中学里通常讲：

- 正弦定理：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$。
- 余弦定理：$c^2 = a^2 + b^2 - 2ab \cos C$。

这两个定理可以解决各种三角形问题（已知三边、两边一角、两角一边等）。

克莱因指出，解三角形是角函数最古老的应用，也是中学里最熟悉的应用。但它只是角函数应用的**起点**，不是**终点**。

#### 2. 测量学

克莱因说，角函数在**测量学**中有重要应用。例如：

- 测量不可到达的物体的高度（如山峰、塔楼）。
- 测量不可到达的两点之间的距离（如河流两岸）。
- 三角测量（用三角形网络测量大面积地形）。

三角测量是地图制作、地理测量、工程测量的基础。克莱因说：

> 三角测量是角函数在测量学中的核心应用，它使我们可以用有限的测量数据推算大范围的地形。
>

#### 3. 解析几何

克莱因说，角函数在**解析几何**中有重要应用。例如：

- 极坐标：用 $r, \theta$ 表示点，$x = r \cos \theta$，$y = r \sin \theta$。
- 参数方程：用 $x = a \cos t$，$y = b \sin t$ 表示椭圆。
- 旋转变换：用 $x' = x \cos \theta - y \sin \theta$，$y' = x \sin \theta + y \cos \theta$ 表示旋转。

克莱因指出，旋转变换是角函数在几何中的核心应用。它与复数乘法（旋转和伸缩）密切相关。

### 三、角函数在物理中的应用

#### 1. 振动与波动

克莱因说，角函数在**振动与波动**中有核心应用。例如：

- 简谐振动：$x(t) = A \cos(\omega t + \phi)$。
- 波动方程：$y(x, t) = A \cos(kx - \omega t)$。
- 声波、光波、电磁波：都可以用角函数描述。

克莱因指出，振动与波动是角函数在物理中的核心应用。它与微分方程 $y'' = -y$ 密切相关。

#### 2. 交流电

克莱因说，角函数在**交流电**中有重要应用。例如：

- 交流电压：$V(t) = V_0 \cos(\omega t + \phi)$。
- 交流电流：$I(t) = I_0 \cos(\omega t + \psi)$。
- 阻抗：$Z = R + iX$，其中 $R$ 是电阻，$X$ 是电抗。

克莱因指出，交流电是角函数在电学中的核心应用。它与复数、指数函数密切相关。

#### 3. 力学

克莱因说，角函数在**力学**中有重要应用。例如：

- 抛体运动：$x = v_0 t \cos \theta$，$y = v_0 t \sin \theta - \frac{1}{2} g t^2$。
- 圆周运动：$x = R \cos \omega t$，$y = R \sin \omega t$。
- 刚体旋转：用角函数描述旋转。

克莱因指出，力学是角函数在物理中的传统应用。它与向量、复数、四元数密切相关。

### 四、角函数在工程中的应用

#### 1. 信号处理

克莱因说，角函数在**信号处理**中有核心应用。例如：

- 傅里叶级数：用角函数表示周期信号。
- 傅里叶变换：用角函数表示非周期信号。
- 滤波器：用角函数设计滤波器。

克莱因指出，傅里叶分析是角函数在工程中的核心应用。它与复数、指数函数密切相关。

#### 2. 通信

克莱因说，角函数在**通信**中有重要应用。例如：

- 调制：用角函数调制载波信号。
- 解调：用角函数解调信号。
- 天线：用角函数描述天线辐射。

克莱因指出，通信是角函数在工程中的重要应用。它与复数、指数函数密切相关。

#### 3. 控制论

克莱因说，角函数在**控制论**中有重要应用。例如：

- 传递函数：用角函数描述系统响应。
- 频率响应：用角函数描述系统对不同频率的响应。
- 稳定性分析：用角函数判断系统稳定性。

克莱因指出，控制论是角函数在工程中的重要应用。它与复数、指数函数密切相关。

### 五、角函数与复数、指数函数的关系

克莱因说，角函数与复数、指数函数的关系是数学中最重要的关系之一。欧拉公式：

$$e^{ix} = \cos x + i\sin x$$

把指数函数、三角函数、虚数单位统一起来。由此可以推出：

$$\cos x = \frac{e^{ix} + e^{-ix}}{2}, \quad \sin x = \frac{e^{ix} - e^{-ix}}{2i}.$$

这两个公式把角函数表示为指数函数的组合，使角函数的理论可以完全纳入指数函数的理论。

克莱因说：

> 借此我们认识了初等分析中出现的种种函数之间的关系。
>

**关键点**：欧拉公式是角函数应用的**核心**。它把角函数与指数函数统一起来，使初等超越函数的理论成为一个整体。

### 六、角函数与微分方程

克莱因说，角函数与**微分方程**密切相关。例如：

- $y'' = -y$ 的解是 $y = A \cos x + B \sin x$。
- $y'' + \omega^2 y = 0$ 的解是 $y = A \cos \omega x + B \sin \omega x$。
- $y'' + ay' + by = 0$ 的解可以用角函数和指数函数表示。

克莱因指出，角函数是微分方程的核心解。它与指数函数一起，构成线性微分方程的基础。

### 七、角函数与傅里叶分析

克莱因说，角函数在**傅里叶分析**中有核心应用。傅里叶级数：

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty} (a_n \cos nx + b_n \sin nx)$$

用角函数表示周期函数。傅里叶变换：

$$F(\omega) = \int_{-\infty}^{\infty} f(t) e^{-i\omega t} dt$$

用复指数函数表示非周期函数。

克莱因指出，傅里叶分析是角函数在分析中的核心应用。它与复数、指数函数密切相关。

### 八、克莱因的批评与建议

克莱因批评中学角函数教学：

1. **只讲解三角形和简单物理问题**：没有揭示角函数的广泛应用。
2. **只讲几何方法**：没有揭示角函数与复数、指数函数的关系。
3. **只讲实数域**：没有揭示角函数在复数域中的性质。

克莱因建议：

1. **揭示角函数的广泛应用**：讲角函数在几何、物理、工程中的应用。
2. **揭示角函数与复数、指数函数的关系**：用欧拉公式统一角函数与指数函数。
3. **引入复数域中的角函数**：讲角函数在复数域中的性质。
4. **引入微分方程和傅里叶分析**：讲角函数在分析中的核心地位。

### 九、本节的核心要点总结

1. **几何应用**：解三角形、测量学、解析几何。
2. **物理应用**：振动与波动、交流电、力学。
3. **工程应用**：信号处理、通信、控制论。
4. **与复数、指数函数的关系**：欧拉公式 $e^{ix} = \cos x + i\sin x$。
5. **与微分方程的关系**：$y'' = -y$ 的解是角函数。
6. **与傅里叶分析的关系**：傅里叶级数、傅里叶变换。
7. **克莱因的批评**：中学角函数教学是片面的、分割的、缺乏应用的。
8. **克莱因的建议**：揭示角函数的广泛应用，揭示与复数、指数函数的关系，引入微分方程和傅里叶分析。

## 问题一：解三角形

**核心问题**：解三角形是角函数最古老的应用。在今天的教学中，解三角形是否被充分重视？它与向量、复数有什么关系？

**展开分析**：

1. **解三角形的内容**：
  - **正弦定理**：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$。
  - **余弦定理**：$c^2 = a^2 + b^2 - 2ab \cos C$。
  - **应用**：已知三边、两边一角、两角一边，解出其余边和角。
2. **在今天的教学中是否被充分重视？**
  - **部分重视**：
    - 解三角形是中学数学的核心内容。
    - 正弦定理、余弦定理是必考内容。
    - 解三角形在实际问题中有应用（如测量）。
  - **仍然不足**：
    - 解三角形往往被孤立地讲，不与向量、复数联系。
    - 学生不知道为什么正弦定理、余弦定理成立。
    - 解三角形的应用往往被简化为“题型训练”。
3. **与向量的关系**：
  - **向量点积**：$\mathbf{a} \cdot \mathbf{b} = |\mathbf{a}| |\mathbf{b}| \cos \theta$。
  - **余弦定理**：$c^2 = |\mathbf{a} - \mathbf{b}|^2 = |\mathbf{a}|^2 + |\mathbf{b}|^2 - 2 \mathbf{a} \cdot \mathbf{b}$。
  - **向量叉积**：$|\mathbf{a} \times \mathbf{b}| = |\mathbf{a}| |\mathbf{b}| \sin \theta$。
  - **正弦定理**：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$ 可以用叉积证明。
  - 所以，解三角形可以用向量统一处理。
4. **与复数的关系**：
  - **复数表示**：用复数表示三角形的顶点 $z_1, z_2, z_3$。
  - **边长**：$|z_1 - z_2|$，$|z_2 - z_3|$，$|z_3 - z_1|$。
  - **角度**：$\arg \frac{z_2 - z_1}{z_3 - z_1}$。
  - **正弦定理、余弦定理**：可以用复数证明。
  - 所以，解三角形可以用复数统一处理。
5. **克莱因的立场**：
  - 他说：“解三角形是角函数最古老的应用，也是中学里最熟悉的应用。但它只是角函数应用的起点，不是终点。”
  - 他主张用向量、复数统一处理解三角形。
  - 他认为解三角形应与向量、复数、指数函数联系。
6. **教学建议**：
  - 先用几何方法引入正弦定理、余弦定理。
  - 再用向量证明正弦定理、余弦定理。
  - 再用复数统一处理解三角形。
  - 让学生理解：解三角形是角函数应用的起点，不是终点。

## 问题二：测量学

**核心问题**：角函数在测量学中有重要应用。在今天的教学中，测量学是否被充分重视？它与三角测量、GPS有什么关系？

**展开分析**：

1. **测量学中的应用**：
  - **测量不可到达的物体的高度**：用角函数计算山峰、塔楼的高度。
  - **测量不可到达的两点之间的距离**：用角函数计算河流两岸的距离。
  - **三角测量**：用三角形网络测量大面积地形。
2. **在今天的教学中是否被充分重视？**
  - **部分重视**：
    - 中学数学中有测量问题（如测量旗杆高度）。
    - 中学物理中有测量问题（如测量山高）。
    - 测量学在实际问题中有应用。
  - **仍然不足**：
    - 测量学往往被简化为“应用题”。
    - 学生不知道为什么三角测量有效。

  - **仍需努力**：分析各分支的整合、几何直观的应用、函数观念的强调。
4. **如何平衡进程A和进程B？**
  - **进程A**：保持逻辑严密性，为后续学习打基础。
  - **进程B**：强调几何直观、函数观念、数学统一性。
  - **结合**：先用进程B引入，再用进程A整理，再回到进程B深化。
  - **例如**：角函数应用先用进程B引入（几何、物理），再用进程A整理（微分方程、傅里叶分析），再用进程B深化（复数、指数函数）。
5. **克莱因的立场**：
  - 他说：“中学的数学教学早已受到进程A方法的片面控制。因此，数学教学改革每走一步，都必须更多强调进程B方法。”
  - 他主张“引入直观启发的教学方法，更注重空间观念本身，特别是函数观念，使空间观念和数的观念融合起来”。
6. **教学建议**：
  - 在分析教学中，应更多强调几何直观、函数图像、数学统一性。
  - 角函数应用的教学应引入几何、物理、工程应用。
  - 分析各分支应整合，而非分割。
  - 教师应了解进程A和进程B的区别，以便在教学中灵活切换。
