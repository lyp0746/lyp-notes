# 第3章 矩阵乘法 —— 四视角与秩1分解

## 📘 本节概览

矩阵乘法 $AB$ 有**四种等价视角**，每种揭示不同结构。最深刻的是外积和视角——它将矩阵乘法分解为秩1矩阵的求和。

## 📐 1. 四个视角

1. **行×列**（定义）：$(AB)_{ij} = \vec{a}_{i\cdot} \cdot \vec{b}_{\cdot j} = \sum_k a_{ik}b_{kj}$
2. **列组合**：$AB$ 的第 $j$ 列 = $A(\vec{b}_{\cdot j})$——$A$ 乘 $B$ 的第 $j$ 列
3. **行组合**：$AB$ 的第 $i$ 行 = $(\vec{a}_{i\cdot})B$——$A$ 的第 $i$ 行乘 $B$
4. **外积和**：$AB = \sum_{k=1}^{p} \vec{a}_{\cdot k}\vec{b}_{k\cdot}$（列向量×行向量=秩1矩阵）

> 💡 外积和视角最深刻——$A$ 的第 $k$ 列 $\vec{a}_{\cdot k}$ 是 $m\times1$，$B$ 的第 $k$ 行 $\vec{b}_{k\cdot}$ 是 $1\times n$，外积 $\vec{a}_{\cdot k}\vec{b}_{k\cdot}$ 是 $m\times n$ 的**秩1矩阵**。矩阵乘法=若干秩1矩阵的叠加。

## 📐 2. 秩与秩1分解

$$\text{rank}(A) = \min\{r : A = \sum_{i=1}^r \vec{u}_i\vec{v}_i^T\}$$

秩=最少需要的秩1矩阵个数。SVD给出最优秩1分解：$A = \sum_{i=1}^r \sigma_i \vec{u}_i\vec{v}_i^T$。

## 📝 本节要点

1. 矩阵乘法四视角：行×列、列组合、行组合、外积和。
2. 外积和→秩1分解→秩的定义→SVD的理论基础。

### 🤔 问题 1：结合律的四视角理解

行×列视角：$(AB)C$ 的 $(i,j)$ 元 = $\sum_k(\sum_l a_{il}b_{lk})c_{kj}$，$A(BC)$ 的 = $\sum_l a_{il}(\sum_k b_{lk}c_{kj})$，两者相等（加法交换律）。

外积和视角：$(AB)C = (\sum_k \vec{a}_{\cdot k}\vec{b}_{k\cdot})C = \sum_k \vec{a}_{\cdot k}(\vec{b}_{k\cdot} C)$，$A(BC) = A(\sum_k \vec{b}_{\cdot k}\vec{c}_{k\cdot}) = \sum_k (A\vec{b}_{\cdot k})\vec{c}_{k\cdot}$。结合律=两种"分组"方式得到相同结果——分配律保证。

### 🤔 问题 2：Kronecker积

$A\otimes B = [a_{ij}B]$（$A$ 的每个元素替换为 $a_{ij}B$）。性质：$(A\otimes B)(C\otimes D) = (AC)\otimes(BD)$——Kronecker积将矩阵乘法"分离"为两个独立部分。

量子计算中，复合系统=张量积（Kronecker积），而非直积。原因：量子态的纠缠无法用普通乘法描述——$|\psi\rangle \otimes |\phi\rangle$ 可以表示纠缠态，而 $|\psi\rangle \cdot |\phi\rangle$ 只能表示可分离态。
