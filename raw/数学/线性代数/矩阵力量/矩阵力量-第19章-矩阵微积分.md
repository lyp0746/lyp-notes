# 第19章 矩阵微积分 —— 导数与梯度

## 📘 本节概览

矩阵微积分是优化和机器学习的语言——损失函数对参数的梯度是矩阵/向量值函数的导数。

## 📐 1. 核心公式

| 函数 $f$ | 梯度 $\nabla f$ |
|----------|-----------------|
| $\vec{a}^T\vec{x}$ | $\vec{a}$ |
| $\vec{x}^T\vec{x}$ | $2\vec{x}$ |
| $\vec{x}^TA\vec{x}$（$A$ 对称） | $2A\vec{x}$ |
| $\|A\vec{x}-\vec{b}\|^2$ | $2A^T(A\vec{x}-\vec{b})$ |

> 🔍 **推导**（$\nabla \vec{x}^TA\vec{x} = 2A\vec{x}$）：$\vec{x}^TA\vec{x} = \sum_{i,j} a_{ij}x_ix_j$。$\frac{\partial}{\partial x_k} = \sum_j a_{kj}x_j + \sum_i a_{ik}x_i = (A\vec{x})_k + (A^T\vec{x})_k$。$A$ 对称→$A=A^T$→$=2(A\vec{x})_k$。

## 📐 2. 矩阵求导的链式法则

$\frac{\partial f(A\vec{x})}{\partial \vec{x}} = A^T \nabla f(A\vec{x})$

> 💡 注意转置！$A$ 在前向传播中，$A^T$ 在反向传播中——这就是神经网络"反向传播"的数学本质。

## 📝 本节要点

1. 核心梯度公式：$\nabla\|A\vec{x}-\vec{b}\|^2 = 2A^T(A\vec{x}-\vec{b})$。
2. 链式法则中转置=反向传播。

### 🤔 问题 1：矩阵的矩阵导数

$\frac{\partial A}{\partial A}$ 是4阶张量：$(\frac{\partial A}{\partial A})_{ijkl} = \delta_{ik}\delta_{jl}$。避免张量的方法：(1) **向量化**：$\text{vec}(AXB) = (B^T \otimes A)\text{vec}(X)$→$\frac{\partial AXB}{\partial X} = B^T \otimes A$（Kronecker积）；(2) **微分法**：$d(AXB) = A(dX)B$→直接记录微分，不求显式导数。

### 🤔 问题 2：迹的导数

$\frac{\partial}{\partial X}\text{tr}(AX) = A^T$：$\text{tr}(AX) = \sum_{i,j} a_{ij}x_{ji}$→$\frac{\partial}{\partial x_{kl}} = a_{lk}$→矩阵 $A^T$。

$\frac{\partial}{\partial X}\text{tr}(X^TAX) = (A+A^T)X$：$d\text{tr}(X^TAX) = \text{tr}(dX^TAX + X^TAdX) = \text{tr}(X^TA^TdX) + \text{tr}(X^TAdX) = \text{tr}((A+A^T)XdX^T)$→梯度=$(A+A^T)X$。$A$ 对称时=$2AX$。
