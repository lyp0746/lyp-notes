# 第6章 向量空间、线性组合与基底

## 第一轮：核心概念

### 6.1 向量空间的定义

$\mathbb{R}^n$ 是向量空间，满足八条公理（加法交换律、结合律、零向量存在、负向量存在、标量乘法分配律等）。

### 6.2 线性组合

$$\mathbf{v} = c_1\mathbf{v}_1 + c_2\mathbf{v}_2 + \cdots + c_k\mathbf{v}_k$$

$\text{span}(\mathbf{v}_1,\dots,\mathbf{v}_k)$ 是所有线性组合的集合。

### 6.3 线性相关与线性无关

$\mathbf{v}_1,\dots,\mathbf{v}_k$ 线性相关 $\iff$ 存在不全为零的 $c_1,\dots,c_k$ 使 $\sum c_i\mathbf{v}_i = \mathbf{0}$。

### 6.4 秩

$\operatorname{rank}(A) = A$ 的列向量中极大线性无关组的向量个数 = 列空间的维数。

**四个典型案例**（$\mathbb{R}^3$ 中）：

| 矩阵 | 构造 | 秩 | 原因 |
|------|------|-----|------|
| $A=[\mathbf{e}_1\;\mathbf{e}_2\;\mathbf{e}_3]$ | 标准基 | 3 | 线性无关 |
| $B=[\mathbf{e}_1\;\mathbf{e}_2\;\mathbf{e}_1+\mathbf{e}_2]$ | 第三列=前两列之和 | 2 | 线性相关 |
| $C=[\mathbf{e}_1\;\mathbf{e}_2]$ | 仅两列 | 2 | 两列无关 |
| $D=[\mathbf{e}_1\;-\mathbf{e}_1\;\frac{1}{2}\mathbf{e}_1]$ | 三列共线 | 1 | 所有列共线 |

### 6.5 基底

$\{\mathbf{v}_1,\dots,\mathbf{v}_n\}$ 是 $\mathbb{R}^n$ 的基底 $\iff$ 它们线性无关且生成 $\mathbb{R}^n$。

基底中向量个数 = 空间维数 $n$。

## 第二轮：推导与直觉

### 推导1：秩的性质证明

**$\operatorname{rank}(A) = \operatorname{rank}(A^T)$**：

行秩 = 列秩。证明思路：对 $A$ 做行化简为行阶梯形，非零行数 = 行秩 = 主元数 = 列秩。

### 推导2：秩-零化度定理

$$\operatorname{rank}(A) + \operatorname{nullity}(A) = n$$

其中 $\operatorname{nullity}(A) = \dim(\ker(A))$ 是零空间维数，$A \in \mathbb{R}^{m \times n}$。

### 推导3：线性相关的几何直觉

- $\mathbb{R}^2$ 中两个向量线性相关 $\iff$ 共线
- $\mathbb{R}^3$ 中三个向量线性相关 $\iff$ 共面
- 秩 = 张成空间的"有效维度"
