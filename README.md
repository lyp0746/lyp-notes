# 数学读书笔记库

一个用 [Obsidian](https://obsidian.md) 组织的数学读书笔记库。**只放数学**：线性代数、微积分、微分拓扑等。

## 三层结构

```
raw/     原始素材（source of truth，只增不改，正文按章拆分）
wiki/    结构化知识（中文命名的概念 / 实体 / 主题页）
output/  派生报告（章节地图、速查表、学习路线、复习卡）
```

约定：**wiki 文件名与索引一律中文**，Obsidian 图谱显示中文。

## 关于来源

- raw 层是**个人精读**的记录（DeepSeek 对话导出后去重、去思考过程、去统计脚注），是内容的事实来源。
- wiki 与 output 由 raw 编译而成，是**索引与提炼**，不是原文替代。
- 涉及的教材版权归原作者与出版社；本库仅供个人学习，请勿公开分发 raw 正文。
